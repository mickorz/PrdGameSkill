# 开局

**什么时候出现**：服务端通知本小局开始。
**谁会看到**：所有人都能看到；重连和回放时这条消息只用来补数据。

## 一、数据上记录了什么（界面变化的基础）

- 标记“游戏已开始”。这个标记会影响头像准备状态的显示，也影响后续重连判断。
- 记录牌墙总张数，并初始化记牌器。“首出提示”的判断依赖它。
- 记录本局最大倍数；匹配场记录底分。
- 记录托管、预托管的等待时间。
- 不是第一局时，记下“发牌阶段自动确认”标记。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 主界面操作区 | 收起吃、碰、杠、胡按钮（回到空状态）；隐藏匹配倒计时；隐藏“换桌”按钮 |
| 玩家头像区 | 清除四家的加倍标记、庄家标记、头像发光框；清掉此前未执行的定时任务 |
| 背景 | 切换到“游戏中”状态：隐藏空闲图标，牌桌美术字切到当前玩法；匹配场刷新底分文字 |
| 开局动画区 | 本局是第一局或非包厢时播放：播放开局音效；出现开局动画，四个头像显示头像、昵称、分数；动画中按节奏淡出并放行服务端，随后局内头像淡入；动画结束隐藏开局动画 |
| 提示动画层 | 重置萧山玩法“先骰子、后升庄”的排队状态 |

## 三、连带影响

- 如果上一局摸到两张及以上财神且没有胡，本局开局会尝试把右下角的“好运来 / 请神”图标切换成对应曝光图标；也可能弹出魅力道具使用引导。
- 开局动画结束时会向服务端确认一次，推进后续流程；如果动画被跳过，四个头像会直接显示。

## 四、重连 / 回放

只记录数据：不播开局动画、不刷新操作区与头像标记、不触发好运来图标。

## 五、注意

- “开局动画是否播放”同时受“是否包厢”和“第几局”控制。改动这个条件会同时影响动画表现和流程放行时机。
