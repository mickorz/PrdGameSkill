# 局数据（庄家与方位）

**什么时候出现**：每一小局开始时，服务端下发本局庄家、连庄档位、门风。
**谁会看到**：所有人。

## 一、数据上记录了什么

- 记录庄家座位，以及服务端座位与本地座位的对应关系。
- 记录连庄数（牢庄档位）。这个值同时用于庄家标记和结算界面。
- 根据门风找到“东风”所在座位，用于摆正牌桌方位。找不到东风时，直接按庄家座位摆正，避免方位盘空掉。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 玩家头像的庄家标记 | 普通玩法：先清掉四家的庄家标记，再在庄家头像上显示“庄”以及连庄档位（1~3）。萧山好友房改用可变数字的庄家标记组件，支持升庄时数字变化 |
| 匹配场头像的庄家标记 | 显示庄 / 庄2 / 庄3；超过 3 档按 3 档显示；其他座位隐藏 |
| 牌桌中央方位盘 | 底图按“人数 + 东风座位”换成对应的方位盘；四角的风向灯也换成对应东风方向的贴图。人数或座位异常时跳过本次刷新，只打印告警，不会崩溃 |

## 三、连带影响

- 连庄档位会被“升庄广播”“胡牌结算”“重连开局”再次读取或覆盖。调整庄家标记的档位含义时，要一起检查结算界面的显示。
- 方位盘底图与风向灯依赖美术资源中的多套方位图（2 人 / 3 人 / 4 人各一套）。

## 四、重连 / 回放

只记录数据，不刷新庄家标记与方位盘；重连后由后续的“权限”“恢复牌墙/手牌”等步骤把界面补齐。
