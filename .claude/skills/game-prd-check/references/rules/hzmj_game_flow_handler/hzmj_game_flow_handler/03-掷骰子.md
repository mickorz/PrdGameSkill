# 掷骰子

**什么时候出现**：开局掷骰子，决定从牌墙哪个位置开始发牌。
**谁会看到**：所有人。

## 一、数据上记录了什么

- 记录两枚骰子的点数。断线重连、回放时用这份数据静态还原骰子。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 牌桌中央的两枚骰子 | 两枚骰子出现，按点数换图并播放滚动动画；播放结束后自动隐藏；若动画异常，5 秒后强制隐藏兜底 |
| 匹配场头像区 | 清除桌面上所有“加倍”标记（新一局不保留上一局的加倍显示） |
| 牌桌中央的倒计时区域 | 骰子播放期间临时屏蔽倒计时数字与方位灯闪烁，业务计时仍在继续；骰子结束后恢复 |
| 萧山好友房的升庄排队 | 记录本局开局动画的序号。骰子播完后，如果有排队中的“升庄”，会接着播放升庄动画，保证“先骰子、后升庄” |

## 三、连带影响

- 重连时使用“跳过动画”的方式：只显示骰子结果，不播放滚动，也不会自动隐藏。

## 四、重连 / 回放

- 重连：仍然显示骰子点数，但不动画。
- 纯补数据（只记录不显示）：完全不出现骰子。

## 五、注意

“跳过动画”和“只补数据”是两种不同的处理：前者重连时仍能看到骰子面，后者什么都看不到。
