# 洗牌（包厢洗牌 / 预约洗牌）

**什么时候出现**：包厢里有人使用洗牌或预约洗牌时，服务端下发“谁洗了牌”。

## 一、数据上记录了什么

- 把对应座位的“预约洗牌”状态清掉。头像上的预约洗牌角标随之消失。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 洗牌动画位 | 对应座位的洗牌动画出现并播放：自己洗牌播第一套动作，别人洗牌播第二套动作；同时播放洗牌音效 |
| 自己洗牌结束 | 额外播放一次“运势上升”祈福动画；本组最后一个洗牌的人播完后，向服务端确认一次，让流程继续 |
| 玩家头像的预约洗牌角标 | 对应座位的“预约洗牌”文字动画与角标隐藏 |

## 三、连带影响

- 不在包厢里时，这条消息**不播放任何洗牌动画**，只清掉预约状态。
- 重连时不重播洗牌动画，只恢复数据。

## 四、重连 / 回放

- 带“只补数据”标记时，连预约状态都不改，由调用方负责。

## 五、注意

如果发现“重连后又看了一遍洗牌动画”，说明调用方没有带“只补数据”标记。
