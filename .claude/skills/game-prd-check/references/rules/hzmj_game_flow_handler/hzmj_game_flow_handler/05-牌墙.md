# 牌墙

**什么时候出现**：开局下发牌墙起点与剩余张数。

## 一、数据上记录了什么

- 处理起点奇偶（起点为奇数时减一，保证牌墙对齐）。
- 记录牌墙总张数。首出提示、剩余张数换算都依赖它。
- 记录牌墙的起点与方向。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 桌面右侧的“剩余张数”牌背 | 显示当前剩余张数；需要隐藏时隐藏该组件 |
| 牌墙本身 | 不在本消息里直接绘制 |
| “显示牌墙”“牌墙出现”两种界面通知 | **目前没有任何界面在监听**，因此不会产生可见变化（只在测试工具里用到） |

## 三、连带影响

- 本消息只负责记录数据 + 刷新剩余张数文本；“牌墙长得怎么样”不在这条消息的表现范围内。
- “显示牌墙”“牌墙出现”属于历史遗留通知，重连和回放里仍会发出，但界面上没有接收方。

## 四、重连 / 回放

只记录牌墙数据，不刷新剩余张数；重连时由“恢复牌墙”负责界面。

## 五、注意

排查“牌墙没显示”时，不要只盯这两个历史通知——当前正式界面并没有监听它们。
