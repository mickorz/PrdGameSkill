# 发牌

**什么时候出现**：开局把初始手牌发给每位玩家。

## 一、数据上记录了什么

- 写入自己的初始手牌。
- 标记桌面进入“发牌”状态。
- 自己的手牌会从记牌器中扣除。
- 统计自己手里已有几张财神，用于之后“多财神未胡”的好运来判断。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 桌面右侧的剩余张数 | 刷新剩余张数 |
| 手牌 | 本消息**不直接刷手牌、也不播发牌动画**，真正的表现由紧随其后的“摸牌”消息完成 |

## 三、连带影响（发牌动画的真实链路）

1. 紧随其后的第一次摸牌会让四家开始发牌：
   - 自己：手牌以随机顺序逐张立起，再自动排序；结束时桌面进入对局状态，并向服务端确认，让流程继续；
   - 其他三家：对应手牌逐张立起。
2. 因此“发牌”的观感取决于“发牌 → 摸牌”两条消息的到达顺序。只收到发牌消息不会出现发牌动画。

## 四、重连 / 回放

只记录手牌、记牌器、财神数量，不刷新剩余张数、不播动画。
