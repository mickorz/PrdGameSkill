# 财神（翻财神 / 白板财神）

**什么时候出现**：开局确定财神牌——翻出的那张牌就是财神；或按房间规则使用“白板财神”。

## 一、数据上记录了什么

- 记录财神牌、翻出的牌。
- 同步自己手里财神的张数。
- 如果是“翻出来并已从牌墙拿走”的财神：记牌器减一，牌墙同步少一张。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 桌面左侧的财神牌 | 显示本局财神牌面；需要隐藏时先隐藏，等翻牌动画结束后再出现 |
| 自己手牌 | 手牌重新排序，保证财神靠左；财神牌染成红色；并重新刷新“禁打置灰”状态 |
| 桌面所有明牌 | 自己与三家的河牌、副露、胡牌区里的财神牌统一染色 |
| 翻财神动画 | 需要翻牌表现时先隐藏桌面财神牌；1.5 秒后播放翻牌动画，翻牌动画结束再让桌面财神牌出现，并向服务端确认；2 秒兜底，避免卡住 |
| 音效 | 翻财神动画期间无额外呼喊，只有翻牌表现 |

## 三、连带影响

- 是否播放翻牌动画：翻出的是白板时，只有房间规则选择了“白板财神”才播放。
- 财神染色会同时影响自己手牌、三家副露、河牌、胡牌区——这是后续所有牌面显示的公共效果。
- 重连时会补发一次“刷新桌面财神牌”，但不播翻牌动画。

## 四、重连 / 回放

只记录财神数据与记牌器，不派发显示与动画；重连时由“场景动作”重连流程补一次桌面财神显示。
