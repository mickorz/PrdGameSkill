# 摸牌（抓牌）

**什么时候出现**：某个玩家摸牌。开局第一次摸牌还会连带触发发牌动画。

## 一、数据上记录了什么

- 自己的记牌器扣掉这张牌。
- 桌面进入“摸牌”状态；别人摸牌时，把“当前操作者”同步为那个人。
- 记录摸到的牌；自己摸到财神时累加“自己摸到财神的张数”。
- 自己摸牌时判断“凑牌光效”：
  - 简单模式、或已有财神时摸到财神/白板 → 不播光效；
  - 凑成刻子 → 记录“敬神（刻）”特效；
  - 凑成顺子、刻子、杠（不含财神参与）→ 记录对应牌值，稍后在自己手牌上播光效。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 手牌（自己） | 先把所有手牌放下，再把摸到的牌摸进来；摸牌完成后触发“凑牌光效” |
| 手牌（其他三家） | 对应座位的手牌做一次摸牌动作 |
| 自己手牌上的凑牌光效 | 按顺子/刻子/杠的花色播放对应光效 |
| 桌面右侧的剩余张数 | 刷新剩余张数 |
| 听牌按钮 | 自己摸牌后，关闭听牌弹窗，并隐藏听牌按钮（等待新的听牌数据） |
| 桌面明牌高亮 | 摸到的牌在四家河牌、胡牌区、副露中高亮显示，并重刷财神颜色 |
| 复盘模式的操作按钮 | 隐藏复盘用的操作按钮 |

## 三、连带影响

- 自己摸牌后会把“本轮已摸牌”标记置上，并清掉“连续未听同花色”的计数。之后“权限”到达时，会依据这个标记决定是否播玄学/魅力特效。
- 摸牌有抓牌音效。
- 开局第一次摸牌会触发四家的发牌动画（见上文“发牌”说明）。

## 四、重连 / 回放

只记录状态、手牌、记牌器、牌墙与光效数据：不摸牌、不发光效、不刷新剩余张数。
