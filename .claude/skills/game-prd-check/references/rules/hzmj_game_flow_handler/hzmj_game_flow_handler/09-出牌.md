# 出牌

**什么时候出现**：任一玩家打出一张牌。

## 一、数据上记录了什么

- 别人出牌时，自己的记牌器扣掉这张牌。
- 记录该玩家托管出牌的次数。
- 记录该玩家打出的牌。
- 自己出牌时，从“打听表”里取出“打这张能听什么”的信息并保存，然后清空打听表。
- 记录“最后一张出牌”（重连时用于恢复箭头位置）。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 手牌 | 自己：手牌里移除这张并可能重新排序，随后收起操作区。别人：对应手牌做一次打牌动作，手牌重排 |
| 河牌区 | 打出的牌落到该玩家的河牌区；落定后播放“出牌落地”特效（受设置里的动画开关控制，播完自动隐藏） |
| 出牌放大牌面 | 先隐藏所有放大牌；若开启“放大出牌”且不是自己出牌，则在对应玩家位置放大显示这张牌，并做财神染色 |
| 听牌箭头 | 自己出牌后刷新“打哪张听什么”的箭头；如果还留有打听数据则保留箭头，否则清空 |
| 听牌按钮 | 自己出牌后关闭听牌弹窗：没有听牌或已胡 → 隐藏听牌按钮；有听牌 → 显示听牌按钮并标记“可胡”状态 |
| 听牌闪光 | 自己此前没播过听牌闪光时，播放一次手牌闪光 |
| 听牌界面（他人出牌） | 刷新听牌列表里各张牌的剩余张数 |
| 操作区 | 收起吃碰杠胡按钮，隐藏多吃/多杠选择，清掉文字提示与庄家提示；已胡时恢复手牌 |
| 手牌置灰 | 清除本回合的出牌限制置灰，手牌恢复可点 |
| 音效 | 播报这张牌的方言语音（若是真财神或白板替牌会换播报内容），并播放出牌音效 |

## 三、连带影响

- 自己出牌且“听牌 + 手里只有一张财神连续未胡”时，会累积次数，用于触发局内的好运来图标切换或道具引导。
- 河牌里出现财神牌时会自动染色。
- 复盘模式下会隐藏复盘操作按钮。

## 四、重连 / 回放

只记录记牌器、托管次数、手牌、听牌信息与“最后出牌”：不播动画、不放大、不刷新听牌界面、不播语音，也不会触发好运来累积。
