# 吃

**什么时候出现**：某个玩家吃了上家打出的牌。

## 一、数据上记录了什么

- 桌面进入“吃”状态。
- 在副露区记录这组牌（记录来源玩家），并按规则排序。
- 清掉“最后一张出牌”。
- 不是自己吃时，自己的记牌器扣掉被吃的牌。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 出牌放大牌面 | 隐藏所有放大牌 |
| 吃碰杠飘动画位 | 该座位播放“吃”动画，并播放“吃”的方言语音；播完自动隐藏 |
| 操作区 | 收起吃碰杠胡按钮，隐藏多吃/多杠选择，清掉文字提示 |
| 副露区 | 从来源玩家的河牌中移除被吃的那张；在吃的玩家副露区增加这组牌；刷新副露来源箭头；手牌重新排列；重刷财神颜色 |
| 玩家头像（自己托管时） | 收起操作区、清提示、恢复手牌可点状态 |
| 听牌界面（别人吃） | 刷新听牌列表的剩余张数 |

## 三、连带影响

- 被吃的牌来自出牌区；不是自己吃时，吃走的三张会从自己的记牌器里扣除，否则听牌剩余张数会偏大。
- 吃后手牌数量会出现“三缺一”的待出状态，但这不是“单放”，出牌限制的置灰逻辑对此有专门处理。
- 吃/碰累计“摊数”由服务端另行下发（三摊更新），本消息不参与。

## 四、重连 / 回放

只记录状态、副露、最后出牌与记牌器，不播放吃动画、不改操作区。
