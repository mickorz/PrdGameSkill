# 碰

**什么时候出现**：某个玩家碰牌。

## 一、数据上记录了什么

- 桌面进入“碰”状态。
- 在副露区记录这组牌。
- 清掉“最后一张出牌”。
- 不是自己碰时，自己的记牌器扣掉两张（碰只消耗两张手牌）。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 出牌放大牌面 | 隐藏所有放大牌 |
| 吃碰杠飘动画位 | 该座位播放“碰”动画，并播放“碰”的方言语音；播完自动隐藏 |
| 操作区 | 收起操作区，清掉文字提示 |
| 副露区 | 从来源玩家河牌移除被碰的那张；碰的玩家副露区增加这组牌；刷新副露来源箭头；手牌重排；重刷财神颜色 |
| 玩家头像（自己托管时） | 收起操作区、清提示、恢复手牌可点状态 |
| 听牌界面（别人碰） | 刷新听牌列表的剩余张数 |

## 三、连带影响

- 摊数（吃/碰累计）由服务端计算，并通过“三摊更新”单独播落地动画，本消息不参与摊数逻辑。
- 只有“有进牌”的碰才会从河牌移除牌；没有进牌的碰不会误删河牌。
- 碰后待出的手牌不会被误判为“单放”，出牌限制的置灰逻辑对此有专门判断。

## 四、重连 / 回放

只记录数据，不播放动画、不改操作区。
