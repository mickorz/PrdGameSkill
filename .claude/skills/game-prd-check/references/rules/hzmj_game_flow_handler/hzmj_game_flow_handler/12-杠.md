# 杠

**什么时候出现**：某个玩家明杠、暗杠或补杠。

## 一、数据上记录了什么

- 桌面进入“杠”状态。
- 在副露区记录这组牌。
- 明杠时清掉“最后一张出牌”。
- 不是自己杠时，自己的记牌器扣掉这组牌。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 操作区 | 收起操作区，隐藏多选池与多杠选择，清提示 |
| 出牌放大牌面 | 隐藏 |
| 吃碰杠飘动画位 | 该座位播放“杠”动画；语音按类型区分：明杠、暗杠、补杠各有一条 |
| 副露区（明杠 / 暗杠） | 新增一组副露；刷新副露来源箭头；手牌重排；重刷财神颜色 |
| 副露区（补杠） | 先把手里那张牌去掉，再把这张牌追加到原来的刻子上（不新增一格副露）；重刷财神颜色 |
| 玩家头像（自己托管时） | 收起操作区、清提示、恢复手牌可点状态 |
| 听牌界面（别人杠） | 刷新听牌列表剩余张数 |

## 三、连带影响

- 杠之后的“杠牌权”“杠上花”“杠后听牌提示”分别由“权限”和“听牌信息”继续处理，不在本消息里。
- 暗杠时，别人看不到具体牌，但记牌器仍按协议扣减；如果要改“别人能看到什么”，需要连这里一起考虑。
- “一次能杠好几种”的多杠选择由“权限”消息里的多杠列表负责，本消息不涉及。

## 四、重连 / 回放

只记录数据；补杠与普通杠在副露区的差异，重连时由“恢复手牌”统一还原。
