# 权限（轮到谁操作）

**什么时候出现**：服务端告诉客户端“当前这个座位可以出牌 / 吃 / 碰 / 杠 / 胡 / 过”。

这是操作区变化最集中的一条消息。

## 一、数据上记录了什么

- 记录当前操作者、可执行的操作、以及本次操作的询问编号。
- 标记“轮到出牌”。
- 机器人的自动报听预设。
- 记录自己本回合是否有胡权限、听牌后连续未胡次数等，用于提示与特效。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 倒计时数字 | 显示当前操作者的剩余时间；最后 3 秒换红色字体并播放倒计时提示音；超过 8 秒没操作会提示玩家尽快操作 |
| 方位盘四角风向灯 | 当前操作者对应方向的灯闪烁，其他方向熄灭；时间结束时停止 |
| 操作者头像框 | 当前操作者头像出现循环发光框，其他座位熄灭 |
| 操作区（他人） | 收起自己的吃碰杠胡按钮 |
| 操作区（自己） | 见下方“自己操作区明细” |
| 听牌按钮 | 自己有出牌权时隐藏听牌按钮；自己有胡权时关闭听牌弹窗 |
| 番型 / 规则弹窗 | 关闭 |
| 手牌置灰 | 自己有出牌权且存在禁打数据时，把禁打的牌置灰、不可点 |
| 玩家头像（自己托管且没有任何操作权） | 收起操作区、清提示 |
| 首出提示 | 判断是否处于“本局第一次出牌”：是且还没提示过 → 显示庄家首出提示（按是否庄家切换文案）、清掉文字提示、隐藏骰子；否则隐藏庄家首出提示 |
| 听牌闪光 | 首出且自己不是庄家时，若有听牌则播放一次手牌闪光 |
| 祈福弹窗 | 按条件弹出“听牌连续 3 次不胡”“三次摸到同一张固定牌”“杠牌不能胡”等提示 |

### 自己操作区明细

| 元素 | 变化 |
|---|---|
| 操作区状态 | 有吃/碰/杠/胡任一项 → 切到“吃碰杠胡”页；否则从该页回到空状态 |
| 吃 / 碰 / 杠 / 过 / 过2 / 胡 按钮 | 按权限显示或隐藏；“报听”按钮在本玩法始终隐藏 |
| 多杠列表 | 有杠权时：只有一种杠不显示列表；有多种杠时显示牌面列表，可点击选择要杠哪种 |
| 胡按钮里的牌面 | 显示要胡的那张牌 |
| 胡按钮里的动作动画 | 点炮/抢杠显示“胡”，自摸显示“自摸” |
| 胡按钮里的倍数 | 显示“X 倍”，封顶标识隐藏 |
| 手牌 | 可以出牌时手牌可点；吃/碰/杠时把相关牌拉亮、其余置灰（多种组合会合并亮起）；若“杠与刚摸的牌无关”，则不置灰、可直接出牌 |
| 按钮光效 | 吃/碰/杠/过/胡按钮播放按钮闪光 |
| 多吃选择池 | 吃有多种组合时，在右侧动态生成多个“整组顺子”的选项，与多杠列表互斥显示 |

## 三、连带影响

1. 自己刚摸过牌时，权限到达会触发玄学 / 魅力道具特效（摸牌后才有意义）。
2. “轮到出牌”的标记会影响做牌类界面的功能页显示。
3. 权限与“出牌限制”有顺序要求：必须先收到出牌限制、再收到权限，手牌置灰才会正确刷新。

## 四、重连 / 回放

只记录权限与询问编号，不刷倒计时、不亮头像框、不弹操作按钮、不置灰、不弹祈福窗口。重连时由“场景动作”在恢复完牌面后，单独补刷倒计时、方位灯和头像框。

复盘模式改用“复盘操作按钮”的显示逻辑：只显示可用的按钮并加光效，不驱动倒计时与流程。
