# 出牌限制（禁打）

**什么时候出现**：服务端下发“哪些手牌不能打、哪张摸上来的单放牌不能打”，用于过张、吃禁手等规则。

## 一、数据上记录了什么

- 禁打的手牌牌值列表。
- 禁打的“单放（刚摸上来那张）”牌值；空表示不禁单放。
- 两者都为空时，清空禁打数据；否则记录到当前座位名下。

设计上的约定：这条消息**只记录**，真正把手牌置灰是在“权限”消息里做的。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 自己手牌 | 有禁打数据时：禁打的手牌变成灰色且不能点击；禁打单放时只作用在最后一张摸上来的牌；其余牌恢复原本的财神颜色 |
| 自己手牌（清空禁打时） | 仅在“当前操作者是自己”时刷新一次，避免别人回合误刷自己的手牌 |

## 三、连带影响

以下时机都会主动重刷一次置灰，否则置灰会丢：

- 刷新财神颜色 / 手牌重新排序之后；
- 权限到达之后；
- 自己出牌、本回合结束 → 清掉置灰。

“单放”的判断依据是“这张是刚摸上来的那张”，不能用“手牌数量除 3 余 2”来判断（吃碰后待出的手牌也会余 2）。

## 四、重连 / 回放

只记录禁打数据，不刷新手牌。重连时先补数据，再由“权限”步骤把置灰刷出来。
