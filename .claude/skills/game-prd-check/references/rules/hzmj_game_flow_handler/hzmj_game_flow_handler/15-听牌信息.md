# 听牌信息（查听 / 打听）

**什么时候出现**：服务端返回“现在已经听什么”和/或“打哪张牌之后听什么”。可能分多条下发。

## 一、先理解消息内容

- 其中“打出牌=0”的条目表示**当前已听**（查听）。
- “打出牌≠0”的条目表示**打这张会听什么**（打听）。
- 标记分为：开始、全部、结束。开始/全部会先清空旧的打听数据；结束/全部表示这一批收完，需要刷新界面。
- 代表“任意牌（爆头）”的特殊值会被统一成界面认识的“任意牌”图案。
- 只处理自己的数据，且自己还没胡。

## 二、数据上记录了什么

- 查听：记录自己当前的听牌信息，并计算箭头类型（大 / 多 / 优）。
- 打听：按“要打出的牌”分别记录听牌信息；收到结束时计算箭头类型。
- 每张听牌的剩余张数按记牌器实时计算；“任意牌”固定不显示剩余张数。

## 三、界面变化

| 界面区域 | 变化 |
|---|---|
| 听牌按钮 | 有查听时关闭听牌弹窗、刷新手牌上的打听箭头；有听牌且未胡 → 显示听牌按钮并标记“可胡”；同时刷新托管/报听按钮状态 |
| 自己手牌上的箭头 | 每张“打了会听”的牌上出现箭头：打出财神听任意牌显示“飘”，其他任意牌听显示“爆”，其余按大/多/优显示 |
| 听牌列表 | **不由本消息直接推**：点击听牌按钮后，听牌界面自己读取当前听牌数据渲染（张数页、每张听牌的倍数与剩余张数、爆头区、封顶文案） |
| 玄学 / 魅力特效 | 判断“打听是否有效”，有效时交给玄学系统播放特效 |
| 祈福弹窗 | 收齐打听数据且有杠权、能杠爆时，弹“杠牌不能胡”提示 |

## 四、连带影响

- 自己出牌时会消费打听数据：取出“打这张听什么”后清空打听表，所以出牌后箭头会消失。
- 重连兜底：断线前若已有“打哪张听什么”的数据，重连时会先保存、再恢复并补刷箭头；服务端随后下发的听牌信息会覆盖它。

## 五、重连 / 回放

- 只有“查听”的情况下，即使只补数据，也会刷新一次听牌按钮（这是刻意的：保证重连后按钮能出现）。
- 打听数据的箭头刷新在“只补数据”时会被跳过。
