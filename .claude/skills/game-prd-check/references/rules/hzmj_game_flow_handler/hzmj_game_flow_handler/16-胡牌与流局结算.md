# 胡牌 / 流局结算

**什么时候出现**：一局结束（有人胡、一炮多响、流局）时，服务端下发完整结算数据。
这是整局中界面变化最多的一条消息，下面按发生顺序说明。

## 一、数据上记录了什么

1. 记录庄家等级、番型明细、摊信息、加倍信息。
2. 把“桌面亮牌”数据写入四家牌面（这是结算时桌面摊牌的依据）。
3. 清理上一轮的桌面飘分、复盘权限、番型记录；然后逐个胡牌玩家记录：
   - 标记已胡；
   - 胡牌类型、单放牌、本地座位；
   - 萧山玩法解析完整的番型表现；
   - 点炮来源座位，并在牌面数据里记录“胡谁的牌”；
   - 番型列表；
   - 自己胡 → 关闭“出牌步”标记。
4. 记录每家本局得失分（用于桌面飘分）。
5. 覆盖玩家累计分数（头像上显示的分）。
6. 记录“本局摸到多张财神但没胡”，供下一局开局的好运来使用。

## 二、界面变化（按发生顺序）

| 顺序 | 界面变化 |
|---|---|
| 1 | **匹配场结果番型**：刷新匹配场专用的结算番型 / 结果层 |
| 2 | **结束类型横幅**：按“自摸 / 点炮 / 流局”等显示对应横幅，1 秒后自动归零 |
| 3 | **操作区**：收起吃碰杠胡按钮，清掉文字提示 |
| 4 | **出牌放大牌面**：全部隐藏 |
| 5 | **全桌摊牌（逐个胡家）**：该家手牌改为“胡牌摊开”状态并拼上胡的那张牌；显示“胡谁的牌”箭头；副露重排并恢复来源箭头；自己胡时手牌不再可点；点炮时从放炮方的河牌里移除那张牌；重刷财神颜色 |
| 6 | **胡牌光柱 + 胡牌落地图**：在每个胡家的胡牌位置播放光柱特效（按穿戴的胡牌特效），并在桌面播放“胡牌落地”图 |
| 7 | **听牌界面**：自己胡时关闭听牌弹窗，并清空打听箭头 |
| 8 | **点炮 / 一炮多响动画**：先隐藏所有碰杠动画，再在放炮座位播放“点炮”或“一炮多响”动画 |
| 9 | **胡牌番型动画（逐个胡家）**：二选一——基础番型显示番型文字动画，组合/高级番型显示“胡 / 自摸”动画；同时播放对应番型的方言语音（普通话或方言）与音效；第一个座位播完后开始播飘分 |
| 10 | **四家飘分 / 得分动画**：四个座位的分数位依次出现，显示本局得分（正数用赢的分数字体、负数用输的分数字体），并播放得分音效；3 秒兜底，避免动画丢失卡流程 |
| 11 | **全桌终局摊牌**：所有副露重置并恢复箭头；所有手牌翻开展示（胡家拼上胡牌）；自己的手牌缩小并右移；胡家显示胡牌落地图；随后通知主界面延迟 1 秒向服务端确认 |
| 12 | **总计确认**：主界面延迟 1 秒回应服务端，推进结算流程 |
| 13 | **小结算**：3 秒后弹出小结算界面（玩家列表 + 左下财神牌，详见“小结算”说明） |
| 14 | **总战绩**：紧接着通知主界面，再延迟 2 秒弹出总战绩界面（如果已标记不弹则跳过） |
| 15 | **震动**：自己胡、并且番型里含“平胡”以外内容时，手机短震动一次；回放模式不震 |

## 三、连带影响

- 本局的完整结算数据会被保存，供回放与“小结算”界面使用。
- 桌面的“胡牌方式标记”（自摸/点炮小标记）不由本消息派发，由结算 / 回放的还原流程另行处理。
- 下一局开局时，“上一局多财神未胡”的记录会决定是否触发好运来图标曝光。

## 四、重连 / 回放

本条消息只在真正结算时下发。回放通过“场景还原”以“重放”方式复用同一套结算逻辑。

## 五、注意 / 风险

- 小结算采用“固定 3 秒后弹出”，不依赖飘分动画的回调。若改飘分动画时长，要同步这 3 秒，否则会出现“分数动画没播完就弹结算”或“等太久”。
- 点炮时移除河牌的最后一张，依赖本消息里的“放炮来源”与“是否已移除”的判断；该判断若被改动，容易出现河牌多一张或少一张。
