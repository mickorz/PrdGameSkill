# 游戏结束

**什么时候出现**：一小局或整局流程结束时，服务端通知结束。

## 一、数据上记录了什么

- 没有记录任何数据，只做界面收尾。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 牌桌中央倒计时 | 清空倒计时数字、停止倒计时、隐藏倒计时区域 |
| 玩家头像区 | 清掉头像上的离线灰态与离线倒计时提示；清除当前操作者的头像发光框 |
| 听牌按钮与听牌祈福按钮 | 关闭（这条来自公共“游戏结束”通知，和本消息同一时机生效） |
| 听牌界面按钮 / 祈福 | 同上 |
| 飘分数字 | 清空四家飘分数字，并放行卡在等回调的结算流程 |

## 三、连带影响

小结算、大结算的弹出时机不受本消息控制，由“胡牌 / 流局结算”那套延迟流程负责。

## 四、重连 / 回放

只补数据时本消息什么都不做。
