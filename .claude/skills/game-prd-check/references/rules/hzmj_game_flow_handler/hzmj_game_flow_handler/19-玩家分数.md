# 玩家分数

**什么时候出现**：服务端广播各家当前累计分数（局中或结算前）。

## 一、数据上记录了什么

- 按服务端座位顺序，把每个玩家的累计分写入玩家数据（头像显示的分数来源）。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 普通房玩家头像 | 该家头像上的分数文本刷新 |
| 匹配场玩家头像 | 头像分数刷新；匹配场另有一套“匹配分数”文本，会做数字缩写（大数显示），正分用亮黄色、非正分用白色 |

## 三、连带影响

- 头像上的分数是“累计分”，与桌面上结算时播放的“本局飘分动画”是两套显示。
- 结算消息会再次覆盖累计分，所以本消息先后顺序不会造成最终分数错误。

## 四、重连 / 回放

只记录分数，不刷新头像。
