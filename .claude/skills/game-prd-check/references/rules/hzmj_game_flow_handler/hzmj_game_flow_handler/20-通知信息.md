# 通知信息（规则提示 / 跟庄成功）

**什么时候出现**：服务端下发“规则限制、操作被拒、跟庄成功”等提示。

## 一、处理规则

- 按提示类型区分。
- 如果这个提示客户端已经点过“知道了”，不再重复提示。
- “跟庄成功”需要全桌播放跟庄动效，不按座位过滤。

## 二、界面变化

| 情况 | 界面变化 |
|---|---|
| 跟庄成功（全桌） | 若房间规则选择“摇骰子赔付”，这里跳过（由“跟庄重扔骰子”统一表现）；否则播放一次“跟庄”动画，定位到对应玩家位置；简单模式下直接跳过 |
| 自己的规则限制提示 | 中央文字提示出现并显示对应文案，1.3 秒后自动消失 |

提示文案：

| 情况 | 文案 |
|---|---|
| 未过手碰牌 | 当前未过手，无法碰牌 |
| 未过手吃胡 | 当前未过手，无法吃胡 |
| 守庄规则 | 守庄规则生效中 |
| 吃禁手规则 | 吃禁手规则生效中 |
| 有财必拷响 | 有财必拷响规则生效中 |
| 只碰不吃 | 只碰不吃规则生效中 |
| 有财 2 番起胡 | 有财2番起胡 |

## 三、连带影响

- 定时消失的提示在显示期间，普通“清提示”不会打断它，只有强制清除才会。
- “跟庄成功”与“跟庄重扔骰子”是同一表现的两种来源，注意不要重复播放。

## 四、重连 / 回放

只补数据时不提示。
