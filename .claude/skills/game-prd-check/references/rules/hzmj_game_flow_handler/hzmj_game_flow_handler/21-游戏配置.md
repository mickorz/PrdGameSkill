# 游戏配置

**什么时候出现**：开局下发房间规则（财神类型、出牌速度、封顶倍数等）。

## 一、数据上记录了什么

- 保存整份房间配置。之后“是否播放翻财神动画”“听牌界面的封顶文案”“结算封顶”等都读这份配置。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 自己手牌 | 按新配置重新刷一次财神颜色（财神牌染红，置灰优先于染色，可点击、不显示角标） |

## 三、连带影响

- 配置决定：是否播放翻财神动画、听牌界面的封顶文案、结算封顶等。
- 重连流程通常仍会执行一次本消息（不是“只补数据”），因此会顺手刷新一次手牌财神颜色。这是刻意的：重连后手牌排序与财神数据可能刚恢复。

## 四、重连 / 回放

在“开局阶段重连”“旧场景开始”这类纯补数据路径里，只保存配置，不刷新手牌颜色。
