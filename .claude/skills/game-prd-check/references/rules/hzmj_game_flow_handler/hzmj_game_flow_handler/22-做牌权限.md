# 做牌权限

**什么时候出现**：包厢“做牌”玩法把做牌权交给某位玩家时。

## 一、数据上记录了什么

- 记录做牌权、当前做牌座位、本轮起始座位。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 做牌界面 | 有做牌权时自动弹出做牌界面，并带上当前做牌座位 |

做牌界面打开后显示的内容：

| 界面区域 | 内容 |
|---|---|
| 候选牌池 | 按牌值升序排列的候选牌，可滑动多选 |
| 做牌座位文本 | 显示当前是谁在做牌（本地座位号） |
| 已选张数 | 显示“已选：N 张” |
| 功能页 | 根据当前是否处于“出牌步”，切换做手牌 / 摸打 / 删牌墙等按钮组 |
| 选中效果 | 被选中的牌变灰，取消后恢复原样 |

## 三、连带影响

- 确认后会把选好的牌发给服务端，并把做牌权交给下一位（或结束做牌）；随后服务端下发“做牌数据”。
- “做牌权限”负责**打开界面**，“做牌数据”负责**填充牌池**。两者顺序可能互换，界面打开时会读取最新数据，因此都能正确显示。

## 四、注意

- 没有做牌权时不会弹界面。
- 重连到做牌阶段时，会按“做牌数据 → 做牌权限”的顺序重新弹出做牌界面，这是预期行为。
