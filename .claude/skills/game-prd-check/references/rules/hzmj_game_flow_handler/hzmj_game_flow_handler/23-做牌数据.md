# 做牌数据（候选牌）

**什么时候出现**：下发可用于做牌的候选牌列表。

## 一、数据上记录了什么

- 保存候选牌列表。

## 二、界面变化

| 情况 | 界面变化 |
|---|---|
| 自己有做牌权 | 打开做牌界面，并显示候选牌池：按牌值升序、可滑动多选；同时显示做牌座位、已选张数、对应功能页 |
| 自己没有做牌权 | 只保存数据，不打开界面 |

## 三、连带影响

- 界面渲染发生在“打开做牌界面”的那一刻，所以“候选牌先到、权限后到”也能正确显示最新牌池。
- 重连到做牌阶段时，这条消息会真实执行，因此会弹出做牌界面；如果希望重连不弹，需要改重连流程，而不是改本消息。

## 四、注意

本消息没有“只补数据”的分支，因此在任何调用路径下都会尝试打开做牌界面。
