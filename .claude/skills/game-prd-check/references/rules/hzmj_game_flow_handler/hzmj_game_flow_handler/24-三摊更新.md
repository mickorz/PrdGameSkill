# 三摊更新（吃碰累计摊数）

**什么时候出现**：吃/碰累计摊数或“承包”关系发生变化时。

## 一、数据上记录了什么

- 记录每家的摊计数，以及“谁摊谁”的承包关系。结算与回放都会读这份数据。

## 二、界面变化

| 情况 | 界面变化 |
|---|---|
| 某一家累计到 3 摊 | 全桌中央播放“三摊落地”动画（不分座位），播完自动隐藏；回放与简单模式不播 |
| 一般的摊数变化 | 桌面上**没有常驻显示**，只记录数据（结算界面读取） |

## 三、连带影响

- 三摊是结算翻倍与承包判定的输入；小结算里的“承保”标记读的是结算消息里的承包数据，不是这里的摊数据。
- 落地动画是全桌居中的，不跟随具体玩家位置。

## 四、重连 / 回放

本消息没有“只补数据”的判断：重连补数据时如果当时恰好有 3 摊，也可能重复播放一次落地动画。若出现“重连又播一次三摊”，需要在这里补判断。
