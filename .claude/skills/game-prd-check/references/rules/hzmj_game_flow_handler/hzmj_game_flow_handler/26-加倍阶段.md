# 加倍阶段

**什么时候出现**：金币场在定庄前进入加倍阶段，服务端在“阶段开始 / 每人选择 / 阶段结束”时各下发一次。

## 一、数据上记录了什么

- 记录当前是否阶段结束、每家选择状态、剩余选择时间。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 主界面操作区 | 阶段进行中且自己还没选 → 显示“加倍 / 不加倍”按钮页，并显示选择倒计时；阶段结束或没有数据 → 收起按钮页、隐藏倒计时 |
| 玩家头像上的加倍标记 | 每人头像上的“加倍”常驻标记：选择加倍时显示。重连后也会恢复 |
| 玩家头像旁的桌面加倍标签 | 阶段进行中显示“未加倍 / 加倍”状态；阶段结束后延迟 1 秒清除，避免一直挂在桌面上 |
| 匹配场头像 | 与普通房相同：头像常驻标记 + 桌面标签 |
| 开局动画里的头像 | 动画中的头像也同步显示加倍标记；阶段结束时全部归零 |

## 三、连带影响

- “操作区状态”是共用的：加倍页和吃碰杠胡页互斥，任何一次操作或重置都会把操作区恢复为空状态。
- 头像上的常驻加分标记与桌面标签是两套：桌面标签在阶段结束后清除，头像标记保留到下一局重置。

## 四、重连 / 回放

只记录加倍数据，不单独刷新界面；重连到加倍阶段时，由“场景加倍”重连流程补一次刷新。
