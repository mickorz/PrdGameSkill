# 跟庄重扔骰子

**什么时候出现**：跟庄成功、且房间规则选择“摇骰子赔付”时。

## 一、数据上记录了什么

- 保存这次跟庄骰子的完整数据，供回放拖动 / 跳转到该步时静态还原。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 牌桌中央倒计时区 | 先临时屏蔽倒计时数字与方位灯闪烁（业务计时继续） |
| 两枚骰子 | 播放骰子动画 |
| 跟庄动画 | 在协议指定座位播放“跟庄”动画 |
| 四家飘分位 | 骰子与跟庄动画都结束后，在对应座位播放跟庄赔付的飘分 |
| 流程 | 动画全部结束后向服务端确认一次，推进流程 |

## 三、异常处理

如果数据不合法（人数不是 4 人、座位越界、骰子点数不在 1~6、赔付金额异常等），直接跳过动画并回包，避免卡住。

## 四、连带影响

- 骰子期间倒计时区域被临时屏蔽，骰子结束或本次流程失效后自动恢复。
- 回放时用保存的数据静态重放，且**不会**向服务端确认。

## 五、重连 / 回放

只补数据时：保存数据，不播动画、不播飘分。
