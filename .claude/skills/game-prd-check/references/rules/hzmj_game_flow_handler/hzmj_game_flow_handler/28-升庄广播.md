# 升庄广播

**什么时候出现**：本局升庄成功，服务端广播新的庄家等级。

## 一、数据上记录了什么

- 更新庄家等级与连庄数（用于庄家标记和结算显示）。

## 二、界面变化

| 玩法 | 界面变化 |
|---|---|
| 萧山好友房 | 先记录下来：如果此时正在等开局骰子，就等骰子播完再播“升庄”；否则立即播放。升级失败或简单模式下直接跳过 |
| 其他玩法 | 先隐藏全桌庄家标记，再在协议座位显示“庄”（并更新连庄档位，超过 3 档按 3 档显示） |
| 其他玩法（动画） | 在协议座位位置播放“加庄”动画；升级失败 / 简单模式 / 没有对应节点时直接跳过 |

## 三、连带影响

- 萧山好友房要求“先开局骰子、后升庄”，由开局阶段记录的状态排队控制。
- 回放时，加庄会并入最近的“掷骰子”这一步一起播放，保证骰子与加庄动画都不会丢。

## 四、重连 / 回放

只补数据时：只更新庄家等级与连庄数，不显示庄家标记、不播动画。
