# 匹配场底分

**什么时候出现**：匹配场下发底分。

## 一、前置条件

- 只有匹配场才处理。
- 底分小于等于 0 时不处理。

## 二、数据上记录了什么

- 保存底分（服务端可能用两种数字格式，统一转成普通数字）。

## 三、界面变化

| 界面区域 | 变化 |
|---|---|
| 背景底分文字 | 显示“底分：XX” |
| 背景的“游戏中”状态页 | 切到游戏中状态，显示空闲图标 |
| 背景牌桌美术字 | 按当前玩法切换 |
| 房间名 | 未开局时按房间数据显示房间名 |

## 四、连带影响

- 背景底分只在匹配场显示；包厢 / 好友房的底分由房间规则展示，不走本消息。
- 重连时本消息只保存数据，底分文字由后续的“游戏开始状态”或“底分刷新”补齐。

## 五、重连 / 回放

只补数据时不刷新底分文字。
