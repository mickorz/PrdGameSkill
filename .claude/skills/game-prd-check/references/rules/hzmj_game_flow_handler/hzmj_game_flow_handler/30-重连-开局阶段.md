# 重连：开局 / 准备阶段

**什么时候出现**：玩家在“开局准备”阶段（开局倒计时中）断线后重连。

## 一、先补齐的数据（内部依次执行）

1. 开局数据：牌墙总数、记牌器、底分、托管时间等（不触发界面）。
2. 匹配场底分（不触发界面）。
3. 游戏配置：保存配置，并刷新自己手牌的财神颜色。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 主界面操作区 | 回到空状态；隐藏出牌放大牌面；清掉多吃 / 多杠选择与复盘按钮；清掉文字提示与庄家提示 |
| 自己手牌 | 清空手牌，重刷财神颜色 |
| 听牌按钮 / 听牌祈福按钮 | 隐藏 |
| 剩余张数 | 隐藏 |
| 胡牌方式标记 | 全部隐藏 |
| 桌面牌面 | 清空四家手牌、河牌、副露、胡牌区；隐藏河牌箭头；隐藏倒计时与两枚骰子；自己手牌的位置与大小还原；桌面财神牌与剩余张数隐藏 |
| 出牌落地 / 胡牌落地特效 | 全部隐藏 |
| 玩家头像区 | 清除加倍标记、庄家标记、头像发光框；清掉未执行定时任务；**保留其他玩家头像**（头像由桌子服务恢复，不清空） |
| 提示动画层 | 清空开局动画、庄家提示、飘分、匹配结果、随机座位提示；停止各类动画；清文字提示；结束类型归零 |
| 小结算界面 | 关闭 |

## 三、连带影响

- 这一步的作用是“把上一局的残留清干净”。真正的本局数据由后续的重连流程（场景动作等）重新写入。
- 若消息里带有“等待确认”，会立刻回应服务端，避免卡在开局等待。
- 注意：这里会清空手牌数据，因此重连顺序上必须由后续“恢复手牌 / 恢复河牌”补回来，否则桌面会空。

## 四、与其他重连的关系

不同断线阶段会走不同的重连消息：准备阶段、对局中、做牌、加倍、洗牌、结算各有专门的入口。本消息用于“服务端单独下发开局重连”的兼容路径。
