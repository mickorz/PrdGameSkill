# 场景开始（旧协议，兼容保留）

**什么时候出现**：旧版本在“开局状态”断线重连时下发。新协议已不再发送，这里只为兼容旧对局快照。

## 一、内部依次补齐的内容

1. 开局数据与表现（同“开局”说明）。
2. 匹配场底分（只补数据）。
3. 游戏配置（保存配置并刷新手牌财神颜色）。
4. 等待确认（记录编号，必要时自动回应服务端）。

## 二、界面变化

本消息自己没有额外的界面动作，所有变化都来自上面几项：

| 来源 | 界面变化 |
|---|---|
| 开局 | 操作区收起；匹配倒计时隐藏；四家加倍标记 / 庄家标记 / 头像发光框清空；背景切到游戏中状态；开局动画（按局数决定）；剩余张数刷新 |
| 游戏配置 | 自己手牌财神颜色刷新 |
| 等待确认 | 一般无可见变化（自动回应服务端） |

## 三、注意

- 因为开局这一步**不是**“只补数据”的方式执行，旧快照重连时会尝试播放开局动画；如果记录里不是第一局，则不会播。
- 新流程请使用“场景动作”或“重连：开局阶段”。
