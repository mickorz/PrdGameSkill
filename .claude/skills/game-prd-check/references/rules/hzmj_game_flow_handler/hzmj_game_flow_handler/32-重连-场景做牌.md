# 场景做牌（重连）

**什么时候出现**：做牌阶段断线后重连。

## 一、内部依次补齐的内容（顺序不能乱）

1. 开局数据（只补数据）。
2. 匹配场底分（只补数据）。
3. 游戏配置（刷新手牌财神颜色）。
4. 局数据：恢复庄家标记与方位盘。
5. 骰子：静态显示骰子点数，不播放滚动。
6. 恢复牌墙：牌墙数据与剩余张数。
7. 做牌数据：候选牌列表，并尝试打开做牌界面。
8. 做牌权限：做牌权与做牌座位，并打开做牌界面。

最后如果带加倍数据，还会刷新一次加倍状态。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 背景 | 匹配场底分与牌桌美术字 |
| 玩家头像 | 庄家标记；加倍标记（先清后按数据重刷） |
| 牌桌中央 | 方位盘底图与四角风向灯；骰子静态点数；剩余张数 |
| 做牌界面 | 弹出：候选牌池（升序、可多选）、做牌座位、已选张数、对应功能页 |
| 主界面操作区 | 加倍阶段已结束时收起按钮页并隐藏倒计时；桌面加倍标签延迟 1 秒清除 |

## 三、注意

- 做牌数据、做牌权限**没有**“只补数据”分支，因此重连会重新弹出做牌界面（预期行为：重连后继续做牌）。
- 顺序必须是“先候选牌、后做牌权”，因为做牌界面打开时会读取当前的候选牌与做牌座位。
- 这个阶段还没有对局手牌，所以不恢复手牌和河牌，属于正常。
