# 场景发牌（旧协议，兼容保留）

**什么时候出现**：旧版本在“发牌状态”断线重连时下发，新协议已不再发送。

## 一、内部依次补齐的内容

1. 开局数据（只补数据）。
2. 匹配场底分（只补数据）。
3. 游戏配置。
4. 局数据（庄家与方位）。
5. 骰子（静态显示，不滚动）。
6. 恢复牌墙（含剩余张数）。
7. 恢复手牌（四家手牌与副露）。

最后若有“等待确认”，立即回应服务端。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 玩家头像 | 庄家标记 |
| 牌桌中央 | 方位盘底图与四角风向灯；骰子静态点数；剩余张数 |
| 手牌与副露 | 四家手牌恢复并排序（财神靠左）；副露恢复并恢复来源箭头；重刷财神颜色 |
| 自己手牌 | 财神颜色刷新 |

## 三、与“场景动作”的区别

相比“场景动作”，这里**没有恢复河牌、没有恢复出牌限制与权限、没有恢复倒计时**。因此旧协议重连后可能出现“河牌空白、没有操作按钮、没有倒计时”，属于已知限制，仅用于旧快照兼容。
