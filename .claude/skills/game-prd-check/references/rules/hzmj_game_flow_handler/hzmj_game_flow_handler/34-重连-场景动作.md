# 场景动作（对局中重连，最常用）

**什么时候出现**：对局进行中断线后重连。准备阶段之后的几乎所有断线场景（庄家摸牌、下家摸牌、自己摸牌、首个等待、跟庄骰子）都走这里。

## 一、内部依次补齐的内容（顺序非常关键）

1. 开局数据（只补数据）。
2. 游戏配置（刷新自己手牌财神颜色）。
3. 局数据：庄家标记、方位盘。
4. 恢复牌墙：牌墙数据与剩余张数。
5. **恢复财神（必须先于手牌）**：否则手牌排序时不知道财神是哪张，财神不会靠左。
6. 恢复手牌：四家手牌、副露（财神已就位）。
7. 恢复河牌：四家河牌、出牌箭头、出牌放大。
8. 恢复杭州麻将专属字段：牢庄等级、摊信息、加倍状态、飘计数、出牌限制（只补数据）。
9. **权限（必须晚于出牌限制）**：操作按钮、倒计时、头像框，并按出牌限制刷手牌置灰。
10. 恢复倒计时与方位灯、操作者头像框。
11. 若有“等待确认”，立即回应服务端。

## 二、界面变化（按区域）

| 界面区域 | 变化 |
|---|---|
| 背景 | 底分、牌桌美术字、游戏中状态页 |
| 牌桌中央 | 方位盘底图、四角风向灯（含闪烁）、倒计时数字、两侧的财神牌与剩余张数 |
| 牌桌牌面 | 四家手牌与副露、四家河牌、河牌箭头、出牌放大牌面；财神统一染色；自己手牌财神靠左 |
| 玩家头像 | 庄家标记、当前操作者的头像发光框 |
| 操作区 | 吃碰杠胡按钮、多杠列表、操作区状态页、手牌可出 / 置灰 |
| 加倍 | 头像与桌面的加倍标记 |
| 骰子 | 保持隐藏（对局中不应显示） |

## 三、注意 / 风险

- **顺序依赖一**：财神必须比手牌先恢复，否则财神不靠左。
- **顺序依赖二**：出牌限制必须比权限先执行，否则手牌置灰不会出现。
- 出牌限制在重连时只补数据，靠“权限”这一步刷灰；如果把权限也改成只补数据，置灰就会丢。
- 本流程**不恢复胡牌标记与摊牌**；胡牌状态的重连由结算场景与回放流程负责。
- 倒计时与头像框是按“当前操作者”恢复的，所以重连后不会错误地落在自己身上。
