# 场景结算（重连）

**什么时候出现**：结算阶段断线后重连。

## 一、数据上记录了什么

1. 用结算后的累计分覆盖玩家的累计分。
2. 遍历每家本局得失分（只用于刷新头像，不单独保存）。
3. 恢复加倍状态，并标记“加倍阶段已结束”。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 玩家头像分数 | 刷新累计分（匹配场另外刷新匹配分数文本，含数字缩写与颜色） |
| 加倍标记 | 头像常驻加倍标记、桌面加倍标签；由于标记为“已结束”，操作区收起、倒计时隐藏、桌面标签延迟 1 秒清除 |

## 三、连带影响

- 结算界面（小结算 / 总战绩）**不由这条消息打开**：正常对局由“胡牌 / 流局结算”的延迟流程打开；重连到结算阶段时依赖公共结算流程。
- 本局得失分只刷新头像，没有写入桌面的飘分数据，因此重连后桌面不会再出现飘分数字（已知差异）。

## 四、注意

- 头像累计分与本局得失分是两个不同来源，不要混用。
- 本消息没有“只补数据”的分支。
