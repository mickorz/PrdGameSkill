# 场景加倍（金币场重连）

**什么时候出现**：金币场在“定庄前的加倍阶段”断线后重连。

## 一、数据上记录了什么

1. 开局数据（只补数据）。
2. 游戏配置（刷新自己手牌财神颜色）。
3. 局数据：庄家与方位。
4. 加倍状态：若服务端下发了加倍状态，则保存并刷新界面。

最后若有“等待确认”，立即回应服务端。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 玩家头像 | 庄家标记；头像上的加倍常驻标记 |
| 牌桌中央 | 方位盘底图与四角风向灯 |
| 主界面操作区 | 自己还没选加倍 → 显示“加倍 / 不加倍”按钮页，并显示剩余选择倒计时 |
| 桌面加倍标签 | 加倍进行中显示每家状态；已结束则收起操作区、隐藏倒计时，并在 1 秒后清除桌面标签 |
| 开局动画里的头像 | 同步加倍标记（若此时仍在开局动画阶段） |

## 三、注意

- 这个阶段没有手牌、河牌和权限，所以不恢复这些区域，属于正常。
- 如果服务端没有下发加倍状态，玩家重连后将看不到加倍按钮与倒计时。遇到“重连后无法加倍”，先确认服务端是否带了这个字段。
- 排查重连问题时，可以留意日志里会打印“加倍重连”的相关信息。
