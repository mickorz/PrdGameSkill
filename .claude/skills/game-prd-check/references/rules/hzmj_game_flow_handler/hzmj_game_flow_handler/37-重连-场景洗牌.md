# 场景洗牌（重连）

**什么时候出现**：洗牌阶段断线后重连。

## 一、内部依次补齐的内容

1. 开局数据（只补数据）。
2. 匹配场底分（只补数据）。
3. 游戏配置（刷新自己手牌财神颜色）。
4. 局数据（庄家与方位）。
5. 骰子：静态显示点数，不播放滚动。
6. 恢复牌墙：牌墙数据与剩余张数。
7. 恢复洗牌座位数据（不重播洗牌动画）。

最后若有“等待确认”，立即回应服务端。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 牌桌中央 | 方位盘底图、四角风向灯、两枚骰子的静态点数、剩余张数 |
| 玩家头像 | 庄家标记 |
| 自己手牌 | 仅刷新财神颜色（洗牌阶段还没有手牌） |
| 洗牌动画 | **不播放** |

## 三、注意

- 如果希望重连时也看到洗牌动画，需要改动重连流程；但这会连带恢复“清除预约洗牌角标”等副作用，需要一起评估。
- 骰子采用“跳过动画”的方式显示时不会自动隐藏，会一直保留到下一次对局推进把它隐藏。重连后骰子常驻属于现有表现。
