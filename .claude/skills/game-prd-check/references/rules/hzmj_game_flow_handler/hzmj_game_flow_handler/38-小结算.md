# 小结算

**什么时候出现**：一局结束、胡牌动画播完后弹出（固定延迟约 3 秒）；回放模式在收到结算时直接弹出。

## 一、数据来源

- 使用“胡牌 / 流局结算”保存的完整结算数据。
- 组装显示内容：庄家、庄家等级、连庄数（与桌面庄家标记同源，不使用结算覆盖后的值）、每家得失分、玩家手牌、胡牌明细、结束类型、流水文案、剩余牌墙、承包结算、加倍信息。

## 二、界面变化

| 界面区域 | 变化 |
|---|---|
| 小结算界面 | 打开，替换在游戏画面之上 |
| 玩家列表区 | 每家一行：头像、昵称、所在方位（自己/下家/对家/上家）、庄家标记（萧山玩法为可变等级）、手牌与副露、胡牌类型与倍数、本局流水（可点开查看明细）、承保标记、加倍状态 |
| 左下角财神牌 | 显示本局财神牌 |
| 公共结算外壳 | 关闭 / 继续、查看总结算、安全中心、洗牌道具等公共按钮（由公共结算界面负责） |
| 手机震动 | 自己胡、且番型里含“平胡”以外内容时短震一次；回放不震 |

## 三、连带影响

- 小结算弹出后，会紧接着通知主界面：延迟 2 秒弹出总战绩。
- 公共结算界面会监听一批公共消息，用于刷新安全按钮、洗牌道具数量、预约洗牌状态、以及“查看总结算”按钮。
- 长按看桌：长按小结算会让桌面上的财神牌高亮，松手取消。

## 四、注意 / 风险

- 弹出时间是固定的 3 秒，与飘分动画时长没有联动；改动画时长要同时考虑这 3 秒。
- 只有“平胡”不触发震动，其余任何番型都会震动；新增基础番型需要同步调整。
- 回放模式下会在收到结算时直接弹出，不等待 3 秒。
- 玩家列表依赖结算界面资源里导出了对应组件；如果缺失会退化成“逐行列表”的兜底样式（日志里会有提示）。
