# 总战绩

**什么时候出现**：整局结束、服务端下发总结算时（由游戏控制器统一处理）。

## 一、数据上记录了什么

1. 把玩家的总结算记录按座位排序。
2. 汇总：每家总得失分、已打局数、创房最大局数、开始/结束时间、房主名、玩法名、房间与对局标识、解散者等。
3. 解析每位玩家的详细统计，生成展示条目：

| 条目 | 内容 |
|---|---|
| 胡 | 胡了几次 |
| 爆头 | 爆头几次 |
| 财飘 | 财飘几次 |
| 财神 | 摸到财神几次 |

4. 保存为“总战绩数据”，供总战绩界面使用。

## 二、界面变化

- 本消息**不直接打开任何界面**。

## 三、真正的弹窗时机（两条路）

1. 游戏控制器统一处理时：
   - 标记游戏已结束、停止安全监控；
   - 若处于回放、或房间被解散且不是机器人解散 → **直接**弹出总战绩界面；
   - 同时通知小结算界面切换到“查看总结算”按钮。
2. 正常对局：胡牌结算播完后通知主界面，主界面延迟 2 秒弹出总战绩；如果已被标记为“不弹”，则跳过。

## 四、注意

- 某位玩家的统计解析失败时会被跳过，因此战绩条目的数量可能少于玩家数。
- “已打局数”和“最大局数”都取创房设置；若以后要区分“实际已打 / 房间设置”，需要改这里。
