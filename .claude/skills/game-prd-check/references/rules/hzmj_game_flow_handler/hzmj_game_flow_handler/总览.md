# 杭州麻将（42319）行为与界面联动总览

本目录按“一个游戏行为 = 一篇说明”整理：**每个行为实际让界面上的哪些元素发生了变化**，并把变化分成三类：

- **直接变化**：这个行为本身直接改动的界面元素；
- **连带变化**：因为数据变化或后续动作而带来的第二层变化；
- **补充数据**：断线重连、回放补数据时，这个行为只记录数据、不播放表现。

每篇说明都按以下顺序书写：

1. 这个行为在什么时候出现；
2. 数据上记录了什么（界面变化的基础）；
3. 界面具体怎么变（按界面区域列出）；
4. 连带影响（音效、弹窗、后续动画、流程放行等）；
5. 重连 / 回放时的差异；
6. 注意事项。

## 阅读建议

1. 想改某个表现：先在本表找到对应行为，再看“界面变化”表格里的界面区域；
2. 想确认“到底动了哪个元素”：看表格中“界面区域”一列；
3. 排查“重连后哪里不对”：看对应重连说明，重点看“注意”里的先后顺序。
