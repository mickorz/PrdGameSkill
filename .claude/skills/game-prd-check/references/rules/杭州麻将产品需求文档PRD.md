### 1.7 产品流程总览
```
金币场：开局 → 加倍 → 定庄 → 掷骰 → [做牌] → 定财神 → 发牌 → 庄家首摸 → 首摸等待 → 对局

对局循环：摸牌 → 动作判定 → 出牌 → 其他玩家响应 → 下一摸
响应优先级：胡 > 碰/杠 > 吃
结束：胡牌/流局 → 结算 → 更新牢庄 → 下一局或大结算
```

## 3. 判定口径

### 3.1 胡牌来源
| 来源 | 定义 | 是否按自摸计算 |
|---|---|---|
| 自摸 | 进张为自己摸到的牌 | 是 |
| 杠上开花 | 杠后补牌自摸 | 是 |
| 点炮 | 进张为他人打出的牌 | 否 |
| 抢杠胡 | 进张为他人补杠的那张牌 | 否 |

### 3.2 进张
- 自摸：本次摸到的牌。
- 点炮：他人打出的牌。
- 抢杠胡：被抢的补杠牌。

### 3.3 财神与财神计数
1. 实际财神：白板财神时为白板；翻财神时为翻出的那张牌。
2. 替代牌：翻财神且实际财神不是白板时，白板登记为替代牌，参与胡牌拆解；白板本身仍是箭牌。
3. 手牌财神数：手牌中的实际财神数 + 进张为实际财神时 +1。
4. 财神总数：手牌财神数 + 本座位出牌区已打出的实际财神数。
5. 财神不能用于吃、碰、杠的凑牌，只能用于胡牌拆解与听牌判断。

### 3.4 敲响（万能听）
1. 判定对象：进张前的手牌 + 副露 + 财神。
2. 判定方法：枚举所有拆牌方案，只要存在一种方案的等待牌包含“任意牌”，即为敲响。
3. 无财神时必然不敲响。
4. 打出财神后是否敲响用于更新飘等级。实际胡牌时，爆头、财飘系列按自摸、飘等级和进张与财神成将判定，代码未额外强制检查敲响；万能听提示使用敲响判定。是否要求实际胡牌也必须敲响【待确认】。

### 3.5 杠链
1. 每次杠（明杠、暗杠、补杠）杠链 +1；暗杠额外记录“含暗杠”标记。
2. 打出非财神 → 杠链清零、暗杠标记清零。
3. 打出财神且不敲响 → 杠链清零、暗杠标记清零。
4. 打出财神且敲响 → 杠链保留。
5. 吃、碰 → 杠链清零、暗杠标记清零。
6. 杠链用于杠开系列番型。

### 4.2 覆盖顺序
1. 好友房：好友房默认值 → 好友房 JSON 覆盖。
2. 金币场：好友房默认值 → 金币场固定差异 → 入场配置解析 → 金币场等级规则覆盖。
3. 金币场等级规则覆盖顺序：全局等级规则 → 本桌最高房间等级对应的等级规则。
4. JSON 未下发某字段时保持当前默认值。
5. 底分 ≤0 时忽略本次下发并记录日志，保持原值。

### 4.3 配置联动与覆盖
1. 好友房：三摊承包开启且人数 ≤2 → 服务端忽略该开关，保持关闭，并置吃碰次数限制 2。金币场不校验人数，二人金币场也可能开启三摊。
2. 守庄开启且人数 ≤2 → 服务端忽略该开关，保持关闭。
3. 显式下发三摊承包=关 → 先把吃碰次数限制置为 2；好友房随后下发吃碰次数限制可再次覆盖；金币场不解析该限制字段，无法直接覆盖。未下发三摊字段时不触发该联动。
4. 吃碰次数限制 = 1 时，等价于“限制 2 次且只能碰不能吃”，并同时开启只碰不吃。
5. **覆盖边界**：金币场按“全局等级规则 → 本桌等级规则”依次覆盖。若全局规则关闭三摊（限制置 2），本桌等级规则随后重新开启三摊，服务端不会清除限制；吃碰限制判断只检查限制值，不检查三摊开关，因此两者可能同时生效。该限制对吃恒生效；对碰/明杠仅在碰算摊开启时生效。【待确认】
6. 好友房三摊承包开启时，吃碰次数限制配置不生效；金币场无此保证，按第 5 条处理。

## 5. 开局

### 5.1 开局准备
1. 好友房杭麻游戏配置消息下发有财必拷响、三摊承包、简洁模式和局 ID；其余配置的客户端获取途径【待核实】。
2. 金币场下发本局游戏配置、虚拟玩家信息（底分、台费、房间等级）。


### 5.2 加倍（仅金币场）
1. 进入阶段时清空全桌加倍选择。
2. 每个座位下发独立倒计时，默认 10 秒。
3. 玩家可提交“加倍”或“不加倍”；重复提交无效；座位号不匹配无效。
4. 超时未提交 → 按“不加倍”处理。
5. 断线玩家不立即处理，等待倒计时结束按“不加倍”处理。
6. 全员完成选择 → 广播阶段结束，固定停 1 秒 → 进入定庄。
7. 加倍开关关闭 → 直接跳过。

### 5.3 定庄
| 局面 | 判定 |
|---|---|
| 首局 | 首局庄家来源 0：随机座位；1：房主 |
| 非首局·流局 | 流局连庄开：庄家不变且连庄 +1；关：逆时针轮换下一位 |
| 非首局·胡牌·赢家坐庄 | 赢家坐庄；原庄自胡视为连庄 |
| 非首局·胡牌·逆时针轮换 | 庄家单人胡牌（含自摸、接炮、抢杠）连庄；闲家胡牌则轮换下一位 |

补充：
1. 首局定庄同时设置首局庄、连庄数 1、牢庄档位为起算档位。
2. 轮换后连庄数重置为 1。
3. 一炮多响不启用，不参与换庄判定。

### 5.4 掷骰、洗牌、做牌
1. 掷骰得到骰子点数，决定开牌位置和翻财神取值。
2. 好友房发牌前检测各座位是否存在待生效的洗牌道具；存在触发座位 → 广播并停留 5 秒，不真正重排牌墙。
3. 做牌开启时，定财神前进入指定牌阶段，记录各座位指定手牌与指定摸牌。
4. 发牌阶段按指定牌取牌；不足标准起手牌数时从牌墙补齐其余手牌。
5. 好友房做牌模式：掷骰后、定财神前记录指定牌；定财神后发牌时落地。
7. 指定牌操作入口与客户端展示【待核实】。

### 5.5 定财神
1. 记录本局财神状态并清空历史。
2. **白板财神**：实际财神 = 白板，无替代牌，无翻出牌。
3. **翻财神**：
   - 取本局骰子点数和 S；
   - 若牌墙数 = 0、S = 0 或 S > 牌墙数 → 本局不翻，实际财神回退为白板；
   - 否则从牌墙尾部倒数第 S 张翻出；
   - 翻出牌即实际财神，并从牌墙中移除该张；
   - 若实际财神不是白板，则白板登记为替代牌；若翻出白板，则不登记（见下条边界）。
4. 翻出白板边界：若翻出的牌是白板，实际财神仍为白板，不登记白板替代牌；翻出的白板从牌墙移除。只有翻出非白板时，才登记白板为替代牌。
5. 注册财神与替代牌，用于胡牌与听牌算法。
6. 从吃、碰、杠候选组中剔除实际财神，保证财神不能用于吃碰杠。
7. 广播财神结果，等待客户端动画确认，超时 3 秒自动推进。

### 5.6 发牌、首摸与听牌提示
1. 按骰子开牌位置发牌，每人起手牌数按玩法标准。
2. 庄家摸第 14 张进入首摸等待。
3. 首摸阶段计算听牌提示：
   - 闲家：13 张起手听牌检测；
   - 庄家：14 张“打哪张 → 听什么牌”检测。
4. 听牌提示按自摸番型口径计算（爆头、财飘、杠开等）；与最终结算金额不等同，最终金额还受封顶、加倍、付款方、承包等影响。
5. 提示只下发信息，不授予“听”权限。
6. 客户端具体展示形式【待核实】。
7. 对局中有出牌权时也计算并下发“打哪张 → 听什么牌”。手牌至少有两张实际财神、打出一张后仍敲响时，补充“打财神 → 听任意牌”提示；有财必拷响开启且仅有一张实际财神时，可补充打掉财神后的普通听牌提示，并排除再次摸到财神的进张。

## 6. 对局

### 6.1 主循环与动作优先级
```
摸牌 → 动作判定 → 出牌 → 其他玩家响应 → 下一摸
```
1. 当前玩家动作：自摸胡、暗杠、补杠、过。
2. 出牌后其他玩家响应优先级：胡 > 碰/杠 > 吃。
3. 同一张牌多人响应时只执行优先级最高者。
4. 多人同时可胡时，按座位权重（相对当前出牌者的座位顺序）仲裁，不按点击先后；吃/碰/杠在同一张牌上通常唯一。
5. 吃、碰后由该玩家出牌；杠后补牌；补杠后保留抢杠胡窗口。
6. 无人响应 → 下家摸牌。

### 6.2 出牌
1. 出牌必须是手牌或刚摸进的牌，且不在禁打黑名单内。
2. 飘财窗口内，受限座位只能打刚摸进的牌。
3. 出牌后依次处理：飘等级与飘财窗口、十风计数、杠链、跟庄状态、解除本座位吃/碰禁手、进入响应分发。
4. 出牌阶段不修改财神、不修改牌墙。

### 6.3 吃
判定条件：
1. 只能吃上家（打牌者的下家）打出的牌。
2. 座位未破产、未胡牌、未处于飘财受限。
3. 吃碰次数限制开启时，该座位对该上家的吃+碰次数 <2。
4. 三摊承包开启且吃方与被吃方均为闲家时，该方向摊数 <2。
5. 只碰不吃开启时禁止吃；若本可吃，提示“只碰不吃规则生效中”。
6. 吃禁手开启时，逐组合过滤“吃后无牌可打”的吃法；全部被过滤则不给吃，并提示。

执行结果：
1. 记录吃牌组合并下发。
2. 吃方对被吃方记 1 摊（恒定，不受碰算摊影响）。
3. 吃碰次数限制开启时，该方向吃+碰次数 +1。
4. 三摊承包开启且该方向摊数达到 3 → 承包关系记为 1，并广播摊数变化。
5. 吃禁手开启时写入禁打牌：吃中间禁打中间；吃两边禁打被吃的牌和另一侧延伸牌。
6. 吃中断跟庄、十风资格、杠链。

### 6.5 杠

#### 明杠
判定：
1. 牌墙剩余 ≥ 补牌张数 + 荒局张数。
2. 座位未破产、未处于飘财受限。
3. 碰算摊开启时，该方向吃+碰次数 <2；闲闲之间摊数 <2。
4. 手牌中必须有 3 张与打出牌相同的牌。

执行：
1. 明杠牌组下发。
2. 碰算摊开启时记 1 摊，达到 3 摊记承包关系 1。
3. 碰算摊开启且吃碰限制开启时，次数 +1。
4. 杠链 +1，暗杠标记不变；记录飘杠先后。
5. 中断跟庄、十风资格。
6. 杠后补牌。

#### 暗杠
判定：
1. 牌墙剩余 ≥ 补牌张数 + 荒局张数。
2. 座位未破产、未听牌等待。
3. 手牌中必须有 4 张相同牌。
4. 飘财窗口不限制暗杠。

执行：
1. 暗杠牌组下发。
2. 不记摊、不计吃碰次数。
3. 杠链 +1，暗杠标记置为真；记录飘杠先后。
4. 中断跟庄、十风资格。
5. 杠后补牌。

#### 补杠
判定：
1. 座位未处于飘财受限、未破产、未听牌等待。
2. 牌墙剩余 ≥ 补牌张数 + 荒局张数。
3. 已碰过的牌与手牌中的同张可组成补杠。
4. 同巡补杠限制开启且当前处于碰牌状态时，刚碰的同张不能立即补杠；杭麻默认关闭该限制，当前未见杭麻配置入口。

执行：
1. 补杠牌组下发。
2. 记录杠牌者，供抢杠胡判定赔付方。
3. 杠链 +1，暗杠标记不变；记录飘杠先后。
4. 中断跟庄、十风资格。
5. 进入抢杠胡窗口：其他玩家可胡则该牌；无人抢则补牌。

杭麻明杠、暗杠、补杠本身不单独收取杠分；杠后胡牌可按杠开系列计算番型倍数。

### 6.6 胡

#### 胡牌权限判定
1. 座位未破产、本局未胡过。
2. 手牌（含进张）能拆成：平胡 3N+2，或七对 2N。
3. 番型命中且番数 ≥ 起胡门槛（默认 1 番）。
4. 有财必拷响开启且手牌含财神时：
   - 仅自摸可胡；
   - 点炮、抢杠一律不授予胡权限；
   - 自摸未敲响且手牌已成牌、但无合法番型时，不授予胡权限；满足提示条件时提示（简洁模式抑制）。
5. 十风资格满足（连续 ≥10 张字牌）且为自摸时，直接授予胡权限，不要求手牌成牌。
6. 十风授权先于有财必拷响判定；两者同时满足时按十风自摸授权。

#### 点炮条件
1. 玩法开启放铳。
2. 庄闲放铳开关开启。
3. 当前牢庄为三牢。
4. 只在庄家与闲家之间成立：庄家打的牌只能被闲家胡，闲家打的牌只能被庄家胡；闲闲之间不可。
5. 打出的牌是财神时不能胡。

#### 抢杠胡条件
1. 玩法开启抢杠。
2. 庄闲放铳开关开启且当前三牢。
3. 除杠牌者外，其他玩家均可抢，不限庄闲关系。
4. 财神不能进副露，因此不会成为补杠牌。

#### 胡牌落地
1. 记录胡牌类型、进张、来源座位、胡牌拆解、番型与番数。
2. 记录三财/四财翻倍触发标记。
3. 本局只取唯一胡牌座位，不启用一炮多响。
4. 抢杠胡成立后，副露中的补杠还原为碰用于展示；已有摊数维持原记录，不因抢杠新增摊数。
5. 进入结算。

### 6.7 过
1. 玩家放弃本次响应时，向全桌广播过牌提示。
2. 合法过牌放弃本次响应，不执行对应吃、碰、杠或胡；响应收齐后继续仲裁或推进摸打流程。
3. 杭麻未启用专门的过胡禁张机制，不因过胡额外登记禁胡牌。
4. 服务端收到过牌请求时先广播提示，再做合法性校验；非法请求也会先广播，是否符合产品预期【待确认】。

## 7. 特殊规则

### 7.1 飘财
1. 打出财神 → 开启飘财窗口，飘次数 +1，并广播。
2. 打出后手牌敲响 → 飘等级 +1；否则飘等级归 0 且杠链清零。
3. 窗口内除所有者外只能摸打，禁吃碰明杠补杠，暗杠允许。
4. 所有者再次出牌 → 窗口关闭。
5. 受限座位出牌只清除本次禁打；窗口仍在且其不是所有者时，下次继续受限。
6. 受限座位或其他人打出财神时，窗口所有者切换。
7. 打出非财神时，出牌者的飘等级归 0；吃、碰、杠本身不清飘等级，但吃、碰会清杠链。

### 7.2 十风
1. 首张出牌必须是字牌，否则本局资格失效。
2. 连续字牌计数 ≥10 后，每次自摸均可胡。
3. 中途打非字牌、吃、碰、任意杠 → 计数归 0、资格永久失效。
4. 十风为独占番型：只记十风，不与平胡/七对/杠开/财神系列叠加；三财/四财、封顶等额外倍率仍按开关生效。
5. 点数 = 2 × 2^(连续字牌数−10)：10 张 = 2 倍，11 张 = 4 倍，12 张 = 8 倍，依此类推。
6. 仅自摸生效；点炮、抢杠不生效。
7. 字牌包括东、南、西、北、中、发、白；翻财神时白板即使作为替代牌，打出仍计入字牌。
8. 有财必拷响开启时，十风自摸仍可按十风授权。

### 7.3 三摊承包
1. 仅庄闲之间；闲闲之间不承包。
2. 吃恒记摊；碰、明杠是否记摊由碰算摊决定；暗杠、补杠不记摊。
3. 庄闲之间累计 3 摊形成承包。
4. 承包结算规则：
   - 摊方胡牌 → 被摊方承包全部输分 ×1；
   - 被摊方胡牌 → 摊方倒承包全部输分 ×2；
   - 双向互满 3 摊 → 按倒承包 ×2。
5. 点炮：仅当放铳者本人是承包对方时才触发承包，第三方点炮不触发。
6. 自摸、点炮由承包关系整体接管付款人；未参与承包的玩家不付。
7. 抢杠胡：杠牌者保留“三家钱”赔付，承包/倒承包在其上独立叠加，不互相抵消。
8. 闲闲之间吃/碰/明杠最多 2 摊，第 3 次拦截；碰/明杠的摊数限制仅在碰算摊开启时生效。

### 7.4 跟庄（仅 4 人）
1. 软跟：最后一位跟庄者可用财神代替目标牌；硬跟：必须原张。
2. 状态机：
   - 未激活：仅庄家本局首张出牌触发，记录目标牌，剩余待跟人数 = 人数 −1；
   - 激活中：其他玩家首张出牌必须跟同张；
   - 非首张出牌、庄家再次出牌、打出不同牌 → 中断；
   - 吃、碰、杠 → 中断；
   - 剩余人数减到 0 → 跟庄成功。
3. 成功赔付：
   - 固定一片：庄家向每个闲家各付 1 份底分；
   - 摇骰子：重新掷骰（不重排牌墙），庄家向每个闲家各付“点数和 × 底分”。
4. 摇骰子方式进入独立阶段，广播骰子与赔付和，停留 3 秒后结算。
5. 跟庄分写入当局输赢，随胡牌分一起结算；流局也保留并展示。
6. 一局只处理一次跟庄，按首轮执行。
7. 牌局提前结束时，未完成的跟庄中断且不赔付；已成功的跟庄分保留。
8. 服务端未强制校验 4 人，设计限制由客户端承担。【待确认】

### 7.5 守庄（仅 3/4 人）
1. 触发对象：庄家的上家。
2. 触发前提：庄家上家手牌中没有实际财神。
3. 限制范围：
   - 3 人局：庄家上家不能碰庄家打出的牌；
   - 4 人局：庄家上家不能碰庄家、庄家下家打出的牌。
4. 仅禁碰；吃、杠不受限。
5. 被拦截时提示“守庄规则生效中”；简洁模式不提示。

### 7.6 牢庄
1. 牢庄档位决定庄家倍数：1 牢 = ×2，2 牢 = ×4，3 牢 = ×8。
2. 升牢：庄家胡牌，或流局且流局连庄开启 → 升 1 牢。
3. 换庄：重置为配置的起算档位。
4. 常规封顶 3 牢。

### 7.7 禁手
1. 吃禁手：吃中间禁打中间；吃两边禁打被吃牌与另一侧延伸牌。
2. 碰禁手：碰后禁打被碰牌。
3. 禁手在本座位下一次出牌后解除并通知客户端。
4. 吃禁手导致吃后剩余手牌全部禁打时，该吃法不成立。
5. 翻财神模式下，禁张与白板替代牌之间做归一化换算，避免误禁。

### 7.8 缺一色与去风
1. 缺一色：仅 2/3 人可开；牌墙去掉全部万字，共 100 张。
2. 去风：去掉风牌 16 张与红中/发财 8 张，保留白板 4 张，共 112 张。
3. 两项可同时开启：先去风再去万，共 76 张。

### 7.9 简洁模式
1. 服务端抑制的规则提示：守庄、巡限碰、吃禁手、有财必拷响、只碰不吃。
2. 不抑制：跟庄成功广播、飘财广播。
3. 客户端三摊落地动画、摸财神动效是否抑制【待核实】。
4. 规则本身仍然生效，仅影响提示与动效。

### 7.10 打片
1. 打片起始片数 >0 时进入打片房。
2. 每小局胡牌结束，任一座位片数 ≤0 → 触发大结算。
3. 连庄不占局数开启且本局庄家胡牌时，本次不触发；此后在符合条件的胡牌结算时重新检查。
4. 当前触发检查仅在胡牌小结算后执行；流局不检查片数，即使跟庄已产生输赢。
5. 杭麻未按付款方剩余片数截断本次付款，结算后片数可为负。连庄不占局数在此处只控制庄家胡牌时的片数结束判定，局数扣减需另行核实。

### 7.11 封顶与托管
1. 单局输分封顶：胡牌结算时，输家本局已有输分（含跟庄）与本次胡牌付款合计超过封顶 → 调整本次胡牌付款；赢家按调整后付款合计计算。纯流局跟庄分不经过该胡牌付款封顶流程。
2. 托管：超时或离线玩家自动摸打；自动摸打状态下不重复进入托管。

### 7.12 明牌
1. 明牌开启后，所有玩家手牌互相可见。
2. 明牌关闭时，仅自己可见。
3. 重连时按明牌配置决定他人手牌是否可见。
4. 结算亮牌不受明牌开关限制，按结算展示规则处理。

| SPEC-18 | 缺一色/去风 | 配置开启 | 缺一色去万字；去风去风牌+红中/发财，留白板 | 4人局缺一色不生效 |
| SPEC-19 | 简洁模式 | 配置开启 | 抑制守庄/巡限碰/吃禁手/有财/只碰不吃提示 | 跟庄、飘财不抑制 |
| SPEC-20 | 打片 | 好友房打片房胡牌结算后 | 任一座位片数≤0触发大结算；连庄不占局数开启且庄家胡牌时不触发 | 流局不检查；片数可为负 |
| SPEC-21 | 封顶 | 好友房胡牌结算且单局输分超限 | 按已有输分调整本次胡牌付款；赢家按调整后付款合计 | 纯流局跟庄分不经该流程 |
| SPEC-22 | 托管 | 超时/离线 | 自动摸打；自动摸打状态不重复进入托管 | 金币场默认开 |
| SPEC-23 | 明牌 | 配置开启 | 所有玩家手牌互见；重连同规则 | 结算亮牌另算 |

## 8. 番型与倍数

### 8.1 判定输入
番型判定基于：胡牌来源、拆牌结构、手牌/副露/进张、实际财神与财神计数、敲响状态、飘等级、杠链、飘杠先后、连续字牌数、相关规则开关。

### 8.2 平胡（1 倍）
1. 拆牌结构必须是 3N+2。
2. 有财必拷响开启、手牌含财神、且为自摸 → 平胡不成立。
3. 其余情况只要 3N+2 成立即命中。
4. 全刻子 3N+2 也按平胡计。
5. 有财必拷响开启时，点炮/抢杠若手牌含财神，会在胡权限阶段被拦截，不会进入平胡；开关关闭时不因此拦截。

### 8.3 七对系列（2N）
#### 带财神组（手牌财神数 >0）
| 番型 | 倍数 | 四张相同组数 | 附加条件 |
|---|---|---|---|
| 七对 | 2 | =0 | 有财必拷响开启且自摸时，进张必须与财神成将，否则不成立 |
| 豪华七对 | 4 | =1 | 同上 |
| 双豪华七对 | 8 | =2 | 同上 |
| 三豪华七对 | 16 | ≥3 | 同上 |

#### 无财神组（“清”= 无财神）
| 番型 | 倍数 | 四张相同组数 |
|---|---|---|
| 清七对 | 4 | =0 |
| 豪华清七对 | 8 | =1 |
| 双豪华清七对 | 16 | =2 |
| 三豪华清七对 | 32 | ≥3 |

#### 四张相同组数的计算
1. 统计拆解中每个牌值的出现次数。
2. 将被财神补成的单张从对应牌值中扣除，得到“真实张数”。
3. 财神替豪七关闭：真实张数 ≥4 才算 1 组。
4. 财神替豪七开启：
   - 财神预算 = 手牌财神数 − 已用于补单张的财神数；
   - 每个牌值升级到 4 张所需额外财神 = 4 − 该牌值当前出现次数；
   - 必须有至少 1 张真实牌作锚点，纯财神组不算；
   - 按所需财神从少到多贪心分配预算，能完成几组就算几组。
5. 组内命中最高档后停止，低档不再重复计。

### 8.4 杠开系列（组内互斥）
| 番型 | 倍数 | 条件 |
|---|---|---|
| 杠上开花 | 2 | 自摸且杠链 =1 |
| 二连杠 | 4 | 自摸且杠链 =2 |
| 三连杠 | 8 | 自摸且杠链 =3 |
| 四连杠 | 16 | 自摸且杠链 ≥4 |

1. 杠链必须是“杠后未被非财神出牌/吃/碰打断”的有效链。
2. 点炮、抢杠不命中。
3. 组内取最高档。

### 8.5 财神系列（组内互斥）
#### 公共前提
1. 必须自摸。
2. 必须满足“进张与财神成将”：
   - 进张是财神 → 拆解中必须存在“财神 + 财神”将；
   - 进张不是财神 → 拆解中必须存在“进张 + 财神”将；
   - 翻财神模式下，进张为白板时按实际财神值比对。
3. 听牌提示场景（等待牌为“任意牌”）时，以敲响状态替代“进张与财神成将”判定。
4. 实际胡牌时当前代码未额外强制判断敲响；是否增加该前提【待确认】。

#### 分档
| 番型 | 倍数 | 飘等级 | 条件 |
|---|---|---|---|
| 爆头 | 2 | =0 | 自摸 + 进张与财神成将 |
| 财飘 | 4 | =1 | 自摸 + 进张与财神成将 |
| 双财飘 | 8 | =2 | 自摸 + 进张与财神成将 |
| 三财飘 | 16 | ≥3 | 自摸 + 进张与财神成将 |

1. 飘等级必须严格对应档位，不能跨档。
2. 进张未与财神成将时，即使手牌有财神也不命中财神系列。
3. 组内取最高档。

### 8.6 十风（独占）
1. 仅自摸。
2. 连续字牌数 ≥10。
3. 不要求手牌成 3N+2 或 2N。
4. 只记十风一条，不与任何其他番型叠加；三财/四财、封顶等额外倍率仍按规则生效。
5. 点数 = 2 × 2^(连续字牌数−10)。

### 8.7 组合番型
| 番型 | 倍数 | 产生条件 |
|---|---|---|
| 杠飘 | 8 | 同时命中“杠上开花”和“财飘”；杠在飘之前 |
| 飘杠 | 8 | 同时命中“杠上开花”和“财飘”；飘在杠之前 |
| 七客 | 七对系列 × 财神系列 | 七对系列与财神系列同时命中，按乘积计算，不单列 ID |

1. 杠飘/飘杠只在基础档拆分：杠链 =1 且飘等级 =1。
2. 更高档组合（二连杠、双财飘等）不拆分，按基础番型连乘。
3. 飘杠先后由杠执行时的飘等级决定：杠时飘等级 >0 → 飘杠；否则 → 杠飘。

### 8.8 结算层倍率
1. 三财翻倍：开关开启且财神总数 ≥3 → 最终番数 ×2。
2. 四财翻倍：开关开启且财神总数 ≥4 → 最终番数 ×2。
3. 两项独立判断；同时满足时连乘，最高 ×4。
4. 财神总数 = 手牌财神数 + 出牌区已打出财神数；不含副露。
5. 倍数封顶：金币场可配置最大倍数，最终番数超过上限时按上限截断。

### 8.9 番型选择顺序与乘积
1. 若连续字牌数 ≥10 且自摸 → 只取十风，直接结束。
2. 否则依次取三组：
   - 基础/七对组：按“三豪华清七对 → 双豪华清七对 → 豪华清七对 → 清七对 → 三豪华七对 → 双豪华七对 → 豪华七对 → 七对 → 平胡”顺序，命中第一个即停；
   - 杠开组：按“四连杠 → 三连杠 → 二连杠 → 杠上开花”顺序；
   - 财神组：按“三财飘 → 双财飘 → 财飘 → 爆头”顺序。
3. 若同时命中“杠上开花”和“财飘”，替换为“杠飘”或“飘杠”。
4. 最终番数 = 命中番型倍数的乘积。
5. 再乘三财/四财翻倍与十风超出部分。
6. 最后按倍数封顶截断。
7. 若一条番型都未命中 → 不成立胡牌。
8. 普通胡牌存在多种合法拆解时，逐个计算番数，选取最高番方案；同番时按财神将、番型及展示拆解对齐情况选取，具体展示以服务端最终拆解为准。

### 8.10 示例
| 组合 | 计算 |
|---|---|
| 七对 + 财飘 | 2 × 4 = 8 |
| 豪华七对 + 双财飘 | 4 × 8 = 32 |
| 杠上开花 + 财飘 | 杠飘 8，不重复 2×4 |
| 十风 12 张 + 四财翻倍 | 2×2^(12−10)=8，再 ×2 = 16 |
| 平胡 + 三财翻倍 | 1 × 2 = 2 |

牌例：白板为财神，无副露、无飘、无杠链，有财必拷响关闭。进张前手牌为 123万、123条、123筒、东东东、白；自摸 9万后以“白 + 9万”作将，命中平胡 ×1 和爆头 ×2，番数为 2。是否还须显式满足敲响见 §3.4。

多拆解牌例：白板为财神，无副露、无飘、无杠链，也未触发三财/四财翻倍或番数封顶；进张前手牌为 1万×2、2万×2、3万×2、4万×2、5万×2、6万×2、7万×1，自摸 7万。既可拆为清七对 ×4，也可拆为 123万×2、456万×2、77万的平胡 ×1；当前代码取较高番的清七对 ×4。

## 9. 结算

### 9.1 结算参数
| 参数 | 含义 |
|---|---|
| B | 底分 |
| F | 番型倍数（含三/四财、十风超出、倍数封顶） |
| M | 牢庄倍数 = 2^牢庄档位 |
| D胜 | 胡牌方加倍倍数（1 或 2） |
| D付 | 付款方加倍倍数（1 或 2） |

### 9.2 基础赔付
| 胡型 | 付款方 | 应付金额 |
|---|---|---|
| 点炮 | 放铳者 | B × F × M × D胜 |
| 抢杠胡·庄家赢 | 杠牌者 | B × F × M × (人数−1) × D胜 |
| 抢杠胡·闲家赢 | 杠牌者 | B × F × (M + 人数−2) × D胜 |
| 自摸·庄家赢 | 每个闲家 | B × F × M × D胜 |
| 自摸·闲家赢 | 庄家 | B × F × M × D胜 |
| 自摸·闲家赢 | 其他闲家 | B × F × D胜 |

说明：
1. 点炮不额外翻倍。
2. 抢杠胡“三家钱”按实际人数折算；2 人局按 1 个对手。
3. 闲家自摸时，只有庄家承担牢庄倍数，其他闲家不乘牢庄倍数。
4. 以上付款金额为负值，记入付款方。

### 9.3 三摊承包改写
1. 仅三摊承包开启时执行。
2. 只处理胡牌方本人参与的承包对；未参与的对不结算。
3. 只处理庄闲对；闲闲对跳过。
4. 点炮时只处理“放铳者 = 承包对方”的对。
5. 对每个承包对：
   - 胡牌方对对方 ≥3 摊（胡牌方是摊方）→ 对方承包全部输分 ×1；
   - 对方对胡牌方 ≥3 摊（对方是摊方）→ 对方倒承包全部输分 ×2；
   - 双向都 ≥3 → 按倒承包 ×2。
6. 无任何承包对 → 保持原付款结构。
7. 抢杠胡：承包金额独立叠加在原付款上，不接管。
8. 点炮、自摸：承包金额整体替换付款结构，未参与承包者不付。
9. 承包明细随结算下发：赔付方、胡牌方、金额、承包/倒承包类型。
10. 多个承包对同时成立时，每个承包方分别按“全部输分基数”承担，不共同分摊一份。例：庄家胡牌，两名闲家各自对庄家有 3 摊（两名闲家均为摊方）→ 两名闲家分别按全部输分 ×2 赔付。是否符合产品预期【待确认】。
11. 承包明细在承包计算后乘付款方自身加倍，但不会随之后的好友房单局输分封顶、金币场财富/携带封顶重新计算；明细金额可能不同于最终实扣，以各座位最终输赢为准。

### 9.4 加倍补乘
1. 胡牌方加倍已在基础公式中作为 D胜 乘入。
2. 承包改写完成后，对每个最终付款方再乘其 D付。
3. 承包明细金额同步乘承包商自己的 D付。
4. 未成为最终付款人的玩家，其自身加倍不计入承包基数。

### 9.5 封顶
封顶包括番型倍数封顶、单局输分封顶、金币场财富/携带封顶；分别作用于番数、单局输分和金币场真实入账。

### 9.6 单局输分封顶
1. 仅好友房配置 >0 时生效。
2. 对每个付款方：本局已产生输分（含跟庄）+ 本次应付 < −上限 → 本次应付改为“−上限 − 已产生输分”。
3. 记录命中封顶的座位。
4. 赢家胡牌得分 = 付款方调整后带符号金额之和取负；本局总分再计入已有跟庄分。正常情况下付款为负，等价于付款金额绝对值之和。
5. 边界：若胡牌前已因跟庄产生超过单局上限的亏损，按公式可能出现“正应付”；该组合需联调确认产品预期。
6. 该计算只在胡牌结算时调整本次付款，不单独截断纯流局的跟庄分。

### 9.7 结算顺序
1. 按胡型计算基础赔付。
2. 三摊承包/倒承包改写付款人。
3. 付款方个人加倍补乘。
4. 单局输分封顶。
5. 赢家胡牌得分 = 各付款方带符号应付金额之和取负，再与已有跟庄分合并。
6. 金币场按各视角执行财富/携带封顶。
7. 累计跨局统计（胡牌、爆头、财飘、财神数量）。
8. 下发小结算（使用本局结算时牢庄档位）。
9. 逐座位写分（带当前牢庄档位）。
10. 更新牢庄档位；下一局开局时判定庄家。
11. 打片房判定是否进入大结算。
12. 结束本局。



### 9.8 流局
1. 流局不产生胡牌输赢分。
2. 已产生的跟庄赔付正常结算并下发。
3. 未完成的跟庄中断且不赔付。
4. 流局后按流局连庄配置决定庄家是否继续。
5. 流局也写分记录，保证座位齐全。
6. 纯流局跟庄分不经胡牌付款封顶；打片房流局不执行片数结束检查。

### 9.9 大结算
1. 房间结束或解散时汇总各小局得分。
2. 胜负按总分正负判定。
3. 附加统计：胡牌次数、爆头次数、财飘次数、财神数量（手牌 + 出牌区 + 胡牌进张）。

### 9.10 结算示例
设 4 人局，B=10，F=4，庄家 3 牢 → M=8，无人加倍。点炮/抢杠胡仅在三牢且对应开关开启时可触发；自摸不受牢数限制。

| 场景 | 计算 | 结果 |
|---|---|---|
| 庄家自摸 | 每个闲家 10×4×8=320 | 庄家 +960，三闲各 −320 |
| 闲家自摸 | 庄家 10×4×8=320；两闲各 10×4=40 | 闲家 +400，庄家 −320，两闲各 −40 |
| 闲家点炮给庄家 | 放铳闲家 10×4×8=320 | 庄家 +320，放铳者 −320 |
| 庄家点炮给闲家 | 庄家 10×4×8=320 | 闲家 +320，庄家 −320 |
| 闲家抢庄家杠 | 10×4×(8+2)=400 | 闲家 +400，杠牌庄家 −400 |
| 庄家抢闲家杠 | 10×4×8×(4−1)=960 | 庄家 +960，杠牌闲家 −960 |

承包示例（4 人，庄家 Z，闲家 A）：
- A 对 Z 有 3 摊，A 胡牌 → Z 承包全部输分 ×1。
- Z 对 A 有 3 摊，A 胡牌 → Z 倒承包全部输分 ×2。
- A、Z 双向都满 3 摊，A 胡牌 → 按倒承包 ×2。
- 庄家 Z 胡牌，闲家 A、B 各自对 Z 有 3 摊 → A、B 分别按全部输分 ×2 赔付，不共同分摊。

加倍与承包示例：4 人局，底分 10、平胡 1 倍、庄家 1 牢，庄家自摸且加倍。基础为每个闲家 10×1×2×2=40，全部输分基数为 120。闲家 A 对庄家有 3 摊，A 倒承包 ×2；若 A 自身也加倍，A 最终应付 120×2×2=480，其余闲家的加倍不计入该承包基数。以上未考虑封顶或已有跟庄分。

### 9.11 结算客户端展示需求

**目标**：玩家在结算页能看懂“谁胡、怎么胡、赢多少、为什么”。服务端应在结算时提供上述数据，客户端负责展示。

**客户端必须展示**
1. 结算结果：胡牌 / 流局 / 被动结束。
2. 胡牌信息：胡牌玩家、胡型（自摸/点炮/抢杠）、番型名称、番数、进张、来源玩家。
3. 输赢信息：每名玩家的本局得分、倍数、封顶/破产状态。
4. 承包信息：承包方、被承包方、承包/倒承包类型、金额。
5. 额外得分：跟庄分等；无则不展示。
6. 牢庄信息：本局结算时牢庄档位与倍数。
7. 加倍信息：各玩家是否加倍。
8. 亮牌信息：胡牌手牌与拆解；全桌手牌、副露、剩余牌墙是否展示由产品确认。

**展示规则**
1. 最终得分以结算结果为准，额外分明细不得重复计分。
2. 番型明细缺失时，客户端应能按胡牌明细中的番型与番数展示。
3. 十风赢家的胡牌手牌按出牌区字牌序列展示；全桌手牌区仍展示实际手牌。
4. 结算亮牌与普通重连的手牌可见性规则不同。
5. 结算展示使用本局结算时牢庄档位，下一局牢庄在结算后更新。
6. 承包明细为封顶前口径，不应直接当作最终实扣；金币场每位玩家收到自己的结算视角，其他座位在该视角中的分值不保证等于其真实入账。

### 10.1 默认、固定与不解析

| 默认（可被等级规则覆盖） | 放铳关、三摊承包开、碰不算摊、加倍开、托管开、十风开、吃/碰禁手开、有财必拷响关 |
| 不解析 | 跟庄、守庄、缺一色、去风、只碰不吃、简洁模式、单局输分封顶、打片、连庄不占局数 |

金币场等级规则可覆盖项：放铳、三摊承包、碰算摊、有财必拷响、十风、吃禁手、碰禁手、打牌超时、加倍开关、加倍超时、托管等待、托管开关。做牌、明牌和最大倍数从金币场根 JSON 读取；当前代码要求 `game_rule` 为对象才继续加载，其中最大倍数在应用存在的等级规则对象时读取。

### 10.2 底分与台费
1. 入场配置解析：各座位用全桌最低金币匹配自己的底分区间表；无匹配时使用该座位入场配置中的底分、台费。非混级房随后统一为最低底分及其对应台费，并将该底分写为本局基础底分；混级房不执行此归一。
2. 开局再按每个玩家视角计算：
   - 取本桌所有玩家虚拟金币的最小值；
   - 用该视角玩家自己的底分区间表匹配底分/台费；
   - 匹配失败 → 取最低金币座位已记录的底分/台费；
   - 底分为 0 时回退默认底分。
3. 开局重匹配后未再次统一各座位底分/台费；即使非混级，区间表不同或匹配失败时也需按各自记录核对，是否要求统一【待确认】。
4. 结算阶段直接读取开局记录，不重新匹配。

### 10.3 输赢上限算法
按每个视角分别计算，避免混级房互相污染。

定义（以视角玩家 V 为基准）：
- 携带值 = V 视角下目标座位虚拟金币 − 台费，下限 0；
- 理论赢 = 该座位正分；若配置最大倍数，则理论赢不超过“最大倍数 × V 底分”；
- 理论输 = 该座位负分的绝对值；
- 实际最大赢 = min(理论赢, 携带值)；
- 实际最大输 = min(理论输, 携带值)；
- 原始赢分 = 封顶前该座位正分（未经最大倍数截断）；
- Y1 = 所有赢家实际最大赢之和；
- S1 = 所有输家实际最大输之和。

分三种情况：
| 情况 | 处理 |
|---|---|
| Y1 = S1 | 赢家得实际最大赢，输家扣实际最大输 |
| Y1 < S1 | 赢家各得实际最大赢；输家按理论输占比分摊 Y1，每人不超过实际最大输 |
| Y1 > S1 | 输家各扣实际最大输；赢家按理论赢占比分摊 S1，每人不超过实际最大赢 |

分摊算法：
1. 每轮按权重比例分配；
2. 达到个人上限者立即封顶并退出本轮；
3. 剩余额度继续由未封顶者按比例分摊；
4. 直到分完或全部封顶；
5. 最后一轮整除余数按 1 分逐个补齐。

状态标记：
| 状态 | 判定 |
|---|---|
| 倍数封顶 | 配置的最大倍数 >0，且“最大倍数 × 视角底分” ≤ 携带值；赢家分到实际最大赢且实际最大赢 < 原始赢分 |
| 输赢封顶 | 赢家分到实际最大赢，且实际最大赢 < 原始赢分，且不满足倍数封顶条件 |
| 破产 | 输家携带值 >0，实际产生扣分且扣满携带值 |
| 正常 | 其他 |

未配置有效最大倍数（≤0）时，不会标记为倍数封顶。

平衡校正：
1. 若单个视角快照内分值和 ≠0，按比例向赢家扣回或向输家退回，直到该快照总和为 0。
2. 该校正只保证“每个视角快照自身平衡”；不能据此推断各座位真实入账总和必为 0。
3. 混级房真实入账取各座位自己视角的对角线，是否守恒需联调验证。

最大倍数有两道作用：胡牌番数计算时先按 `max_mult` 截断；金币结算时再将每个赢家的理论赢分限制在 `max_mult × 该视角底分`。两道限制分别作用于番数和赢家总分，后者不等同对每个输家单独封顶。

示例：4 人局，底分 10、胡牌番数 4、庄家三牢且自摸，无加倍和承包，基础应收 960。若有效最大倍数为 10，番数 4 不截断，但赢家理论赢分上限为 10×10=100；在赢家和三名输家携带值充足时，该视角赢家实得 100，输家合计付 100。

### 10.4 写入
1. 每个座位读取自己视角快照中“自己座位”的值（对角线），不读取他人视角。
2. 写入虚拟分时携带台费。
3. 结算数据附金币场埋点：是否庄家、底分、结算结果、总番、胡牌轮数、玩法结果、有财必拷响标记、房间等级。
