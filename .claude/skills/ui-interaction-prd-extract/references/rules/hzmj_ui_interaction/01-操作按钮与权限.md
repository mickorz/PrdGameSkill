# 操作按钮与权限（客户端 UI 交互基准）

> 来源：42319 代码逆向。锚点格式：文件 → 方法。检查需求文档对操作按钮、权限到达后的界面变化的描述是否完整、与实现一致。

## 一、权限驱动按钮显隐

1. 权限是位掩码：过1(0x0001 无需上报)、过2(0x0002 需上报)、出牌(0x0004)、吃(0x0008)、碰(0x0010)、胡(0x0020)、杠(0x0040)、听(0x0080)、补(0x0100)。锚点：config/BoxMahDefine.ts → PowerType
2. 服务端权限消息到达后按位解析，逐个设置碰/杠/胡/过/过2按钮 visible；已胡后即使带出牌位也不可出牌。锚点：layer/BoxHzmjMainView.ts → setPower / _getPowerShowState
3. 操作区由控制器 C_BtnState 驱动页面切换：0=空白、3=碰杠胡、4=选择多杠、5=报听选择；碰/杠/胡任一可显示时切 3，否则回 0。锚点：BoxHzmjMainView.ts → _updatePowerBtnState
4. 他人收到权限时自己操作区直接收起（关按钮区、锁手牌、清提示）。锚点：BoxHzmjMainView.ts → setPower / closeOperate
5. 杭麻无吃操作界面入口（按钮未注册）、报听已移除（按钮空实现且强制隐藏）。锚点：BoxHzmjMainView.ts → initSkin / onBtnBaoTing

## 二、按钮行为与互斥

6. 两个过按钮分工：过（需发服务端）点击后 sendCancel 上行；过2（无需上报）点击仅本地收尾不发任何包。锚点：BoxHzmjMainView.ts → onBtnGuo / onBtnGuo2
7. 硬互斥：有胡权限且操作区在展示态时，任何出牌尝试（单击/双击/滑动）都被拦截，必须先点过；提示"点'过'才能出牌"3 秒。锚点：BoxHzmjMainView.ts → canPlayMahCheck
8. 胡按钮内容联动：显示要胡的那张牌牌面 + 倍数文本（"X倍"）；点炮/抢杠胡皮肤用"hu"，自摸用"zimo"。锚点：BoxHzmjMainView.ts → _updateHuPower
9. 杠单组合 vs 多组合：仅一种杠直接发送；多于一种先进入选择多杠态显示牌面列表，点列表项确认后发送；多杠态下点取消 = 同时执行过（发 sendCancel）。锚点：BoxHzmjMainView.ts → onBtnGang / showMoreGang / onBtnCancel
10. 碰只有一种组合固定直接发送，无选择列表。锚点：BoxHzmjMainView.ts → onBtnPeng
11. 每个权限按钮点击后有 0.5 秒防连点（touchable=false 后延迟恢复）。锚点：BoxHzmjMainView.ts → onDelayBtnTouchu

## 三、手牌交互

12. 出牌三种方式：单击直接出（需设置项开启）、双击（先提再点同牌出）、滑动出牌（需设置项开启且仅限单张提起态，滑出牌区显示幽灵牌跟随）。锚点：mahModule TouchHandCardsBaseBox → _handleTouchUpCard 等；设置项 common_game CommonGameData → getBoxAloneOpen / getBoxSlidePlay
13. 打听牌禁止单击直接打出（强制提牌看听牌信息后用双击/滑动出）。锚点：BoxHzmjMainView.ts → canPlayMahCheck
14. 提牌/放下：点击抬起牌上移并回调通知（联动听牌弹窗）；同时最多抬起 1 张，超限自动放下最早的。锚点：TouchHandCardsBaseBox → upDownCard
15. 有碰或杠权限且无胡权限时，除目标牌外整手置灰；有胡权限或无碰杠权限时清灰（已胡保护不清）。锚点：BoxHzmjMainView.ts → _updatePowerGray / onClearGray
16. 置灰颜色优先级：黄 > 灰 > 财神红 > 正常。锚点：TouchHandCardsBaseBox → _resolveMahColor
17. 置灰清除时机：点碰/杠/过按钮、收操作区、他人权限到达，三处都会清灰。锚点：BoxHzmjMainView.ts → onBtnPeng / closeOperate
18. 出牌后理牌动画：摸的那张飞起、旋转、平移插入排序位；托管出牌路径不走理牌直接重摆。锚点：TouchHandCardsBaseBox → liPai
19. 快出牌开关：房规或匹配场时出牌飞行动画时长由 0.15s 缩到 0.1s。锚点：BoxHzmjMainView.ts → initSelfHand

## 四、权限到达的连带界面变化

20. 倒计时：中央数字逐秒倒数，最后 3 秒切红色字体，自己回合且未自动胡时播倒计时音效；>999 不显示；复盘模式不显示。锚点：layer/BoxHzmjMah2DView.ts → setClock
21. 方位盘当前行动家亮光呼吸闪烁、其他灭；行动家头像显示循环光框；同一时刻只有一个座位亮。锚点：BoxHzmjMah2DView.ts → setDeskCentLight；layer/BoxHzmjPlayerView.ts → onShowPower
22. 首出提示：本局第一次出牌权限时显示庄/闲提示条（按自己是否庄家切文案）、隐藏骰子，仅显示一次。锚点：GamePowerCmd → _updateFirstPlayTips
23. 倒计时进行中他人超 8 秒未操作时弹道具引导提醒层（仅他人）。锚点：BoxHzmjMah2DView.ts → tipPlayerOperation
24. 权限上行全部携带询问编号 askid（出牌/过/胡/碰/杠），服务端据此匹配应答。锚点：data/GameData.ts → setPowerAskid；gameController.ts → sendPlay 等

## 五、操作区收起的统一时机

25. 自己出牌后、碰/杠确认回包、胡牌回包、流局、托管——五类事件统一收操作区。锚点：各 cmd dispatch onCloseOperate；BoxHzmjMainView.ts → closeOperate
