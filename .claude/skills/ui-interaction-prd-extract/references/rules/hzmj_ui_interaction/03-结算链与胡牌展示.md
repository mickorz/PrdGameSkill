# 结算链与胡牌展示（客户端 UI 交互基准）

> 来源：42319 代码逆向。检查需求文档对局终动画顺序、小/大结算、摊牌、飘分的描述完整性。

## 一、局终动画四步链

1. 局终主入口（胡牌结果命令）按固定顺序执行：收操作区 → 隐藏出牌放大 → 摊牌前置处理 → 各家胡牌态 → 四步动画链：①点炮/一炮多响动画+赢家番型动画 → ②摊牌+台面标识（每步停留 1.5 秒）→ ③小结算 → ④大结算。锚点：controller/cmd/gameCmd/GameResultHuCmd.ts → _playHuAnimations
2. 流局路径：摊牌 → 隐藏听牌按钮/听牌弹窗/出牌放大 → 收操作区 → 倒计时与方位光熄灭 → 结束类型切"荒牌"页。锚点：controller/cmd/gameCmd/GameDrawnCmd.ts → execute
3. 台面标识枚举：未叫嘴/叫嘴/点炮/胡炮/自摸，按胡型与叫嘴数据标注每人头顶。锚点：config/GameDefine.ts → ResultTableSign；GameResultHuCmd → _updateRobKongHuView

## 二、胡牌表现

4. 摊牌：所有有手牌的玩家手牌推倒，胡家手牌末张落地图，自己手牌右移缩小；完成后延迟 1 秒发应答推进流程。锚点：layer/BoxHzmjMah2DView.ts → playHuEnd
5. 胡家手牌置胡牌态并重排、显示胡牌来源指示；点炮时从炮手河牌移除最后一张；自己胡后手牌禁止触摸。锚点：BoxHzmjMah2DView.ts → setHu
6. 胡牌光柱动画需设置"显示特效"开启且非复盘且有特效换装。锚点：layer/BoxHzmjTipAniView.ts → onMsgPlayHuLight
7. 点炮/一炮多响动画：一炮多响与单点炮不同皮肤；番型动画按番型选皮肤，未配置回落平胡；特效关闭时只播简单胡/自摸动画。锚点：BoxHzmjTipAniView.ts → onMsgHuDianPaoAni / onMsgPlayHuNew
8. 飘分：有分数变化的座位逐个播分数动画（正负分字体区分），全部座位动画完成才进下一步；有 runId 防串台与保底兜底机制（动画回调丢失时强制触发）。锚点：BoxHzmjTipAniView.ts → onShowResultScore / onClearResultScore
9. 番型动画番型选取：胡牌过程命令按升序取最小番型、局终命令按降序取最大番型（两处口径不同，需求需注意）。锚点：GameHuExCmd → 取最小；GameResultHuCmd → 取最大

## 三、小结算

10. 小结算数据：庄座位、输赢、叫嘴、手牌、额外流水、结束类型、剩余牌墙；流水文案格式"动作(番名)[方位] ±N分"，按人数生成方位文案（本家/上家/下家/对家）。锚点：controller/cmd/helperCmd/ResultCmd.ts → 数据组装
11. 一炮多响放炮流水去重：按来源座位排序拼接，额外番只叠加到第一条避免重复计分。锚点：ResultCmd.ts → 一炮多响去重
12. 小结算界面每家显示：头像昵称、方位、分数（正负字体区分，大数字格式）、庄标、胡牌单放牌、组合牌（杠 4 张页/暗杠背面）、手牌列表、胡型、叫嘴标识、流水汇总与总番。锚点：common_game BoxRoomGzmjResultView.ts → 视图组装
13. 小结算外围按钮：剩余牌按钮（有剩余牌墙才显示）、安全按钮（非匹配场）、洗牌按钮（盒内道具）、幸运按钮（自己赢且非最后一局）、按住半透明查看牌桌。锚点：BoxRoomGzmjResultView.ts → 按钮组
14. 继续游戏按钮：最后一局 → 转弹大结算；否则关小结算 + 自动准备下一局。锚点：BoxRoomGzmjResultView.ts → onBtnGoon
15. 匹配场关闭按钮：小结算缩成角标并显示牌桌（不关）；非匹配场直接关。锚点：BoxRoomGzmjResultView.ts → onBtnClose
16. 自己胡出超基础组合番型时手机震动一次（复盘不震）。锚点：ResultCmd.ts → 震动

## 四、大结算

17. 大结算数据只存不弹：解析总分通知，按座位排序，组装总局数/起止时间/房主/游戏名/解散人 + 每家明细（自摸/接炮胡/叫嘴/未叫嘴次数）。锚点：controller/cmd/helperCmd/TotalResultCmd.ts
18. 大结算弹出时机：动画链第 4 步延迟 2 秒后弹出（已显示则跳过防重）；解散局跳过动画链立即弹出。锚点：layer/BoxHzmjMainView.ts → showBoxTotalResultView；gameController.ts → gameTotalResult
19. 收到大结算事件后小结算强制切"最后一局"页。锚点：BoxRoomGzmjResultView.ts → onTotalResult

## 五、重连与复盘分支

20. 复盘模式局终：只做隐藏出牌放大 → 抢杠拆牌 → 摊牌 → 台面标识；小结算不弹改上报完成、大结算不弹。锚点：GameResultHuCmd.ts → replay 分支
21. 重连在结算阶段：静默重放胡牌数据后，对有胡牌标记的座位恢复台面标识与摊牌。锚点：controller/cmd/helperCmd/RecoverHuInfoCmd.ts
