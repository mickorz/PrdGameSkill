# 断线重连与场景恢复（客户端 UI 交互基准）

> 来源：42319 代码逆向。检查需求文档对重连恢复流程、恢复顺序、补刷项的描述完整性。

## 一、场景快照恢复机制

1. 重连入口是场景应答：非空闲状态时按服务端时钟恢复倒计时基准、记录流逝时间、恢复记牌器开关，再走场景恢复。锚点：common_game/controller/tableController.ts → respSceneData
2. 场景恢复按状态分发五个场景命令：开始/做牌/发牌/行牌/洗牌快照；状态无映射不执行任何恢复。锚点：42319/controller/gameController.ts → HZMJ_SCENE_HANDLER_BY_STATE
3. 行牌快照恢复顺序固定：开局数据(静默) → 玩家信息(静默) → 游戏配置 → 局数据 → 牌墙 → 手牌 → 河牌 → 权限(完整路径) → 恢复倒计时/方位灯/头像框 → end_wait 自动应答。锚点：controller/cmd/sceneCmd/SceneActionCmd.ts → execute
4. 恢复完固定补刷：上报 GPS、切换局内状态、头像位置切换、显示自己玩家。锚点：gameController.ts → gameSceneBack
5. 各恢复子命令走"只写数据缓存、不触发界面动画"模式；骰子用"跳过动画"模式静态展示（播一次入场帧后不自动隐藏）。锚点：各 cmd 的 justUpdateData 分支；BoxHzmjMah2DView.ts → showDice skipAni
6. 他人手牌恢复为背面立牌（不翻开）。锚点：controller/cmd/helperCmd/RecoverHandsCmd.ts → isShow=false

## 二、恢复后单独补刷与不刷项

7. 补刷：庄家标识（局数据命令完整路径）、首出提示与骰子隐藏（权限命令补判）。锚点：GameJuDataCmd → execute；GamePowerCmd → _updateFirstPlayTips
8. 补刷：权限与按钮按位完整恢复（碰/杠/胡/过显隐、手牌置灰、听牌按钮隐藏）；他人权限立即收操作区。锚点：GamePowerCmd → execute；BoxHzmjMainView.ts → setPower
9. 补刷：河牌恢复后若最后出牌者与最后河牌一致，补箭头位置与出牌放大。锚点：controller/cmd/helperCmd/RecoverOutsCmd.ts → execute
10. 不刷：行牌中重连骰子不展示；发牌/洗牌/做牌重连骰子静态展示不播完整动画。锚点：SceneActionCmd → THROW_CHIP 静默；SceneTakeFirstCmd → skipAni
11. 不刷：重连恢复不播开局动画、摸牌动画、胡牌动画（静默数据模式）。锚点：GameStartGameCmd / GameTakeCmd / GameResultHuCmd 的 justUpdateData 分支
12. 重连倒计时恢复：方位灯秒数比倒计时多 1 秒余量。锚点：SceneActionCmd → _recoverClock

## 三、end_wait 应答机制

13. 快照带 end_wait 时立即自动应答（防服务端等待卡死）；三个场景命令（行牌/发牌/洗牌）均有此检查。锚点：SceneActionCmd / SceneTakeFirstCmd / SceneMixCardCmd → _checkEndWait
14. 正常发牌动画完成时才解除重连标记并发应答；有 1 秒延迟兜底（摊牌后）。锚点：BoxHzmjMainView.ts → onTakeFirstAniSelf / sendEndWaitDelay
15. 非首局发牌后自动应答：第 2 局起跳过界面等待直接应答。锚点：GameStartGameCmd → setTakeFirstEndWait；GameEndWaitCmd → 消费标记
16. 胡牌多段动画中应答只发一次（防重标记）。锚点：GameHuExCmd → _playHuAnimations 的 _endWaitSent

## 四、断线表现

17. 断线：头像覆盖断线图标 + 分秒计时（mm:ss，不足 10 补 0），满 1 小时封顶显示"60:00"停表；断线时长初值按断线时间戳计算。锚点：common_game BasicPlayerComp.ts → showOffline / CountdownTime
18. 重连恢复后若在托管状态弹托管遮罩。锚点：tableController.ts → respSceneData 尾部检查
19. 回归提示：玩家任意操作数据到达即隐藏超时提示弹层 + 弹"玩家X已返回"3 秒横幅。锚点：gameController.ts → _playerBotHintTimeoutEnd
20. 断线不回滚牌局：动画播放过程中玩家断线不中断他人动画。锚点：需求侧规则，客户端无中断逻辑（实现事实）

## 五、死代码注意（防误报）

21. 两个重连专用事件已定义但全工程无派发点（死事件）；一个恢复命令注册但无执行点。需求文档若描述这些行为，与实现不符。锚点：FguiViewDefine.ts 死事件；helperCmd/RecoverHuInfoCmd.ts 无执行点
