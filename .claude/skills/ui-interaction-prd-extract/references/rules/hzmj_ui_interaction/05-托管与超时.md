# 托管与超时（客户端 UI 交互基准）

> 来源：42319 代码逆向。检查需求文档对托管、超时提示、托管惩罚的描述完整性。

## 一、托管类型与入口

1. 两种托管：托管(kBot) 与 自动摸打(kBotAuto)；房规开托管功能才生效。锚点：common_game/data/BoxRoomData.ts → getBoxRoomTrustee
2. 入口一：听牌组件上"自动胡"按钮（好友房走托管请求、匹配场走匹配托管请求）。锚点：layer/BoxHzmjMainView.ts → onBtnAutohu
3. 入口二：菜单"主动托管"：非出牌阶段弹"当前阶段无法主动托管"、已托管弹"正在托管中"；按钮可见性 = 房规开托管且处于出牌阶段。锚点：common_game GameMenuPopView.ts → onBtnTrust
4. 托管请求是 toggle 语义：已托管再点 = 取消；未托管时点操作按钮附带的取消托管请求是空操作。锚点：common_game/controller/tableController.ts → reqTrustee

## 二、托管界面表现

5. 进入托管：操作按钮组收回空白态、锁手牌出牌、清文字提示、清手牌置灰（未胡时恢复可触摸）；触发点：收到空权限（房规开托管）或自己碰/杠/胡结算后。锚点：BoxHzmjMainView.ts → onShowTrustee；GamePowerCmd → _checkShowTrustee
6. 托管遮罩：全屏蒙层盖住桌面（取消托管按钮唯一出口）；游戏结束时直接关（防结束后残留）。锚点：common_game GamePopTrustView.ts
7. 头像托管角标刷新口径：托管显示、自动摸打不显示托管角标。锚点：BasicPlayerComp.ts → showTrust
8. 自己"自动胡"按钮选中态随托管状态同步（进出托管刷新）。锚点：BoxHzmjMainView.ts → _checkBotAutoBtn
9. 他人进入托管：他人头像角标 + "X进入托管状态"横幅 + 托管举报计时启动。锚点：common_game NotifyPlayerActionCmd → kBot 分支

## 三、托管代打与惩罚

10. 客户端无本地代打逻辑：托管中出牌仍由服务端下发，客户端仅累计托管出牌次数。锚点：GamePlayCmd → addBotCount
11. 托管惩罚提醒：房规开托管解散且托管出牌次数达阈值（缺省 4 次）时，他人头顶弹"已托管出牌X次，若结算时为托管状态本局将解散，点击提醒他"；点击 = 微信分享提醒；只对他人显示；玩家回归时隐藏。锚点：common_game TableData.ts → addBotCount；BasicPlayerComp.ts → tip 文案与点击

## 四、超时提示体系

12. 出牌超时预提醒（服务端驱动）：玩家超时先弹"玩家X操作超时，超时Y秒自动解散房间/当前超时时间Z秒"提示层，视图内每秒自增计数；提示阈值缺省 60 秒、解散阈值缺省 300 秒（房间配置可覆盖）。锚点：NotifyPlayerActionCmd → kBotHintTimeout；BoxRoomTimeoutTipView.ts
13. 超时提示解除：该玩家任意操作数据到达且未断线 → 隐藏提示 + "已返回"横幅。锚点：gameController.ts → _playerBotHintTimeoutEnd
14. 离线解散预警：玩家离线触发预警提示（好友房缺省 600 秒，房间配置可覆盖）。锚点：GameUtil.ts → 时长配置；NotifyPlayerActionCmd → kOfflineDismissWarn
15. 取消托管刷新倒计时：当前行牌玩家取消托管或任何人取消自动时，按服务端剩余时间重设倒计时。锚点：BoxHzmjMainView.ts → onPlayerStateChange

## 五、倒计时超时兜底

16. 倒计时数字 >999 不显示（防异常值）；归零后显示"00"等待（无强制本地代打）。锚点：BoxHzmjMah2DView.ts → setClock
17. 他人倒计时超 8 秒未操作弹道具引导提醒层。锚点：BoxHzmjMah2DView.ts → tipPlayerOperation
