# 界面清单与弹层生命周期（客户端 UI 交互基准）

> 来源：42319 代码逆向。检查需求文档的界面清单完整性、弹层开合时机、防抖与清理规则。

## 一、界面清单（常驻视图）

| 界面 | 类型 | 打开方式 | 职责 |

| 背景层 | 常驻 Base·Back | 随场景创建 | 游戏背景+房间信息（游戏类型图/底分/开局状态） |
| 牌面层 | 常驻 Base·Card | 随场景创建 | 手牌/河牌/胡牌/组合牌/牌墙/骰子/倒计时/方位盘 |

| 提示动画层 | 常驻 Base·Ani | 随场景创建（不可交互） | 开局动画/庄家提示/飘分/碰杠胡动画/匹配面板 |

## 三、防抖规则

1. 听牌弹窗重复点击切换关闭；大结算已显示则跳过（防重弹）。锚点：BoxHzmjMainView.ts → onBtnTing / showBoxTotalResultView
2. 做牌弹窗关闭时先移除全局触摸监听再关。锚点：BoxHzmjSpecfView.ts → closeView
3. 弹窗资源预加载：听牌包与小结算包在进游戏时预加载（防弹结算卡顿）。锚点：Game42319.ts → preloadDir

## 四、清理规则（换房/再来一局/解散）

4. 再来一局：统一重置事件驱动所有视图各自清理（清数据/按钮态归零/隐藏大牌出牌/停动画/关小结算弹窗）。锚点：BoxHzmjMainView.ts → playAgain → onResetUI
5. 重新加入匹配队列：清数据 + 重置 + 重开匹配动画 + 刷新底分 + 隐藏换房按钮。锚点：BoxHzmjMainView.ts → onMatchJoinSuccess
6. 匹配桌解散：自己已准备则自动重新进匹配并隐藏换房按钮。锚点：BoxHzmjMainView.ts → onMatchRoomDismiss
7. 游戏结束：隐藏听牌相关、清倒计时、清飘分。锚点：GameEndCmd → onGameEnd 各视图
8. 头像层重置双语义：准备回包/重连时"不藏其他玩家头像"只清状态；重新匹配时隐藏其他三家。锚点：BoxHzmjPlayerMatchView.ts → resetUI 参数
9. 换座动画：头像飞中心再飞回，完成后通知服务端。锚点：BoxHzmjPlayerView.ts → onRandomSeat

## 五、界面加载与命名（实现参考）

10. 进游戏先清动态层注册；视图按序加载：背景 → 牌面 → 主界面 → 动画层（好友房加头像层）；进入时清掉大厅与加载场景弹层。锚点：Game42319.ts → start / init；BoxHzmjBackView.ts → _hideFguiAll
11. 仅定义名字常量无实现的界面（结算旧版/番型弹窗/流水视图等 7 个）不作为需求文档界面清单依据。锚点：config/FguiViewDefine.ts → 死定义
