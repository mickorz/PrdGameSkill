# 桌面常驻元素（客户端 UI 交互基准）

> 来源：42319 代码逆向。检查需求文档对倒计时、方位盘、剩余牌数、庄标、财神指示、出牌放大的描述。

## 一、倒计时

1. 中央两位数字逐秒倒数，<10 补前导零，归零显示"00"等待。锚点：layer/BoxHzmjMah2DView.ts → setClock
2. 配色：>3 秒默认蓝色，最后 3 秒切红色字体；自己回合且未自动胡时播倒计时音效。锚点：setClock → 字体切换
3. 阶段开始时按该阶段配置秒数刷新；流局时归零熄灭。锚点：GamePowerCmd → _updatePowerClock；GameDrawnCmd

## 二、方位盘

4. 按人数+东风座位选方位盘底图（2/3/4 人不同资源），东风座位由局数据门风决定，缺省回落庄家。锚点：BoxHzmjMah2DView.ts → onShowDeskCentBg；GameJuDataCmd
5. 方位光：当前行动家亮、其余灭；亮光随倒计时呼吸闪烁；同一时刻只亮一家；归零熄灭。锚点：BoxHzmjMah2DView.ts → setDeskCentLight
6. 行动家头像光框循环动画，同一时刻只有一个座位亮。锚点：BoxHzmjPlayerView.ts → onShowPower

## 三、剩余牌数

7. 剩余牌数组件挂在返回按钮栏；更新时机：发牌后、每次抓牌后；重置时隐藏。锚点：layer/comp/BoxHzmjMahLeftComp.ts → onUpdateMahCnt
8. 牌墙显示开关按玩家设置；牌墙按骰子和的奇偶推算哪边多一墩。锚点：GameWallMahCmd → resetWall；GameData → walls

## 四、庄标与庄家体系

9. 庄标：庄家头像显示庄标（控制器切页），重置全隐藏；换庄切到新庄家头像。锚点：BoxHzmjPlayerView.ts → onShowZhuang
10. 首出庄/闲提示：本局第一次出牌权限时显示提示条（按自己是否庄家切文案）+ 隐藏骰子，仅一次。锚点：GamePowerCmd → _updateFirstPlayTips
11. 连庄计数由局数据命令维护（连庄次数字段），庄家展示样式（平庄/庄二/庄三倍数文案）归玩法规则，UI 侧按倍数文案展示。锚点：GameJuDataCmd → setLianZhuangCount

## 五、财神指示

12. 现网客户端无财神指示牌视图与翻财神动画（财神命令无处理类，仅数据字段留存）；手牌癞子角标按配置牌表设置黄色角标。锚点：CmdDefine.ts → CMD_JOKER 无处理类；BoxHzmjPlayerHandCards.ts → updateHandCorner
13. 需求文档若定义中央财神指示牌/翻财神动画（如杭麻需求的"白板财神指示牌"），属新需求：记 P3 差异说明，提示标注"与现网实现差异"。锚点：基准说明检查口径 4

## 六、出牌展示

14. 他人出牌放大展示（按座位），受设置开关控制；碰/杠/胡/流局/重置时统一隐藏。锚点：BoxHzmjMainView.ts → showPutCardUi / hidePutCardUi
15. 最后出牌箭头指示；重连恢复时若最后出牌匹配则补箭头。锚点：RecoverOutsCmd → relinkSetArrowPos
16. 河牌区布局按人数切换资源（2/3/4 人），自己恒在下方。锚点：BoxHzmjMah2DView.ts → 出牌区布局
17. 同牌高亮：摸牌/出牌时全桌河牌/副露中同牌值高亮（复盘不生效）；放下提牌时清除。锚点：BoxHzmjMah2DView.ts → showSpecialMah
