# 开局流程（客户端 UI 交互基准）

> 来源：42319 代码逆向。检查需求文档对开局、定庄、掷骰、牌墙、发牌、理牌、洗牌道具的描述。

## 一、开局命令序列

1. 开局命令序列固定：开局数据 → 局数据（定庄）→ 牌墙 → 掷骰 → 发牌数据 → 首抓（触发发牌动画）。锚点：controller/cmd/CmdDefine.ts → 命令序列
2. 仅首局或非包厢播开局动画；第 2 局起跳过开场等待直接应答推进。锚点：GameStartGameCmd → onMsgStartAni 条件 / setTakeFirstEndWait

## 二、开局动画

3. 开局面板：每家显示头像/昵称（截 10 字）/分数；spine 播放中面板挂骨骼挂点（按人数 2/3/4 挂不同挂点）；面板淡出后发应答。锚点：BoxHzmjTipAniView.ts → onMsgStartAni
4. 动画兜底：spine 事件未触发时强制头像归位（防头像缺失）。锚点：TipAniView → 播完回调兜底
5. 匹配场等待面板：30 秒倒计时循环 + 8 秒轮播玩法提示文案；开局后隐藏。锚点：TipAniView → showMatch / updateMatchTips

## 三、定庄与掷骰

6. 定庄数据：庄家座位、连庄次数、门风（找东风值，缺省回落庄家）；界面刷新庄标+方位盘底图。锚点：GameJuDataCmd → execute
7. 掷骰：桌面中央两颗骰子 spine 动画，播完延迟 1 秒自动隐藏；重连静态展示（播入场帧后留到首出提示收起）。锚点：GameThrowChipCmd → setDice；BoxHzmjMah2DView.ts → showDice

## 四、牌墙与发牌

8. 牌墙：按骰子结果推算哪边多一墩；显示开关按玩家设置。锚点：GameWallMahCmd → resetWall；GameData → isSelfLong
9. 发牌数据（每家 13 张）仅更新剩余牌数；发牌动画由首抓命令触发：自己手牌先随机乱序背面 → 逐张翻牌 → 排序 → 解除重连标记 → 发应答；同时牌墙逐张消失（每张 0.25 秒）+ 发牌音效。锚点：GameTakeFirstCmd；GameTakeCmd → flag==0 分支；BoxHzmjMainView.ts → onTakeFirstAniSelf
10. 常规摸牌：自己摸牌滑入动画 + 凑牌动画检查（凑成顺/刻/杠按花色播动画）；他人直接摆牌；牌墙消一张 + 剩余牌数更新。锚点：GameTakeCmd → setTakeMah；BoxHzmjMainView.ts → onShowCouPaiAni

## 五、理牌

11. 出牌后理牌动画（插入式/平移式）由手牌组件执行；托管出牌不走理牌直接重摆。锚点：TouchHandCardsBaseBox → liPai；见操作按钮基准 18 条

## 六、洗牌道具（预约洗牌）

12. 预约条件：自己已胡 + 非最后一局 + 未预约 + 非复盘；当日首次显示带提示。锚点：BoxHzmjMainView.ts → onUpdateReserveShuffle
13. 洗牌动画：对每个预约座位播 spine（自己/他人不同动画段）；最后一个座位动画完成后发应答。锚点：GameMixCard.ts；TipAniView → KW_MixCard
14. 重连在洗牌阶段走洗牌快照恢复（静态骰子+牌墙+应答）。锚点：SceneMixCardCmd → execute

## 七、牌库与人数适配

15. 杭麻 136 张牌库（万条筒 108 + 风 16 + 箭 12）；每家初始 13 张。锚点：GameData.ts → maxWallNum=136 / _initHandCardNum
16. 2/3/4 人场：河牌区资源、方位盘底图、开局动画挂点、头像布局均按人数切换；座位映射表固定（自己恒 0 号 UI 位）。锚点：GameDefine.ts → SC_PLAYER_LOCAL_SEAT_MAP；各视图按人数分支
