# 共享需求提取命令速查（hzmj 项目）

阶段 2 起的正式提取命令。参数是**身份约定**（不程序化推导：projectKey 决定 REQ-ID 身份体系隔离单位，文件改名不得影响它）。

## 提取命令（opencode）

```
/workflow prd_requirements_extract
```

args：

```json
{
  "projectKey": "hzmj",
  "extractionRunId": "ext-YYYYMMDD-01"
}
```

- `projectKey`：固定 `hzmj`（身份隔离单位，永不从文件名推导）
- `extractionRunId`：`ext-<日期>-<序号>`，日期用当天（沙箱禁取当前时间，须显式传入），同日多次提取序号递增（01、02...，不覆盖）
- `inputFiles`：不传则自动扫描 `input/`（当前仅一份 PRD 时可省）
- `date`：runId 已显式时冗余，可不传

产物：`output/projects/hzmj/extractions/<extractionRunId>/`（requirements.json / manifest.json / source-manifest.json / validation.json），identity-map 在 `output/projects/hzmj/identity-map.json`（跨运行持久）。

提取采用「计划 + 机械切片」两段式，agent 不抄原文、不生成临时脚本：

- `plans/part-01.plan.json`：agent 写的提取计划（标题 + 行号 + 可选 `startText/endText` 片段锚点）
- `requirements/parts/part-01.json`：`slice-part.mjs` 从源文件机械切出的分片
- 命令输出 `[覆盖] 需求行 x/y`：未覆盖章节说明漏提，除文首/总览/目录/附录外须补齐后重跑

手工复跑切片（不改 workflow 时）：

```
node .opencode-workflows/scripts/slice-part.mjs output/projects/hzmj/extractions/<extractionRunId>/plans/part-01.plan.json
```

自检：`node .opencode-workflows/scripts/slice-part.example.mjs`

## 提取后的对齐验证（确定性脚本，直接跑）

```
node .opencode-workflows/scripts/align-check.mjs \
  examples/game-prd-check-workflow/rtm/runs/run-20261112 \
  output/projects/hzmj/extractions/<extractionRunId>/requirements.json \
  <报告输出目录> --min-rate 0.9
```

- 基线：game RTM run-20261112（363 条，11-11 版 PRD）
- 门槛：exact + anchor 对齐率 >= 90%
- 未匹配项进 `align-report.md` 人工确认清单，**不自动合并**
- 文件名已做跨版本归一（AI11-11 与 AI-11-12-2 剥版本段后视为同一文档）

## 统一 RTM 合并与统一 Dashboard（阶段 6-8 接入后）

```bash
# 1. 合并三维度产物为统一 rtm.json（game 必传，ui/bug 可选；悬空 REQ 拒绝）
node .opencode-workflows/scripts/rtm-merge.mjs output/projects/hzmj/unified-rtm/<日期> \
  --requirements output/projects/hzmj/extractions/ext-20261112-01 \
  --game examples/game-prd-check-workflow/rtm/runs/run-20261113 \
  --ui <ui 产物目录含 report.json> \
  --bug <bug 产物目录含 bug-verdicts.json>

# 2. 校验（结构/引用闭合/枚举/统计一致）
node .opencode-workflows/scripts/validate-rtm.mjs output/projects/hzmj/unified-rtm/<日期>/rtm.json

# 3. 生成含第 5 Tab「统一覆盖」的 Dashboard（不改原四 Tab；unified 不传则按钮隐藏）
node .claude/skills/game-prd-check/scripts/build-dashboard.mjs <report.md> <输出目录> \
  --rtm <game run 快照目录> \
  --unified-rtm output/projects/hzmj/unified-rtm/<日期>
```

注意：game run 目录的 `rule-catalog.json` 为顶层数组格式（rtm-merge 已兼容 `{ruleCoverage:[]}` 包装）。
