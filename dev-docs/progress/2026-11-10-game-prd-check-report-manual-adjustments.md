## 三、记录规范

1. 每次手动调整后，在“调整记录”表追加一行，写明改了什么、涉及哪些问题 ID 或章节、为什么改。
2. 涉及问题条目删除、合并、改优先级时，同时登记调整后的总数与优先级分布，便于与基线对比。
3. 涉及原始引文修改时必须注明“引文已人工核对”，避免与检查证据混淆。
4. 只记录对 report.md 的手工变更；workflow 脚本变更记入第 5 节，并在对应记录行的“workflow 回填”列标注规则编号。
