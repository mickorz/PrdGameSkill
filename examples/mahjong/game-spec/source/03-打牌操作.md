## 一、摸牌

| 项 | 内容 |
|---|---|
| **时机** | 轮到自己，且上一家已出牌、无人碰 / 杠 / 胡 |
| **衔接** | **摸牌需在上一家打出牌的同时进行**——肉眼可见上家打出牌的瞬间下家摸牌 |
| **来源** | 从牌堆取 1 张 |
| **后果** | 手牌 +1；随后进入出牌阶段 |
| **位置** | 摸到的牌置于手牌**最右侧**，与一般手牌**间隔 1/4 牌距离** |
| **展示** | 从手牌最右侧从上往下缓冲落下 |
| **理牌联动** | 每个打牌回合结束（出牌后）重新理牌，将刚摸进且未打出的牌**插入至手牌中**（详见 §12 理牌） |

**庄家首巡**：庄家起手 14 张，首巡**直接出牌**（不再摸牌）。🔎 **推导**：庄家起手 14 张 = 13 + 摸牌位 1 张（[基础规则 §1.2](01-基础规则.md)），且需求 §2.2.2【庄家】「由庄家先出牌」——两者合推得首巡无需再摸。

## 二、打牌（出牌）

### 2.1 条件与限制

| 限制 | 规则 |
|---|---|
| **危牌禁打** | **未亮倒玩家**手中**既有危牌也有非危牌**时，**无法打出危牌**（不计算碰杠牌区）|
| **全危牌例外** | 手中**全是危牌**时，任何危牌均可打出（**不计算碰杠牌区**，仅计算手中牌——含摸 / 补的牌）|
| **亮倒后** | 亮倒后不可改牌，只能摸打；只能打出**维持听牌**的牌 |
| **扣牌限制** | 扣下的牌带【扣】标签且带遮罩，**不可打出** |

**提示**：打出危牌时，出现浮动提示「打出该牌将会放炮！」。

### 2.2 出牌方式

| 方式 | 默认 | 说明 |
|---|---|---|
| **双击出牌** | **默认开启** | 出牌阶段点击**已提起**的牌可将该牌打出 |
| **单击出牌** | 默认关闭 | 出牌阶段点击不可听牌的牌**直接打出**，无需提起。开启时，若轮到自己出牌前有牌提起则自动下落 |
| **滑动出牌** | **默认关闭** | 出牌阶段**向上滑动手牌超过提起高度**可显示该牌透明状态牌，随手指移动；手指松开可将该牌打出；将牌移回提起高度水平线则透明牌消失、撤回打出 |

> **双击出牌与单击出牌互斥**；**滑动出牌不互斥**。
>
> **默认值依据**：以需求 §3.6.3.2「游戏内设置」表为准——该表是设置项的专门规格，每项有独立「默认状态」行（**单击出牌默认关闭、滑动出牌默认关闭**）。需求 §3.2.10.1 手牌操作章行文中的「滑动出牌（默认开）」为叙述性括注，**以设置表为准**。

### 2.3 提牌

| 项 | 内容 |
|---|---|
| **触发** | 单击牌面 |
| **效果** | 对应牌提起，提起高度约为牌高度的 **1/4**；**每次只能提起 1 张牌** |
| **放下** | 点击非牌面空白处可放下；**点击该牌牌面不能放下** |
| **滑动选择** | 可滑动选择多张牌，手牌依次提起、每次只提起 1 张；手指离开手牌时，**最终手指离开的对应牌提起** |
| **联动** | 提起【打出可听牌】时，弹出**听牌提示**页面 |

### 2.4 出牌后果

| 项 | 内容 |
|---|---|
| **摆放** | 本家：打出牌放置于该玩家面前牌堆中。其他家：开启「放大出牌」（默认开）时出牌放大展示，并放置于该玩家面前牌堆中，**下一个玩家有操作行为后消失**；不开启时直接放置 |
| **提示** | 出牌时**玩家头像处增加流光提示**；**方位处增加闪烁提醒** |
| **他人视角** | 其他家打出的牌**始终是摸到的那张牌** |
| **高亮** | 新摸到的牌或提起单张牌，若出牌河和碰牌区域存在同样的牌，则**高亮显示** |
| **牌河** | 牌河根据玩家出牌顺序从左至右依次摆放；**打出牌若被其他玩家碰、杠、胡，则不在牌堆中展示** |

### 2.5 超时托管

| 情况 | 托管行为 |
|---|---|
| **有提起的牌** | 走托管逻辑——**打新摸进来的牌** |
| **无提起的牌** | 走托管逻辑——**打新摸进来的牌** |

## 四、碰

| 项 | 内容 |
|---|---|
| **时机** | 任意一家打出一张牌时 |
| **条件** | 玩家手上有 **2 张及以上**相同的牌 |
| **范围** | **可以碰任何一家**的牌（不限上家）|
| **危牌** | **危牌可碰** |
| **后果** | 3 张组成刻子亮于手牌左侧；该玩家取得**出牌权**，须再打出 1 张 |
| **摆放** | 从左往右根据本局操作顺序放置，**放于手牌左侧**；展示牌面 |
| **方位箭头** | 碰牌上方显示箭头，指向对应碰牌方位：碰对家 ↑ / 碰上家 ← / 碰下家 → |
| **操作优先级** | **吃胡 / 自摸 / 抢杠胡 > 碰 / 杠** |
| **超时** | 配置开启托管时，**超时默认【过】** |
| **界面** | 手牌右上方显示【碰】+【过】；手牌中可碰牌高亮、其他暗置（**如果有胡则不需要暗置**）|

## 五、杠

### 5.1 杠的类型（含别名）

| 类型 | 别名 | 定义 | 前置条件 |
|---|---|---|---|
| **直杠** | 大明杠 | 别人打出某张牌，玩家手中存在相同的 **3 张** → 开杠 | 无 |
| **明杠** | **补杠 / 加杠** | 玩家**碰牌后**，除当前回合不可杠，后续摸到相同的牌 → 开杠 | 必须先碰过 |
| **暗杠** | — | **非碰牌后的出牌阶段**，手上有 **4 张**相同牌 → 开杠 | 无 |

> ⚠️ **术语陷阱**：本玩法的「**明杠**」= 通用麻将的**补杠**，**不是**「手中 3 张 + 他人打出第 4 张」的直杠。见 [基础规则 §2.1 别名对照](01-基础规则.md)。

### 5.2 杠分

| 类型 | 杠分 |
|---|---|
| **直杠** | 打出牌的玩家支付直杠玩家 **2 倍底分** |
| **明杠** | 其他玩家**各**支付补杠玩家 **1 倍底分** |
| **暗杠** | 其余玩家**各**支付暗杠玩家 **2 倍底分** |

- **杠分实时结算**，小局结束时不额外再算。
- **流局未听牌，不需要返还杠分**。
- **荒庄后杠分不退还**。

### 5.3 杠上杠（连杠）

| 项 | 内容 |
|---|---|
| **触发** | 玩家杠牌后摸到的牌继续杠；或补牌后打出的牌**被别人杠** |
| **公式** | `本次杠分 = 基础杠分 × 2^(连续杠次数 − 1)` |
| **跨玩家** | 连杠可在不同玩家手中连续（A 杠 → 打出一张 B 杠 → B 打出一张 C 杠，仍算连杠）|
| **中断** | 玩家补牌后打出一张**无人杠** → 本次连杠结束，倍数清零重新计算 |
| **与胡分关系** | 杠上杠**仅计算杠分**，之前的杠分不转移；触发杠上花 / 杠上炮 / 抢杠胡时，**这些番型倍数不跟随杠上杠翻倍，走初始值**（初始 2，可勾选为 4）|

**示例**：

| 步骤 | 事件 | 连杠次数 | 倍数 | 收分 |
|---|---|---|---|---|
| T1 | A 补杠 | 1 | 1 | A 收其他玩家 1 分 |
| T2 | A 杠上摸牌，继续暗杠 | 2 | 2 | A 收其他玩家 2 × 2 = **4 分** |
| T3 | A 继续杠上摸牌后打出一张，B 直杠 | 3 | 4 | B 收 A 2 × (2×2) = **8 分** |
| T4 | B 杠上摸牌后打出，无事发生 | — | 重置 | 连杠结束 |

### 5.4 杠牌限制（五条）

| 限制 | 规则 |
|---|---|
| **回手杠**（配置）| ① 手上有 3 张一样的牌，别人打出时如果选择**碰**，则这张牌**本小局不能再明杠**。<br>② **已经碰过的牌，摸到第四张时必须立刻杠**，否则本小局这张牌不能再明杠。 |
| **剩余牌限制** | **牌堆剩余牌为 0 时，不可杠**。 |
| **亮倒限制** | 玩家亮倒后，手牌中**未扣下的牌不可杠**；手中有 4 张牌、扣下 3 张也**不可杠**（哪怕摸到维持听牌的牌）。<br>**已经碰的牌，明杠不受此限制**（仍受剩余牌、回手杠、危牌限制）。 |
| **危牌限制** | **未亮倒时，危牌不可明杠（补杠）**；**直杠和暗杠可以**。 |
| **扣牌相关** | 亮倒后**仅扣下的刻子可杠**；未扣下的刻子无论别人打出还是自己摸到都**不可杠**；扣下的刻子若第 4 张在自己手中且已亮出，仍**不可杠**（会改牌）。 |

> 📌 **标识名说明**：需求在 §2.2.2 给【回手杠】标注「（**配置**）」，但三张创房表**均无**对应开关项。本套文档以规则名「**回手杠**」作为该项的**定位标识**（便于下游引用），**该标识名系本套自拟、非需求原名**；开关名与默认值需求未给。**Step 5 已裁：按「可配置的规则层约束」登记，不自行虚构开关**。

### 5.5 杠的界面与展示

| 类型 | 操作按钮 | 摆放 |
|---|---|---|
| **直杠** | 手牌右上方显示【碰】+【杠】+【过】 | 点杠：对家 ↑ / 上家 ← / 下家 → |
| **明杠（补杠）** | 手牌右上方显示【杠】+【过】 | 杠牌上方显示【补】 |
| **暗杠** | 手牌右上方显示【杠】+【过】 | 下三张牌背、上一张牌面 |

- 可杠牌高亮、其他暗置（**如果有胡则不需要暗置**）。
- 从左往右根据本局操作顺序放置，**放于手牌左侧**。
- **杠牌动画播放同时摸牌（补牌）**。
- **边界**：若是补杠且有人选择是否抢杠胡，则**不播放动画、不播放飘分**，直到抢杠胡玩家完成选择再根据杠和胡走对应流程。
- **多杠状态**：玩家手牌右上方显示「可杠牌选择框 +【杠】+【过】」；点击选择需要杠的牌，点击【过】则放弃此次操作并隐藏杠选择；**可直接点击出牌，不用选择**。配置开启托管时**超时默认不杠**。

## 七、胡

### 7.1 胡牌方式

| 方式 | 触发 | 界面按钮 | 倍数影响 |
|---|---|---|---|
| **自摸** | 摸 / 补到一张牌，手牌符合胡牌规则 | 【自摸】+【过】 | 基础 |
| **点炮（捉炮胡）** | 其他玩家打出的牌符合胡牌规则 | 【胡】+【过】 | 基础；**番型 × 加倍项 ≤ 1 时不可捉炮** |
| **抢杠胡** | 其他玩家**明杠（补杠）**的牌恰为自己的胡牌 | 【胡】+【过】 | **×2**（勾选「杠上花/炮\*4」后 ×4——需求 §2.3.1.2 三项并列受同一勾选控制）；**可多人抢杠胡一家** |
| **杠上花** | 开杠后**补到的牌**导致胡牌 | — | **×2**（勾选后 4 倍）|
| **杠上炮** | 开杠后**补牌打出的牌**点炮 | — | **×2**（勾选后 4 倍）|
| **海底捞** | 摸到**最后一张牌**后胡牌 | — | **×2**（勾选后生效）|
| **海底炮** | 摸到最后一张牌后，打出的牌点炮 | — | **×2**（勾选后生效）|
| **一炮多响** | 打出一张牌导致**多个玩家胡牌** | — | 各家分别计分 |

### 7.2 胡牌限制层

番型合法之外，还有 5 层限制，**任一拦截即不可胡**：

| # | 限制 | 规则 |
|---|---|---|
| 1 | **番数门槛** | 番型 × 加倍项 **> 1** 才可捉炮；**只有 1 倍时只能自摸** |
| 2 | **危牌** | 见 §2.1；手中全是危牌时例外 |
| 3 | **亮倒限制**（可选）| 勾选「胡牌必须亮倒」后仅亮倒状态才能胡；勾选「双亮」后 3 人时已有 2 人亮倒 → 第三人**免亮可胡（自摸、点炮均可）** |
| 4 | **漏胡** | 见 §11 |
| 5 | **操作优先级** | **吃胡 / 自摸 / 抢杠胡 > 碰 / 杠** |

> 📌 限制层（否决条件）与番型（计分条件）为 **AND** 关系，**判定顺序不影响结果**；本套按「先算番型 → 再过限制层」叙述仅为行文顺次。详见 [基础规则 §七](01-基础规则.md)。

### 7.3 胡牌界面与展示

| 项 | 内容 |
|---|---|
| **自摸按钮** | 手牌右上方显示【自摸】+【过】；【自摸】左侧显示**本次胡的牌**与**本次胡牌的倍数**（自摸按自摸显示）；如有倍数封顶则显示【封顶】，倍数仅显示封顶倍数 |
| **点炮按钮** | 手牌右上方显示【胡】+【过】；【胡】上显示本次胡的牌与倍数（非自摸不含自摸）；封顶同上 |
| **摆放（自摸）** | 摊开摆放在**自己手牌右侧**，间隔 1/4 牌距离，显示手掌标记 |
| **摆放（点炮 / 抢杠胡）** | 摊开摆放在自己手牌右侧，间隔 1/4 牌距离；自己角度显示对应点牌玩家的**方位箭头**：胡对家 ↑ / 胡上家 ← / 胡下家 → |
| **超时** | 配置开启托管时，**超时默认胡** |
| **多操作状态** | 有自摸按钮时**不可直接出牌** |

### 7.4 一炮多响的特殊展示

| 视角 | 展示 |
|---|---|
| **放炮玩家 / 围观** | 一炮多响动画 → 光柱画面 → **所有玩家所胡番型** + 飘分（正分黄色，负分灰色）|
| **胡牌玩家** | 一炮多响动画 → 光柱画面 → **自己所胡番型** + 飘分 |

## 九、过

| 项 | 内容 |
|---|---|
| **定义** | 有机会碰 / 杠 / 胡时主动放弃 |
| **界面** | 每次操作机会均显示对应的【过】按钮 |
| **超时** | 配置开启托管时，碰 / 杠**超时默认【过】**；有胡牌的多状态**超时默认胡牌** |
| **扣牌环节** | 扣牌界面点【取消】**等同于【过】**，且桌面交互按钮不会再出现 |
| **亮倒环节** | 亮倒界面点【取消】**等同于【过】**，回到正常出牌界面 |

## 十、亮倒

### 10.1 权限触发

| 条件 | 说明 |
|---|---|
| 打出一张**非危牌**后可听牌 | 触发亮倒权限，玩家**可选择**是否亮倒 |
| **手牌中全是危牌** | **去掉「非危牌」的限制**，同样可触发 |
| **自摸时** | **每次都会展示亮的权限**，包括自摸时 |

**展示**：摸牌或补牌后，若满足亮倒条件，出现【亮】+【过】按钮；听牌标签正常展示。

### 10.2 亮倒后的行为限制

| 项 | 内容 |
|---|---|
| **明牌** | 亮出所有手中牌 |
| **不可换牌** | 只能摸打，且**亮倒的牌必须维持听牌** |
| **危牌产生** | 胡的牌成为其他**未亮倒**用户的【危牌】；**玩家亮倒后自己的危牌标签去掉** |
| **杠的限制** | 仅可对**已扣下的刻子**进行直杠 / 补杠；暗杠仅可摸到第 4 张暗杠，**第 4 张在手牌中不可暗杠** |

### 10.3 亮倒计分

- 亮倒状态下，**输 / 赢时均计算亮倒**，**番型分 ×2**，**不影响加分项**。
- **输赢双方均亮倒（对亮），仅计算一次亮倒 ×2**。
- 若创房勾选**「对亮 ×2」**，胡牌双方均亮倒时计算**两个**亮倒（共 4 倍）。

### 10.4 亮倒的界面流程

```
点击【亮】
    ↓
所有碰杠胡交互按钮消失（听牌提示箭头不消失）
    ↓
扣牌判断（见 §11）
    ├─ 无可扣的刻子 → 跳过扣牌，进入「亮倒-打牌」界面
    └─ 有可扣的刻子 → 打开扣牌界面
```

**「亮倒-打牌」界面**：

- 如有选择扣住的牌，扣住的牌带【扣】标签且带遮罩，**不可打出**。
- 手牌中**打出后可听的牌会亮起**，并带听牌提示标签；其余牌全部带遮罩。
  - **危牌不会被排除在「亮起」之外、不加遮罩**（**显示层口径**：危牌正常带【危】标签、正常计算）；**点击时仍按危牌规则阻断出牌**（交互层，见本节「交互」表）。
  - **扣下的牌不带该标签**；危牌被扣下时标签切换为【扣】。
- 出现提示「请选择胡口」；右上角出现取消按钮。

**交互**：

| 操作 | 结果 |
|---|---|
| **点击取消** | 等同于【过】，回到正常出牌界面（【扣】标签消失、遮罩消失、正常展示所有听牌提示、可正常提牌出牌）|
| **点击亮起的牌（非危牌）** | 根据玩家设置正常执行提牌、出牌等操作 |
| **点击亮起的牌（是危牌）** | 出现提示「打出该牌将会放炮！」，并**阻断出牌** |
| **点击有遮罩的牌** | 无效果 |

### 10.5 托管与亮倒

| 情况 | 行为 |
|---|---|
| **亮倒后（无托管）** | 打牌：等待 1 秒打出摸到的牌。杠：触发后**等待玩家操作**。胡：触发后**等待玩家操作** |
| **亮倒后 + 同时触发托管** | 按托管逻辑执行；**亮倒后危牌标签已去除，不用考虑危牌情况** |

## 十一、扣牌

### 11.1 触发与判定

**触发时机**：**亮倒的同时**进行扣牌判断。**亮倒之后不可再扣牌**。

**可扣判断**（遍历手中所有刻子与四张相同牌，逐个判断）：

```
将该刻子去掉（四张相同牌则去掉三张）
  → 剩余手牌是否仍满足「打出一张非危牌后可听牌」？
      ├─ 满足 → 这种牌可扣下
      └─ 不满足 → 不可扣
```

| 牌型 | 扣下张数 |
|---|---|
| 3 张相同牌（刻子）| **全部扣下**（3 张）|
| 4 张相同牌 | **扣下 3 张** |

**多组同时扣下**：玩家可同时扣下多组刻子，但需**再次检测**：扣多组后的剩余手牌是否仍满足「打出一张非危牌后可听牌」。

> **需求原文示例**：手牌 `筒 12333 · 78999 · 中中中`，摸进 5 条、无危牌。此时打出 5 条可听 369 筒。
> - 红中扣下后仍听 369 筒；3 筒扣下后仅听 3 筒；9 筒扣下后听 69 筒 → **3 种牌均可单独扣下**
> - 但 **3 筒与 9 筒同时扣下**后剩余为 `12筒 · 78筒 · 中中中 · 5条`，不满足条件 → **不可同时扣下**

**扣牌与听牌**：扣牌后**按剩余亮出的牌决定听牌**。

> **需求原文示例**：手牌 `11 56667`，此时听 1 和 6；扣住 6 后手牌变为 `11 57`，此时**仅听 6**。

### 11.2 扣牌界面

| 项 | 内容 |
|---|---|
| **遮罩** | 自己手牌上方展示半透明遮罩 |
| **标题** | 【请选择扣牌】 |
| **候选区** | 手中所有**可以扣的牌**，以**单张**形式展示在标题下方；顺序与手牌中左到右顺序一致；每张牌右下角有选中圆圈 |
| **手牌区** | 可扣的牌不变，**其余牌全部带遮罩** |
| **按钮** | 遮罩下方展示【取消】【选择完成】两个按钮 |

**交互**：

| 操作 | 结果 |
|---|---|
| **点击某张候选牌** | 在选中 / 取消选中之间切换。选中时：右下角圆圈中出现绿色对号，同时**手牌中对应的三张牌出现【扣】标签**；取消选中时两者同步消失 |
| **点击【取消】** | 扣牌界面消失，且**桌面交互按钮不会再出现**（等同于【过】）|
| **点击【选择完成】** | 判断扣下所有选中的刻子后，剩余牌是否可打出一张牌后听牌。<br>· **不可以** → 取消所有选中，弹出提示「当前扣牌没有胡口！」<br>· **可以听牌** → 界面消失，切换到「亮倒-打牌」界面 |

### 11.3 扣牌后的展示

| 视角 | 展示 |
|---|---|
| **自己** | 非「部分亮」时，扣牌规则与「部分亮」的暗牌一致，只是标签从【暗】改为【扣】。部分亮时，扣牌按【暗】牌展示，标签也为【暗】 |
| **他人** | 扣住的牌按「部分亮」时的暗牌展示（背面朝上）|
| **摸牌** | 此时每个玩家摸得的牌位置不变，且仍为立着 |

## 十二、理牌

每个打牌回合结束（出牌后）**重新理牌**，将刚摸进且未打出的牌插入至手牌中。

| 方式 | 触发场景 | 表现 |
|---|---|---|
| **插入式** | 有牌需要插入原手牌**第 1 张至倒数第 2 张**位置 | 打出去的牌位置空出后，要插入的牌变斜提起，同时手牌中的牌自动往打出去的空位对齐移动并空出要插入的位置；变斜的牌提起后平移到要插入的位置上方，随后**变竖落下** |
| **平移式** | 打出的牌**非最右侧隔开的牌**，且其他牌无需改变排序 | 打出去的牌的空位由右侧的牌**往左平移**，最右侧隔开的牌也以同样速度往左靠，最终排靠在一起 |

**插入位置规则**：

| 情况 | 规则 |
|---|---|
| 插入的牌**已有多张** | **随机插入位置** |
| 插入的牌**仅有一张** | 根据牌的**排序顺序**插入 |

## 十三、过手规则

| 项 | 规则 |
|---|---|
| **漏胡（过胡）** | 玩家 A 可胡牌时选择不胡牌，即为漏胡。**漏胡玩家在摸牌前不可胡牌**；**漏胡状态在摸牌后解除（含杠后补牌）**。|
| **漏胡提示** | 触发漏胡不胡后，出现浮动提示「当前未过手，无法胡牌」，1.5 秒后消失。|
| **过碰** | 🔎 **按同厂商同品类通用口径**：过碰后、**轮到自己回合前**，其他玩家再打出同张牌时**不可再碰**。需求仅定义【漏胡】（§2.2.2：漏胡玩家在**摸牌前**不可胡，摸牌后解除），**未定义过碰** → 按其**同一「过手至摸牌解除」的时机模型**推导（与血战 / 贵阳「过手碰」口径一致）。 |
| **过杠** | 🔎 **与过碰同口径**：过杠后、**轮到自己回合前**不可再杠同张。推导依据同过碰。 |

## 十四、托管

| 触发场景 | 托管逻辑 |
|---|---|
| **触发托管** |托管状态下**无法进行提牌操作**，仍可选择碰 / 杠 / 胡 / 过的操作，但操作后则**取消托管状态**。<br>· **打牌**：按摸打逻辑出牌，等待 1 秒打出摸到的牌。<br>　- 摸到的牌是**危牌**时，在非危牌中从左到右选择第一张打出。<br>　- 手牌**全是危牌**时，等待 1 秒打出摸到的牌。<br>· **碰 / 杠**：等待 1 秒后取消。<br>· **胡**：等待 1 秒后胡牌。 |
| **听牌后勾选自动摸打**（头像不展示托管）|**打牌**：按摸打逻辑出牌，等待 1 秒打出摸到的牌。<br>　- 摸到的牌是危牌时，**退出自动摸打**；退出后如进入托管，按托管逻辑执行。<br>· **碰 / 杠**：等待 1 秒后取消。<br>· **胡**：等待 1 秒后自动胡牌。 |
| **亮倒后** |**打牌**：等待 1 秒打出摸到的牌。<br>· **杠**：触发后**等待玩家操作**。<br>· **胡**：触发后**等待玩家操作**。 |
| **亮倒后 + 同时触发托管** | 按托管的逻辑执行；**亮倒后危牌标签已去除，不用考虑危牌情况**。 |

> **自动摸打与托管的区别**：自动摸打的**头像不展示托管图标**；听牌时可点击勾选自动摸打，勾选后进入托管，期间可再次点击取消勾选或点击「取消托管」按钮取消。
