## 判定总览

胡牌判定分**两层**：先判**牌型**（番型是否成立），再走**限制层**（法律之外的额外门槛）。**两层都通过才可胡**。

```
                        ┌──────────────────────────────┐
 │ 第一层 · 牌型判定 │
 │ 见 [番型](04-番型.md) §1.2 │
 │ 七对结构 / 4 副面子 + 1 对将 │
 │ ├─ 判不出任何番型 → ❌ 不可胡 │
 │ └─ 判出番型 → 记为「牌型分」 │
                        └───────────────┬──────────────┘
                                        ↓
                        ┌──────────────────────────────┐
 │ 第二层 · 限制层（本章） │
 │ │
 │ ① 番数门槛 │
 │ 番型 × 加倍项 > 1 ? │
 │ ├─ 否（= 1）→ 只能自摸 │
 │ └─ 是 → 可自摸可捉炮 │
 │ │
 │ ② 和牌方式判定 │
 │ ├─ 自摸类 → 通过 │
 │ └─ 捉炮类 ↓ │
 │ │
 │ ③ 危牌限制 │
 │ 手中全是危牌 ? → 例外放行 │
 │ 否则出危牌 → ❌ 阻断 │
 │ │
 │ ④ 亮倒限制（可选） │
 │ 勾选「胡牌必须亮倒」? │
 │ ├─ 是 且 未亮倒 → ❌ 不可胡 │
 │ └─ 是 且 已 2 人亮倒（双亮） │
 │ → 第三人例外放行 │
 │ │
 │ ⑤ 漏胡限制 │
 │ 摸牌前 → ❌ 不可胡 │
 │ 摸牌后 / 杠后补牌后 → 解除 │
 │ │
 │ ⑥ 操作优先级 │
 │ 吃胡/自摸/抢杠胡 > 碰/杠 │
                        └───────────────┬──────────────┘
                                        ↓
                              ✅ 可胡 → 进入结算
```

### 步骤表

| 步骤 | 判定项 | 通过条件 | 不通过 |
|---|---|---|---|
| 1 | **牌型成立** | 属于某一基础番型（14 种之一）或条件型叠加 | 不可胡 |
| 2 | **番数门槛** | 番型 × 加倍项 > 1（捉炮）；自摸不受限 | 不可捉炮，只能自摸 |
| 3 | **和牌方式** | 自摸 / 点炮 / 抢杠胡 / 杠上花 / 杠上炮 / 海底捞 / 海底炮 / 一炮多响 之一 | 无和牌方式则不成立 |
| 4 | **危牌限制** | 打出的牌不是危牌；或手中全是危牌 | 不可打出该牌（在出牌阶段即被阻断）|
| 5 | **亮倒限制**（可选）| 未勾选该选项；或已亮倒；或已满足双亮例外 | 不可胡 |
| 6 | **漏胡限制** | 未处于漏胡状态；或已摸牌（含杠后补牌）| 不可胡 |
| 7 | **操作优先级** | 吃胡 / 自摸 / 抢杠胡 **优先于** 碰 / 杠 | 优先级低者让位 |

> **先后顺序的依据**：需求 §2.3.1.4【点炮】明写「**牌型\*加倍项＞1，即可捉炮**」——判定「能不能捉炮胡」须先算出**牌型分**，故**番型（步骤 1）先算、限制层（步骤 2~6）后过**，与本章叙述一致。

## 一、和牌前置（共用）

### 1.1 牌型成立

胡牌的前提是手牌（含碰杠牌区）加上和入张，能构成 [番型 §1.1](04-番型.md) 中列举的某一结构：

| 结构 | 说明 |
|---|---|
| **4 副面子 + 1 对将** | 4 副顺子 / 刻子 / 杠 + 1 对将牌 |
| **七对（2N）** | 7 个对子 |
| **条件型叠加** | 卡五星 / 明四归 / 暗四归，附加在上述结构之上 |

**判不出任何番型 → 不可胡。**

### 1.2 番数门槛

| 场景 | 条件 | 结果 |
|---|---|---|
| **捉炮（点炮）** | **番型 × 加倍项 > 1** | ✅ 可捉炮 |
| **捉炮（点炮）** | **番型 × 加倍项 = 1** | ❌ **不可捉炮**（需求原文：「只有 1 倍时，无法捉炮胡」）|
| **自摸** | 不受番数门槛限制 | ✅ 可自摸 |

> **需求原文**：「只有 1 倍时，只能自摸，＞1 倍时，可自摸可捉炮（番型 × 加倍项）」。
> **提示文案**：番数不足无法捉炮时，出现浮动提示「番数不足，无法捉炮！」。
>
> **示例**：平胡 1 倍、无任何加倍项与加分项 → 番型 × 加倍项 = 1 → **只能自摸，不可捉炮**。
> 平胡 1 倍 + 亮倒 ×2 → 1 × 2 = 2 > 1 → **可以捉炮**。

### 1.3 操作优先级

```
吃胡 / 自摸 / 抢杠胡 > 碰 / 杠
```

高优先级操作优先执行；同一张牌既有胡又有碰时，**胡优先**。

## 二、胡牌限制层（M5）

牌型成立之后，还需通过以下 5 层限制，**任一拦截即不可胡**（与 [基础规则 §七](01-基础规则.md)、[打牌操作 §7.2](03-打牌操作.md) 同源）：

| # | 限制层 | 触发条件 | 结果 | 例外 |
|---|---|---|---|---|
| 1 | **番数门槛** | 番型 × 加倍项 ≤ 1 | ❌ 不可捉炮 | 自摸不受限 |
| 2 | **危牌限制** | 打出的牌是危牌（未亮倒玩家手中，是任一其他亮倒玩家胡的牌）| ❌ 该牌**不可打出**（在出牌阶段即被阻断，提示「打出该牌将会放炮！」）| **手中全是危牌**时可打出 |
| 3 | **亮倒限制**（可选）| 勾选「**胡牌必须亮倒**」且自己未亮倒 | ❌ 不可胡 | 勾选「**【卡五星专属】双亮**」后，3 人时**已有 2 个玩家亮倒** → 第三个玩家**无需亮倒也能胡牌** |
| 4 | **漏胡限制** | 玩家处于漏胡状态（曾可胡而不胡）| ❌ **摸牌前不可胡牌** | **摸牌后（含杠后补牌）解除** |
| 5 | **操作优先级** | 同一张牌同时有多人可操作 | **吃胡 / 自摸 / 抢杠胡 优先于 碰 / 杠** | — |

### 2.1 限制层之间的互斥与优先

| 关系 | 说明 |
|---|---|
| **「胡牌必须亮倒」× 「双亮」** | **两者互斥**（创房勾选层面即互斥）|
| **危牌限制 × 亮倒** | 玩家亮倒后，**自己的危牌标签去掉**；亮倒玩家不受危牌限制 |
| **危牌限制 × 杠** | 危牌**不可明杠（补杠）**；**直杠和暗杠可以** |

## 三、过手胡

| 项 | 规则 |
|---|---|
| **触发** | 玩家 A 可胡牌时**选择不胡牌**，即为**漏胡** |
| **限制** | **漏胡玩家在摸牌前不可胡牌** |
| **解除** | **漏胡状态在摸牌后解除（含杠后补牌）** |
| **提示** | 触发漏胡不胡后，出现浮动提示「**当前未过手，无法胡牌**」，1.5 秒后消失 |
| **过碰** | 🔎 **按同厂商同品类通用口径**：过碰后、**轮到自己回合前**，其他玩家再打出同张牌时**不可再碰**。需求仅定义【漏胡】（§2.2.2：漏胡玩家在**摸牌前**不可胡，摸牌后解除），**未定义过碰** → 按其**同一「过手至摸牌解除」的时机模型**推导（与血战 / 贵阳「过手碰」口径一致）。 |

> **示例**：A 打出 `7条`，B 手牌听 `7条` 与 `4筒`（多面听）。B 此时可选择胡，但**选择不胡** → B 进入**漏胡状态**。
> 在 B 下一次摸牌之前，任何人再打出 `7条` 或 `4筒`，B **均不可胡**（界面提示「当前未过手，无法胡牌」）。
> B 摸牌后（含杠后补牌），漏胡状态**解除**，之后可正常胡牌。

## 四、自摸

| 项 | 规则 |
|---|---|
| **触发** | 摸牌或补牌后，手牌符合胡牌规则（**包括杠上开花**）|
| **番数门槛** | **不受限**（1 倍也可自摸）|
| **收分对象** | 其他所有玩家 |
| **界面** | 手牌右上方显示【自摸】+【过】；【自摸】左侧显示本次胡的牌与本次胡牌的倍数（自摸按自摸显示）|
| **封顶显示** | 如有倍数封顶，则显示【封顶】，且倍数仅显示封顶倍数 |
| **超时** | 配置开启托管时，**超时默认胡** |
| **不可出牌** | 有自摸按钮时**不可直接出牌** |
| **展示** | 摊开摆放在自己手牌右侧，间隔 1/4 牌距离，显示手掌标记 |
| **限制层** | 自摸**不受**番数门槛、危牌限制约束；**受亮倒限制**（勾选「胡牌必须亮倒」且自己未亮倒 → 不可胡；「双亮」例外除外）；**漏胡限制在摸牌后即解除，故自摸不受漏胡限制** |

## 五、杠开

### 5.1 杠上花

> **是否与其他番型叠加**：**叠加（乘算）**。杠上花属**加倍项**（需求 §2.3.3.1 列入「加倍项」表），按加倍项语义在牌型分上乘算，不与其他番型互斥。仅**高分玩法**下「杠开卡五星」按 **20 倍合并档**计（不叠乘）。依据见 [结算 §4.2](06-结算.md)。

| 项 | 规则 |
|---|---|
| **触发** | 开杠后**补到的牌**导致胡牌 |
| **倍数** | **×2**（默认生效）|
| **创房** | 勾选「杠上花/炮\*4」后变为 **×4** |
| **生效条件** | **默认生效（2 倍）**，勾选后升为 4 倍。⚠ 需求 §2.3.3.1「**加倍项**」表 #3 另写「勾选后生效」（与「2 倍」并存矛盾），**采创房表口径**——创房表写「勾选后，杠上花/炮**变为**4倍」，「变为」蕴含存在原值 |
| **与杠上杠的关系** | 触发时**倍数不跟随杠上杠翻倍，走初始值**（初始 2，可勾选为 4）|
| **归类** | 属**自摸类**（需求原文：自摸「包括杠上开花」）|

### 5.2 杠上炮

| 项 | 规则 |
|---|---|
| **触发** | 开杠后补牌，并**打出一张牌后点炮** |
| **倍数** | **×2**（默认生效）|
| **创房** | 勾选「杠上花/炮\*4」后变为 **×4** |
| **生效条件** | 同杠上花（默认生效 2 倍，勾选后 4 倍）|
| **与杠上杠的关系** | 同杠上花 |
| **归类** | 属**点炮类**（由他人打出补牌后的牌而胡）|

### 5.3 番型播放的优先级

胡牌回合触发多个番型时，动画播放的选取规则（优先播特殊番型、特殊番型清单、多个特殊番型时优先播杠相关、无特殊番型时播最大普通番型）——**属 UI 表现，见 [UI交互 §9.8](09-UI交互.md)**，本篇不重复展开。

## 六、抢杠胡

| 项 | 规则 |
|---|---|
| **触发** | 其他玩家进行**明杠（补杠）**，且明杠的牌恰为自己的胡牌 |
| **范围** | **仅针对明杠（补杠）**；直杠、暗杠不可抢（🔎 推导：需求只正面声明「明杠可抢」，直杠的牌可正常点炮、暗杠无外部牌，故排除）|
| **多人** | **可多人抢杠胡一家** |
| **归类** | **点炮类**（需求 §2.2.2【点炮】：他人打出**或补杠的牌**形成胡牌 = 点炮或抢杠胡、杠上炮）|
| **倍数** | **×2**（**勾选「杠上花/炮 \*4」后 ×4**）|
| **后果** | **抢杠胡后，明杠玩家视为未杠成功，不收取杠分，杠上杠也会中断** |
| **杠分冲销** | 因本玩法**杠分实时结算**（见 [基础规则 §4.1](01-基础规则.md)），「**视为未杠成功、不收取杠分**」在实现上即**已实时收取的该杠杠分需回退**（🔎 由「实时结算」+「视为未杠成功」两句合成推导）；杠上杠随之中断、连杠次数清零 |
| **坐庄归属** | 属**点炮类**（见上）→ 按 §2.3.5【轮庄】「**一炮多响时，点炮玩家坐庄**」，**多人抢杠胡时由补杠的那一家坐庄** |
| **与杠上杠** | 倍数不跟随杠上杠翻倍，走初始值（初始 2，可勾选为 4）|
| **界面** | 手牌右上方显示【胡】+【过】 |
| **动画边界** | 补杠时若有人选择是否抢杠胡，则**不播放杠动画、不播放飘分**，直到抢杠胡玩家完成选择再根据杠和胡走对应流程 |
| **优先级** | 抢杠胡属**高优先级**（吃胡 / 自摸 / 抢杠胡 > 碰 / 杠）|
| **收分对象** | **明杠（补杠）的那一家**（按点炮类口径）|

## 七、点炮（捉炮胡）

| 项 | 规则 |
|---|---|
| **触发** | 玩家打出的牌，刚好为其他玩家要胡的牌 |
| **番数门槛** | 番型 × 加倍项 **> 1** 才可捉炮 |
| **界面** | 手牌右上方显示【胡】+【过】；【胡】选项上显示本次胡的牌和本次胡牌的倍数（非自摸不含自摸）|
| **封顶显示** | 如有倍数封顶，则显示【封顶】，倍数仅显示封顶倍数 |
| **收分对象** | **仅点炮玩家**（自摸才收所有玩家）|
| **展示** | 摊开摆放在自己手牌右侧，间隔 1/4 牌距离；自己角度显示对应点牌玩家的**方位箭头**（胡对家 ↑ / 胡上家 ← / 胡下家 →）|
| **超时** | 配置开启托管时，**超时默认胡** |

## 九、一炮多响

| 项 | 规则 |
|---|---|
| **触发** | 打出一张牌后，导致**多个玩家**胡牌 |
| **结算** | 各家**分别**和牌、分别计分 |
| **轮庄** | 一炮多响时，**点炮玩家坐庄** |
| **上楼联动** | 触发下一小局的**上楼 ×2**（同一大局内）。上楼完整触发条件与倍数上限见 [番型 §5.6](04-番型.md) / [结算 §4.1](06-结算.md) |
| **大结算统计** | 点炮 X 次中，**一炮多响只算一次**（一小局最多一次）|
| **界面（胡牌玩家视角）** | 一炮多响动画 → 光柱画面 → **自己所胡番型** + 飘分 |
| **界面（放炮玩家 / 围观视角）** | 一炮多响动画 → 光柱画面 → **所有玩家所胡番型** + 飘分 |
| **飘分配色** | **正分为黄色，负分为灰色** |

## 十、亮倒类

亮倒与胡牌的关系分两层：**限制层**（能不能胡）与**加倍项**（胡了算多少）。

### 10.1 作为限制层

| 选项 | 规则 |
|---|---|
| **胡牌必须亮倒** | 勾选后，**仅亮倒状态下才能胡牌**；**与双亮互斥** |
| **【卡五星专属】双亮** | **仅卡五星有此选项**；**仅 3 人时可勾选**，2 人时置灰；勾选后 3 人时若**已经 2 个玩家亮倒**，则第三个玩家**无需亮倒也能胡牌**；**与「胡牌必须亮倒」互斥**。<br>**勾选后若改为 2 人开局，该规则自动失效** |

### 10.2 作为加倍项

| 场景 | 倍数 |
|---|---|
| **亮倒状态**（输 / 赢**均**计算）| **番型分 ×2**；**不影响加分项** |
| **双方均亮倒（对亮）**，未勾选「对亮\*2」| **仅计一次亮倒 ×2** |

> **需求原文说明**：对亮「比未勾选时多一个」。

### 10.3 亮倒与胡牌的衔接

- 亮倒**不改变**能否胡牌的判定，只在限制层（若勾选「胡牌必须亮倒」）与加倍项上起作用。
- 玩家亮倒后，**自己的危牌标签去掉**——即亮倒玩家**不再受危牌限制**。
- 亮倒后**扣牌**：扣下的刻子不可打出、不可杠（除非满足杠的条件）。

## 十二、各胡法 × 限制层对照矩阵

| 胡法 | 番数门槛 | 危牌限制 | 亮倒限制 | 漏胡限制 | 倍数 |
|---|---|---|---|---|---|
