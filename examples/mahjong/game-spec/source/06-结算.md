```

      ├─ 有人胡牌  → 走 S1~S8，再走 S10（若触发包牌）、S11（若触发特殊场景）
      └─ 荒庄      → 走 S9 荒庄分支

      ↓

      ↓

      ├─ 是 → 取封顶倍数            （[§五](#五封顶s4)）
      └─ 否 → 原值
      ↓

      ↓

      ↓

```

## 一、对局结果与总公式（S0）

### 1.1 主公式

```
小局结束的最终得分 = 底分 × 番型 × 加倍项 + 马分 + 漂分 + 坎分
```

> 需求原文（§2.4）：「小局结束的最终得分 = 底分 × 番型 × 加倍项 + 番型加分项 + 马分 + 漂分 + 坎分 + 字分」。

### 1.2 结果类型

| 结果 | 触发 | 计分路径 |
|---|---|---|
| **正常胡牌** | 有玩家胡牌 | S1~S8（+ S10 / S11）|
| **荒庄** | 可摸牌数 = 0 且无人胡牌 | S9（查叫 / 亮倒荒庄赔付）|

### 1.3 底分

需求**未单列底分配置项**，公式中的「**底分**」为所有倍数的**乘算单位**（所有倍数均表述为「**N 倍底分**」）。
🔎 **推导取值**：按主公式的乘算语义，**底分 = 1**（即「N 倍底分」在实际计分中等值于 N 分）。此项为推导所得，与 `rule-inventory.md` §0 登记一致。

## 二、牌型分（S1）

**牌型分** = 按 [番型 §1.3](04-番型.md) 的**维度化口径**汇总：**同一维度内取高、跨维度相加**。

| 维度 | 内含番型（**取高**）| 倍数 |
|---|---|---|
| **结构维度** | 平胡 / 碰碰胡 | 1 / 2（创房可调 4；高分玩法下 8）|
| **花色维度** | 清一色 | 4 |
| **三元维度** | 小三元 / 大三元 | 4 / 8 |
| **听口维度** | 卡五星 | 2|
| **手牌形态维度** | 手抓一 | 2|
| **四归子维度** | 明四归 ／ 暗四归 **各自独立** | 2 / 4（受**频道**控制触发）**— 二者可同时成立即叠加；各自只计一次** |
| **七对维度** | 七对 / 龙七对 / 双龙七对 / 三龙七对 | 4 / 8 / 32 / 128（高分玩法下 8 / 20 / 40 / 80）|
| **七对叠加项** | 三元七对 | **8**（在**七对维度所取档位**基础上 **×2**），可与龙 / 双龙 / 三龙**叠加**（**不按取高处理**）|

**跨结构处理**：七对维度与结构维度**可同时成立**时**取分值较高者**；**不互斥**。

**需求明示的互斥**（按 [番型 §1.3](04-番型.md) 剔除后再求和）：

| 互斥规则 | 处理 |
|---|---|
| 清一色 × 明四归 | **仅计清一色**（**仅限明四归**）|
| 清一色 × 暗四归 | **可叠加** |
| 七对类 × 明四归 / 暗四归 | 七对类不计四归 |
| 三元七对 × 小三元 / 大三元 | 不会同时触发 |
| 清一色 × 三元类 | 结构上不可能同时成立（🔎 推导）|

**示例**：
- 碰碰胡（结构 2）+ 清一色（花色 4）+ 手抓一（形态 2）= **8 倍**
- 大三元（三元 8）+ 平胡（结构 1）= **9 倍**；大三元 + 碰碰胡 = **10 倍**
- 清一色（花色 4）+ 明四归（四归 2）同时满足 → **仅计清一色 4 倍**（需求明示互斥）
- 全筒七对 = 七对（七对维度 4）+ 清一色（花色维度 4）= **8 倍**（跨维度叠加）

## 三、分值 remap（M9）

创房勾选「**高分玩法**」后，以下 8 个番型的倍数**换档计分**（其中 **6 项升档**、三龙七对为**唯一降档项**、「杠开卡五星」为**新增档**）：

| 番型 | 基础倍数 | 高分玩法下倍数 | 变化 |
|---|---|---|---|
| 七对 | 4 | **8** | ↑ |
| 龙七对 | 8 | **20** | ↑ |
| 双龙七对 | 32 | **40** | ↑ |
| **三龙七对** | **128** | **80** | **↓** ⚠ 见 §3.2 |
| 卡五星 | 2 | **8** | ↑ |
| 碰碰胡 | 2 | **8** | ↑ |
| 杠上开花 | 2 | **8** | ↑ |
| 杠开卡五星 | — | **20** | 新增档 |

### 3.1 互斥关系

**「高分玩法」与以下番型选项互斥**：卡五星、碰碰胡、杠开、三元七对。勾选后，这些选项**变灰且切换为不勾选**。

### 3.2 配置状态说明

上述 8 个番型的倍数分**两个配置状态**取值，**两值不冲突**：

| 状态 | 取值来源 | 说明 |
|---|---|---|
| **高分玩法 未勾选（基准）** | 需求 §2.3.3.1「基础番型」表 | 七对 4 / 龙七对 8 / 双龙七对 32 / 三龙七对 128 |
| **高分玩法 已勾选** | 需求 §3.1.1.1/2/3「高分玩法」条 | 七对 8 / 龙七对 20 / 双龙七对 40 / 三龙七对 80 |

**三龙七对的特殊性**：勾选「高分玩法」后，七对系列的其余三项均**升档**（4→8、8→20、32→40），唯**三龙七对为 80 倍、低于基础的 128 倍**。

> **分析**：高分玩法下的七对系列 **20 → 40 → 80** 构成完整的 ×2 递进链，**80 是该链的必然取值**（并非笔误）；而基准表的 32 → 128 为 ×4 递进。即「高分玩法」是**另一套档位表**，不是基准表的等比放大，故不保证每档都 ≥ 基准值。
> **落地口径**：按需求明示值 **80** 计。该档**低于基础 128**，但**非笔误** —— 高分档七对系列为 **20→40→80** 完整 ×2 链，80 为三龙档必然取值。

### 3.3 影响范围

**「高分玩法」的作用面 = 牌型分（番型倍数）**，换档后**参与封顶的仍是「番型 × 加倍项」中的番型部分**。<br>依据：公式为「底分 × **番型** × 加倍项」，而「高分玩法」在需求中的表述是「勾选后：七对 **8 倍底分**、龙七对 **20 倍底分**……」——**逐项改的是番型倍数**，故 remap 落在公式的「番型」位；封顶口径（§五「仅计算番型 × 加倍项」）不变。**无需另行确认**。

## 四、加倍项（S3）

```
番型 × 加倍项 = 牌型分 × Π(各加倍项倍数)
```

| 加倍项 | 倍数 | 触发 |
|---|---|---|
| **亮倒** | 2 | 亮倒状态下，输 / 赢**均**计算；**不影响加分项** |
| **对亮** | 2 | 勾选后，胡牌双方均亮倒 → 与亮倒相乘得 **4 倍**；未勾选只计一个亮倒（×2）|
| **杠上花** | 2 | 杠后补到的牌胡牌；勾选「杠上花/炮\*4」后变 4 倍 |
| **杠上炮** | 2 | 杠后补牌打出的牌点炮；勾选后变 4 倍 |
| **抢杠胡** | 2（勾选「杠上花/炮\*4」后 **4**——§2.3.1.2 与杠上花/炮并列受同一勾选控制）| 补杠时其他家胡这张牌 |
| **海底捞** | 2 | 摸到最后一张牌后胡牌；勾选「海底捞/炮\*2」后生效 |
| **海底炮** | 2 | 摸到最后一张牌后打出的牌点炮；勾选后生效 |
| **上楼** | 2 / 4 | ① 上一小局荒庄或一炮多响 → ×2；② 本小局两骰子点数一致 → ×2；①② 同触发 → ×4 |

### 4.1 上楼细则

| 条件 | 倍数 |
|---|---|
| ① 同一大局内，**上一小局荒庄或者一炮多响** | 本小局**倍数** **×2** |
| ② 本小局**开局打骰子时两个骰子点数一致** | 本小局**倍数** **×2** |
| ① 与 ② **同时触发** | **×4** |

- 1、2 的翻倍**可叠加，最高 4 倍**（需求原文：「1、2 的翻倍可叠加，最高 4 倍」）。
- **上楼为加倍项，不可突破封顶倍数**。
- 需创房勾选「上楼」才生效。
- 📌 **「倍数」的射程**：指**番型 × 加倍项**，**不含**马 / 漂 / 坎等**加分项**。**Step 5 裁决**：需求 §2.3.3.1「加倍项」表 #8 两处均写「本小局**倍数** X2」；§2.2.2【上楼】的「所有分数\*2」与同条「不可突破封顶倍数」不相容 → **采加倍项表**。

### 4.2 杠开是否与其他番型叠加

🔎 **本条为本文档裁决**（需求 §3.1.1.2 仅留批注「杠开不与其他番型叠加？」未给答案）。

**结论：叠加（乘算）。**

> **裁决依据**：需求 §2.3.3.1 把**杠上花 / 杠上炮列在「加倍项」表**（非「基础番型」表），而加倍项的定义即「在牌型分上乘算」；§2.3.1.2 亦写「杠上开花倍数 \*2」——「倍数」即乘子。故杠开与同时成立的番型**乘算**，不互斥。
>
> 需求 §3.1.1.2「高分玩法」条上的批注「**杠开不与其他番型叠加？**」针对的是**高分玩法**场景：该处把「**杠开卡五星 20 倍**」列为**独立合并档**，即高分玩法下「杠上开花 + 卡五星」按 **20 倍合并计**，而非 8 × 8 叠乘。**基础玩法下仍按加倍项乘算。**

### 4.3 加倍项与杠上杠

**杠上杠时触发杠上花、杠上炮、抢杠胡时，倍数不跟随杠上杠翻倍，走初始值**（初始 2，可勾选为 4）。杠上杠仅计算杠分。

### 4.4 易错点

| 易错 | 正解 |
|---|---|
| 亮倒 ×2 也算在加分项上 | ❌ 亮倒**只乘番型分**，**不影响加分项**（漂 / 马 / 坎）|
| 双方都亮倒就 ×4 | ❌ 未勾选「对亮\*2」时**只计一个亮倒 ×2** |
| 上楼可以突破封顶 | ❌ 上楼是加倍项，**受封顶约束** |

## 五、封顶（S4）

| 项 | 规则 |
|---|---|
| **封顶口径** | **仅计算「番型 × 加倍项」**，不可超过封顶倍数 |
| **触发** | 番型 × 加倍项 > 封顶倍数时，按封顶倍数计算 |
| **不参与封顶的项** | **所有加分项不参与封顶计算，无上限**：漂、马、坎、杠 |
| **上楼** | 上楼为加倍项，**不可突破封顶倍数** |
| **可选值** | **8 / 16 / 32 / 64 / 不封顶** |

### 5.1 封顶与加分项的关系

```
           ┌─ 番型 × 加倍项 ──→ 执行封顶截断 ──┐
最终得分 = │                                  ├─ → 合计
 └─ 加分项（漂/马/坎/杠）──→ 不截断 ─┘
```

> **需求原文**：「封顶只控制番型 × 加倍项的倍数，马分、漂分、坎分、杠分这种额外加分项不受封顶影响，单独计算」。

### 5.2 示例

**示例 1（未触发封顶）**：封顶 32 倍。某局清一色（4）+ 碰碰胡（2）= **6 倍**牌型分，亮倒 ×2 = **12 倍** → 12 < 32，**不截断**。

**示例 2（触发封顶，加分项不截断）**：封顶 32 倍。某局清一色（4）+ 手抓一（2）+ 碰碰胡（2）= **8 倍**牌型分，亮倒 ×2 = 16 倍，上楼 ×4 = **64 倍** > 封顶 32 → **截断为 32 倍**。
若本局漂分为 3 倍底分、马分为 5 分，则：

```
最终得分 = 底分 × 32（截断后的番型 × 加倍项）+ 3 倍底分（漂）+ 5 分（马）
           └─ 受封顶 ─┘                      └──── 不受封顶 ────┘
```

## 六、杠分（S5）

**杠分实时结算**，小局结束时不额外再算。

| 类型 | 杠分 | 赔付方向 |
|---|---|---|
| **直杠** | 2 倍底分 | 打出牌的玩家 → 直杠玩家 |
| **明杠（补杠）** | 1 倍底分 | 其他玩家各付 → 补杠玩家 |
| **暗杠** | 2 倍底分 | 其余玩家各付 → 暗杠玩家 |

**杠上杠**：`本次杠分 = 基础杠分 × 2^(连续杠次数 − 1)`；连杠可跨玩家连续；中断后重新计算。

**荒庄**：**杠分不退还**。**流局未听牌，不需要返还杠分**。

**抢杠胡**：抢杠胡后，**明杠玩家视为未杠成功，不收取杠分，杠上杠也会中断**。 详见 [打牌操作 §五](03-打牌操作.md)。

## 七、马分（S6）

买马的总得分，**不受封顶影响**。

| 马数 | 计分 |
|---|---|
| **买一** | 中发白记 10 倍底分；1~9 记同数字倍的底分 |
| **买一送一** | 同上，两张分数之和 |
| **买6马** | 出现 1 / 4 / 7 / 白 每张 1 倍底分（**命中集即此四种，不含中 / 发**）；**中 0 张按 6 马计分** |
| **买5马** | 出现 1 / 4 / 7 / 白 每张 1 分（**命中集即此四种，不含中 / 发**）；**一张不中或者中 5 张，按 6 马计分** |

**收分对象**：**自摸收取所有玩家**。
**不买马的情形**：不买马配置；荒庄；买一 / 买一送一时**剩余牌数量不足**。
详见 [基础规则 §6.2](01-基础规则.md)。

## 八、漂分（S7）

```
胡牌玩家向某玩家收取的漂分 = （胡牌玩家漂数 + 该玩家漂数）× 底分
```

- **捉炮胡**：仅收**点炮玩家**；**自摸胡**：收**所有玩家**。
- **每个玩家单独计算**。
- **不受封顶影响**。
- **荒庄查叫时漂也赔**。

> **需求原文示例**：A 漂 0，B 漂 2，C 漂 1。
> - B 自摸：收 A (2+0) = **2 倍底分**；收 C (2+1) = **3 倍底分**
> - A 点炮、B 胡牌：仅收 A (2+0) = **2 倍底分**

## 九、坎分（S8）

**计算范围** = 自己的**手中** + **胡的那张** + **碰杠牌区**。

| 牌型 | 加分 |
|---|---|
| 每个**暗刻** | +1 倍底分 |
| 每个**明杠 / 直杠** | +1 倍底分 |
| 每个**暗杠** | +2 倍底分 |
| 手中**4 张一样**的牌 | +2 倍底分（必须是**顺 + 刻**，不与暗刻重复计算）|

**收分对象** = 需付胡牌分的玩家：点炮胡收**放炮玩家**；自摸胡收**其他所有玩家**。
**不受封顶影响**。

**关键口径**：

| 口径 | 说明 |
|---|---|
| **必须是刻子** | 仅是 3 张相同牌但不成刻的**不算** |
| **胡的那张** | **自摸才参与计算，捉炮不参与** |
| **查叫时计算坎分** | 但**不计算胡的那张牌**（因为荒庄没有胡）|

## 十二、荒庄分支（S9）

### 12.1 触发

**玩家可摸牌数 = 0**（牌堆摸完）仍无人胡牌 → 荒庄。

### 12.2 查叫（需勾选）

```
未听牌玩家 → 听牌玩家 赔付： 底分 × 番型 × 加倍项 + 漂分 + 坎分
    └──── 受封顶控制 ────┘   └─ 不受封顶 ─┘
```

| 项 | 规则 |
|---|---|
| **开启条件** | **需勾选「查叫」才开启** |
| **最大倍数** | **最大倍数计亮倒**（需求原文：「最大倍数计亮倒」）|
| **封顶** | 「底分 × 番型 × 加倍项」**受封顶控制**；漂分、坎分**不受封顶影响** |
| **封顶标识展示** | 查叫金额被截断时，**按与胡分同一标识规则展示** —— 输分者在总得分处加【封顶】标识、详情分数下方写「（封顶）」（见 [UI §结算](09-UI交互.md)）。依据：§2.2.2【查叫】明写「**最大倍数受封顶影响**」，截断行为与胡分同源 |
| **坎分** | 查叫时计算坎分，但**不计算胡的那张牌**（没有胡）；**听双碰时会生效**；**在查叫时听双碰也算** |
| **漂** | **查叫时漂也赔** |
| **买马** | 荒庄**不买马** |
| **杠分** | 荒庄后**杠分不退还** |

### 12.3 亮倒荒庄赔付（首亮赔付）

**规则**：荒庄后，如果存在玩家亮倒，本小局**第一个亮倒的玩家**向**其他所有玩家**赔付 **1 倍底分**。

> **裁决依据（赔付对象）**：需求三处表述不同——
> - §2.2.2【荒庄】（名词定义）：「第一个亮倒的玩家赔付**其他玩家** 1 倍底分」
> - §2.3.1.6（规则详情）：「本小局第一个亮倒的玩家需要给**其他玩家**赔付 1 倍底分」
> - §2.4（算分逻辑）：「**存在多个亮倒玩家时**，首个亮倒玩家向**其他亮倒玩家**赔付 1 倍底分」
>
> **采前两处的「其他玩家」**（= 除自己外的全部玩家，含未亮倒者）：① 两处独立表述一致，且分属**名词定义**与**规则详情**两个权威章节；② §2.4 的句子带前置条件「**存在多个亮倒玩家时**」，是对「多人亮倒时谁算首亮」这一**子场景**的说明，**不构成赔付对象的限定**。

> **裁决依据（金额表述）**：「1 倍底分」（§2.2.2 / §2.3.1.6 / §2.4）与「1 分」（§2.3.6.1~3 规则页文案）**数值相同、非两套口径**——本玩法**底分 = 1**（见 [§1.3](#13-底分)），故「1 倍底分」=「1 分」。**统一采用「1 倍底分」表述**（与全文「N 倍底分」体系一致）。
> 旁证：§2.3.6 为标题带「（**待补充**）」的规则页草稿节，其「查叫赔 **2 倍分**」亦与 §2.4 的查叫主口径（**1 倍**）冲突，且孝感段仍写有该变体并不存在的「全频道 / 双亮 / 包牌 / 上楼」——**该节未定稿，不作为口径依据**。

| 变体 | 赔付金额 | 说明 |
|---|---|---|
| **卡五星** | **1 倍底分** | — |
| **十堰卡五星** | **2 倍底分** | 需求 §2.2.2【荒庄】明示「十堰 2 倍底分」 |

**展示**：结算页签中输分者展示【首亮赔付−X】、赢分者【首亮赔付+X】。**先展示查叫、后展示首亮赔付**。

### 12.4 查叫与亮倒荒庄可以同时赔付

需求原文：「卡五星、十堰卡五星中，**查叫与亮倒荒庄可同时赔付**」。

**结算信息展示顺序**：**先展示查叫、后展示首亮赔付**。

### 12.5 荒庄结算路径

```
牌堆摸完无人胡
    ↓
所有玩家摊牌展示 → 展示【荒庄】
    ↓
有未听牌玩家？
    ├─ 无 → 直接出小结算
    └─ 有 → 所有未听牌玩家飘字【未听牌】
            ├─ 查叫（若勾选）：展示查叫分数
            └─ 亮倒赔付（若触发）：展示【亮倒荒庄】文字并赔付，展示加分和扣分
            ↓ 出小结算界面
```

## 十三、包牌（S10）

| 项 | 规则 |
|---|---|
| **适用范围** | **仅 3 人时开启**；少人开局变为无效；创房面板选 2 人时选项**灰色且不勾选** |
| **触发** | 点炮**亮倒玩家** |
| **赔付范围** | 点炮者需支付**相当于亮倒玩家自摸的分数**，含：**番型 × 加倍项、马、漂、坎** |
| **与买马的关系** | **包牌下买马照常触发**，马分**由点炮者一人承担**。<br>**依据**：① 包牌定义即「亮倒玩家**算自摸**，**分由点炮人一人出**」→ 视同自摸，故「自摸买马 / 亮牌自摸买马」两种触发条件**均满足**（亮倒玩家本身即亮倒）；② 赔付范围明列「**马**」——若买马不触发则马分恒为 0，列此项无意义。买马算法与「买一 / 买一送一 / 买 5 马 / 买 6 马」各档**同常规**（见 §八）|
| **第二家亮倒** | 如果另一个玩家**也亮倒**，则还需支付给**另一个玩家**分数（**按其点炮计算，马、漂、坎也要计算**）。<br>**裁决依据**：需求该行两列口径不同——**说明**列（专门规格列）作「按给其点炮计算（**马、漂、坎也要计算**）」，**说明内容**列（规则卡片摘要列）作「支付该玩家**最大牌型分**」。说明列**给出分项构成**、为细则；卡片列为摘要行文 → **细则优于摘要**，采说明列。**Step 5 已裁** |

每个玩家的结算信息，按以下顺序从前到后展示：

### 15.2 各分项的计算口径

### 15.3 各分项的展示规则

| 分项 | 展示 |

| **胡分** | 仅展示玩家自己参与分数流转的胡分，无则不展示。自摸 / 一炮多响 / 包牌 / 查叫赔付多人等**多条胡分合并为一条**并展示总得分。内容 = 「胡分」+ 实际得分（**实际得分 = 本小局该玩家所有胡的总分**）|

| **荒庄赔付** | · **查叫**：赢分者【查叫+X】，输分者【被查叫−X】<br>· **首亮赔付**：输分者【首亮赔付−X】，赢分者【首亮赔付+X】<br>· **同时出现**：先展示查叫、后展示首亮赔付<br>· 未开启规则或者为 0 **不显示** |
| **漂分** | 漂合并计算，**只显示一条**。显示【漂+X / 漂−X】。未开启或为 0 **不显示** |
| **马分** | 马分合并计算，**只显示一条**。显示【马+X / 马−X】。未开启或为 0 **不显示** |

### 15.6 详情页展示规则

点击玩家自己的结算信息右侧的**详情按钮**，打开详情页签。**整体顺序**：杠分 → 胡分 → 荒庄查叫。

| 分项 | 展示 |
|---|---|
| **杠分** | 展示本小局该玩家参与的所有流转的杠，**多个杠按发生顺序显示**。<br>· **第一行**：杠的种类 + [对象] + 右侧分数。杠的种类 = 暗杠 / 直杠 / 明杠。对象 = 对家 / 上家 / 下家 / 两家。分数 = 该杠实际赢 / 输的分，显示为 +X / −X。<br>· **第二行**：仅当该杠触发**杠上杠**时展示，显示「**杠上杠 \*Y**」（Y 为杠上杠的翻倍倍数）|
| **胡分** | · **合并规则**：玩家输 / 赢多家时，若多家信息完全一致则**合并为一条**，展示总得分与「两家」；否则**分多条**，按本玩家**逆时针顺序**展示与每个玩家的结算信息。<br>· **分条的情况**：本玩家自摸且勾选对亮 X2 而其他两家一家亮一家未亮；本玩家一炮多响。<br>· **第一行**：**类型**（= 自摸 / 被自摸 / 捉炮胡 / 点炮〔含一炮多响〕）+ [对象] + 最右侧分数。若触发封顶，分数下方额外写「（封顶）」。<br>· **第二行**：番型、加倍项。若有亮倒信息**优先展示「亮倒 X2」**，其余按番型表 ID 顺序展示；有其他番型时**不展示【平胡】**；多个信息之间用英文逗号隔开 |
| **荒庄查叫** | · **查叫**：分两行。第一行「查叫 / 被查叫 + [对象] + 分数」；第二行展示具体番型（规则同胡分）。<br>· **首亮赔付**：仅一行，展示「荒庄赔付 + [对象] + 分数」（输赢玩家文字固定）。<br>· **多条与合并**：查叫赢 / 输多个玩家时**每个玩家一条、拆分展示**，顺序为自己开始逆时针；首亮赔付**仅展示一条** |
| **其他分** | 仅一行，展示「数坎 + [对象] + 分数」|
| **漂分** | 仅一行，展示「漂 + [对象] + 分数」|
| **马分** | 仅一行，展示「买马 + [对象] + 分数」|

| 统计项 | 口径 |
|---|---|

## 十六、易错场景

| # | 易错场景 | 正解 |
|---|---|---|
| 1 | 把亮倒 ×2 也乘到漂 / 马 / 坎上 | 亮倒**只乘番型分**，加分项不受影响 |
| 2 | 双方都亮倒直接 ×4 | 未勾选「对亮\*2」时**只计一个亮倒 ×2** |

| 4 | 抢杠胡后仍给明杠玩家算杠分 | 抢杠胡后**明杠玩家视为未杠成功，不收杠分**，杠上杠中断 |

| 6 | 荒庄也算买马 | **荒庄不买马** |
| 7 | 捉炮时胡的那张牌计入数坎 | **捉炮不参与数坎**（只有自摸才把胡的那张算进坎数）|
| 8 | 查叫时把胡的那张牌计入坎分 | 荒庄没有胡的那张，**不计算** |
| 9 | 番型 × 加倍项 = 1 仍可捉炮 | **只有 1 倍时只能自摸** |
| 10 | 清一色和明四归同时计分 | **仅计清一色**，明四归不计 |
| 11 | 龙七对同时计暗四归 | 七对类**与暗四归互斥** |
| 12 | 上楼能突破封顶 | 上楼是**加倍项，受封顶约束** |
| 13 | 包牌只赔番型分 | 包牌**含番型 × 加倍项、马、漂、坎** |
| 14 | 杠上杠把之前的杠分也翻倍转移 | 杠上杠**仅计算本次杠分**，之前的杠分不转移 |
| 15 | 杠上杠时杠上花倍数也跟着翻倍 | 触发杠上花 / 杠上炮 / 抢杠胡时**倍数走初始值**（不随杠上杠翻倍）|
| 16 | 以为高分玩法只会升档 | 三龙七对在高分玩法下为 **80 倍、低于基础的 128 倍**（七对系列 20→40→80 的必然取值）；其余 **6 项升档**，另有「杠开卡五星」为**新增档**（20 倍，基础玩法无此项）|
| 17 | 把「基础番型可叠加」理解成**同维度也相加** | **同维度取高、跨维度叠加**（见 [番型 §1.3](04-番型.md)）：碰碰胡 = **2 倍**（非 平胡 1 + 碰碰胡 2 = 3 倍）；清一色 + 平胡 = **5 倍** |
| 18 | 以为七对类与 4 副面子结构必然互斥 | 两者**可同时成立**（如 `1111筒 2222筒 3333筒 44筒`），此时**取分值较高者**，非互斥 |
| 19 | 以为清一色与七对互斥 | **叠加**——全筒七对 = 七对 4 + 清一色 4 = **8 倍** |
| 20 | 2 人局仍可开启包牌 / 双亮 | **包牌、双亮仅 3 人可开**，2 人时置灰 |

| **坎分** | 胡牌玩家 | 点炮玩家（捉炮）/ 其他所有玩家（自摸）|
| **查叫** | 听牌玩家 | 未听牌玩家 |
| **亮倒荒庄赔付** | **其他所有玩家**（含未亮倒者）| 本小局第一个亮倒的玩家；**1 倍底分** |
| **【卡五星专属】包牌** | 亮倒的捉炮玩家 + 其他亮倒玩家 | 点炮者 |

### 17.2 分值一览

| 项 | 值 |
|---|---|
| **封顶** | 8 / 16 / 32 / 64 / 不封顶 |
| **漂分** | 1 / 2 / 5 / 10（固定漂默认 2）|
| **数坎** | 暗刻 +1 / 明杠直杠 +1 / 暗杠 +2 / 手中四张 +2 |
| **买马** | 中发白 10 倍底分；1~9 同数字倍；买 5/6 马按 1/4/7/白各 1 分 |
| **杠分** | 直杠 2 / 明杠 1 / 暗杠 2；杠上杠按 `2^(n−1)` 翻倍 |
| **上楼** | ×2 / ×4 |
| **亮倒** | ×2；对亮勾选后 ×4 |

### 17.3 主公式速记

```
最终得分 = 底分 × 番型 × 加倍项 + 马分 + 漂分 + 坎分
                └─ 受封顶 ─┘   └────────── 不受封顶 ──────────┘
```
