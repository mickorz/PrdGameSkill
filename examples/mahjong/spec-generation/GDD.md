## 一句话定位

- 项目 ID：`mahjong`
- 游戏名称：卡五星（好友房）
- 品类：地方麻将（卡五星）· 2~3 人好友房私局
- 核心体验（一句话）：以「卡五星」（4-6 卡 5 听口）核心番型为钩子，靠亮倒 ×2、漂/马/坎/杠多加分项与封顶截断的博弈玩法驱动的快节奏地方麻将。（综述，依据 SRC-009 / SRC-320 / SRC-590）

## 目标用户与卖点

- 目标用户：待确认（原文未定义；仅可推知为好友房私局用户，房主创建房间邀请同好，SRC-104）

## 核心循环

```text
进入房局（创房入座）→ 打漂 → 定庄摇骰定方位 → 发牌理牌 → 行牌（逆时针循环）
→ 结束分支（有人胡牌 / 荒庄）→ 买马（仅胡牌分支若触发）→ 小结算 → 大结算 → 续局
```

| 环节 | 玩家目标 | 主要界面 | 成功标准 | 来源事实 |
|---|---|---|---|---|
| 进入房局 | 创建/加入好友房并入座 | 创房面板与牌桌 | 2~3 人坐满、开局 | SRC-104 / SRC-105 / SRC-021 |
| 打漂 | 按创房模式选定漂数（不漂/1/2/5/10） | 选漂环节 | 全员完成选漂、结果常显头像旁 | SRC-110~SRC-116 |
| 定庄摇骰 | 确定首局庄家与方位 | 骰子/方位区 | 庄标与方位显示、骰子停止 | SRC-017~SRC-020 / SRC-118~SRC-130 |
| 发牌理牌 | 拿齐起手牌并自动理牌 | 手牌区 | 庄 14 张/闲 13 张 | SRC-136~SRC-149 |
| 行牌 | 摸打碰杠胡过；听牌后可亮倒扣牌 | 手牌与操作按钮 | 有人胡牌或荒庄收束 | SRC-152~SRC-159 |
| 买马 | 胡牌后翻剩余牌计马分（若触发） | 买马环节 | 马分计入本局得分 | SRC-169~SRC-173 |
| 结算 | 收取胡分/杠分/漂马坎 | 小结算/大结算 | 各家得分展示并续局或终局 | SRC-174~SRC-186 |

## 操作规则

### 摸牌与打牌

- 摸牌时机：轮到自己，且上一家已出牌、无人碰/杠/胡；摸牌需在上一家打出牌的同时进行（上家打出牌的瞬间下家摸牌）。（SRC-202 / SRC-203）
- 摸牌来源与后果：从牌堆取 1 张；手牌 +1，随后进入出牌阶段；摸到的牌置于手牌最右侧。（SRC-204 / SRC-205）
- 打牌：出牌阶段打出 1 张；庄家首巡直接出牌不再摸牌（DERIVED-GDD-D03，SRC-207）。
- 危牌禁打：未亮倒玩家手中既有危牌也有非危牌时，无法打出危牌（判定不计算碰杠牌区）。（SRC-208 / SRC-070）
- 全危牌例外：手中全是危牌时，任何危牌均可打出（不计算碰杠牌区，仅计算手中牌，含摸/补的牌）。（SRC-209 / SRC-072）
- 亮倒后不可改牌，只能摸打；只能打出维持听牌的牌。（SRC-210）
- 扣下的牌带【扣】标签且带遮罩，不可打出。（SRC-211）
- 超时托管：配置开启托管时，出牌超时打新摸进来的牌；碰/杠超时默认【过】；有胡牌的多状态超时默认胡牌。（SRC-095 / SRC-227 / SRC-296 / SRC-299）

### 碰

- 时机：任意一家打出一张牌时；条件：手上有 2 张及以上相同的牌（原文措辞「及以上」，见 AMB-210，实现按恰好持有 2 张同牌处理）；范围：可碰任何一家的牌；危牌可碰。（SRC-229~232 / SRC-073）
- 后果：3 张组成刻子亮于手牌左侧；该玩家取得出牌权，须再打出 1 张。（SRC-233）

### 杠（三种）与杠分

| 杠类 | 触发条件 | 杠分（实时结算） | 可否被抢 | 来源事实 |
|---|---|---|---|---|
| 直杠（别名大明杠） | 别人打出某张牌，手中存在相同 3 张 | 打出牌的玩家支付直杠玩家 2 倍底分 | 不可被抢 | SRC-026 / SRC-239 / SRC-243 |
| 明杠（别名补杠/加杠） | 玩家碰牌后（当前回合不可杠）后续摸到相同的牌 | 其他玩家各支付补杠玩家 1 倍底分 | 可被抢杠胡 | SRC-027 / SRC-240 / SRC-244 |
| 暗杠 | 非碰牌后的出牌阶段，手上有 4 张相同 | 其余玩家各支付暗杠玩家 2 倍底分 | 不可被抢 | SRC-028 / SRC-241 / SRC-245 |

- 杠分实时结算，小局结束时不额外再算。（SRC-029 / SRC-246 / SRC-532）
- 流局未听牌不需要返还杠分；荒庄后杠分不退还。（SRC-030 / SRC-247 / SRC-248 / SRC-535）
- 杠的通用限制：牌堆剩 0 不可杠（SRC-041）；亮倒后手牌中未扣下的牌不可杠（已碰牌的明杠是否受限存在口径冲突，见 GDD-U18，SRC-042 / SRC-259）；未亮倒时危牌不可明杠（补杠），直杠和暗杠可以（SRC-043 / SRC-260）；亮倒后仅扣下的刻子可杠，扣下的刻子若第 4 张在自己手中且已亮出仍不可杠（会改牌）（SRC-044 / SRC-261）。
- 补牌：杠牌之后从牌堆倒序摸一张牌，视为摸牌；剩余牌数额外减 1 张。（SRC-269 / SRC-270 / SRC-045）
- 抢杠胡边界：补杠且有人选择是否抢杠胡时，不播放动画与飘分，直到抢杠胡玩家完成选择再走对应流程（交互时序，机制见「抢杠胡」条）。（SRC-267 / SRC-465）

### 回手杠（两条）

- 回手杠①：手上有 3 张一样的牌，别人打出时如果选择碰，则这张牌本小局不能再明杠。（SRC-038 / SRC-255）
- 回手杠②：已经碰过的牌，摸到第四张时必须立刻杠，否则本小局这张牌不能再明杠。（SRC-039 / SRC-256）
- 配置说明：回手杠为常驻规则；需求名词条标注「（配置）」但三张创房表均无对应开关项，开关名与默认值需求未给，按「常驻规则层约束」登记、不虚构开关。（SRC-040 / SRC-257，待确认 GDD-U05）

### 杠上杠（连杠）

- 触发：玩家杠牌后摸到的牌继续杠；或补牌后打出的牌被别人杠。（SRC-031 / SRC-249）
- 倍率公式（照录）：本次杠分 = 基础杠分 × 2^(连续杠次数 − 1)；连杠次数 1/2/3/n 对应 1/2/4/2^(n−1) 倍。（SRC-032 / SRC-250 / SRC-534）
- 跨玩家：连杠可跨玩家连续——A 杠→打出一张被 B 杠（算连杠）→B 打出一张被 C 杠（仍算连杠）。（SRC-033 / SRC-251）
- 中断：玩家补牌后打出一张无人杠，则本次连杠结束，倍数清零重新计算。（SRC-034 / SRC-252）
- 需求原文连杠示例 T1~T4：A 补杠收 1 分→A 杠上暗杠收 2×2=4 分→B 直杠收 2×(2×2)=8 分→B 杠上打出无事发生，重置，下次从 ×2 重新开始。（SRC-035 / SRC-254）
- 杠上杠仅计算杠分，之前的杠分不转移。（SRC-036 / SRC-253 / SRC-574）
- 杠上杠时触发杠上花、杠上炮、抢杠胡，这些倍数不跟随杠上杠翻倍，走初始值（初始 2，可勾选为 4）。（SRC-037 / SRC-253 / SRC-527）

### 抢杠胡专项

- 仅针对明杠（补杠）；直杠、暗杠不可抢（原文自附推导：需求只明示「明杠可抢」，直杠的牌可正常点炮、暗杠无外部牌）。（SRC-456，DERIVED 于源文件）
- 可多人抢杠胡一家；多人计分细节未明示（建议按「各抢杠者各按 ×2 分别向补杠者收分」实现，待确认 GDD-U15）。（SRC-457 / SRC-498）
- 后果：明杠玩家视为未杠成功、不收取杠分；杠上杠也会中断。（SRC-048 / SRC-460）
- 杠分冲销：已实时收取的该杠杠分需回退。（SRC-049 / SRC-345 / SRC-461，DERIVED-GDD-D05）
- 属点炮类，计入点炮次数（与点炮胡同口径）。（SRC-050 / SRC-458，DERIVED-GDD-D04）
- 不触发上楼（即便多人抢杠胡也不等同于一炮多响）。（SRC-051，DERIVED-GDD-D07）
- 多人抢杠胡时，由补杠的那一家坐庄。（SRC-052 / SRC-346 / SRC-462，DERIVED-GDD-D06）

### 过与漏胡

- 过的定义：有机会碰/杠/胡时主动放弃。（SRC-297）
- 漏胡（过胡）：玩家可胡牌时选择不胡即为漏胡；漏胡玩家摸牌前不可胡牌；漏胡状态在摸牌后解除（含杠后补牌）。（SRC-093 / SRC-1037 / SRC-429~431）
- 多面听示例：A 打 7 条，B 听 7 条与 4 筒而选择不胡→进入漏胡；下一次摸牌前任何人再打 7 条或 4 筒 B 均不可胡；B 摸牌（含杠后补牌）后解除。（SRC-434）
- 过碰/过杠：过碰后、轮到自己回合前，其他玩家再打出同张牌时不可再碰；过杠与过碰同口径。（SRC-096 / SRC-1039 / SRC-1040，DERIVED-GDD-D13，待确认 GDD-U17）

### 操作优先级与多状态

- 操作优先级：吃胡 / 自摸 / 抢杠胡 > 碰 / 杠；同一张牌既有胡又有碰时，胡优先。（SRC-092 / SRC-236 / SRC-286 / SRC-419）
- 有胡牌的多状态，配置开启托管时超时默认胡牌；其余超时默认【过】。（SRC-296 / SRC-299）
- 非托管模式的超时行为未定义。（SRC-496，待确认 GDD-U16）

### 亮倒

- 权限三触发：①打出一张非危牌后可听牌→可选择是否亮倒；②手牌中全是危牌→去掉「非危牌」限制同样触发；③自摸时每次都会展示亮的权限。（SRC-053 / SRC-1001~1003）
- 前提：玩家摸/补牌之后，若勾选「少于12张不亮」且牌堆牌 < 12 张，则不会再触发亮牌（不下放权限）。（SRC-058 / SRC-651）
- 后果：明牌（亮出所有手中牌）、不可改牌只能摸打；亮倒的牌必须维持听牌；胡的牌成为其他未亮倒用户的危牌；玩家亮倒后自己的危牌标签去掉。（SRC-054 / SRC-1005~1007 / SRC-427）
- 计分：输/赢时均计算亮倒，番型分 ×2，不影响加分项。（SRC-055 / SRC-1009 / SRC-488）
- 对亮：输赢双方均亮倒仅计算一次亮倒 ×2；若创房勾选「对亮 *2」则计算两个亮倒（共 4 倍）。（SRC-056 / SRC-1010 / SRC-339）
- 部分亮（创房勾选）：亮倒后仅非扣下、与胡的牌相关的牌亮出，其余牌全部扣下；不影响算分，仅决定亮出范围。（SRC-057 / SRC-650）
- 胡牌必须亮倒（创房勾选）：勾选后仅亮倒状态下才能胡牌；与「双亮」互斥。（SRC-059 / SRC-486 / SRC-426）
- 双亮（创房勾选，【卡五星专属】）：仅 3 人时可勾选、2 人时置灰；勾选后 3 人时若已有 2 个玩家亮倒，第三个玩家无需亮倒也能胡牌（自摸、点炮均可，DERIVED-GDD-D20）；勾选后若改为 2 人开局，该规则自动失效；与「胡牌必须亮倒」互斥。（SRC-060 / SRC-487 / SRC-656 / SRC-682）

### 扣牌

- 触发时机：亮倒的同时进行扣牌判断；亮倒之后不可再扣牌。（SRC-061 / SRC-1019）
- 可扣判断（照录）：遍历手中所有刻子与四张相同牌逐个判断，将该刻子去掉（四张相同则去掉三张）→剩余手牌仍满足「打出一张非危牌后可听牌」→可扣；不满足→不可扣。（SRC-062 / SRC-1020）
- 扣下张数：3 张相同（刻子）全部扣下（3 张）；4 张相同扣下 3 张。（SRC-063 / SRC-1021）
- 多组同时扣下：可同时扣多组刻子，但需再次检测扣多组后剩余手牌是否仍满足条件。（SRC-064 / SRC-1022）
- 需求原文示例两则：①手牌筒 12333·78999·中中中、摸进 5 条无危牌，打出 5 条听 369 筒；中/3 筒/9 筒可单独扣下，但 3 筒与 9 筒同时扣后不满足条件不可同扣；②手牌 11 56667 听 1 和 6，扣住 6 后手牌变为 11 57 仅听 6。（SRC-065 / SRC-1023 / SRC-1025）
- 扣牌与听牌：扣牌后按剩余亮出的牌决定听牌。（SRC-066 / SRC-1024）
- 展示与空集：扣住的刻子亮倒后他人不可见（牌背朝上）；没有可扣的刻子时跳过扣牌环节。（SRC-067）
- 危牌可以扣下（只要满足扣牌条件）。（SRC-068）

### 危牌

- 定义：同一小局中，未亮倒玩家手中的牌若是任一亮倒玩家胡的牌→标记为危牌；碰杠牌区的牌不算危牌；玩家亮倒后危牌标签去掉。（SRC-069 / SRC-422）
- 危牌限制 1：危牌不可打出（未亮倒玩家手中既有危牌也有非危牌时，不计算碰杠牌区）。（SRC-070 / SRC-208）
- 危牌限制 2：不可危牌明杠（补杠）；可直杠和暗杠。（SRC-071 / SRC-428）
- 危牌限制 3：手中牌全是危牌时可打出危牌（仅计算手中牌，含摸/补的牌）。（SRC-072 / SRC-209）
- 危牌可以碰。（SRC-073）

## 番型与胡牌条件

### 结构与判定流水线

- 结构三大类：4 副面子+1 对将（4×3+1×2=14）；七对 2N（7×2=14，含四张相同按「龙」计）；条件型（不独立构成结构，为追加的听口或四归条件）。（SRC-300）
- 判定层次七步（照录，SRC-315）：①拆结构（七对/4 副面子，同时成立取分值较高者）；②结构内取高（七对按龙数取档；面子结构下小三元→大三元取高）；③叠加各维度番型（三元、花色、听口、手牌形态、四归子；七对结构下另叠加三元七对 ×2，不按取高处理）；④处理互斥（清一色×明四归/三元类；七对类×四归；三元七对×小三大三元）；⑤各维度求和得牌型分；⑥加倍项乘算参与封顶截断（例外：高分玩法下杠开卡五星按 20 倍合并档不叠乘）；⑦加分项加算不受封顶。
- 判定顺序（判胡顺序口径）：拆结构→结构内取高→维度叠加（相加）→互斥处理→求和牌型分→加倍项乘算参与封顶→加分项加算不封顶；番型先算、限制层后过，判定顺序不影响结果。（SRC-315 / SRC-410 / SRC-287 / SRC-090）
- 「取高」与「相加」分界示例（照录）：中发白三刻+123 筒+44 筒将 = 平胡 1 + 大三元 8 = 9 倍；同三刻+111 筒+99 筒将全刻 = 碰碰胡 2 + 大三元 8 = 10 倍。（SRC-302 / SRC-517）
- 维度划分：结构（平胡/碰碰胡）、花色（清一色）、三元（小三元/大三元）、听口（卡五星）、手牌形态（手抓一）、四归子（明/暗各自独立）、七对（四档）、七对叠加项（三元七对）。（SRC-303，DERIVED-GDD-D09）
- 跨结构取高：七对与 4 副面子两结构可同时成立时取分值较高者（原文示例：1111 筒 2222 筒 3333 筒 44 筒——七对侧=三龙七对 128+清一色 4=132 倍；面子侧=平胡 1+清一色 4=5 倍，取七对侧）。（SRC-305 / SRC-515）
- 条目数核对：基础番型 14+加倍项 8+其他加分项 4+高分玩法合并档 1=合计 27 条。（SRC-378）

### 胡牌限制层（五层，任一拦截即不可胡）

牌型判定（计分条件）与限制层（否决条件）为 AND 关系，判定顺序无关结果。（SRC-090 / SRC-287 / SRC-400 / SRC-420）

1. 限制 1 番数门槛：番型 × 加倍项 > 1 才可捉炮（点炮）；只有 1 倍时只能自摸；自摸不受限。需求原文照录：「只有 1 倍时，只能自摸，＞1 倍时，可自摸可捉炮（番型 × 加倍项）」。示例：平胡 1 倍、无任何加倍项与加分项→只能自摸不可捉炮；平胡 1 倍+亮倒 ×2→1×2=2＞1→可以捉炮。加分项是否参与门槛判定未明示（按公式字面实现，待确认 GDD-U13）。（SRC-091 / SRC-415~418 / SRC-499）
2. 限制 2 危牌：打出的牌是危牌则阻断；手中全是危牌时例外放行（见「危牌」节）。（SRC-422 / SRC-283）
3. 限制 3 亮倒限制（可选）：勾选「胡牌必须亮倒」且未亮倒则不可胡；已 2 人亮倒（双亮）时第三人例外放行。（SRC-405 / SRC-423 / SRC-426）
4. 限制 4 漏胡：处于漏胡状态则摸牌前不可胡牌；摸牌后（含杠后补牌）解除。（SRC-406 / SRC-424 / SRC-429~431）
5. 限制 5 操作优先级：吃胡/自摸/抢杠胡 > 碰/杠，优先级低者让位。（SRC-407 / SRC-425）

各胡法 × 限制层对照（照录，SRC-492）：自摸类（自摸/杠上花/海底捞）番数门槛不受限、不受危牌限制、漏胡摸牌后即解除；捉炮类（点炮/杠上炮/抢杠胡/海底炮）番数门槛 > 1 才可、受危牌/亮倒/漏胡限制；一炮多响各胡牌方各自判（各判番数门槛 > 1、各自判危牌/亮倒/漏胡限制、各家分别计分）。（SRC-493）

## 结算规则

### 主公式（照录）

- 小局结束的最终得分 = 底分 × 番型 × 加倍项 + 马分 + 漂分 + 坎分。（SRC-500 / SRC-591）
- 所引需求原文 §2.4 另有：「小局结束的最终得分 = 底分 × 番型 × 加倍项 + 番型加分项 + 马分 + 漂分 + 坎分 + 字分」——其中「番型加分项」「字分」本套源文件无任何定义，二者是否存在待确认（以正文公式为准）。（SRC-592 / SRC-593，待确认 GDD-U11）
- 底分 = 1（需求未单列底分配置项，推导值）。（SRC-503，DERIVED-GDD-D01，待确认 GDD-U19）

### 结算顺序（照录）

结算信息展示顺序：胡分 → 杠分 → 荒庄查叫 → 漂分 → 马分 → 其他分（坎分）。（SRC-013 / SRC-575）

### 结算流水线 S0~S11（照录，SRC-504）

- S0 确认对局结果（有人胡牌→走 S1~S8，再走 S10 若触发包牌、S11 若触发特殊场景；荒庄→走 S9）
- S1 牌型分（各维度番型汇总，同维度取高、跨维度相加）
- S2 分值 remap（勾选「高分玩法」后按换档表重算）
- S3 番型×加倍项（牌型分×Π各加倍项倍数）
- S4 封顶截断（番型×加倍项>封顶倍数则取封顶倍数）
- S5 +杠分（实时结算，不受封顶）
- S6 +马分（不受封顶）
- S7 +漂分（不受封顶）
- S8 +坎分（不受封顶）
- S9 荒庄分支（仅荒庄时走）
- S10 包牌（仅点炮亮倒玩家时走）
- S11 特殊场景（一炮多响/对亮/杠上杠）
- 最终得分 = 底分×番型×加倍项+马分+漂分+坎分

### 加倍项公式（照录）

番型 × 加倍项 = 牌型分 × Π(各加倍项倍数)。（SRC-522）

| 加倍项 | 倍数 | 触发与规则 | 来源事实 |
|---|---|---|---|
| J01 亮倒 | 2 | 亮倒状态下输/赢均计算，番型分 ×2；不影响加分项（漂/马/坎/杠分） | SRC-338 / SRC-055 |
| J02 对亮 | 2（勾选「对亮*2」后双方均亮倒与亮倒相乘得 4 倍；未勾选只计一个亮倒 ×2） | 输赢双方均亮倒时生效 | SRC-339 / SRC-056 |
| J03 杠上花 | 2 常驻（勾选「杠上花/炮*4」后 4） | 杠牌后通过补的牌胡牌；不随杠上杠翻倍走初始值 | SRC-340 / SRC-446~449 |
| J04 杠上炮 | 2 常驻（勾选后 4） | 杠牌后补牌打出的牌让其他玩家胡牌；同上 | SRC-341 / SRC-450~453 |
| J05 抢杠胡 | 2 常驻（随「杠上花/炮*4」勾选为 4） | 补杠时其他家胡这张补杠的牌；未杠成功、杠分回退、连杠中断 | SRC-344~347 |

- 加倍项易错点（照录）：亮倒 ×2 只乘番型分、不影响加分项；未勾选「对亮*2」时双方都亮倒只计一个亮倒 ×2；上楼是加倍项、受封顶约束，不可突破封顶。（SRC-528）

### 封顶（照录）

- 需求原文照录：「封顶只控制番型 × 加倍项的倍数，马分、漂分、坎分、杠分这种额外加分项不受封顶影响，单独计算」。（SRC-530）
- 封顶口径仅计算「番型×加倍项」，不可超过封顶倍数；触发 = 番型×加倍项 > 封顶倍数时按封顶倍数计算；不参与封顶的项 = 所有加分项（漂、马、坎、杠）不参与封顶计算、无上限；上楼为加倍项不可突破封顶倍数；可选值 8/16/32/64/不封顶。（SRC-529 / SRC-638）
- 封顶示例（照录）：示例 1（未触发）封顶 32 倍，清一色（4）+碰碰胡（2）=6 倍牌型分，亮倒 ×2=12 倍 < 32 不截断；示例 2（触发）封顶 32 倍，清一色（4）+手抓一（2）+碰碰胡（2）=8 倍牌型分，亮倒 ×2=16，上楼 ×4=64 > 32 截断为 32 倍；若本局漂分 3 倍底分、马分 5 分，则最终得分 = 底分 × 32（截断后的番型×加倍项）+ 3 倍底分（漂，不受封顶）+ 5 分（马，不受封顶）。（SRC-531）
- 默认 8 倍（默认值依据为截图 IMG-601：AI 无法读取截图数值，需人工提供文本补充；实拍下拉露出 128 倍与选项列冲突，已裁按选项列 8/16/32/64/不封顶，DERIVED-GDD-D25）。（SRC-602 / SRC-630）

### 加分项总原则（照录）

加分项为额外加分，每一项单独计算，不与番型、加倍项进行乘算，且不受封顶影响（无上限）。（SRC-352 / SRC-507）

### 漂分（照录）

- 漂分公式（照录）：胡牌玩家向某玩家收取的漂分 = （胡牌玩家漂数 + 该玩家漂数）× 底分。（SRC-544 / SRC-078）
- 收分方向：捉炮胡仅收点炮玩家；自摸胡收所有玩家；每个玩家单独计算。（SRC-545 / SRC-578）
- 需求原文漂分示例照录：A 漂 0、B 漂 2、C 漂 1——B 自摸收 A (2+0) = 2 倍底分、收 C (2+1) = 3 倍底分；A 点炮 B 胡牌仅收 A (2+0) = 2 倍底分。（SRC-547 / SRC-079）
- 漂四模式：不漂 / 自由漂 / 开局定漂（首局定漂）/ 固定漂；自由漂选项【不漂】【漂1】【漂2】【漂5】【漂10】；固定漂下拉框 1/2/5/10、默认 2（需求明文，取明文不取实拍）。（SRC-074~077 / SRC-642 / SRC-629）
- 荒庄时漂也赔（查叫赔付含漂分）。（SRC-080 / SRC-546）
- 「漂数」的取值来源未明示（推断=玩家所选漂值，待确认 GDD-U12）。（SRC-594）

### 马分（照录）

- 马分 = 买马的总得分，不受封顶影响；自摸收取所有玩家。（SRC-537 / SRC-542）
- 买一：剩余牌翻 1 张，中发白记 10 倍底分、1~9 条/筒记同数字倍底分，数量不足时不买马。（SRC-082 / SRC-538）
- 买一送一：翻 2 张，两张分数之和为该小局马分，数量不足时不买马。（SRC-082 / SRC-539）
- 买 6 马：翻 6 张，出现 1/4/7/白 每张计 1 倍底分，总分为该小局马分；数量不足有多少买多少、剩余牌为 0 则不买；中 0 张按 6 马计分。（SRC-083 / SRC-540）
- 买 5 马：翻 5 张，出现 1/4/7/白 每张计 1 分；一张不中或中 5 张，按 6 马计分。（SRC-084 / SRC-541）
- 命中集「1/4/7/白」不含中、发系有意设计（84 张中命中 28 张=1/3；若含中发则为 36/84 非常数比例）；与买一/买一送一的「中发白记 10 倍」不矛盾——后者按牌面值给分（全牌覆盖）、前者按是否命中计数（仅四类）。（SRC-085）
- 触发模式：不买马 / 自摸买马（自摸胡后触发）/ 亮牌自摸买马（亮牌自摸胡后触发）；荒庄不买马。（SRC-081 / SRC-086 / SRC-543 / SRC-173）
- 单位「1 分」与「1 倍底分」按底分=1 等值处理（待确认 GDD-U20）。（SRC-541 / SRC-590）

### 坎分（数坎，照录）

- 计算范围 = 自己的手中 + 胡的那张 + 碰杠牌区。（SRC-548 / SRC-087）
- 加分表（照录）：每个暗刻 +1 倍底分；每个明杠/直杠 +1 倍底分；每个暗杠 +2 倍底分；手中 4 张一样的牌 +2 倍底分（必须是顺+刻，不与暗刻重复计算）。（SRC-549 / SRC-088）
- 关键口径（照录）：必须是刻子（仅是 3 张相同牌但不成刻的不算）；胡的那张自摸才参与计算、捉炮不参与；查叫时计算坎分但不计算胡的那张牌（因为荒庄没有胡）。（SRC-551 / SRC-089）
- 收分对象 = 需付胡牌分的玩家：点炮胡收放炮玩家；自摸胡收其他所有玩家；不受封顶影响。（SRC-550）
- 需创房勾选「数坎」才开启（默认值依据为截图 IMG-601：AI 无法读取截图数值，需人工提供文本补充）。（SRC-614 / SRC-661）

### 杠分（照录）

- 三类（实时结算）照录：直杠 2 倍底分（打出牌的玩家→直杠玩家）；明杠（补杠）1 倍底分（其他玩家各付→补杠玩家）；暗杠 2 倍底分（其余玩家各付→暗杠玩家）。（SRC-533 / SRC-026~028）
- 杠上杠公式（照录）：本次杠分 = 基础杠分 × 2^(连续杠次数 − 1)；连杠可跨玩家连续；中断后重新计算。（SRC-534 / SRC-032~034）
- 荒庄杠分不退还；流局未听牌不需要返还杠分。（SRC-535 / SRC-030）
- 抢杠胡后明杠玩家视为未杠成功，不收取杠分（实现上为已实时收取的该杠杠分需回退），杠上杠也会中断。（SRC-536 / SRC-049）
- 杠上杠仅计算杠分，之前的杠分不转移。（SRC-574 / SRC-036）

### 荒庄分支（S9，照录）

- 荒庄触发：可摸牌数 = 0 且无人胡牌（牌堆摸完）仍无人胡牌即荒庄。（SRC-502 / SRC-164）
- 荒庄结算路径（照录）：牌堆摸完无人胡→所有玩家摊牌展示、展示【荒庄】→有未听牌玩家？无→直接出小结算；有→所有未听牌玩家飘字【未听牌】→查叫（若勾选）展示查叫分数；亮倒赔付（若触发）展示【亮倒荒庄】文字并赔付、展示加分和扣分→出小结算界面。（SRC-563 / SRC-165~167）
- 荒庄不买马；荒庄后杠分不退还。（SRC-556 / SRC-543 / SRC-173）

### 查叫（照录）

- 查叫公式（照录）：未听牌玩家→听牌玩家赔付 = 底分 × 番型 × 加倍项 + 漂分 + 坎分；其中「底分×番型×加倍项」受封顶控制，漂分、坎分不受封顶。（SRC-552）
- 开启条件：需勾选「查叫」才开启（默认值依据为截图 IMG-601：AI 无法读取截图数值，需人工提供文本补充）；最大倍数计亮倒（需求原文照录）。（SRC-553 / SRC-621）
- 查叫时坎分口径：计算坎分但不计算胡的那张牌（没有胡）；听双碰时会生效。（SRC-555）
- 查叫时漂也赔。（SRC-556）

### 首亮赔付（亮倒荒庄赔付，【卡五星专属】，照录）

- 规则（照录）：荒庄后如果存在玩家亮倒，本小局第一个亮倒的玩家向其他所有玩家赔付 1 倍底分。（SRC-557 / SRC-014）
- 赔付对象裁决：采「其他玩家」（= 除自己外的全部玩家，含未亮倒者；DERIVED-GDD-D18）。（SRC-558 / SRC-692）
- 金额：统一「1 倍底分」表述（§2.3.6 未定稿草稿「查叫赔 2 倍分」不作为口径依据）。（SRC-559）
- 变体表：卡五星赔付 1 倍底分；十堰卡五星赔付 2 倍底分（本变体为 1 倍）。（SRC-560）
- 查叫与亮倒荒庄可同时赔付（卡五星、十堰卡五星中）；展示先查叫、后首亮赔付。（SRC-562 / SRC-561）

### 包牌（【卡五星专属】，照录）

- 适用范围：仅 3 人时开启；少人开局变为无效；创房面板选 2 人时选项灰色且不勾选。（SRC-564 / SRC-632 / SRC-682）
- 触发：点炮亮倒玩家；赔付范围：点炮者需支付相当于亮倒玩家自摸的分数，含番型×加倍项、马、漂、坎。（SRC-565）
- 包牌下买马照常触发，马分由点炮者一人承担。（SRC-566，DERIVED-GDD-D14）
- 第二家亮倒：如果另一个玩家也亮倒，则还需支付给另一个玩家分数（按其点炮计算，马、漂、坎也要计算；裁决采说明列细则，DERIVED-GDD-D19）。（SRC-567）
- 结算标签：点炮者展示【点炮】；捉炮者展示【包牌】；获得包牌赔付的玩家展示【包牌】。（SRC-568 / SRC-578）

### 一炮多响（照录）

- 各家分别和牌、分别计分；轮庄为点炮玩家坐庄；上楼联动为触发下一小局的上楼 ×2（同一大局内）。（SRC-569 / SRC-480 / SRC-481）
- 结算标签：捉炮玩家展示【捉炮胡】；点炮玩家展示【一炮多响】。（SRC-570）
- 一炮多响 × 包牌组合：点炮者向每个胡牌玩家分别赔付；其中亮倒的胡牌玩家那一笔按包牌口径计（相当于自摸的分数，含番型×加倍项、马、漂、坎）；各亮倒胡牌者各得一份，均按包牌口径；未亮倒的胡牌者按其正常捉炮胡计算。（SRC-571 / SRC-572）
- 大结算点炮统计：一炮多响只算一次（一小局最多一次）。（SRC-482 / SRC-016 / SRC-585）

### 易错场景正解（选录自需求 20 条正解汇总，SRC-587）

1. 亮倒只乘番型分，加分项（漂/马/坎）不受影响。
2. 未勾选「对亮*2」时只计一个亮倒 ×2。
3. 漂/马/坎/杠均不受封顶。
4. 抢杠胡后明杠玩家视为未杠成功不收杠分、杠上杠中断。
5. 荒庄杠分不退还；荒庄不买马。
6. 捉炮不参与数坎（只有自摸才把胡的那张算进坎数）。
7. 查叫时没有胡的那张、不计算。
8. 只有 1 倍时只能自摸。
9. 清一色和明四归同时满足仅计清一色。
10. 七对类与暗四归互斥（龙七对不同时计暗四归）。
11. 上楼是加倍项受封顶约束。
12. 包牌含番型×加倍项、马、漂、坎。
13. 杠上杠仅计算本次杠分、之前的杠分不转移；杠上杠时杠上花/杠上炮/抢杠胡倍数走初始值。
14. 同维度取高、跨维度叠加（碰碰胡 = 2 倍而非平胡 1 + 碰碰胡 2 = 3 倍；清一色 + 平胡 = 5 倍）。
15. 七对类与 4 副面子结构可同时成立、取分值较高者、非互斥；清一色与七对叠加（全筒七对 = 8 倍）。
16. 包牌、双亮仅 3 人可开、2 人时置灰。
