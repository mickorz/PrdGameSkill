## 4. 总体建议

问题最集中的模块是断线重连 / 场景恢复，共 4 条，即 Q02、Q13、Q18、Q19，其次是听牌提示系列与结算系列。建议优先解决 P0 的 Q01（承载查听的常驻组件与查听按钮显隐规则整体缺失）和 Q02（end_wait 场景快照自动应答链路缺失），随后处理 P1 中的 Q03、Q06、Q14、Q15 以及 Q07、Q08、Q09、Q10 四条冲突，并合并 Q15 与 Q29、Q30 与 Q01、Q33 与 Q06、Q38 与 Q09、Q40 与 Q39、Q49 与 Q55、Q65 与 Q57、Q66 与 Q61 等同根因重复条目。结论：不建议进入开发。P0 尚未闭环，重连与结算两条主链路仍为空白或彼此矛盾，此时开发必然返工，建议补齐后再评审一轮。
