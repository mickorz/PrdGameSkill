# 听牌提示（客户端 UI 交互基准）

> 来源：input-ui/xuanwulobby/assets/42319 代码逆向，提取日期 2026-11-11。锚点格式：文件 → 方法。检查需求文档对听牌提示相关交互的描述是否完整、与实现一致。

## 一、听牌数据下发与解析（查听 / 打听）

1. 听牌信息是服务端单向下发数据：下行协议 XZ_GP_WAIT_INFO 被映射为命令 CMD_WAIT_INFO 后交给 GameWaitInfoCmd 处理，客户端不存在主动请求查听或打听的发送接口（GameController 只有出牌、胡、过、吃、碰、杠、结束等待等 send 方法）。锚点：input-ui/xuanwulobby/assets/42319/controller/gameController.ts → Hzmj_SVR_PUSH_CMD_BY_XYID / input-ui/xuanwulobby/assets/42319/protocol/GameGlcProtocol.ts → XYID.XZ_GP_WAIT_INFO。

2. 非自己座位的听牌包被整包丢弃，已胡牌的自己也丢弃该包，即界面只承载自己、且未胡牌时的听牌数据。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute（localSeat != SELF_LOCAL_SEAT return、GameData.getIsHu(SELF_LOCAL_SEAT) return）。

3. 同一听牌包按 play_mah 拆成两路：play_mah==0 的记录是「已听/查听」结果，play_mah!=0 的记录是「打哪张牌后会听什么」的打听结果，两路共用同一个列表弹窗展示。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute（noPlayTingInfo、playTingInfos）。

4. 仅收到查听记录（play_mah==0 且无任何打听记录）时，客户端立即写入当前听牌数据、计算汇总并直接刷新听牌按钮，不等待分包结束标记。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute（noPlayTingInfo !== undefined && playTingInfos.length === 0 分支 → checkShowTingBtnOnRecover）。

5. 分包起始（START）或整包（ALL）到达时先清空旧的打听缓存，避免上一手残留；同一包内既有查听又有打听时，先写查听数据再走打听箭头，防止提前 return 把箭头清空。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute（clearCanTingValue、noPlayTingInfo 先写 setTingVaule）。

6. 打听数据要等分包结束（END）或整包（ALL）才合并计算「大/多/优」听牌类型；分包中间态（UPDATE/START 的单条）只累积数据、不判定类型，因此中途不会出现类型箭头。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute（flag END/ALL 才 calcCanTingInfo）。

7. 重连补数据阶段（justUpdateData）只写数据缓存并直接返回，不派发听牌箭头、不亮听牌按钮、不播特效；界面恢复依赖后续实时下发或重连场景恢复。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute（justUpdateData return 位于界面分支之前）。

8. 单条听牌数据由协议字段构造：card 取 mah、fan 取 point、fanId 固定 0、fanIdEx 取 fan_ids、cnt 固定 0、tingType 固定为普通听牌；服务端不下发剩余张数，剩余张数完全由客户端计算后回填。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → _modifyTingInfo。

9. 听牌剩余张数来自客户端记牌器估算：初始化每种牌 4 张，自己摸牌、自己手牌、他人出牌、他人碰、他人杠会扣减，他人摸牌与牌墙剩余不参与统计，因此列表中「剩余张数」是可见信息估算值而非服务端精确值。锚点：input-ui/xuanwulobby/assets/42319/data/GameData.ts → initCardCounter / updateCardCounter / getMahLeftCount，配合 GameTakeCmd.ts → execute（localSeat === SELF_LOCAL_SEAT && updateCardCounter）。

10. 汇总计算会重算总张数、总收益、最大番数、最大显示番数，并按房间封顶（max_mult，匹配场改用 GameData.getMaxMult）截断；当最大番数为 0（无剩余张数）时按 1 倍显示。锚点：input-ui/xuanwulobby/assets/42319/data/GameData.ts → calcTingInfo。

11. 听牌类型判定规则：番数严格最大且不全相同、且不只一个候选时标「大听」；剩余张数最多且最大值比最小值至少多 2 张时标「多听」；同时满足大与多的标「优听」并从大/多中剔除；未命中的保持普通。锚点：input-ui/xuanwulobby/assets/42319/data/GameData.ts → calcCanTingInfo。

12. 代码中保留了一条「已胡时把可听牌数据清空」的守卫，但承载该守卫的写入方法没有调用方（见第 62 条），胡牌后的实际清理由胡牌命令派发空听牌数据并隐藏听牌按钮、关闭弹窗完成。锚点：input-ui/xuanwulobby/assets/42319/data/GameData.ts → setCanTingVaule（getIsHu 时 canTingValue = {}），input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuView。

## 二、听牌按钮与自动胡按钮（KW_CompTing）

13. 听牌入口组件位于主界面底部中央，资源默认隐藏且没有控制器联动，只能由代码显隐；组件内含「听牌」按钮、受 C_IsHu 页控制的「自动胡」按钮与祈福按钮。锚点：input-ui/xuanwulobby/fgui_game/fgui_hzmj/assets/box_hzmj_main/component/HzmjMainComponent.xml → KW_CompTing，component/CompTing.xml → C_IsHu / KW_BTN_TING / KW_BTN_AUTOHU。

14. 听牌组件的显隐唯一入口是 showTingPaiBtn(show)，它只改 KW_CompTing.visible；组件资源本身以隐藏态发布，局结束与重置 UI 时显式传入 false。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → showTingPaiBtn / resetUI / onGameEnd，input-ui/xuanwulobby/fgui_game/fgui_hzmj/assets/box_hzmj_main/component/HzmjMainComponent.xml → KW_CompTing（visible="false"）。

15. 自己出牌后（checkShowTingBtnOnPlay）固定先关闭听牌列表弹窗，再判断：仍有打听数据时手牌箭头保留（注释明确匹配场常先到 play_mah==0 的 recover，勿误清）；当前无听牌数据或自己已胡则隐藏按钮；否则显示按钮并把 C_IsHu 置为「胡」页。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → showTingBtn（@gf.listen checkShowTingBtnOnPlay）/ _refreshTingCompHuState。

16. 自己摸牌后（checkShowTingBtnOnTake）同时关闭听牌列表弹窗并隐藏听牌按钮，即摸牌到出牌之间的这段时间不提供听牌入口。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → checkShowTingBtnOnTake。

17. 权限更新时（checkShowTingBtnOnPower）分两个独立条件：拥有出牌权则隐藏听牌按钮；拥有胡权则关闭听牌列表弹窗（隐藏弹窗但不隐藏听牌按钮）。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → checkShowTingBtnOnPower。

18. 自己胡牌时（checkShowTingBtnOnSelfHu）隐藏听牌按钮并关闭听牌祈福提示，按钮与祈福同时下线。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → checkShowTingBtnOnSelfHu / onHideQFTingPaiBtn。

19. 重连恢复（checkShowTingBtnOnRecover）等价于执行一次出牌后的按钮检查，并把托管/自动胡状态回填到自动胡按钮；此时若玩家未托管，会同时把本地自动胡标记复位为 false。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → checkShowTingBtnOnRecover / _checkBotAutoBtn。

20. 小局结束、荒牌、重置 UI 都会关闭听牌按钮与听牌祈福按钮；荒牌还额外关闭听牌列表弹窗。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onGameEnd，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameDrawnCmd.ts → execute（showTingPaiBtn false、hideFgui）。

21. C_IsHu 只有单向置 1 的代码（听牌后显示自动胡按钮），整个模块没有任何复位为 0 的调用，因此同一局内只要出现过一次听牌，后续每次显示听牌组件都会带出自动胡按钮。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → _refreshTingCompHuState（唯一写入点）。

22. 点击自动胡按钮没有二次确认与前置校验：直接置本地自动胡标记并请求托管，匹配场走 reqMatchTrust，普通房间走 reqTrustee(kBotAuto)。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onBtnAutohu（由 KW_BTN_AUTOHU 名称自动绑定，见 input-ui/xuanwulobby/assets/node_modules/kiwi/src/core/FguiView.ts → processBtnEvent）。

## 三、听牌列表弹窗（BoxHzmjTingPaiView）

23. 听牌列表是 Pop 层弹层，声明为可缓存、notLoading，依赖 box_hzmj_tingPai 与 box_hzmj_mah2D_Main 两个分包；进入游戏后会在预加载阶段提前加载该分包目录。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → @FguiView，input-ui/xuanwulobby/assets/42319/Game42319.ts → preloadGameRes。

24. 点击听牌按钮是开关式交互：弹窗已打开则关闭并返回，未打开才读取当前听牌数据打开；按钮点击由「KW_BTN_」名称约定自动绑定到 onBtnTing，代码没有额外的点击监听。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onBtnTing，input-ui/xuanwulobby/assets/node_modules/kiwi/src/core/FguiView.ts → processBtnEvent。

25. onBtnTing 未对 getTingVaule() 判空，直接传给 showFgui；「无听牌数据时不可点击」完全依赖按钮显隐守卫，而不是点击时校验。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onBtnTing。

26. 同一弹窗也用于提牌时的单张听口预览，第二处入口把 canTing[mahValue] 直接交给 showFgui，与查听列表共用同一套渲染逻辑。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onUpDownMah。

27. 列表排序先按番数降序，番数相同再按牌值升序，排序直接作用于传入的数据数组。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → initUI（this._data = data.tingInfo.sort）。

28. 弹窗按条目数切换 6 档布局：1 条、2 条、3 条、4 条、5 到 8 条、其余（含 0 条与 9 条以上）分别对应 C_Count 的 0 到 5 页，布局宽度与行高由控制器驱动。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → initUI（C_Count.selectedIndex 分支）。

29. 听牌列表不是虚拟列表：setVirtual 调用被注释，改为直接设置 numItems 并逐条 itemRender，条目数量与听牌牌种数量一致。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → initUI（// setVirtual 注释、numItems = cnt）。

30. 单条听牌渲染写三个值：牌面、倍数、剩余张数；剩余张数为 0 时整张牌置灰，非 0 时恢复正常颜色。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → itemRender（setMahColor gray/normal）。

31. 单条倍数显示受房间封顶约束：房间 max_mult 大于 0 时显示 min(番数, max_mult)，否则原样显示服务端番数。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → itemRender。

32. 倍数文字的宽度档位由番数决定：番数小于 1000 用窄版（<=3 字），番数大于等于 1000 切到宽版（4 字），避免长数字溢出。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → itemRender（conLen.selectedIndex = data.fan < 1000 ? 0 : 1），input-ui/xuanwulobby/fgui_game/fgui_hzmj/assets/box_hzmj_tingPai/component/TingCard.xml → C_Len。

33. 封顶文案规则：封顶值为 0 或 -1 显示「无封顶」，其余显示「封顶N倍」；普通房间取房间规则 max_mult，匹配场取对局下发的 GameData.getMaxMult。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → initUI（KW_FengDing 分支）。

34. 匹配场存在两套封顶来源不一致的风险：封顶文案使用 GameData.getMaxMult，而单条倍数截断仍使用房间规则 BoxRoomData.getGameRule().max_mult，两值不同时会出现「文案封顶值与实际截断值不同」。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → initUI 与 itemRender。

35. 听牌总张数 KW_HuNum 由各听牌牌种的剩余张数求和得出，不是服务端字段。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → calcTotalCnt。

36. 监听 updateTingPaiViewLeftCnt 只重新求和并刷新总张数文本，既不重新计算每张听牌的剩余张数（未调用 calcTingInfo），也不重绘列表项（虚拟列表刷新代码被注释）；因此他人出牌、碰、杠、胡时该事件对已打开的列表几乎无可见变化。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → updateTingPaiViewLeftCnt / calcTotalCnt。

37. 弹窗没有超时自动关闭逻辑，关闭路径全部是显式事件：再次点听牌按钮、触摸手牌区、自己出牌、自己摸牌、获得胡权、自己胡牌、荒牌、局结束、重置 UI。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onTouchOther / showTingBtn / checkShowTingBtnOnPower / checkShowTingBtnOnTake / checkShowTingBtnOnSelfHu，GameDrawnCmd.ts → execute。

38. 触摸手牌区的任何一次按下（无论是否命中某张牌、手牌是否可触摸）都会先触发 touchOtherCb，主界面在该回调里关闭听牌弹窗并派发点击桌面事件；因此提牌时是「先关弹窗、抬起后再用该牌听口重新打开」，不存在「点弹窗自身也关闭」的分支。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onTouchOther，input-ui/xuanwulobby/assets/biz_modules/mahModule/src/mah2D_Box/TouchHandCardsBaseBox.ts → onTouchBegin。

39. 换牌背时弹窗会遍历已生成的列表项逐张刷新牌背，避免监听牌背变更后弹窗内仍是旧牌背。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → onChangeMahBack。

40. 弹窗资源内的爆头页（C_BaoTou）、番型提示 KW_FanTip、爆头单卡 KW_BaoTou 在 42319 代码中没有任何引用，永远不会被显示（死 UI 分支，需求不得据此描述爆头态听牌列表）。锚点：input-ui/xuanwulobby/fgui_game/fgui_hzmj/assets/box_hzmj_tingPai/component/TingPai.xml → C_BaoTou / KW_FanTip / KW_BaoTou。

## 四、听牌箭头（手牌牌面提示）

41. 听牌箭头挂在自己手牌牌面上方（节点 KW_TingTip，Spine 动画，默认隐藏、不可点击），手牌组件来自 game_mah 包而非 box_hzmj_mah2D_Main 包。锚点：input-ui/xuanwulobby/fgui/assets/game_mah/component/hand/mahHandSelf.xml → KW_TingTip，input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMah2DView.ts → initUI（"ui://game_mah/mahHandSelf"）。

42. 箭头显隐与形态由 setCardTing 统一控制：关闭时隐藏节点；开启时按听牌类型切换 Spine 动画名，普通/大/多/优分别对应 HuPaiTips、HuPaiDaTips、HuPaiDuoTips、HuPaiYouTips，类型越界一律回落为普通。锚点：input-ui/xuanwulobby/assets/biz_modules/mahModule/src/mah2D_Box/Mah2DBaseBox.ts → setCardTing。

43. 同一种牌在手上有多张时只给最右一张标真实听牌类型箭头，其左侧同牌只显示普通箭头；判断从手牌末尾向头部扫描并用值去重。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjPlayerHandCards.ts → showTingArrow（showFlag 去重、TYPE_COMMON 兜底）。

44. 没有听牌信息的牌会被显式关闭箭头，因此每次刷新都是一次全量重绘，不会残留上一手的箭头。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjPlayerHandCards.ts → showTingArrow（else 分支 setCardTing(item, false)）。

45. 清空手牌会同时清空全部听牌箭头；自己胡牌时派发空听牌数据同样会清空箭头。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjPlayerHandCards.ts → clear，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuView（setTingInfo {}）。

46. 自己出牌后不会直接清空箭头，而是仅在仍有打听数据时用打听数据刷新（保留 play_mah==0 先到的重连场景），没有打听数据才清空。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → showTingBtn（keepDaTingArrow）。

47. 听牌亮光动画只在「出牌后首次进入听牌」时播一次，由 GameData 的听牌动画标记守门；听牌数据为空时只复位标记不播动画。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GamePlayCmd.ts → _updateTingMahAni（setTingMahAni）。

48. 首出牌阶段非庄家玩家会补一次听牌动画检查（重连到首出场景时补偿亮光），检查条件为「有听牌数据且标记未播过」。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GamePowerCmd.ts → _updateFirstPlayTips，input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMah2DView.ts → checkShowTingPaiAni。

## 五、提牌联动与出牌拦截

49. 提牌链路：手牌每次抬起调用 upDownCardCb(牌值, true)，主界面 onUpDownMah 收到后立刻用打听数据中该牌对应的听口打开听牌列表。锚点：input-ui/xuanwulobby/assets/biz_modules/mahModule/src/mah2D_Box/TouchHandCardsBaseBox.ts → upDownCard，input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onUpDownMah。

50. 提牌弹出听口列表的条件是：打听数据存在该牌、自己未胡、牌值不为 0、动作为抬起；没有出牌权校验，因此只要数据在就可能弹出。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onUpDownMah。

51. 放下牌不会关闭听牌弹窗：放下时只把牌值 0 派发给特殊牌高亮事件，没有 hideFgui 分支，弹窗继续保留到下一次关闭事件。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onUpDownMah。

52. 每次提牌、放牌还会派发 showSpecialMah（抬起的牌值 / 0），用于特殊牌高亮，与听牌弹窗独立。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onUpDownMah（this.dispatch(showSpecialMah, isUp ? mahValue : 0)）。

53. 单击直接出牌前有听牌拦截：若该牌存在打听数据、自己未胡且牌值不为 0，单击出牌被拒绝（需改为提牌或双击出牌），该拦截只对「单击出牌」类型生效，且单击出牌本身还要求开启「单独出牌」开关。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → canPlayMahCheck（WillPlayMahType.ONE_TOUCH 分支），input-ui/xuanwulobby/assets/biz_modules/mahModule/src/mah2D_Box/TouchHandCardsBaseBox.ts → _handleTouchDownCard。
