# 听牌提示（客户端 UI 交互基准）

> 来源：input-ui/xuanwulobby/assets/42319 代码逆向，提取日期 2026-11-11。锚点格式：文件 → 方法。检查需求文档对听牌提示相关交互的描述是否完整、与实现一致。

## 一、听牌数据下发与解析（查听 / 打听）

1. 听牌数据只有「服务端推送」一条来路：推送映射表把 XYID.XZ_GP_WAIT_INFO 映射到命令 CMD_WAIT_INFO，客户端发送侧只有出牌、过、胡、吃、碰、杠、结束等待以及特殊手牌/特殊摸牌/特殊牌墙等接口，不存在主动查听或打听的请求，因此界面上不存在「发起查询」的等待态与失败态。锚点：input-ui/xuanwulobby/assets/42319/controller/gameController.ts → Hzmj_SVR_PUSH_CMD_BY_XYID，input-ui/xuanwulobby/assets/42319/protocol/GameGlcProtocol.ts → XYID.XZ_GP_WAIT_INFO / MsgWaitInfo。

2. 听牌包有前置守卫：非自己座位（localSeat != SELF_LOCAL_SEAT）整包丢弃，自己已胡（GameData.getIsHu(SELF_LOCAL_SEAT)）也整包丢弃，界面只承载「自己且未胡」的听牌数据。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute。

3. 一个听牌包按 play_mah 拆成两路：play_mah==0 的记录是「已听/查听」结果，play_mah!=0 的记录是「打哪张牌会听什么」的打听结果，两路共用同一个听牌列表弹窗。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute（noPlayTingInfo / playTingInfos）。

4. 只有查听记录（存在 play_mah==0 且没有任何打听记录）时，客户端立即写入当前听牌数据、计算汇总并直接派发「恢复式」按钮检查后返回，不等待分包结束标记。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute（noPlayTingInfo !== undefined && playTingInfos.length === 0 分支 → checkShowTingBtnOnRecover）。

5. 分包起始（START）或整包（ALL）到达时先清空旧的打听缓存；同一包内既有查听又有打听时先写查听数据再写打听数据，避免提前 return 把箭头清掉。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute（clearCanTingValue、noPlayTingInfo 先 setTingVaule）。

6. 打听数据要等分包结束（END）或整包（ALL）才合并计算「大/多/优」听牌类型，并用合并后的全量打听数据刷新手牌箭头；分包中间态只累积数据，因此中途不会出现类型箭头。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute（flag END/ALL 才 calcCanTingInfo 与 dispatch setTingInfo）。

7. 同一包的 END/ALL 分支里，若自己当前有杠权，会再做一次「手里有杠牌时能否继续听/开花」判定（手牌数模 3 余 2、打听数据非空、手里只有一组四张或碰后单张），命中即弹 QF_SHOW_TYPE.GANG_CARD_CANNOT_HU 提示；代码注释说明「移除记牌器后不再基于剩余张数判定，统一按无法精确判断处理」。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute，input-ui/xuanwulobby/assets/42319/data/GameData.ts → checkCanGangBao。

8. 重连补数据阶段（justUpdateData）只写数据缓存并直接返回，位置在「数据/界面」分界线之后，因此不刷箭头、不亮听牌按钮、不播特效；界面恢复依赖后续实时下发或场景恢复。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → execute。

9. 单条听牌记录由协议字段直接映射：card 取 mah、fan 取 point、fanIdEx 取 fan_ids；cnt 固定 0、fanId 固定 0、tingType 固定为普通听牌，四个汇总字段全部置 0，剩余张数必须由客户端随后计算回填。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameWaitInfoCmd.ts → _modifyTingInfo。

10. 汇总计算会重算每张牌的剩余张数、总张数、总收益（底分固定 1 × 番数加权）、最大番数与最大显示番数，并按房间封顶（max_mult，匹配场改用 GameData.getMaxMult）截断；最大番数为 0（无剩余张数）时按 1 倍显示。锚点：input-ui/xuanwulobby/assets/42319/data/GameData.ts → calcTingInfo。

11. 听牌列表里的「剩余张数」是客户端记牌器估算值，不是服务端字段：初始化时每种牌 4 张（两房牌去掉万子），扣减点只有自己发牌整手、自己摸牌、他人出牌、他人碰（前两张）、他人杠；他人发牌、他人摸牌与牌墙剩余都不参与，扣减值被钳制在 0 到 4 之间。锚点：input-ui/xuanwulobby/assets/42319/data/GameData.ts → initCardCounter / updateCardCounter / getMahLeftCount，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameTakeFirstCmd.ts → execute，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameTakeCmd.ts → execute，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GamePlayCmd.ts → _updatePlayData，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GamePungCmd.ts → execute，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameKongCmd.ts → execute。

12. 复盘模式下记牌器既不初始化也不扣减（三个入口都以 isFupanMode 直接 return），剩余张数恒为 0，因此复盘时打开的听牌列表所有牌面都是置灰态、总张数为 0。锚点：input-ui/xuanwulobby/assets/42319/data/GameData.ts → initCardCounter / updateCardCounter / recoverCardCounter / getMahLeftCount，input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → itemRender。

13. 「大/多/优」判定写在客户端：番数严格最大且候选不全相同、候选多于一个才标「大听」；剩余张数最多且最大值比最小值至少多 2 张才标「多听」；同时命中大与多的标「优听」并从大、多中同时剔除；未命中的保持普通听牌。锚点：input-ui/xuanwulobby/assets/42319/data/GameData.ts → calcCanTingInfo。

## 二、听牌按钮与自动胡按钮（KW_CompTing）

14. 听牌入口是主界面底部中央的 KW_CompTing 组件，资源以隐藏态发布（visible="false"）且没有控制器联动，只能由代码显隐；组件内含「听牌」按钮（KW_BTN_TING）、受 C_IsHu 页控制的「自动胡」按钮（KW_BTN_AUTOHU）与祈福按钮（KW_BTN_Qi_Fu_Ting）。锚点：input-ui/xuanwulobby/fgui_game/fgui_hzmj/assets/box_hzmj_main/component/HzmjMainComponent.xml → KW_CompTing，component/CompTing.xml → C_IsHu / KW_BTN_TING / KW_BTN_AUTOHU / KW_BTN_Qi_Fu_Ting。

15. 组件显隐的唯一方法是 showTingPaiBtn(show)，它只改 KW_CompTing.visible；重置 UI 与小局结束时都显式传入 false。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → showTingPaiBtn / resetUI / onGameEnd。

16. 自己出牌后（checkShowTingBtnOnPlay）固定先关闭听牌列表弹窗，再刷新手牌箭头，然后判断：无听牌数据或自己已胡则隐藏听牌按钮并结束；否则显示按钮并把 C_IsHu 置为「胡」页。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → showTingBtn / _refreshTingCompHuState，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GamePlayCmd.ts → _updateSelfPlayView。

17. 自己摸牌后（checkShowTingBtnOnTake）同时关闭听牌列表弹窗并隐藏听牌按钮，即「摸牌到出牌之间」不提供听牌入口；该事件只在抓牌玩家是自己时派发。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → checkShowTingBtnOnTake，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameTakeCmd.ts → _updateTakeView。

18. 权限更新时（checkShowTingBtnOnPower）是两个独立判断而非互斥分支：拥有出牌权则隐藏听牌按钮；拥有胡权则关闭听牌列表弹窗（关弹窗但不隐藏听牌按钮）；两者可同时命中。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → checkShowTingBtnOnPower，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GamePowerCmd.ts → _updateSeatPowerView。

19. 自己胡牌时（checkShowTingBtnOnSelfHu）隐藏听牌按钮并关闭听牌祈福按钮及其下飘，按钮与祈福同时下线。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → checkShowTingBtnOnSelfHu / onHideQFTingPaiBtn，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _dispatchSetHu。

20. 重连恢复（checkShowTingBtnOnRecover）等价于执行一次出牌后的按钮检查，并把托管/自动胡状态回填到自动胡按钮的选中态；回填值为 false 时同时把本地自动胡标记复位。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → checkShowTingBtnOnRecover / _checkBotAutoBtn。

21. 小局结束（公共局结束通知）只隐藏听牌按钮与听牌祈福按钮，不调用弹窗的 hideFgui；听牌列表弹窗的关闭由胡牌、出牌、摸牌、点击桌面区等事件分别负责。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onGameEnd，input-ui/xuanwulobby/assets/common_game/controller/cmd/NotifyBoxActionCmd.ts → execute（dispatch GameCommonUIEventDefine.onGameEnd），input-ui/xuanwulobby/assets/common_game/controller/cmd/NotifyMatchActionCmd.ts → execute。

22. C_IsHu 只有单向置 1 的写入（听牌后显示自动胡按钮），全模块没有复位为 0 的调用；自动胡按钮用 gearDisplay 绑在 C_IsHu 的第 1 页，因此同一局内只要出现过一次听牌，之后每次显示听牌组件都会带出自动胡按钮。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → _refreshTingCompHuState（唯一写入点），input-ui/xuanwulobby/fgui_game/fgui_hzmj/assets/box_hzmj_main/component/CompTing.xml → KW_BTN_AUTOHU gearDisplay pages="1"。

23. 点击自动胡按钮没有二次确认与前置校验：直接置本地自动胡标记并请求托管，匹配场走 reqMatchTrust，普通房间走 reqTrustee(kBotAuto)；按钮点击由「KW_BTN_」名称约定自动绑定到 onBtnAutohu。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onBtnAutohu，input-ui/xuanwulobby/assets/node_modules/kiwi/src/core/FguiView.ts → processBtnEvent。

## 三、听牌列表弹窗（BoxHzmjTingPaiView）

24. 听牌列表是 Pop 层弹层，声明为可缓存（cachable）、notLoading，依赖 box_hzmj_mah2D_Main 与 box_hzmj_tingPai 两个分包；进入游戏后预加载阶段会提前加载 box_hzmj_tingPai 目录。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → @FguiView 声明，input-ui/xuanwulobby/assets/42319/Game42319.ts → preloadGameRes。

25. 点击听牌按钮是开关式交互：弹窗已打开则关闭并返回，未打开才读取当前听牌数据打开；「听牌」按钮由 KW_BTN 名称约定自动绑定到 onBtnTing，没有额外 addClick。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onBtnTing，input-ui/xuanwulobby/assets/node_modules/kiwi/src/core/FguiView.ts → processBtnEvent。

26. onBtnTing 不校验数据是否为空，直接把 GameData.getTingVaule() 传给 showFgui；「无听牌数据时打不开」完全依赖按钮显隐守卫，而不是点击时校验。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onBtnTing。

27. 同一弹窗还承担提牌时的单张听口预览：把打听数据中该牌对应的 tingInfo[mahValue] 直接交给 showFgui，与查听列表共用同一套渲染逻辑，两种入口没有视觉区分。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onUpDownMah。

28. 列表排序先按番数降序、番数相同再按牌值升序；排序是对传入的 tingInfo 数组原地 sort，而该数组就是 GameData 里保存的同一份数据，因此会改变后续读取顺序。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → initUI。

29. 弹窗按条目数切换 6 档布局：1 条、2 条、3 条、4 条、5 到 8 条、其余（含 0 条与 9 条以上）分别对应 C_Count 的第 0 到第 5 页，宽度与高度由 C_Count 的 gearSize 驱动（344、536、729、925 单行、925 两行、925 三行）；C_Count 的第 6 页「baotou」代码从不选中。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → initUI（C_Count.selectedIndex 分支），input-ui/xuanwulobby/fgui_game/fgui_hzmj/assets/box_hzmj_tingPai/BoxHzmjTingPaiView.xml → C_Count gearSize。

30. 听牌列表不是虚拟列表：setVirtual 调用被注释，改为直接设置 numItems 并逐条 itemRender，列表条目数等于「听牌牌种数」而不是剩余张数。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → initUI（// setVirtual 注释、KW_PaiGrp.numItems = cnt）。

31. 单条听牌渲染三处内容：牌面（Mah2DBase_Box.setCard）、倍数（KW_BeiShuNum）、剩余张数（KW_LeftNum）；剩余张数为 0 时牌面置灰（MahColor_Box.gray），非 0 时恢复普通色（MahColor_Box.normal）；倍数文字宽度另有档位，番数小于 1000 用窄版（不超过 3 字）、大于等于 1000 切宽版（4 字）。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → itemRender（C_Len.selectedIndex = data.fan < 1000 ? 0 : 1），input-ui/xuanwulobby/fgui_game/fgui_hzmj/assets/box_hzmj_tingPai/component/TingCard.xml → C_Len。

32. 单条倍数受房间封顶约束：房间 max_mult 大于 0 时显示 min(番数, max_mult)，否则原样显示服务端番数。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → itemRender。

33. 封顶文案规则：封顶值为 0 或 -1 显示「无封顶」，其余显示「封顶N倍」；普通房间取房间规则 max_mult，匹配场改取对局下发的 GameData.getMaxMult。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → initUI（KW_FengDing 分支），input-ui/xuanwulobby/assets/42319/data/GameData.ts → getMaxMult。

34. 匹配场存在两套封顶来源：弹窗左下文案用 GameData.getMaxMult，而单条倍数截断仍用 BoxRoomData.getGameRule().max_mult，两值不同时会出现「文案封顶值与列表实际截断值不一致」。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → initUI 与 itemRender。

35. 弹窗中央的听牌总张数 KW_HuNum 由各听牌牌种的剩余张数求和得出，不是服务端字段。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → calcTotalCnt。

36. 监听 updateTingPaiViewLeftCnt 时只重新求和并刷新总张数文本：既不重新计算每张听牌的剩余张数（未再调用 calcTingInfo），也不重绘列表项（虚拟列表刷新被注释、numItems 未变不会重新 itemRender），因此他人出牌、碰、杠、胡触发的该事件对已打开列表几乎无可见变化。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → updateTingPaiViewLeftCnt / calcTotalCnt，派发方 input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GamePlayCmd.ts → _updateOtherPlayerPlayView、GamePungCmd.ts → execute、GameKongCmd.ts → execute、GameHuExCmd.ts → _updateHuView。

37. 弹窗没有超时自动关闭，资源内既无关闭按钮也无 KW_AUTO_CLOSE 节点，关闭路径全部是显式事件：再次点听牌按钮、触摸桌面区（任意按下，含手牌不可触摸时）、自己出牌、自己摸牌、获得胡权、自己胡牌；关闭入口分别是 onBtnTing、onTouchOther、showTingBtn、checkShowTingBtnOnTake、checkShowTingBtnOnPower 与胡牌命令。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onBtnTing / onTouchOther / showTingBtn / checkShowTingBtnOnTake / checkShowTingBtnOnPower，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _dispatchSetHu，input-ui/xuanwulobby/fgui_game/fgui_hzmj/assets/box_hzmj_tingPai/BoxHzmjTingPaiView.xml → displayList。

38. 触摸区域绑定在桌面触摸图（KW_Desk_Image，见 BoxHzmjMah2DView.initUI 的 setTouchArea），该区域任何一次按下都会先回调 touchOtherCb，主界面在该回调里关闭听牌弹窗并派发点击桌面事件；手牌不可触摸（canTouch=false）时同样回调，因此不存在「按下时弹窗不关」的情况。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onTouchOther（initSelfHand 绑定 touchOtherCb），input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMah2DView.ts → initUI（setTouchArea(view.KW_Desk_Image)），input-ui/xuanwulobby/assets/biz_modules/mahModule/src/mah2D_Box/TouchHandCardsBaseBox.ts → onTouchBegin。

39. resetUI（再来一局/重开）只隐藏听牌按钮与祈福按钮，不关闭听牌列表弹窗，弹窗清理依赖后续胡牌或手牌事件。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → resetUI。

40. 换牌背时弹窗会遍历当前 numItems 逐张刷新列表项牌背；弹窗资源内的爆头页（C_BaoTou）、爆头单卡（KW_BaoTou）、番型提示（KW_FanTip / KW_FanIdTxt）、行数控制器 C_Row 在 42319 全模块没有任何写入点（代码只写 C_Count 与 C_Len），因此不会出现爆头态听牌列表、也不会展示番型名称（死 UI 分支，需求不得据此描述）。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjTingPaiView.ts → onChangeMahBack / initUI / itemRender，input-ui/xuanwulobby/fgui_game/fgui_hzmj/assets/box_hzmj_tingPai/component/TingPai.xml → C_BaoTou / KW_BaoTou / KW_FanTip / C_Row。

## 四、听牌箭头（手牌牌面提示）

41. 听牌箭头挂在手牌牌面上方（纵向偏移 -46），是 loader3D 动画节点，资源默认隐藏、不可点击、loop=true、默认动画名 HuPaiTips。锚点：input-ui/xuanwulobby/fgui/assets/game_mah/component/hand/mahHandSelf.xml → KW_TingTip，input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMah2DView.ts → initUI（手牌组件来源）。

42. 箭头显隐与形态由 setCardTing 统一控制：ting=false 时隐藏节点；ting=true 时按听牌类型切换动画名——普通 HuPaiTips、大听 HuPaiDaTips、多听 HuPaiDuoTips、优听 HuPaiYouTips，类型越界一律回落为 HuPaiTips；节点同时置 playing=true。锚点：input-ui/xuanwulobby/assets/biz_modules/mahModule/src/mah2D_Box/Mah2DBaseBox.ts → setCardTing。

## 五、提牌联动与出牌拦截

49. 提牌链路：手牌抬起时由手牌组件回调 upDownCardCb(牌值, true)，主界面 onUpDownMah 用打听数据中该牌对应的听口打开听牌列表弹窗。锚点：input-ui/xuanwulobby/assets/biz_modules/mahModule/src/mah2D_Box/TouchHandCardsBaseBox.ts → upDownCard，input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onUpDownMah（initSelfHand 绑定 upDownCardCb）。

50. 提牌弹出听口列表的条件是：打听数据存在该牌、自己未胡、牌值不为 0、动作为抬起；该分支没有出牌权校验，只要数据命中且手牌可触摸就会弹出。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onUpDownMah。

51. 放下牌不会关闭听牌弹窗：放下时只额外派发 showSpecialMah(0)，没有 hideFgui 分支，弹窗保留到下一次关闭事件。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onUpDownMah。

52. 每次提牌与放牌都会派发 showSpecialMah（抬起时是牌值、放下时是 0），用于特殊牌高亮，与听牌弹窗互相独立。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → onUpDownMah（dispatch showSpecialMah，isUp ? mahValue : 0）。

53. 单击直接出牌前有听牌拦截：单击出牌类型下，若该牌存在打听数据、自己未胡且牌值不为 0，canPlayMahCheck 返回 false，本次不出牌；单击出牌本身还要求可出牌（canPutCard）且开启「单独出牌」开关，任一不满足都会回落到「抬起该牌」，从而又打开听口弹窗。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → canPlayMahCheck（WillPlayMahType.ONE_TOUCH 分支），input-ui/xuanwulobby/assets/biz_modules/mahModule/src/mah2D_Box/TouchHandCardsBaseBox.ts → _handleTouchDownCard / playCard。

54. 当自己拥有胡权且操作按钮组仍未收起时，任何出牌都被拦截并弹出 3 秒提示「点“过”才能出牌」，与听牌拦截是两条独立守卫（该提示写在出牌前置校验里，对提牌后的出牌同样生效）。锚点：input-ui/xuanwulobby/assets/42319/layer/BoxHzmjMainView.ts → canPlayMahCheck（showHu && C_BtnState.selectedIndex == 3 分支）。

55. 补杠会把手牌中与碰牌同值的牌当作「已打出那张」去查打听表：自己未胡时把听牌数据切换为该张对应的听口并清空打听缓存，保证补杠后听牌按钮与列表同步。锚点：input-ui/xuanwulobby/assets/42319/data/PlayerCardsData.ts → setCombo（CMF_TKONG 分支，CMF_CARDS）。

## 六、听牌相关提示、特效与音效

56. 听牌后的连续未胡提示只在「自己有出牌权且有本次摸牌记录」时判定一次；连续 3 次听牌未胡触发 LISTEN_CARD_LAST_3_NOT_HU 祈福弹窗，连续 3 次摸到缺张触发 THREE_TIMES_TOUCH_THE_FIXED_CARD 祈福弹窗（二者 if/else if 互斥），有杠权且满足听牌条件时另追加 GANG_CARD_CANNOT_HU 提示。锚点：input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GamePowerCmd.ts → _checkListenPop / _updateTingNotHuCount / _showTingCountPop / _showGangCannotHuPop，input-ui/xuanwulobby/assets/42319/controller/cmd/gameCmd/GameTakeCmd.ts → _updateTakeView（setHadTaskCard / setTingNotSuitCardCount）。
