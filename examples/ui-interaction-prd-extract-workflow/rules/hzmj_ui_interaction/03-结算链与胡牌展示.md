# 结算链与胡牌展示（客户端 UI 交互基准）

> 来源：input-ui/xuanwulobby/assets/42319 代码逆向，提取日期 2026-11-11。锚点格式：文件 → 方法。检查需求文档对结算链与胡牌展示相关交互的描述是否完整、与实现一致。

## 一、局终消息与界面收束

1. 收到 GP_END_GAME 时执行 CMD_END_GAME；GameEndCmd 只记录日志并在非 justUpdateData 时派发 onGameEnd，不直接弹出任何小结算或大结算界面。锚点：assets/42319/controller/cmd/gameCmd/GameEndCmd.ts → execute；assets/42319/controller/gameController.ts → Hzmj_SVR_PUSH_CMD_BY_XYID。
2. 收到 onGameEnd 的界面收束：TipAniView 立即调用 onClearResultScore（强制推进飘分回调并隐藏分数节点）；MainView 隐藏听牌按钮与听牌祈福按钮；PlayerMatchView 关闭所有玩家离线/托管展示并清空权限光效；Mah2DView 只清倒计时文字；PlayerView 的 onMsgGameEnd 为空实现。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onGameEnd；assets/42319/layer/BoxHzmjMainView.ts → onGameEnd；assets/42319/layer/BoxHzmjPlayerMatchView.ts → onGameEnd；assets/42319/layer/BoxHzmjMah2DView.ts → onGameEnd；assets/42319/layer/BoxHzmjPlayerView.ts → onMsgGameEnd。
3. onClearResultScore 是飘分阶段的失败恢复兜底：对本轮所有未完成座位依次触发保底完成回调，使计数达到总数并推进后续动画链；随后 runId 自增使旧回调全部失效；分数节点延迟 2 帧隐藏并停止动画，避免客户端结束过快时节点被误隐藏。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onClearResultScore。
4. 再来一局/重连重置时清理结算表现：MainView.resetUI 清空 GameData、隐藏胡牌台面标识、隐藏通用小结算视图；TipAniView.resetUI 隐藏 KW_ResultScore0~3、停止其 ani 并把 alpha 复位为 1、隐藏胡牌与碰杠动画、把 C_GameEnd 置为无结束类型；CardDownView.resetUI 隐藏全部胡牌底图和出牌底图。锚点：assets/42319/layer/BoxHzmjMainView.ts → resetUI；assets/42319/layer/BoxHzmjTipAniView.ts → resetUI；assets/42319/layer/BoxHzmjCardDownView.ts → resetUI。
5. 结束等待采用 askid 回执：GameEndWaitCmd 记录服务端 askid；若此时存在"发牌结束待回执"标记，则清除该标记并立即调用 sendEndWait 后返回，不进入后续界面分支。锚点：assets/42319/controller/cmd/gameCmd/GameEndWaitCmd.ts → execute；assets/42319/data/GameData.ts → setTakeFirstEndWait/getTakeFirstEndWait。
6. 局终消息本身不产生结算弹层：END_GAME 不调用 CMD_GAME_RESULT、CMD_GAME_TOTAL_RESULT，也不派发 showBoxTotalResult；结算弹层必须由 ResultHu 链或通用结算数据流另行触发（可达性见第十二节）。锚点：assets/42319/controller/cmd/gameCmd/GameEndCmd.ts → execute。

## 二、胡牌结果数据处理

7. 胡牌结果入口的前置守卫：hu_items 为空时直接 return，不写胡牌数据、不派发任何动画或结算事件。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → execute。
8. 进入胡牌处理先清桌分（clearTableScore）、清复盘权限（clearFuPanPower）、清番型缓存（clearHuFanIds）；ResultHu 额外把出牌步骤置为 false，HuEx 仅在胡牌座位为自己时置 false。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateHuData；assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuData。
9. 对每个 hu_item 的固定写入：服务器座位换本地座位、setIsHu(true)、PlayerCardsData.setHu 重置手牌/副露并返回是否需要移除点炮河牌、记录 hu_type 与 dan_fang、番型列表写入 GameData.setHuFanIds；需要移除河牌时清空 GameData.lastCard（同时取消出牌箭头数据）。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuData；assets/42319/data/PlayerCardsData.ts → setHu。
10. 点炮类判定为 HT_DISCARD、HT_DIAN_GANG_HUA、HT_ROBKONG 三种；ResultHu 据此把胡牌家台面标识记为 HU_PAO、把点炮来源记为 DIAN_PAO；HT_SELF 记为 HU_ZI_MO。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _isPaoHuType/_updateHuData；assets/42319/config/GameDefine.ts → HuType/ResultTableSign。
11. 未胡座位的台面标识：无 jiao_zui 字段时一律 NO_TING；有 jiao_zui 时，座位在 jiao_zui_seats 内记 TING，否则记 NO_TING。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuData。
12. 一炮多响判定两处口径不同：ResultHu 用 hu_items.length > 1；HuEx 用服务端下发的 duo_xiang 字段。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuData；assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateHuData。
13. 抢杠胡（HT_ROBKONG）表现：把点炮来源玩家对应的补杠组合降级为碰（CMF_TKONG 改 CMF_PONG、清空 nMaha、nInMahs 填 3 张 dan_fang），然后以 setHandCard 重刷该玩家手牌与副露，保证桌面不残留第 4 张补杠牌。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateRobKongHuView；assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateRobKongHuView。
14. 桌分写入只服务非零分：win_losts 中 score === 0 的座位直接跳过，不生成飘分节点；其余座位写 type=NONE、score、mult、state、endWait=false，并记录自己胡牌的最大 mult。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateTableScore；assets/42319/config/GameDefine.ts → ResultScoreType。
15. 玩家身上分更新：player_score.scores 按服务器座位顺序写入对应玩家 sr；该步骤只改数据，不直接派发分数界面刷新。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updatePlayerScore。
16. 自己点炮统计：按 hu_items 顺序扫描，自己作为 df_from 的点炮类胡（含点杠花、抢杠胡）连续段只计 1 次，多次点炮累加；结果连同自己最大倍率写入 setLastPaoHu。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateLastPaoHu。
17. 自己胡牌后的界面守卫：禁止继续出牌（setPlayCardStep(false)）、隐藏听牌弹层、清空听牌信息、隐藏听牌按钮；若自己处于托管状态，额外派发托管提示。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _dispatchSetHu；assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _dispatchSetHu。

## 三、台面标识（几胡/叫嘴/点炮/自摸）

18. 每个本地座位对应一个 HuIndex 节点；onShowResultTableSign 时节点 visible=true，并把 C_HuType.selectedIndex 写为 sign；sign 取值 NO_TING=0、TING=1、DIAN_PAO=2、HU_PAO=3、HU_ZI_MO=4。锚点：assets/42319/layer/BoxHzmjMainView.ts → onShowResultTableSign；assets/42319/config/GameDefine.ts → ResultTableSign；assets/42319/fgui_uideclare/box_hzmj_main/FGUI_box_hzmj_main_HuIndex.d.ts → C_HuType。
19. 带 aniIndex 与 nextCallBack 的台面标识显示会 scheduleOnce 1.5 秒后推进下一段动画；不带回调时只显示，不推进链。锚点：assets/42319/layer/BoxHzmjMainView.ts → onShowResultTableSign。
20. 台面标识清理：onClearResultTableSign 隐藏全部 HuIndex 节点；MainView.resetUI 会主动调用一次，保证换局后不残留上一局标识。锚点：assets/42319/layer/BoxHzmjMainView.ts → onClearResultTableSign/resetUI。
21. 重连恢复台面标识只传座位号：RecoverHuInfoCmd 在重放 HuEx 数据后，对 huIndex 非零的座位派发 onShowResultTableSign(i)，未传 sign 与动画回调，MainView 会把 undefined 写入 C_HuType.selectedIndex，且不进入 1.5 秒推进链；同时以自己为胡牌来源重放 onSetHu（needRemove=false）。该表现的前提是 HuEx 重放不抛错（见第 86 条）。锚点：assets/42319/controller/cmd/helperCmd/RecoverHuInfoCmd.ts → execute；assets/42319/layer/BoxHzmjMainView.ts → onShowResultTableSign。
22. 结束类型横幅：C_GameEnd.selectedIndex 直接取 EndGameFlag（0 无、1 胡牌、2 荒牌、3 被动结束）；模块内唯一派发点是 ResultHu 在 end_type==ET_DRAWN 时置 ET_DRAWN，resetUI 置 ET_NONE；GameDrawnCmd 中对应派发已被注释。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onShowGameEndType/resetUI；assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _showResultTableSign；assets/42319/controller/cmd/gameCmd/GameDrawnCmd.ts → execute。

## 四、胡牌动画链

23. ResultHu 的动画链顺序为：点炮/一炮多响动画 → 每个胡家番型动画（只有第一个胡家携带回调驱动下一步）→ 摊牌并显示台面标识 → 小结算 → 大结算。首段有结束类型守卫：end_type 不等于 ET_HU 时跳过点炮与番型动画，直接进入摊牌段；台面标识段在荒牌时额外派发 ET_DRAWN 横幅。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _playHuAnimations/_showResultTableSign。
24. HuEx 的动画链顺序为：点炮/一炮多响动画 → 各家番型动画 → 飘分 → 几胡并逐座位刷新头像分；飘分阶段即发送一次 endWait（isLastHuInHand 固定 true，并用一次性标记防止重复上行）。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _playHuAnimations。
25. 点炮动画类型：duoXiang==1 播一炮多响（skinName=yipaoduoxiang），dfFrom != -1 播点炮（skinName=dianpao），其余不播；动画节点在 dfFrom 座位，资源为 Paixing_wz02；开始前先隐藏残留碰杠动画。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _getHuAniType；assets/42319/layer/BoxHzmjTipAniView.ts → onMsgHuDianPaoAni。
26. 番型动画资源固定 Paixing_wz01，skinName 查 HzmjFanAniSkinName（如 G_pinghu、G_qidui、R_zimo），未配置时回落字符串 "Pinghu"；杠开单独使用 KW_Ani_GSKH 节点；天胡/地胡时背景 Paixing_texiao 播 animation2，其余播 animation1。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onMsgPlayHuNew；assets/42319/config/FanDefine.ts → HzmjFanAniSkinName。
27. 关闭 Spine 开关（getBoxSpineOpen=false）时改播简版胡牌动画：点炮类 skinName="hu"，自摸类 skinName="zimo"，资源 Paixing_wz04，不显示番型名与番型背景。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onMsgPlayHuNew。
28. 胡牌音效：点炮类（HT_DISCARD/HT_ROBKONG/HT_DIAN_GANG_HUA）播 HU 动作音，其余播 ZIMO；开启番型 Spine 时额外播 gangfen 音效；点炮/一炮多响动画本身不额外播动作音。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onMsgPlayHuNew；assets/42319/config/GameSoundConfig.ts → GameSoundConfig/gangfen。
29. 播放哪一个番型由番型排序表决定，但两处口径相反：ResultHu 按 HzmjFanAniSortingMap 降序取第一个（??999 兜底）；HuEx 按升序取第一个且用 ||999 把排序值 0 当作 999；均无番型时回落平胡。同一番型集合在两链可能播放不同番型动画。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _getFirstHuFanId；assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _getFirstHuFanId；assets/42319/config/FanDefine.ts → HzmjFanAniSortingMap。
30. 胡牌光柱有显示前置：只有该座位最后一张手牌可见且 CardState_Box.Up 时才取牌中心；TipAniView 还需开启 Spine、已装备 MAH_HU_CARD_ANI 道具且非复盘，才在 KW_HuPaiAni_{seat} 播动画；任一不满足则不显示光柱。锚点：assets/42319/layer/BoxHzmjMah2DView.ts → onPlayHuLight；assets/42319/layer/BoxHzmjTipAniView.ts → onMsgPlayHuLight。
31. 胡牌/点炮开始时先隐藏所有碰杠动画节点，防止上一动作残留。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onMsgHuDianPaoAni/onMsgPlayHuNew/hidePengGangAni。
32. 复盘播放用等待点与完成点成对：HuEx 链在开始时 waitMe(GP_HU_EX)，飘分完成时 reportFinish(GP_HU_EX)；ResultHu 链在开始时 waitMe(GP_Hzmj_RESULT_HU)，小结算段在复盘模式直接 reportFinish(GP_Hzmj_RESULT_HU) 并返回。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _playHuAnimations；assets/42319/layer/BoxHzmjTipAniView.ts → _finishResultScore；assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _showResultView/_playHuAnimations。

## 五、飘分（结果分数）

33. onShowResultScore 先执行 onClearResultScore 清掉上一轮并自增 runId，再按 playCnt 逐座位遍历；只为 getTableScore 非空的座位播放，展示总数等于非空座位数；动画节点按 SC_PLAYER_LOCAL_SEAT_MAP 映射到 KW_ResultScore{0..3}。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onShowResultScore/_getResultScoreTotal/initWithPlayCnt。
34. 展示总数为 0 时立即完成本轮（走统一完成逻辑并回调），不等待任何动画。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → _tryFinishEmptyResultScore。
35. 单个座位分数文案：正数前缀 "+"，非正数原样，统一追加"分"；分数 >= 0 用 fnt_win 字体，否则 fnt_lose；分数值超过 100000 用大数缩写；C_ResultScoreType 固定选 NONE。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onShowScore；assets/42319/controller/cmd/helperCmd/ResultCmd.ts → _formatResultScore。
36. 飘分推进按座位计数：每座位动画完成一次计数加一并清空其完成回调；只有计数等于展示总数时才置 endWaitFlag（取最后完成座位的 scoreInfo.endWait）、执行本轮回调、reportFinish(GP_HU_EX)，endWaitFlag 为 true 时再 sendEndWait。同一 runId 下重复完成会被忽略。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → _finishOneResultScoreSeat/_finishResultScore。
37. 飘分动画速度受房间设置影响：play_speed==1 或匹配场时挂 ani 的 callbackCB 钩子后 play；否则 ani.play(callback)；bAni=false 时直接回调。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onShowScore。
38. 单座位播放抛异常时捕获并立即执行该座位的完成回调，保证计数继续推进；异常只打日志，不中断整轮飘分。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → _showOneResultScoreSeat。
39. 飘分固定播放 wincoin 音效；ShowResultScore 组件内含 KW_ScoreCom（ResultScoreCom：KW_Score 数字、KW_Score_Flag 图标）及 ani 过渡（回调帧 callbackCB、结束帧 end）。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onShowResultScore；input-ui/kawuxing-fgui/assets/boxkawuxing_mah_tipAni/component/ShowResultScore.xml；input-ui/kawuxing-fgui/assets/boxkawuxing_mah_tipAni/component/ResultScoreCom.xml。
40. 旧结算子类型不再按类型展示：ResultScoreType 仅保留 NONE，onShowScore 收到非 NONE 只 console.warn；ResultScoreCom 资源仍保留花猪/查叫/退税/退税双/未听牌/呼叫转移等旧页签（无代码消费）。锚点：assets/42319/config/GameDefine.ts → ResultScoreType；assets/42319/layer/BoxHzmjTipAniView.ts → onShowScore；input-ui/kawuxing-fgui/assets/boxkawuxing_mah_tipAni/component/ResultScoreCom.xml → C_ResultScoreType。

## 七、摊牌与胡牌底图

43. 摊牌 playHuEnd 遍历所有有手牌的座位，把手牌状态置 Up 并重排，同时按胡牌来源设置来源箭头；随后派发 onSendEndWaitDelay（默认 1 秒）再 sendEndWait。锚点：assets/42319/layer/BoxHzmjMah2DView.ts → playHuEnd；assets/42319/layer/BoxHzmjMainView.ts → sendEndWaitDelay。
44. 摊牌时自己手牌会缩小到 0.8 倍并向右偏移 140 像素，为结算信息让位；重连/换局 resetUI 才恢复原始位置与缩放。锚点：assets/42319/layer/BoxHzmjMah2DView.ts → playHuEnd/resetUI。
45. 胡牌底图：CardDownView 在 KW_ImgCarDown_{seat} 显示胡牌底布，按方位叠加偏移（自己 +14，下家 -4/+16，对家 +8，上家 +4/+20）；节点缺失时静默跳过。锚点：assets/42319/layer/BoxHzmjCardDownView.ts → onMsgShowHuDown。

47. 摊牌触发点只有两处：ResultHu 的 _tanPai（live 与 replay 分支都会调用）和 GameDrawnCmd 的 playHuEnd；HuEx 动画链不触发摊牌。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _tanPai/_updateHuView；assets/42319/controller/cmd/gameCmd/GameDrawnCmd.ts → execute；assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _playHuAnimations。

## 八、小结算

48. 小结算使用通用视图 BoxRoomGzmjResultView，数据由 ResultCmd 组装：庄家座位、win_losts、jiao_zui、player_hands、hu_items、extra_score、end_type、flow_str_items、空 show_chickens、remaining_wall_cards；随后直接 showFgui(resultViewData)。锚点：assets/42319/controller/cmd/helperCmd/ResultCmd.ts → execute/_buildResultViewData。
49. 流水按四类收集：胡牌主流水（自摸/被自摸、抢杠/被抢杠、点炮/放炮）、加分豆、扣分豆、被包豆；胡牌主流水按 from_seats 排序后的座位集合去重，一炮多响时逐条生成，自摸额外番型分只叠加到第一条，避免重复计分。锚点：assets/42319/controller/cmd/helperCmd/ResultCmd.ts → _collectFlowItemsBySeat/_appendMainHuFlow/_dedupeByFromSeats。
50. 额外番流水只对白名单生成：天胡、地胡、杠开、抢杠、热炮、素面、硬胡、硬幺筒；其中素面在主流水循环中被 continue 跳过，避免与额外番重复。锚点：assets/42319/controller/cmd/helperCmd/ResultCmd.ts → _dealHuLiuShui/_isExtraHuFan。
51. 流水文案规则：主流水为"动作(番型)[来源]"；额外番为"(番型)[来源]"；连庄追加"(x连庄数)"；流局叫嘴流水在 fan_id 非 0 时用番型名替换动作名；豆流水在 flag==1 时追加"(烧)"；分数统一格式为"+N分"或"-N分"。锚点：assets/42319/controller/cmd/helperCmd/ResultCmd.ts → _createFlowItemWithFan/_createFlowItemNoFan/_getDouFlowTitle/_formatResultScore。
52. 来源方位名规则：四人场单来源按下家/对家/上家；三人场按左右距离较短者判下家或上家；二人场单来源为对家；来源数等于人数减一时显示"三家"（四人）/"两家"（三人）/"对家"（二人）；无来源返回空串，文案不显示方括号。锚点：assets/42319/controller/cmd/helperCmd/ResultCmd.ts → getDirectionNameBetweenSeats/getDirectionNameBySeatInFourRoom。

## 九、大结算

57. CMD_GAME_TOTAL_RESULT 组装大结算数据：按 chair_id 升序排序 user_results，提取输赢数组、局数、起止时间（秒乘 1000 转毫秒）、uuid、boxId；补齐房主名、房间总局数、玩家列表、GAME_NAME、解散者，写入 BoxRoomData.setBoxRoomTotalResult。锚点：assets/42319/controller/cmd/helperCmd/TotalResultCmd.ts → execute。
58. 大结算每人统计四项：解析 user_results[i].data JSON，展示自摸次数、接炮胡次数、叫嘴次数、未叫嘴次数；该玩家 data 为空或空字符串时跳过，不生成其统计行。锚点：assets/42319/controller/cmd/helperCmd/TotalResultCmd.ts → execute。
59. 大结算收束流程：置非局中、停止安全监控、标记总结束、执行 CMD_GAME_TOTAL_RESULT、派发 onTotalResult、清 popTotalResult 标记，并检查是否含机器人解散标记。锚点：assets/42319/controller/gameController.ts → gameTotalResult。
