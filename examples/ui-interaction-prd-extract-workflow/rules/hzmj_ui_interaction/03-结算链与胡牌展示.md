# 结算链与胡牌展示（客户端 UI 交互基准）

> 来源：input-ui/xuanwulobby/assets/42319 代码逆向，提取日期 2026-11-11。锚点格式：文件 → 方法。检查需求文档对结算链与胡牌展示相关交互的描述是否完整、与实现一致。

## 一、局终消息与界面收束

1. 收到 GP_END_GAME 时执行 CMD_END_GAME；GameEndCmd 只写一条日志，不写游戏数据、不调用 CMD_GAME_RESULT 或 CMD_GAME_TOTAL_RESULT、不派发 showBoxTotalResult。justUpdateData 类型下发时直接 return，连本地 onGameEnd 也不派发。锚点：assets/42319/controller/cmd/gameCmd/GameEndCmd.ts → execute；assets/42319/controller/gameController.ts → Hzmj_SVR_PUSH_CMD_BY_XYID/svrPushToClient。
2. 模块内存在两条同名不同源的"游戏结束"事件，不能混用：GameEventBoxHzmj.onGameEnd（字符串 BOX_Hzmj_onGameEnd）由 GameEndCmd 派发，消费方只有 Mah2DView（收起倒计时）、PlayerMatchView（对所有玩家关闭离线展示并清空权限光效）、PlayerView（空实现）；GameCommonUIEventDefine.onGameEnd（字符串 GameCommonEvent_onGameEnd）由 common_game 的 NotifyBoxActionCmd/NotifyMatchActionCmd 派发，消费方是 MainView（隐藏听牌按钮与听牌祈福按钮）和 TipAniView（执行 onClearResultScore）。因此 END_GAME 本身不会触发 TipAniView 的飘分兜底，只有公共结束通知才会。锚点：assets/42319/config/FguiViewDefine.ts → GameEventBoxHzmj.onGameEnd；assets/common_game/config/EventDefine.ts → GameCommonUIEventDefine.onGameEnd；assets/42319/layer/BoxHzmjMah2DView.ts → onGameEnd；assets/42319/layer/BoxHzmjPlayerMatchView.ts → onGameEnd；assets/42319/layer/BoxHzmjPlayerView.ts → onMsgGameEnd；assets/42319/layer/BoxHzmjMainView.ts → onGameEnd；assets/42319/layer/BoxHzmjTipAniView.ts → onGameEnd；assets/common_game/controller/cmd/NotifyBoxActionCmd.ts → execute；assets/common_game/controller/cmd/NotifyMatchActionCmd.ts → execute。
3. onClearResultScore 是飘分阶段的失败恢复兜底：对本轮所有未完成座位依次触发保底完成回调（使完成计数继续推进），清空保底回调列表，runId 自增让旧回调全部失效；随后对每个分数节点延迟 2 帧隐藏并停止动画，避免客户端结束过快时节点被误隐藏。它既在公共 onGameEnd 时执行，也在每次 onShowResultScore 开始时先执行。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onClearResultScore/onShowResultScore。
4. 换局/重连重置时清理结算表现：MainView.resetUI 调用 GameData.clearData（清空手牌、胡牌标记、桌分、番型缓存、胡牌结果缓存、结束类型等），隐藏全部台面标识，执行 unscheduleAllCallbacks 并隐藏通用小结算视图；TipAniView.resetUI 隐藏 KW_ResultScore0~3、停止其 ani 并把 KW_ScoreCom.alpha 复位为 1、隐藏胡牌与碰杠动画、清除文本提示、把 C_GameEnd 置为 ET_NONE；CardDownView.resetUI 隐藏全部胡牌底布与出牌底布动画。锚点：assets/42319/layer/BoxHzmjMainView.ts → resetUI；assets/42319/layer/BoxHzmjTipAniView.ts → resetUI；assets/42319/layer/BoxHzmjCardDownView.ts → resetUI；assets/42319/data/GameData.ts → clearData。
5. 结束等待采用 askid 回执：GameEndWaitCmd 先记录服务端 askid；若此时存在"发牌结束待回执"标记，则清除该标记并立即调用 sendEndWait 后 return，不再执行后续的 justUpdateData 判断；该优先分支使重连静默补数据时也会立即回执一次。锚点：assets/42319/controller/cmd/gameCmd/GameEndWaitCmd.ts → execute；assets/42319/data/GameData.ts → setTakeFirstEndWait/getTakeFirstEndWait/setEndWaitAskid；assets/42319/controller/gameController.ts → sendEndWait。
6. 局终消息本身不产生结算弹层：END_GAME 不写结算数据、不派发 showBoxTotalResult，也不会让通用小结算视图出现；小/大结算必须由 ResultHu 链或公共结算数据流另行触发（可达性见第十二节）。锚点：assets/42319/controller/cmd/gameCmd/GameEndCmd.ts → execute；assets/42319/controller/cmd/helperCmd/ResultCmd.ts → execute；assets/42319/layer/BoxHzmjMainView.ts → showBoxTotalResultView。

## 二、胡牌结果数据处理

7. 胡牌结果入口的前置守卫：GameHuExCmd 在 body 为空时 return，在 hu_items 为空数组时 return，两者都发生在任何数据写入与界面派发之前。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → execute。
8. ResultHu 的数据流程：body 为空直接 return；先把整包写入 GameData.setGuiYangResultData（后续小结算、复盘恢复都读这份缓存）；再按 player_hands 逐个座位 seatToLocal 并用 setHandCards(RESET, hands, dan_fang, combs) 全量重刷手牌与副露；justUpdateData 类型下发在数据写完后就 return，否则先派发 onUpdateReserveShuffle 再进入 _updateHuView。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → execute。
9. HuEx 的数据流程：守卫通过后依次执行 _updateHuData、_updateTableScore、_updatePlayerScore、_updateLastPaoHu，再派发 onUpdateReserveShuffle；justUpdateData 判断位于该派发之后，因此静默补数据仍会触发预约洗牌按钮刷新；非静默时再进入 _updateHuView。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → execute。
10. 进入胡牌处理先清桌分（clearTableScore）、清复盘权限（clearFuPanPower）、清番型缓存（clearHuFanIds）；ResultHu 无条件把出牌步骤置为 false，HuEx 只在该条 hu_item 的本地座位为自己时置 false。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuData；assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateHuData。
11. 每条 hu_item 的固定写入：服务器座位换本地座位、setIsHu(true)、PlayerCardsData.setHu 重写手牌/副露并返回是否需要移除点炮河牌、记录 hu_type 与 dan_fang、番型列表写入 GameData.setHuFanIds。台面标识在同一循环内写入：点炮类胡把胡家记 HU_PAO 并把点炮来源记 DIAN_PAO，自摸记 HU_ZI_MO；胡牌方位关系用 localToLocalSeat2 写入玩家数据；需要移除河牌时清空 GameData.lastCard。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuData/_isPaoHuType；assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateHuData；assets/42319/config/GameDefine.ts → HuType/ResultTableSign。
12. PlayerCardsData.setHu 的内部边界：复盘模式下不覆盖手牌数据；先按 dan_fang 记录摸牌再把 moCard 归零；副露的 from_seat 逐条换算成本地相对座位；hu_idx/hu_type 落库并把 dan_fang 压入胡牌列表。只有 HT_DISCARD（点炮）会要求移除点炮家河牌最后一张；一炮多响且该条 df_stay 为 0 时强制取消移除。锚点：assets/42319/data/PlayerCardsData.ts → setHu。
13. 未胡座位的台面标识：无 jiao_zui 字段时一律 NO_TING；有 jiao_zui 时，服务器座位号在 jiao_zui_seats 内记 TING，否则记 NO_TING。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuData。
14. 一炮多响判定两处口径不同：ResultHu 用 hu_items.length > 1；HuEx 用服务端下发的 duo_xiang 字段。该差异会同时影响台面标识与点炮动画类型。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuData/_getHuAniType；assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateHuData。
15. 抢杠胡（HT_ROBKONG）表现：把点炮来源玩家对应的补杠组合降级为碰（CMF_TKONG 改 CMF_PONG、清空 nMaha、nInMahs 填 3 张 dan_fang），然后以 setHandCard 重刷该玩家手牌与副露，保证桌面不残留第 4 张补杠牌。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateRobKongHuView；assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateRobKongHuView。
16. 桌分与玩家分只做数据写入：桌分遍历 win_losts，score === 0 的座位直接跳过、不生成飘分节点，其余座位写 type=NONE、score、mult、state、endWait=false，并记录自己胡牌的最大 mult；玩家分按 player_score.scores 的服务器座位顺序写入对应玩家 sr，不派发分数界面刷新，玩家缺失时只 console.warn。自己的点炮统计按 hu_items 顺序扫描，连续的点炮类胡（含点杠花、抢杠胡）只计 1 次，多次点炮累加，结果连同最大倍率写入 setLastPaoHu。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateTableScore/_updatePlayerScore/_updateLastPaoHu；assets/42319/config/GameDefine.ts → ResultScoreType。
17. 胡牌后的界面守卫：两个命令的 live 分支在 _updateHuView 里先派发 onCloseOperate、onHidePutCardUi、updateTingPaiViewLeftCnt（ResultHu 的 replay 分支只派发 onHidePutCardUi），再执行抢杠修正与 onSetHu；对每个胡家派发 onSetHu 与 onPlayHuLight。自己胡牌时额外隐藏听牌弹层、清空听牌信息、派发 checkShowTingBtnOnSelfHu；若自己处于托管状态再派发 onShowTrustee。ResultHu 在 _updateHuData 阶段已禁用出牌，HuEx 只在自己胡牌时禁用。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuView/_dispatchSetHu；assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _updateHuView/_dispatchSetHu；assets/42319/config/GameDefine.ts → SELF_LOCAL_SEAT。

## 三、台面标识（几胡/叫嘴/点炮/自摸）

18. 每个本地座位对应一个 HuIndex 节点：初始化按 SC_PLAYER_LOCAL_SEAT_MAP 取 KW_Hu_Index_{uiIdx} 存入 _huIndex[localSeat]；2 人场只使用 uiIdx 0/2，3 人场使用 0/1/3。锚点：assets/42319/layer/BoxHzmjMainView.ts → initWithPlayCnt；assets/42319/config/GameDefine.ts → SC_PLAYER_LOCAL_SEAT_MAP；assets/42319/fgui_uideclare/box_hzmj_main/FGUI_box_hzmj_main_CompHuIndex.d.ts → KW_Hu_Index_0~3。
19. onShowResultTableSign 时节点 visible=true，并把 C_HuType.selectedIndex 写为 sign；sign 取值 NO_TING=0、TING=1、DIAN_PAO=2、HU_PAO=3、HU_ZI_MO=4。锚点：assets/42319/layer/BoxHzmjMainView.ts → onShowResultTableSign；assets/42319/config/GameDefine.ts → ResultTableSign；assets/42319/fgui_uideclare/box_hzmj_main/FGUI_box_hzmj_main_HuIndex.d.ts → C_HuType。
20. 带 aniIndex 与 nextCallBack 的台面标识显示会 scheduleOnce 1.5 秒后推进下一段动画；两者任一缺失时只显示标识，不推进动画链。锚点：assets/42319/layer/BoxHzmjMainView.ts → onShowResultTableSign。
21. 台面标识清理：onClearResultTableSign 隐藏全部 HuIndex 节点；MainView.resetUI 会主动调用一次，保证换局后不残留上一局标识。锚点：assets/42319/layer/BoxHzmjMainView.ts → onClearResultTableSign/resetUI。
22. 结束类型横幅：C_GameEnd.selectedIndex 直接取 EndGameFlag（0 无、1 胡牌、2 荒牌、3 被动结束）。模块内唯一派发点是 ResultHu 在 end_type==ET_DRAWN 时置 ET_DRAWN；TipAniView.resetUI 直接置 ET_NONE；GameDrawnCmd 中对应派发已被注释。因此只有 ResultHu 链能让横幅显示"荒牌"，胡牌/被动结束横幅无派发来源。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onShowGameEndType/resetUI；assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _showResultTableSign；assets/42319/controller/cmd/gameCmd/GameDrawnCmd.ts → execute；assets/42319/config/GameDefine.ts → EndGameFlag。

## 四、胡牌动画链

23. ResultHu 的动画链顺序为：点炮/一炮多响动画 → 每个胡家番型动画（只有第一个胡家携带动画回调驱动下一步）→ 摊牌并显示台面标识 → 小结算 → 大结算。首段有结束类型守卫：end_type 不等于 ET_HU 时跳过点炮与番型动画，直接进入摊牌段；台面标识段在荒牌时额外派发 ET_DRAWN 横幅。小结算段显示后立即推进大结算段，不等小结算关闭。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _playHuAnimations/_showResultTableSign/_showResultView/_showTotalResultView。
24. 台面标识段的推进回调会按座位复制：_showResultTableSign 对 context.tableSign 的每个本地座位（seatToLocal 得到的 0..playCnt-1）都携带同一个 aniIndex/nextCallBack 派发，MainView 为每个座位各 scheduleOnce 一次 1.5 秒回调；因此 ResultHu 链在 2/3/4 人场分别收到 2/3/4 次推进，其中每一次都会再次执行小结算段并派发大结算，小结算被 showFgui 多次、大结算 showBoxTotalResult 被派发多次；MainView 的 isShowFgui 去重只在调度前执行，无法阻止已排队的多次弹层。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _showResultTableSign/_playHuAnimations/_updateHuData；assets/42319/layer/BoxHzmjMainView.ts → onShowResultTableSign/showBoxTotalResultView。
25. HuEx 的动画链顺序为：点炮/一炮多响动画 → 各家番型动画 → 飘分 → 几胡并逐座位刷新头像分。飘分阶段即发送一次 endWait（isLastHuInHand 固定 true，并用一次性标记防止重复上行）；几胡阶段不再发送。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _playHuAnimations。
26. 点炮动画类型：duoXiang==1 播一炮多响（skinName=yipaoduoxiang），dfFrom != -1 播点炮（skinName=dianpao），其余不播；动画节点固定在 dfFrom 座位，资源为 Paixing_wz02。开始前先隐藏残留碰杠动画；动画结束时仅当四个子节点都不可见才隐藏整层。一炮多响与点炮共用同一个 dfFrom 节点。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _getHuAniType；assets/42319/layer/BoxHzmjTipAniView.ts → onMsgHuDianPaoAni/hidePengGangAni。
27. 番型动画资源固定 Paixing_wz01，skinName 查 HzmjFanAniSkinName（如 G_pinghu、G_qidui、R_zimo），未配置时回落字符串 "Pinghu"；杠开单独使用 KW_Ani_GSKH 节点；天胡/地胡时背景 Paixing_texiao 播 animation2，其余播 animation1。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onMsgPlayHuNew；assets/42319/config/FanDefine.ts → HzmjFanAniSkinName。
28. 关闭 Spine 开关（getBoxSpineOpen=false）时改播简版胡牌动画：点炮类 skinName="hu"，自摸类 skinName="zimo"，资源 Paixing_wz04，不显示番型名与番型背景，且不播 gangfen 音效。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onMsgPlayHuNew。
29. 胡牌音效：点炮类（HT_DISCARD/HT_ROBKONG/HT_DIAN_GANG_HUA）播 HU 动作音，其余播 ZIMO；动作音按玩家性别分男女版本。开启番型 Spine 时额外播 gangfen 音效；点炮/一炮多响动画本身不额外播动作音。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onMsgPlayHuNew；assets/42319/config/GameSoundConfig.ts → ActionSoundKey/HU/ZIMO/GameSoundConfig.gangfen。
30. 播放哪一个番型由番型排序表决定，但两处口径相反：ResultHu 按 HzmjFanAniSortingMap 降序取第一个（??999 兜底，排序值 0 保留为 0）；HuEx 按升序取第一个且用 ||999 把排序值 0 当作 999。表内报听、杀报、软番、硬胡、硬幺筒的排序值为 0，素面为 -10，因此同一番型集合在两链可能播放不同番型动画。锚点：assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _getFirstHuFanId；assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _getFirstHuFanId；assets/42319/config/FanDefine.ts → HzmjFanAniSortingMap。
31. 胡牌光柱有显示前置：Mah2DView 只在胡家最后一张手牌可见、牌面状态为 Up 且带 KW_Value 时才取牌中心并派发 onMsgPlayHuLight/onMsgShowHuDown；TipAniView 还需开启 Spine、已装备 MAH_HU_CARD_ANI 道具且非复盘，才在 KW_HuPaiAni_{seat} 播放动画，播完自动隐藏；任一条件不满足则不显示光柱或底图。锚点：assets/42319/layer/BoxHzmjMah2DView.ts → onPlayHuLight；assets/42319/layer/BoxHzmjTipAniView.ts → onMsgPlayHuLight。
32. 复盘播放用等待点与完成点成对：HuEx 链启动时 waitMe(GP_HU_EX)，飘分完成时 reportFinish(GP_HU_EX)；ResultHu 链启动时 waitMe(GP_Hzmj_RESULT_HU)，小结算段在复盘模式直接 reportFinish(GP_Hzmj_RESULT_HU) 并继续推进到大结算段，而大结算段在复盘模式直接 return。锚点：assets/42319/controller/cmd/gameCmd/GameHuExCmd.ts → _playHuAnimations；assets/42319/layer/BoxHzmjTipAniView.ts → _finishResultScore；assets/42319/controller/cmd/gameCmd/GameResultHuCmd.ts → _playHuAnimations/_showResultView/_showTotalResultView。

## 五、飘分（结果分数）

33. onShowResultScore 的入口固定动作：先执行 onClearResultScore 清掉上一轮，再自增 runId，按当前人数创建上下文并立即登记座位保底回调，然后尝试空轮完成、逐座位播放，最后播放一次 wincoin 音效。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onShowResultScore/_createResultScoreContext。
34. 展示总数等于 tableScore 非空的座位数（只统计 0..playCnt-1）；只为非空座位播放，节点在 initWithPlayCnt 阶段按 SC_PLAYER_LOCAL_SEAT_MAP 绑定到 KW_ResultScore{uiIdx}，因此 2 人场第二个座位使用 KW_ResultScore2、3 人场第三个座位使用 KW_ResultScore3。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → _getResultScoreTotal/_showResultScoreSeats/initWithPlayCnt。
35. 展示总数为 0 时立即完成本轮（走统一完成逻辑并回调），不等待任何座位动画。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → _tryFinishEmptyResultScore。
36. 单个座位分数文案直接取 StringUtils.dealBigNumEx(score, 100000, 2)：不添加 "+" 前缀、不追加"分"，超过 100000 用大数缩写；分数 >= 0 用 fnt_win 字体，否则 fnt_lose；C_ResultScoreType 固定选 NONE，收到非 NONE 只 console.warn。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onShowScore；assets/42319/config/GameDefine.ts → ResultScoreType。
37. 飘分推进按座位计数：每座位动画完成一次计数加一并清空其完成回调；只有计数等于展示总数时才置 endWaitFlag（取最后完成座位的 scoreInfo.endWait）、执行本轮回调并 reportFinish(GP_HU_EX)；同一 runId 下重复完成与过期 runId 的完成都会被忽略。endWaitFlag 为 true 时再 sendEndWait，但该分支实际不可达（见第 84 条）。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → _finishOneResultScoreSeat/_finishResultScore。
38. 飘分动画速度受房间设置影响：play_speed==1 或匹配场时先挂 ani 的 callbackCB 钩子再 play；否则 ani.play(callback)；bAni=false 时跳过动画直接回调。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → onShowScore。
39. 单座位播放抛异常时捕获并立即执行该座位的完成回调，保证计数继续推进；异常只打日志，不中断整轮飘分。锚点：assets/42319/layer/BoxHzmjTipAniView.ts → _showOneResultScoreSeat。

## 九、大结算

57. CMD_GAME_TOTAL_RESULT 组装大结算数据：按 chair_id 升序排序 user_results，提取输赢数组、局数、起止时间（秒乘 1000 转毫秒）、uuid、boxId；补齐房主名、房间总局数、玩家列表、GAME_NAME、解散者，写入 BoxRoomData.setBoxRoomTotalResult。锚点：assets/42319/controller/cmd/helperCmd/TotalResultCmd.ts → execute。
