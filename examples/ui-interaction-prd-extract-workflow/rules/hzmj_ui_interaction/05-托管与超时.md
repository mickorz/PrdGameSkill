# 托管与超时（客户端 UI 交互基准）

> 来源：input-ui/xuanwulobby/assets/42319 代码逆向，提取日期 2026-11-11。锚点格式：文件 → 方法。检查需求文档对托管与超时相关交互的描述是否完整、与实现一致。

## 一、托管与自动摸打的入口

1. 自动摸打按钮位于听牌组件内部（KW_CompTing.KW_BTN_AUTOHU），只有该组件的 C_IsHu 控制器切到"已听"页时才随组件显示；听牌组件本身由主界面按"自己有听牌数据且未胡牌"开关，因此该按钮只在"已听牌且自己未胡"时出现。锚点：layer/BoxHzmjMainView.ts → showTingBtn / showTingPaiBtn；fgui_uideclare/box_hzmj_main/FGUI_box_hzmj_main_CompTing.d.ts → C_IsHu / KW_BTN_AUTOHU；fgui_uideclare/box_hzmj_main/FGUI_box_hzmj_main_AutoHuBtn.d.ts → C_Button。
2. 按钮点击按名称自动绑定到 onBtnAutohu：先把自动胡标记置为 true（GameData.setAutoHu(true)），再按房型发包——匹配场走 reqMatchTrust()，其它房型走 reqTrustee(boxid, kBotAuto)。锚点：layer/BoxHzmjMainView.ts → onBtnAutohu；node_modules/kiwi/src/core/FguiView.ts → processBtnEvent（KW_BTN_ 前缀转 onBtn 方法）。
3. 匹配场发包前置守卫：非匹配场、或当前未开局（TableData.getIsGameStart() == false）时直接 return，不发包；发出时 bot 值取"selfPlayer.isBot 取反"，即同一按钮在已托管时发的是取消托管。锚点：common_game/controller/tableController.ts → reqMatchTrust。
4. 好友房/普通房发包前置守卫：复盘模式直接 return；当请求类型为 kInvalid（取消）且自己既非托管也非自动摸打时，类型仍为 kInvalid 并在发包前 return（取消请求被拦截）；若自己处于托管/自动摸打，类型被改写为 kBot/kBotAuto，并以 bot=false 真正发出取消。锚点：common_game/controller/tableController.ts → reqTrustee。
5. 响应处理只在成功时改界面：校验 table_id 与 flag == kSuccess；失败仅 console.error，不改任何托管状态、不弹提示（失败保持原状态，无 UI 反馈）。锚点：common_game/controller/cmd/RespPlayerBotCmd.ts → execute；common_game/controller/cmd/RespPlayerBotAutoCmd.ts → execute。
6. 成功后的统一动作：写入 TableData 的托管/自动摸打标记；bot=true 时显示托管遮罩，bot=false 时隐藏遮罩并记录服务器回传的原始时钟；同时向自己派发 kBot/kUnBot 或 kBotAuto/kUnBotAuto 状态事件。锚点：common_game/controller/cmd/RespPlayerBotCmd.ts → execute；common_game/controller/cmd/RespPlayerBotAutoCmd.ts → execute。
7. 按钮选中态回写：_checkBotAutoBtn 把 AutoHuBtn 的 C_Button.selectedIndex 写成 1/0；来源是状态事件 kBot、kBotAuto → 1，kUnBot、kUnBotAuto → 0；重连恢复时按 self.isBot || self.isBotAuto 直接回写。锚点：layer/BoxHzmjMainView.ts → onPlayerStateChange / _checkBotAutoBtn / checkShowTingBtnOnRecover。
8. 取消自动摸打时同步复位自动胡标记：只有 flag 为 false 的分支会调 GameData.setAutoHu(false)（开启时不在这里置 true，开启动作在按钮点击处完成）。锚点：layer/BoxHzmjMainView.ts → _checkBotAutoBtn。
9. 每小局开始时强制复位自动胡标记（GameData.setAutoHu(false)），避免上一局的自动摸打标记影响本局倒计时音效抑制。锚点：layer/BoxHzmjMainView.ts → onGameStart（@gf.listen GameCommonUIEventDefine.onGameStart）。
10. 手动操作会取消自动摸打：碰、杠（含选择杠）、自摸、胡、过（以及"取消选择杠"复用的过）都会在发包后调用 cancelAuto() 发出取消请求。锚点：layer/BoxHzmjMainView.ts → onBtnPeng / onBtnChooseGang / onBtnZimo / onBtnHu / onBtnGuo / onBtnCancel → cancelAuto。
11. 边界：自己主动出牌不调用 cancelAuto（onPlayMah 只发 sendPlay 并关闭操作区），因此自动摸打/托管状态在出牌后继续保持，需通过取消托管入口或托管遮罩按钮解除。锚点：layer/BoxHzmjMainView.ts → onPlayMah。
12. 托管代打的服务端出牌表现：自己并未本地点牌（手牌组件内 _curPlayMah == 0）时收到自己的出牌，会走"托管出牌"分支——重排手牌、关闭操作区、派发 addPlayMah 落牌，不经过本地点击选中/抬牌流程。锚点：layer/BoxHzmjPlayerHandCards.ts → playMah（注释"托管出牌"）。
13. 自动胡标记在本玩法只服务于倒计时音效抑制与按钮态复位，不改变出牌/胡牌判定；每次操作取消或每小局开始时都会被复位。锚点：data/GameData.ts → setAutoHu / getAutoHu；layer/BoxHzmjMah2DView.ts → setClock（`!GameData.getAutoHu()` 条件）；layer/BoxHzmjMainView.ts → _checkBotAutoBtn / onGameStart。

14. 托管遮罩是两个同构弹层，按房型切换视图名：好友房/包厢使用 GameBoxTrustView，金币场/匹配场使用 GamePopTrustView；两者都是 Base 层、Ani 排序（盖在牌桌之上）。锚点：common_game/Game.ts → _initBoxRoomEntry / _initNormalRoomEntry（改写 fui.FuiCommonGameViewDefine.GamePopTrustView）；common_game/config/FuiCommonGameView.ts → GamePopTrustView。
15. 遮罩弹出时机有三类：自己进入托管（kBot/kBotAuto 通知）时打开；托管/取消托管响应成功时打开/关闭；恢复到局内且自己 isBot 或 isBotAuto 时补开（同一恢复流程里另有一处仅判 isBot 的分支）。锚点：common_game/controller/cmd/NotifyPlayerActionCmd.ts → _playerBot / _playerBotAuto；common_game/controller/cmd/RespPlayerBotCmd.ts / RespPlayerBotAutoCmd.ts → execute；common_game/controller/tableController.ts → _checkPlayerBot。

17. 取消托管按钮的两套实现：GamePopTrustView 在匹配场调 cancelMatchTrust()，其它房型调 GameInstController.inst.CardController?.sendMsgTrust(false)（CardController 不存在时静默不发包）；GameBoxTrustView 统一走 reqTrustee(kInvalid)。两者在游戏已结束（getIsGameStart() == false）时直接关闭界面。锚点：common_game/layer/GamePopTrustView.ts → onBtnCancel；common_game/layer/GameBoxTrustView.ts → onBtnCancel。
18. 25. 他人进入手动托管时给全员一条提示：非自己座位弹出"xxx进入托管状态"提示条（MessageSimpleBoxView），3 秒后标记该提示展示完成；自己进入托管不弹这条提示，而是弹托管遮罩。锚点：common_game/controller/cmd/NotifyPlayerActionCmd.ts → _playerBot。

## 三、超时提示与超时回归

27. 他人操作超时弹层内容固定两句：主文案"玩家{昵称}操作超时，超时{N}秒自动解散房间"，次行"当前超时时间{M}秒"；M 取传入的已超时秒数，并由界面自己每秒 +1 刷新。锚点：common_game/layer/boxRoom/BoxRoomTimeoutTipView.ts → initDesc / initTimer。
28. 弹层参数来源：玩家昵称、好友房最大超时解散秒数、当前已超时秒数；已超时秒数小于配置的最小提示秒数时，以配置值作为起始值；弹出后把房间累计超时时间清零。锚点：common_game/controller/cmd/NotifyPlayerActionCmd.ts → _playerBotHintTimeout。
29. 弹层前置守卫三条：增量更新（justUpdateData）不弹；按 seat 查不到玩家不弹；超时玩家是自己的 numid 时不弹。复盘模式下不弹这个弹层，改为向该玩家座位派发"超时提示气泡"事件。锚点：common_game/controller/cmd/NotifyPlayerActionCmd.ts → _playerBotHintTimeout。
30. 弹层两个按钮：关闭按钮只隐藏界面，未在该方法内停止 1 秒计步回调；提示按钮调起微信"提醒玩家"分享（供队友催回）。锚点：common_game/layer/boxRoom/BoxRoomTimeoutTipView.ts → onBtnClose / onBtnTip；common_game/data/BoxShareData.ts → dealPlayerHintInviteData。
31. 超时回归：每条带 seat 的下行协议处理完后都会检查该座位是否仍在"超时提示中"，是且未断线则——关闭超时弹层、弹一条"玩家{昵称}已返回"提示（显示 3 秒）、向该座位派发"玩家已返回"事件、把超时提示标记复位。锚点：controller/gameController.ts → svrPushToClient / _playerBotHintTimeoutEnd。
32. 回归检查的守卫：消息体没有 seat 字段（或 seat 非数字）直接返回；按座位查不到玩家直接返回；玩家 isWireBreak 仍为 true 时也返回，此时弹层不关闭、"已返回"提示不出现、超时标记保留，等待下一次下行协议。锚点：controller/gameController.ts → _decodeSeatForBotHint / _playerBotHintTimeoutEnd。
33. 超时弹层不携带座位标识，只有玩家昵称与时间参数，关闭与回归都作用于同一个视图实例；因此同时有多人超时时，界面显示的是最近一次打开的参数，无法为多名玩家各保留一个弹层。锚点：common_game/layer/boxRoom/BoxRoomTimeoutTipView.ts → IBoxRoomTimeoutTipViewParam / initUI。
34. 自己座位的回归不参与超时弹层逻辑（自己超时本就不弹层），只触发番型面板重新显示。锚点：controller/gameController.ts → _playerBotHintTimeoutEnd（先判自己 numid 再判超时标记）。
35. 匹配等待阶段有独立倒计时界面：匹配场且未开局时显示匹配面板 KW_MATCH，倒计时从 30 秒起每秒递减，减到负数后回到 30 循环；同时每 8 秒轮换一条玩法提示；收到开始游戏消息会关闭该面板，而重新加入匹配队列成功会再次把它打开（传 true）。锚点：layer/BoxHzmjTipAniView.ts → initUI / showMatch / matchTimeSche / updateMatchTips；layer/BoxHzmjMainView.ts → onMsgStartGame（onShowMatchAni, false）/ onMatchJoinSuccess（onShowMatchAni, true）。

## 四、托管次数与解散惩罚提醒

36. 每次出牌按出牌座位累加托管次数（GamePlayCmd → TableData.addBotCount）：只有房间规则开启托管（rule.bot）且该玩家 isBot 时才 +1；重连补数据（justUpdateData）也计数，但计数后直接返回、不弹提醒。锚点：controller/cmd/gameCmd/GamePlayCmd.ts → _updatePlayData（注释"如果玩家是托管状态需要增加托管次数"）；common_game/data/TableData.ts → addBotCount。
37. 惩罚提醒的触发条件是"规则开启托管解散（bot_dismiss）"且累计次数 >= 好友房最大托管出牌次数配置；满足时向该座位派发托管次数事件（携带座位与次数）。锚点：common_game/data/TableData.ts → addBotCount。
38. 托管次数气泡展示在玩家头像旁（KW_BOT_TIP，左/右/上三种同构组件，内含单行文本 KW_TXT_TIP）：文案为"{昵称}已托管出牌{N}次，若结算时为托管状态，本局将解散，点击提醒他"，显示 3 秒后自动隐藏。锚点：common_game/layer/component/BasicPlayerComp.ts → onNotifyBotCount / delayHideBotTip；fgui_uideclare/box_hzmj_player/FGUI_box_hzmj_player_PlayerSelfBase.d.ts → KW_BOT_TIP；FGUI_box_hzmj_player_BotTipLeft.d.ts → KW_TXT_TIP。
39. 该气泡不对自己显示（自己座位且非复盘时直接 return）；复盘模式下自己座位也显示。锚点：common_game/layer/component/BasicPlayerComp.ts → onNotifyBotCount。
40. 点击该气泡会调起微信"提醒他"分享，并立即隐藏气泡（不等待 3 秒定时器）。锚点：common_game/layer/component/BasicPlayerComp.ts → onBotTipClick（initUI 内 addClick 绑定 KW_BOT_TIP）。
41. 超时解散气泡文案为"操作操时的时间过长，触发超时解散~"（原文如此，含错别字"操时"），显示 3 秒后隐藏；该文案只走气泡通道（复盘分支），其它模式用第 27 条的弹层表达。锚点：common_game/layer/component/BasicPlayerComp.ts → onNotifyBotHintTimeout。
42. 离线解散警告气泡文案为"离线{N}秒后将解散房间，点击气泡邀他回来~"；复盘模式固定 3 秒隐藏，非复盘模式按 N 秒隐藏。锚点：common_game/layer/component/BasicPlayerComp.ts → onNotifyOfflineDismissWarn。
43. 玩家返回时隐藏该座位的提示气泡（同一 KW_BOT_TIP 容器，托管次数、超时、离线三类提醒互斥共用）。锚点：common_game/layer/component/BasicPlayerComp.ts → onNotifyPlayerBackGame。
44. 每次新提醒先取消该组件上一个隐藏定时器，再重新计时 3 秒（离线为 N 秒），避免旧定时器提前关掉新提醒，也避免提醒叠加。锚点：common_game/layer/component/BasicPlayerComp.ts → onNotifyBotCount / onNotifyBotHintTimeout / onNotifyOfflineDismissWarn（unschedule + scheduleOnce delayHideBotTip）。

## 五、托管与超时的自动举报

45. 开局协议写入两个举报时间点：bot_time（优先毫秒字段 bot_time_ms ÷ 1000，否则用秒字段 bot_time）作为托管举报时间；auto_bot_time 只处理毫秒字段 auto_bot_time_ms，没有秒字段兜底，写入出牌预举报时间。锚点：controller/cmd/gameCmd/GameStartGameCmd.ts → execute。
46. 举报计时器每 0.1 秒步进；累计时间走过托管举报时间点时，对场上所有 isBot 或 isBotAuto 的玩家各上报一次，且同一倒计时周期只查一次。锚点：common_game/controller/reportController.ts → _tick / _checkBotUser。
47. 累计时间走过预举报时间点时，上报预举报名单；名单由每次权限下发时把 isBotAuto 玩家的座位追加进列表累积（不清空则持续累积，直到时钟重置）。锚点：common_game/controller/reportController.ts → _checkGamePreReport / setPreReportList；controller/cmd/gameCmd/GamePowerCmd.ts → _checkBotAutoReport。
48. 倒计时自然结束时对所有人上报一次（who 的 num_id 与 area_id 都为 0）。锚点：common_game/controller/reportController.ts → _tick / _checkEnd / _report。
49. 每次收到大于 0 的新服务器时钟都会重置举报检查标记与预举报名单，并重新起计时器，因此同一倒计时周期内"托管举报"与"出牌预举报"各只触发一次（时钟值为 0 时不重置）。锚点：common_game/controller/reportController.ts → setClock / setRelinkClock / _resetClock；common_game/controller/tableController.ts → _checkSvrClock / _checkSvrRelinkClock。
50. 小局结束（通用房间/匹配结束行为）清空计时器与举报标记，避免下一局沿用上一局举报进度。锚点：common_game/controller/reportController.ts → onGameEnd；common_game/controller/cmd/NotifyBoxActionCmd.ts / NotifyMatchActionCmd.ts。
51. 举报报文按房型区分：包厢用 UserTimerOutRequest（带 boxid），匹配场用 GameLogicProtocol.TimeoutRequest（带 table_id）；指定座位举报时要求该玩家 areaid > 0 且 numid > 0，否则跳过不报（"举报所有人"不受此限制）。锚点：common_game/controller/reportController.ts → _report。

## 六、DelayCall 与兜底定时

52. DelayCall 的语义是"同一目标最后一次生效"：先把目标对象上的 tween 全部 kill，再创建延迟回调；对同一对象连续调用会取消上一次未到期的延迟。锚点：config/FguiViewDefine.ts → DelayCall。
53. 限时文字提示默认 1.3 秒后自动隐藏（如"当前未过手，无法碰牌""当前未过手，无法吃胡"）；由于 DelayCall 会 kill 同目标 tween，连续触发时以最后一次为起点重新计时。锚点：layer/BoxHzmjTipAniView.ts → onShowTextTimeTips；controller/cmd/gameCmd/GameNotifyInfoCmd.ts → execute（两处均传 1.3）。
54. 常驻文字提示会主动取消正在进行的自动隐藏：显示前若正处于"限时提示"计时中，会先把计时标记置 false 并 kill 文本节点上的 tween，之后该提示不会自动消失。锚点：layer/BoxHzmjTipAniView.ts → onShowTextTips。
