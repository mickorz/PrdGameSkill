# 桌面常驻元素（客户端 UI 交互基准）

> 来源：input-ui/xuanwulobby/assets/42319 代码逆向，提取日期 2026-11-11。锚点格式：文件 → 方法。检查需求文档对桌面常驻元素相关交互的描述是否完整、与实现一致。

## 一、倒计时

1. 倒计时数字是方位盘组件内的一个文本框（KW_DeskCent.KW_Clock_Num），由麻将 2D 视图独占写入；其它视图不直接改这个文本。锚点：layer/BoxHzmjMah2DView.ts → setClock / initUI。
2. 数字固定两位显示：剩余秒小于 10 补前导零（如 08、05），归零那一次写入固定字符串 "00"，不会显示空或单字符。锚点：layer/BoxHzmjMah2DView.ts → setClock（`time < 10 ? "0" + time` 与 `time == 0` 分支）。
3. 数字字体随剩余秒切换：大于 3 秒用默认字体（Fntdaojishi01-export），小于等于 3 秒切红色字体（Fntdaojishi02-export）；倒计时自然结束后停在红色 "00"。锚点：layer/BoxHzmjMah2DView.ts → setClock（font 赋值 + 结束态写入）。
4. 显示的秒数不是服务端逐秒推送，而是取公共计时器 ReportController.getClock()（下发总时长减已流逝时间，向下取整，小于 0 归 0）；每次收到权限消息时用该值启动本地位倒计时。锚点：controller/cmd/gameCmd/GamePowerCmd.ts → _updatePowerClock；controller/cmd/sceneCmd/SceneActionCmd.ts → _recoverClock。
5. 前置守卫：取到的秒数小于等于 0 时不刷新倒计时、方位光与头像框（直接返回），界面保留上一次的显示状态。锚点：controller/cmd/gameCmd/GamePowerCmd.ts → _updatePowerClock（`clockInfo <= 0` 直接 return）。
6. 前置守卫：复盘模式不显示倒计时（setClock 直接返回）；秒数大于 999 视为异常值，忽略本次刷新并保留原显示（仅打日志）。锚点：layer/BoxHzmjMah2DView.ts → setClock（isFupanMode / `time > 999` 分支）。
7. 最后 3 秒提示音有四个同时满足的条件：剩余秒小于等于 3、当前权限座位是自己、调用方允许播放音效（playSound 默认 true）、未开启自动胡；满足时每秒播一次倒计时音效（countdown2）。锚点：layer/BoxHzmjMah2DView.ts → setClock。
8. 超时引导：他人在同一权限阶段倒计时累计走过超过 8 秒且尚未提示过时，弹出"点击桌面"引导层（GameBoxPropGuideView，按座位定位）；该引导只对非自己座位、且处于开局中的包厢触发，每次刷新倒计时前会先关闭上一个引导层。锚点：layer/BoxHzmjMah2DView.ts → setClock / tipPlayerOperation。
9. 取消托管后重算显示：当前权限玩家取消托管（或自动托管取消）时，用计时器当前剩余秒数重新刷新倒计时，避免停在托管期间的旧数字。锚点：layer/BoxHzmjMainView.ts → onPlayerStateChange。
10. 归零与清空不是同一动作：流局时以"倒计时 0"收尾（显示红色 00，同时方位光传 0 走熄灭分支）；结束游戏走 setClockHide 清空数字并停表；重置（再来一局/重进）把数字置空并停表。锚点：controller/cmd/gameCmd/GameDrawnCmd.ts；layer/BoxHzmjMah2DView.ts → onGameEnd / resetUI。
11. 计时器与文本动画的生命周期：每次启动新倒计时前先停止旧计时器、kill 文本上的 tween；视图销毁时停止倒计时与方位光计时器。锚点：layer/BoxHzmjMah2DView.ts → setClock / onDestroy。

## 二、方位盘与行动家光效

12. 方位盘底图按"人数 + 东风座位"选图：2/3/4 人各有一组底图资源（desk_base09/08、desk_base06/07/05、desk_base01/04/03/02），以东风所在的本地座位号作为该组资源的索引，实现"庄家为东风"的旋转。锚点：layer/BoxHzmjMah2DView.ts → onMsgDeskCentBg + bg_url_map。
13. 越界兜底：人数无对应底图组、人数小于等于 0、或东风座位映射缺失时，打告警并直接返回，保留上一张底图（不崩溃、也不清空）；东风座位在当前人数映射中不存在时回落为 0 号位。锚点：layer/BoxHzmjMah2DView.ts → onMsgDeskCentBg。
14. 东风座位的数据来源有两处：局数据里 men_feng 中"东"所在的座位（找不到东风时回落为庄家座位），以及空闲场景数据里的 men_feng（找不到东风时回落 0 号位）；两者都会写缓存并立即刷新方位盘。锚点：controller/cmd/gameCmd/GameJuDataCmd.ts；controller/cmd/gameCmd/GameIdleCmd.ts。
15. 方位光资源与底图使用同一套映射（desk_light_east/south/west/north 01~04），并跟随玩家牌桌皮肤包：若装备了牌桌皮肤（DRESS_DASHBOARD_UI_MAP 命中）则底图与光圈都取自皮肤包，否则取自 box_hzmj_mah2D_Main 包。锚点：layer/BoxHzmjMah2DView.ts → onMsgDeskCentBg / onLoadDress。
16. 方位光同一时刻只亮一家：循环按人数逐一设置，等于当前座位者显示、其余隐藏；同时把光圈容器（KW_ShowLight）强制置为可见，因此传入的座位号无效时会出现"容器可见但没有光圈"的空亮区，不会自动隐藏容器。锚点：layer/BoxHzmjMah2DView.ts → setDeskCentLight。
17. 呼吸闪烁实现：秒数大于 0 时新建递增型计时器，每秒对当前光圈做一次 alpha 渐变，奇偶秒交替淡入淡出（透明在 0 与 1 之间往复）。该计时器是递增型，不会自然结束，因此光圈会一直闪到下一次权限刷新、重置或视图销毁。锚点：layer/BoxHzmjMah2DView.ts → setDeskCentLight（`new CountdownTime(time, this, true)`）。
18. 方位光的分支守卫：传入秒数为 0 时停止计时器并隐藏当前光圈；复盘模式不启动呼吸（停表后返回）；秒数大于 999 视为异常，停表并返回（光圈保持现有显隐）。锚点：layer/BoxHzmjMah2DView.ts → setDeskCentLight。
19. 行动家一组表现是打包下发的：同一条权限消息内依次刷新倒计时（同一秒数）、方位光（同一秒数）、然后点亮该座位头像框；头像框光效同样同一时刻只有一个座位可见（点亮前先把所有人熄灭）。锚点：controller/cmd/gameCmd/GamePowerCmd.ts → _updatePowerClock；layer/BoxHzmjPlayerView.ts → onShowPower；匹配场同构实现 layer/BoxHzmjPlayerMatchView.ts → onShowPower。
20. 重连恢复顺序：场景动作命令先按 power.seat 换算本地座位，再用计时器剩余秒数刷新倒计时，方位光用"剩余秒数 + 1"传值（避免 0 值走熄灭分支），最后点亮头像框。锚点：controller/cmd/sceneCmd/SceneActionCmd.ts → _recoverClock。

## 三、剩余牌数与牌墙

21. 界面上没有独立的"剩余牌数"面板：它是一个可挂载组件（BoxHzmjMahLeftComp，标题文本显示张数），由主界面主动向返回按钮栏请求绑定，最终挂到返回按钮栏左上菜单的占位（KW_PART_LEFTTOP_MENU.KW_LEFT_MAHS）并置为可见。锚点：layer/BoxHzmjMainView.ts → bindMahLeftCompToBackButtonsView；layer/comp/BoxHzmjMahLeftComp.ts → initUI / updateMahCnt。
22. 张数来源是牌墙剩余数（GameData.getLeftCard()，内部字段 _wallLeftNum）：非重连重置时等于总牌数，每次抓牌按抓走张数扣减；重连时直接使用服务端下发的剩余数。锚点：data/GameData.ts → resetWall / takeWalls / getLeftCard。
23. 刷新时机共四处：发牌命令、抓牌命令、重连恢复牌墙命令、复盘恢复场景命令各刷新一次；重置（再来一局/重进）时以"0 且隐藏"刷新。锚点：controller/cmd/gameCmd/GameTakeFirstCmd.ts；controller/cmd/gameCmd/GameTakeCmd.ts → _updateTakeView；controller/cmd/helperCmd/RecoverWallCmd.ts；controller/cmd/RecoverGameSceneCmd.ts → _recoverWall；layer/BoxHzmjMainView.ts → resetUI。
24. 刷新只控制数字显隐：每次刷新都会把张数写进标题文本，hide 只切换标题子节点的可见性，组件外壳（牌背图）不随 hide 隐去；hide 默认 false。锚点：layer/comp/BoxHzmjMahLeftComp.ts → updateMahCnt。
25. 3D 牌墙的显示开关已下线：设置项读取函数恒返回 false，因此牌墙命令与重连命令下发的"显示牌墙"永远是 false，四面牌墙节点始终隐藏；"显示牌墙时出牌区缩到 0.9"的分支实际不会生效（该监听为死代码，无派发方）。锚点：controller/cmd/gameCmd/GameWallMahCmd.ts；controller/cmd/helperCmd/RecoverWallCmd.ts；common_game/data/CommonGameData.ts → getBoxCardwallOpen（恒 false）；layer/BoxHzmjMah2DView.ts → onShowWall / onCardwallChange。
26. 牌墙"哪一侧多一墩"由骰子和的奇偶结合庄家座次推算，2 人、3 人、4 人规则不同（2 人只看奇偶，3/4 人看庄家座位奇偶并与本地座位换位）。锚点：layer/BoxHzmjMah2DView.ts → onMsgWallAppear。
27. 抓牌时会跳过"财神牌墙位"（当财神牌不可被抓且财神位已设置时该位不消耗抓牌次数）；但本玩法没有任何命令写入财神位（字段恒为 -1），该分支永不触发（死代码，无消费方）。锚点：data/GameData.ts → takeWalls / jokerPos；config/BoxMahDefine.ts → isFanCardCanTake。
28. 牌墙总数默认 136（万条筒 108 + 东南西北 16 + 中发白 12），开局命令用服务端 wall_all 写入、牌墙命令再用 wall_left 覆盖为当前牌墙规模，剩余张数以覆盖后的值为基准。锚点：data/GameData.ts → maxWallNum / setTotalCard；controller/cmd/gameCmd/GameStartGameCmd.ts；controller/cmd/gameCmd/GameWallMahCmd.ts。

## 四、庄标与首出提示

29. 庄标是玩家头像组件内的图片（KW_Img_zhuang）配一个两页控制器（C_Bank，show/hide），代码只切控制器页，不直接改图片可见性；同一时刻只允许一个座位处于 show 页。锚点：layer/BoxHzmjPlayerView.ts → onShowZhuang / onHideZhuang；组件声明 fgui_uideclare/box_hzmj_player/FGUI_box_hzmj_player_PlayerPanel.d.ts；匹配场同构实现 layer/BoxHzmjPlayerMatchView.ts。
30. 设庄是"先全隐再显示"：收到局数据时先用人数作为座位号把所有人庄标隐藏，再给庄家座位切 show；因此换庄一定只留一个庄标。锚点：controller/cmd/gameCmd/GameJuDataCmd.ts → execute 派发 onShowZhuang；layer/BoxHzmjPlayerView.ts → onShowZhuang（内部先调 onHideZhuang(playCnt)）。
31. 重置（再来一局/重进/解散重连）把全部座位庄标隐藏，避免上一局庄标残留。锚点：layer/BoxHzmjPlayerView.ts → resetUI（onHideZhuang(playCnt)）；layer/BoxHzmjPlayerMatchView.ts → resetUI / _clearAllPlayerHeads。
32. 断线重连与复盘恢复会按缓存的庄家本地座位补一次庄标。锚点：controller/cmd/RecoverGameSceneCmd.ts → _recoverZhuang。
33. 首出庄/闲提示条（KW_ZhuangTips，控制器 C_Zhang：0=庄、1=闲）的触发条件是"剩余牌数恰好等于 总牌数 - 人数 × 初始手牌数 - 1"（即本局第一次出牌权限）且本局尚未提示过；满足时清空文字提示、显示提示条、记住已提示、并同时隐藏骰子，属于一次性提示。锚点：controller/cmd/gameCmd/GamePowerCmd.ts → _updateFirstPlayTips；layer/BoxHzmjTipAniView.ts → onMsgShowZhuangTips。
34. 首出提示条的互斥隐藏：非首出权限每次都会隐藏提示条；自己点击碰/杠/胡（含选择杠）、关闭操作区、进入托管、重置都会清掉提示条。锚点：controller/cmd/gameCmd/GamePowerCmd.ts → _updateFirstPlayTips；layer/BoxHzmjMainView.ts → onBtnChooseGang / onBtnHu / closeOperate / onShowTrustee / resetUI。
35. 复盘模式下不显示首出提示条（只允许隐藏，不允许显示），也不弹首出提示相关的引导。锚点：layer/BoxHzmjTipAniView.ts → onMsgShowZhuangTips（isFupanMode && show 直接 return）。
36. 连庄信息不上桌面：局数据只缓存连庄次数，桌面常驻区没有连庄/庄二/庄三等标识或倍数角标，该数值仅用于结算流水文案后缀 "(xN)"。锚点：controller/cmd/gameCmd/GameJuDataCmd.ts → setLianZhuangCount；controller/cmd/helperCmd/ResultCmd.ts → _createFlowItemNoFan（K_LT_LIAN_ZHUANG 分支）。

## 五、财神指示

37. 现网没有财神指示牌、翻财神动画或财神提示横幅：命令表里保留了财神数据命令名，但本玩法没有任何命令类注册处理它（全量注册清单中无该命令），协议层只保留了消息解码注册，属无消费方链路。锚点：controller/cmd/CmdDefine.ts → CMD_JOKER；protocol/GameGlcProtocol.ts → XYID.GP_JOKER / MsgJoker；对照 controller/cmd 下全部 @RegisterCmd 清单。
38. 财神在界面上的唯一表现是手牌角标：收到游戏配置后，按配置里的癞子牌表给对应牌值设置黄色角标与癞子标记（同值牌只标一次，由底层手牌组件处理）。锚点：layer/BoxHzmjPlayerHandCards.ts → updateHandCorner；layer/BoxHzmjMainView.ts → onReceiveGameConfig。
39. 财神牌位字段（jokerPos）只读不写：默认为 -1，本玩法没有任何赋值点，因此"翻出的财神牌保留在牌墙、不参与抓牌"的逻辑恒不生效（死代码，无消费方）；财神牌值本身只作为数据字段（白板 83）存在。锚点：data/GameData.ts → jokerPos / takeWalls；config/BoxMahDefine.ts → mahBai。
40. 若需求文档定义中央"财神指示牌"或翻财神开牌动画，属于新增功能而非现网行为：应按 P3 差异说明处理，并标注"与现网实现差异"，不能用现网无实现反推需求错误。锚点：本基准第 37、39 条；config/BoxMahDefine.ts → isFanCardCanTake / mahBai。

## 六、出牌放大

41. 他人出牌后，在该座位对应的放大牌位（KW_ShowCard0~3 / CompCardBig 组件）显示刚打出的那张牌；显示前先隐藏全部放大牌位，因此同一时刻只显示一张。锚点：layer/BoxHzmjMainView.ts → showPutCardUi / hidePutCardUi；组件声明 fgui_uideclare/box_hzmj_main/FGUI_box_hzmj_main_HzmjMainComponent.d.ts / CompCardBig.d.ts。
42. 两个前置守卫：出牌者是自己时直接返回（自己不放大）；设置项"大出牌"关闭时不放大。该设置默认开启，缺省读不到本地存储也按开启处理，关闭状态会持久化。锚点：layer/BoxHzmjMainView.ts → showPutCardUi（`seat == SELF_LOCAL_SEAT` 与 `getBoxShowBigOut()`）；common_game/data/CommonGameData.ts → getBoxShowBigOut / 初始化读取 boxShowBigOut。
43. 触发链路：只有收到他人出牌协议（出牌 S 到 C）才触发；重连补数据阶段（只更新数据、不播界面）不触发，因此静默恢复不会弹出放大牌。锚点：controller/cmd/gameCmd/GamePlayCmd.ts → _updatePlayView（justUpdateData 提前 return）。
44. 隐藏时机是事件驱动而不是计时：他人碰、他人杠、他人胡（含复盘胡、结果胡）、流局、重置都会统一隐藏；按钮点击后不会自己消失，会一直保留到上述事件发生或下一次出牌替换。锚点：controller/cmd/gameCmd/GamePungCmd.ts；controller/cmd/gameCmd/GameKongCmd.ts；controller/cmd/gameCmd/GameHuExCmd.ts → _updateHuView；controller/cmd/gameCmd/GameResultHuCmd.ts → _updateHuView；controller/cmd/gameCmd/GameDrawnCmd.ts；layer/BoxHzmjMainView.ts → resetUI。
45. 出牌放大没有超时兜底，也没有"停留 N 秒后自动关闭"的配置；关闭只由事件或设置项（下一次出牌时判断）决定。锚点：layer/BoxHzmjMainView.ts → showPutCardUi / hidePutCardUi（无 scheduleOnce/DelayCall）。
46. 失败与恢复：断线重连恢复出牌区时，若服务端"刚出的牌"与该座位最后一张河牌一致，则补出牌箭头并补放大牌；复盘场景恢复出牌区时同样补放大。放大本身不判断房间类型，也不判断是否复盘。锚点：controller/cmd/helperCmd/RecoverOutsCmd.ts → execute；controller/cmd/RecoverGameSceneCmd.ts → _recoverOuts。
