# 开局流程（客户端 UI 交互基准）

> 来源：input-ui/xuanwulobby/assets/42319 代码逆向，提取日期 2026-11-11。锚点格式：文件 → 方法。检查需求文档对开局流程相关交互的描述是否完整、与实现一致。

## 一、开局阶段与界面切换

1. 开局消息 CMD_START_GAME 到达即写入对局态：标记已开局、清除「换座中」标记、非匹配场写底分、写封顶倍数、以协议 wall_all 覆盖总牌数、重建记牌器（复盘模式跳过记牌器初始化）。锚点：controller/cmd/gameCmd/GameStartGameCmd.ts → execute
2. 包厢好友房第 2 局起，收到开局消息先预置「首抓结束等待」标记；此后 CMD_END_WAIT 到达时若标记为真，客户端立即回 CS_END_WAIT、清标记并直接返回，不进入界面分支。锚点：controller/cmd/gameCmd/GameStartGameCmd.ts → execute；controller/cmd/gameCmd/GameEndWaitCmd.ts → execute
3. 开局动画的播放条件为「首局」或「非包厢（匹配场）」；包厢房从第 2 局起不派发 onMsgStartAni，直接进入数据推进。锚点：controller/cmd/gameCmd/GameStartGameCmd.ts → execute（`curRound === 1 || !isBoxRoom()` 分支）
4. 小局开始（公共 onGameStart）时收起匹配等待面板、隐藏换桌按钮、操作条回初始页。锚点：layer/BoxHzmjMainView.ts → onGameStart / clearAllActionSign
5. 背景层进入对局态：onIsGameStart(true) 时非匹配场隐藏封面图标、把控制器 C_StartGame 切到 1 页；匹配场只刷新玩法图标与底分，不切封面页。锚点：layer/BoxHzmjBackView.ts → onIsGameStart
6. 包厢场自己头像位置切换：onIsGameStartPlayerPos(true) 把自己头像从 KW_POS_FREE 移到 KW_POS_GAME、同步头像坐标缓存并派发 onMeMoveHeadPos；匹配场玩家层无该监听，头像不做位移。锚点：layer/BoxHzmjPlayerView.ts → onIsGameStartPlayerPos（layer/BoxHzmjPlayerMatchView.ts 无对应监听）
7. 首批加载包含背景层、2D 牌桌层、主界面层与提示动画层；包厢房追加包房玩家层，匹配场追加匹配玩家层，匹配场还追加匹配按钮层；资源全部加载完成后播放背景音乐。锚点：Game42319.ts → initUI
8. 匹配场未开局时显示等待面板 KW_MATCH：30 秒倒计时（倒数到负数后回到 30 继续循环），标题为两位补零数字加「秒」；玩法提示每 8 秒横向轮播，共 8 条文案。锚点：layer/BoxHzmjTipAniView.ts → initUI / showMatch / matchTimeSche / updateMatchTips
9. 等待面板没有超时关闭逻辑，只在开局事件或再入匹配事件下关闭或重新打开；再入匹配成功会重置桌面数据与界面并重新显示等待面板。锚点：layer/BoxHzmjTipAniView.ts → showMatch；layer/BoxHzmjMainView.ts → onMatchJoinSuccess

## 二、开局动画

10. 开局动画面板位于提示动画层的 KW_Start：开始时置为可见、隐藏「开局随机换座中」提示、隐藏全部局内玩家头像，并播放开局音效 GameSoundConfig.start。锚点：layer/BoxHzmjTipAniView.ts → _prepareStartAniPlayers
11. 面板内每位玩家显示分数（10 万起按两位小数缩写）、昵称截断 10 字、按 headId/headUrl 取头像。锚点：layer/BoxHzmjTipAniView.ts → _updateStartPlayerInfo
12. 头像面板按人数挂到 spine 骨骼挂点：2 人用 KW_Player_0/KW_Player_2 挂 Player1Icon/Player3Icon；3 人用 KW_Player_0/KW_Player_3/KW_Player_1 挂 Player1Icon/Player2Icon/Player4Icon；4 人用 KW_Player_0~3 挂 Player1Icon~Player4Icon；其他人数返回空数组（不挂点）。锚点：layer/BoxHzmjTipAniView.ts → _getStartAttachToBone
13. spine 事件 add_img1 触发所有首次头像面板 0.1 秒淡出，全部淡出完成后回 CS_END_WAIT（开局动画靠该事件推动服务端流程）。锚点：layer/BoxHzmjTipAniView.ts → _handleStartSpineEvent / _fadeStartPlayerNodes
14. spine 事件 add_img2 逐座位派发头像归位与局内头像淡入（alpha 0→1，0.0168 秒）；头像归位事件在每个座位循环中重复派发，无去重。锚点：layer/BoxHzmjTipAniView.ts → _showStartPlayerAni；layer/BoxHzmjPlayerView.ts → onIsGameStartPlayerPos / onShowPlayerAni
15. 动画播完回调隐藏 KW_Start，并再补一次头像归位与全体显示；但该兜底分支不补发 CS_END_WAIT，spine 事件 add_img1 缺失时流程不会自动推进。锚点：layer/BoxHzmjTipAniView.ts → _playStartSpineAni（完成回调）
16. 开局动画层整层 touchable=false，播放期间不拦截桌面点击。锚点：layer/BoxHzmjTipAniView.ts → initUI
17. 重置界面直接隐藏 KW_Start（不等待动画），同时清掉庄提示、结果分数、碰杠/胡牌动画节点。锚点：layer/BoxHzmjTipAniView.ts → resetUI
18. 重连落在「场景开始」阶段会重播完整开局动画：SceneStartCmd 以非「仅数据」方式执行 CMD_START_GAME。锚点：controller/cmd/sceneCmd/SceneStartCmd.ts → execute

## 三、定庄与方位盘

19. 局数据 CMD_JU_DATA 写入庄家本地座位、服务器庄位与连庄次数；开局界面只消费庄家本地座位。锚点：controller/cmd/gameCmd/GameJuDataCmd.ts → execute
20. 门风坐标取 men_feng 中「东」（牌值 65）所在座位并转本地；数组中找不到东时回退庄家座位。锚点：controller/cmd/gameCmd/GameJuDataCmd.ts → execute
21. 庄标表现：先清空本局所有座位庄标，再把庄家座位头像的 C_Bank 切到 show；匹配场实现同构。锚点：layer/BoxHzmjPlayerView.ts → onShowZhuang / onHideZhuang；layer/BoxHzmjPlayerMatchView.ts → onShowZhuang
22. 方位盘底图按人数 + 东风位选图（2 人 desk_base09/08，3 人 desk_base06/07/05，4 人 desk_base01/04/03/02），并按同一映射表点亮每个座位的风向光圈；每次设置先把 KW_DeskCent.KW_Bg 置可见。锚点：layer/BoxHzmjMah2DView.ts → onMsgDeskCentBg + bg_url_map；config/GameDefine.ts → SC_PLAYER_LOCAL_SEAT_MAP3
23. 人数或东风位非法时只打告警并放弃本次设置（底图与光圈保持原状），不会用 0 号位兜底。锚点：layer/BoxHzmjMah2DView.ts → onMsgDeskCentBg（两处 warn 分支）
24. 空闲态（无局数据）也能单独刷新方位盘：CMD_SCENE_IDLE 只取门风，门风数组为空时直接返回，找不到东时回退本地 0 号位。锚点：controller/cmd/gameCmd/GameIdleCmd.ts → execute
25. 首出庄闲提示：剩余牌数等于「总牌数 − 人数 × 每家初始手牌数 − 1」时视为首出阶段，弹出 KW_ZhuangTips（庄家页 0 / 闲家页 1），每局只弹一次，并同时隐藏骰子；非庄家额外触发一次听牌动画检查。锚点：controller/cmd/gameCmd/GamePowerCmd.ts → _updateFirstPlayTips
26. 复盘模式下庄闲提示不展示：收到显示指令且为复盘时直接返回。锚点：layer/BoxHzmjTipAniView.ts → onMsgShowZhuangTips
27. 连庄次数不参与开局界面展示，仅在小结算文案中以「×N」出现。锚点：controller/cmd/gameCmd/GameJuDataCmd.ts → execute（setLianZhuangCount）；controller/cmd/helperCmd/ResultCmd.ts → 结算文案拼接

## 四、掷骰子

28. CMD_THROW_CHIP 写入两颗骰子点数并派发 onShowDice(点数1, 点数2, 是否跳过动画)；跳过动画标记来自命令 type（重连场景传 skipAni）。锚点：controller/cmd/gameCmd/GameThrowChipCmd.ts → execute
29. 骰子节点为桌面中央 KW_DeskCent.KW_ANI_DICE_0 / KW_ANI_DICE_1：显示时两者同时可见、skinName 直接取点数；正常流程播 animation，第二颗播完后延迟 1 秒自动隐藏。锚点：layer/BoxHzmjMah2DView.ts → showDice
30. 跳过动画分支（重连/复盘）播放 animation1 静态帧，且不注册自动隐藏，停留到首出提示时由 onHideDice 收起。锚点：layer/BoxHzmjMah2DView.ts → showDice；controller/cmd/gameCmd/GamePowerCmd.ts → _updateFirstPlayTips
31. 重置界面（重开一局）时两颗骰子强制隐藏。锚点：layer/BoxHzmjMah2DView.ts → resetUI

## 五、牌墙

32. CMD_WALL_MAH 收到时先以协议 wall_left 覆盖总牌数，再把 first_asc 为奇数的情况自减 1 对齐偶数索引，并用 first_asc/first_desc 重置牌墙索引；非重连分支把牌墙按总牌数整格填成空牌，剩余张数记为该总数。锚点：controller/cmd/gameCmd/GameWallMahCmd.ts → execute；data/GameData.ts → setTotalCard / resetWall
33. 牌墙可见性由包厢设置 getBoxCardwallOpen 决定，一次控制 wall0~wall3 四个方向的牌墙组件；牌墙可见时出牌区缩放到 0.9。锚点：layer/BoxHzmjMah2DView.ts → onShowWall
34. 牌墙底图 wallbg0~3 跟随牌桌道具单独开关，与牌墙牌块显隐互不联动。锚点：layer/BoxHzmjMah2DView.ts → onChangeMahWall / initDress
35. 设置面板改牌墙开关实时生效。锚点：layer/BoxHzmjMah2DView.ts → onCardwallChange
36. 多一墩方向：由骰子点数和奇偶 + 庄家座位（4 人看庄位奇偶，3 人看庄位是否自己，2 人只看和值奇偶）决定 isSelfLong，并按人数修正牌墙起始座位；骰子不足两颗时按「自己方向、多一墩」默认处理。锚点：layer/BoxHzmjMah2DView.ts → onMsgWallAppear
37. 牌墙落桌使用 GameData.maxWallNum 作为牌墙格数、GameData.walls 作为占位数据。锚点：layer/BoxHzmjMah2DView.ts → onMsgWallAppear
38. 剩余牌数通过 onUpdateMahCnt 推到牌墙旁计数组件 title，hide=true 时隐藏数字。锚点：layer/comp/BoxHzmjMahLeftComp.ts → updateMahCnt

## 六、发牌

39. CMD_TAKE_FIRST（每家发牌数据）写入该座位手牌并把牌桌状态置为「发牌」；自己额外扣减记牌器；该命令只刷新剩余张数，不播放任何发牌动画。锚点：controller/cmd/gameCmd/GameTakeFirstCmd.ts → execute
40. CMD_TAKE 且 flag 为 0 视为首抓：牌桌状态置「抓牌」，对本局每个本地座位派发一次发牌动画，并对牌墙一次性派发首抓消失列表。锚点：controller/cmd/gameCmd/GameTakeCmd.ts → execute / _updateTakeData / _playTakeFirstAni / _takeWalls
41. 首抓牌墙消失张数为「自己手牌数 × 人数 + 1」（4 人为 53 张），牌墙逐张消失，每批同时消失 4 × 人数 张。锚点：controller/cmd/gameCmd/GameTakeCmd.ts → _takeWalls；layer/BoxHzmjMah2DView.ts → onTakeFirstAniAll
42. 自己的首抓动画顺序：手牌先随机乱序背面摊开 → 逐张翻牌 → 按牌值排序 → 牌桌状态置「开始」→ 清除重连标记 → 回 CS_END_WAIT。锚点：layer/BoxHzmjMainView.ts → onTakeFirstAniSelf
43. 他人的首抓直接按数据摆牌（takeFirst(cards)），没有逐张翻牌过程。锚点：layer/BoxHzmjMah2DView.ts → onTakeFirstAniAll（非自己分支）
44. 自己首抓时额外派发公共发牌事件 onEventFaPai(0)，该事件在 42319 内无监听，由公共层消费。锚点：layer/BoxHzmjMah2DView.ts → onTakeFirstAniAll
45. 首抓动画没有「只播一次」守卫：任何 flag==0 的抓牌命令都会对全部座位重复派发同一套发牌动画。锚点：controller/cmd/gameCmd/GameTakeCmd.ts → _playTakeFirstAni（无重复标记校验）
46. 常规抓牌（flag 非 0）不算发牌：牌墙按方向与张数消牌，自己走摸牌滑入与凑牌动画，他人直接摆牌。锚点：controller/cmd/gameCmd/GameTakeCmd.ts → _takeWalls / _updateSelfMoMahAni；layer/BoxHzmjMah2DView.ts → setTakeMah

## 七、洗牌道具（预约洗牌）

47. 洗牌入口 KW_BTN_Xi_Pai 的显示条件：自己已胡 + 非匹配场 + 未到最后一局 + 未预约 + 非复盘；任一条件不满足时先把按钮置隐再返回。锚点：layer/BoxHzmjMainView.ts → onUpdateReserveShuffle
48. 该按钮每日首次显示会把 C_ShowTip 切到 1 页提示，用本地存储日期键 VipShow_CurTypeLimitDayRecord 记录；当日再次显示时提示页为 0。锚点：layer/BoxHzmjMainView.ts → onUpdateReserveShuffle
49. 点击洗牌按钮打开通用购买弹层 BoxRoomXiPaiView，并把提示页切回 0。锚点：layer/BoxHzmjMainView.ts → onBtnXiPai
50. 入口刷新时机为胡牌链（多人胡、结果胡）与续桌成功；小结算弹出时强制隐藏入口。锚点：controller/cmd/gameCmd/GameHuExCmd.ts → execute；controller/cmd/gameCmd/GameResultHuCmd.ts → execute；layer/BoxHzmjMainView.ts → onContinueSuccess / onShowGameResult
51. CMD_MIX_CARD 在非包厢房直接返回（不播洗牌动画）；包厢房按协议座位逐个清预约标记、派发洗牌动画（最后一个座位带「需回 end_wait」标记），并把该座位头像上的洗牌图标清掉。锚点：controller/cmd/gameCmd/GameMixCard.ts → execute
52. 洗牌动画节点为提示动画层 KW_MixCard_0~3 的 spine（Xipai_dh）：自己播 animation1、他人播 animation2；自己播完后额外播一次运势上升动画，再按 end_wait 标记回 CS_END_WAIT；他人只在「最后一个座位」回 CS_END_WAIT，播放同时播公共音效 mj_xipai。锚点：layer/BoxHzmjTipAniView.ts → onShowMixCardAni
53. 预约图标表现：头像上 KW_XiPai 显示、C_XiPai 切 1 并循环播放 spine Xipai_wenzi；收到取消（propId 为 0）或未配置的道具 id 时隐藏。锚点：layer/BoxHzmjPlayerView.ts → _updatePlayerXiPai / onPlayerReserveShuffle / onOtherXipaiNotify
54. 重连进入洗牌阶段不重播洗牌动画，只恢复数据与静态桌面。锚点：controller/cmd/sceneCmd/SceneMixCardCmd.ts → execute

## 八、断线重连与复盘恢复

55. 场景状态与恢复命令一一映射：开始 → SceneStart、发牌 → SceneTakeFirst、动作 → SceneAction、洗牌 → SceneMixCard。锚点：controller/gameController.ts → Hzmj_SCENE_HANDLER_BY_STATE
56. 重连统一入口先派发 onResetUI(false)（不清他人头像），再执行场景命令，最后统一派发 isGameStart、头像归位、显示自己。锚点：controller/gameController.ts → gameSceneBack
57. 重连落在「发牌」阶段：开始游戏与虚拟玩家信息仅写数据、游戏配置、局数据、骰子静态展示、恢复牌墙、恢复手牌（直接摆出，自己仍为背面），end_wait 非空时补回 CS_END_WAIT；不播开局动画与发牌动画。锚点：controller/cmd/sceneCmd/SceneTakeFirstCmd.ts → execute；controller/cmd/helperCmd/RecoverHandsCmd.ts → execute
58. 重连落在「洗牌」阶段的恢复顺序与发牌阶段一致，但不恢复手牌。锚点：controller/cmd/sceneCmd/SceneMixCardCmd.ts → execute
59. 重连恢复牌墙用服务端 asc/desc/wall_left 重建占位并刷新剩余张数，同时按包厢设置决定牌墙是否可见。锚点：controller/cmd/helperCmd/RecoverWallCmd.ts → execute；data/GameData.ts → resetWall（isRelink 分支）
60. 复盘恢复到「开始游戏」帧的顺序为：牌墙 → 骰子（静态）→ 手牌 → 庄标；其他帧顺序为牌墙 → 庄标 → 骰子 → 手牌 → 河牌 → 权限 → 胡牌信息。锚点：controller/cmd/RecoverGameSceneCmd.ts → execute（GP_START_GAME / default 分支）
61. 复盘场景恢复在 justUpdateData 为真时完全跳过 UI。锚点：controller/cmd/RecoverGameSceneCmd.ts → execute

## 九、牌库与人数适配

62. 客户端默认牌库 136 张（万条筒 108 + 风 16 + 箭 12），每家初始手牌 13 张；收到协议后总牌数以 wall_all / wall_left 覆盖。锚点：data/GameData.ts → clearData / _initHandCardNum；controller/cmd/gameCmd/GameStartGameCmd.ts → execute；controller/cmd/gameCmd/GameWallMahCmd.ts → execute
63. 记牌器在非复盘时按筒/条/风/箭/万各 4 张初始化（共 34 种牌），gameConfig.is_two_suit 为真时不初始化万子；自己发牌与每次抓牌扣减对应张数，扣减下限 0、上限 4。锚点：data/GameData.ts → initCardCounter / updateCardCounter
64. 2/3/4 人适配：座位映射固定为自己恒为 0 号 UI 位（2 人 0/2，3 人 0/1/3，4 人 0/1/2/3）；方位盘底图与光圈、开局动画挂点、牌墙多墩判定、出牌区显隐均按人数分支。锚点：config/GameDefine.ts → SC_PLAYER_LOCAL_SEAT_MAP；layer/BoxHzmjMah2DView.ts → initWithPlayCnt；layer/BoxHzmjTipAniView.ts → _getStartAttachToBone
65. 人数变化事件会重建各层节点表：提示动画层重建头像、结果分数、杠位、胡牌动画节点；牌桌层重建河牌、手牌、胡牌、组合与风向光圈引用。锚点：layer/BoxHzmjTipAniView.ts → initWithPlayCnt；layer/BoxHzmjMah2DView.ts → initWithPlayCnt

## 十、死代码与无消费方（报告防误报依据）

66. 事件 onStartGame（BOX_Hzmj_onStartGame）只有两个监听方（主界面、包厢玩家层），全仓库无派发方，两处监听均为死代码。锚点：config/FguiViewDefine.ts → GameEventBoxHzmj.onStartGame；layer/BoxHzmjMainView.ts → onMsgStartGame；layer/BoxHzmjPlayerView.ts → onMsgStartGame
67. 事件 onMsgStartGame 有派发（开局命令）但无任何监听方，事件无消费方。锚点：controller/cmd/gameCmd/GameStartGameCmd.ts → execute
68. 事件 onShowWallMah 仅声明，既无派发也无监听。锚点：config/FguiViewDefine.ts → GameEventBoxHzmj.onShowWallMah
69. 音效配置 points（骰子滚动）无消费方，掷骰流程实际没有骰子音效。锚点：config/GameSoundConfig.ts → GameSoundConfig.points
70. 开局动画播放开关的 false 分支（只显示头像、不播 spine）无调用方传入 false，当前恒走 true 分支。锚点：layer/BoxHzmjTipAniView.ts → onMsgStartAni（唯一派发方 GameStartGameCmd 不传参）
71. 开局 spine 资源地址赋值代码已被注释，动画资源由 FGUI 组件内置。锚点：layer/BoxHzmjTipAniView.ts → _playStartSpineAni（注释行）
72. 数据访问器 getTableState、getMahDeskCentEast、getFirstZhuangTips 在 42319 内无消费方（仅写入或仅定义）。锚点：data/GameData.ts → getTableState / getMahDeskCentEast / getFirstZhuangTips
73. 初始手牌数设置器 setInitHandCardNum 在 42319 内无调用方，手牌数恒为默认 13。锚点：data/GameData.ts → setInitHandCardNum
