# 开局流程（客户端 UI 交互基准）

> 来源：input-ui/xuanwulobby/assets/42319 代码逆向，提取日期 2026-11-11。锚点格式：文件 → 方法。检查需求文档对开局流程相关交互的描述是否完整、与实现一致。

## 一、开局协议与开局界面

1. 首次进入 42319 加载 4 个常驻界面：背景层 BoxHzmjBackView、2D 牌桌层 BoxHzmjMah2DView、主界面 BoxHzmjMainView、提示动画层 BoxHzmjTipAniView；包厢房追加玩家层 BoxHzmjPlayerView（复盘再追加 BoxRoomFupanView，否则追加通用菜单栏 GameBaseBoxMenuView 与返回按钮 GameBaseBackButtonsView），非包厢房追加匹配场玩家层 BoxHzmjPlayerMatchView；匹配场再追加 GameMatchButtonsView。锚点：Game42319.ts → initUI（strViewList）
2. 匹配场且尚未开局时，提示动画层立即显示匹配等待面板 KW_MATCH：倒计时初值 30 秒、每秒减 1、减到负数后回到 30 循环；标题为两位补零秒数加「秒」；玩法提示共 8 条、每 8 秒横向轮播一次。锚点：layer/BoxHzmjTipAniView.ts → initUI / showMatch / matchTimeSche / updateMatchTips
3. 关闭匹配等待面板只停止秒数定时器，8 秒轮播用的 delayedCall 递归没有停止入口，面板隐藏后轮播仍会继续触发（无面板可见性守卫）。锚点：layer/BoxHzmjTipAniView.ts → showMatch（仅 unschedule matchTimeSche）/ updateMatchTips（GTween.delayedCall 递归）
4. 提示动画层整层 touchable=false，开局动画与结算动画播放期间不拦截桌面点击。锚点：layer/BoxHzmjTipAniView.ts → initUI（this.view.touchable = false）
5. 收到开局协议 CMD_START_GAME 先写数据：标记已开局、清除「随机换座中」标记、非匹配场才写底分、写房间封顶倍数、以协议 wall_all 覆盖牌墙总数、重建记牌器（复盘模式跳过）；随后按 bot_time_ms/bot_time 与 auto_bot_time_ms 写入托管时长。锚点：controller/cmd/gameCmd/GameStartGameCmd.ts → execute
6. 补数据模式（通知 type 为 "justUpdateData"）只执行第 5 条的数据段即返回，不派发任何开局界面事件，因此重连补数据不会重播开局表现。锚点：controller/cmd/gameCmd/GameStartGameCmd.ts → execute（justUpdateData 早退）
7. 包厢房非首局会预置「首抓结束等待」标记，首局不预置；首局判定用严格等于 1（curRound === 1），局号为 0 或其它值都按非首局处理。锚点：controller/cmd/gameCmd/GameStartGameCmd.ts → execute（curRound != 1 → setTakeFirstEndWait(true)）
8. 正常开局依次派发三个界面事件 onMsgStartGame、clearAllActionSign、onIsGameStart(true)；随后只在「首局」或「非包厢房」时再派发 onMsgStartAni，包厢房第 2 局起不播开局动画、直接进入数据推进。锚点：controller/cmd/gameCmd/GameStartGameCmd.ts → execute
9. 事件 onMsgStartGame 只有派发方、全模块无任何监听（死代码），开局消息不会直接驱动主界面/玩家层。锚点：config/FguiViewDefine.ts → GameEventBoxHzmj.onMsgStartGame；controller/cmd/gameCmd/GameStartGameCmd.ts → execute
10. 事件 onStartGame（BOX_Hzmj_onStartGame）只有两个监听方（主界面、包厢玩家层），全模块无派发方，两处监听均为死代码。锚点：layer/BoxHzmjMainView.ts → onMsgStartGame；layer/BoxHzmjPlayerView.ts → onMsgStartGame
11. clearAllActionSign 到达时：主界面隐藏换桌按钮；匹配场玩家层按「全部座位」清一次动作标识（隐藏准备/操作标记）。锚点：layer/BoxHzmjMainView.ts → clearAllActionSign；layer/BoxHzmjPlayerMatchView.ts → clearAllActionSign
12. 公共小局开始事件 onGameStart 到达时：关闭自动胡标记、收起匹配等待面板、隐藏换桌按钮。锚点：layer/BoxHzmjMainView.ts → onGameStart
13. 背景层按开局态切换：非匹配场收到 onIsGameStart(true) 时隐藏封面图标 KW_Icon 并把 C_StartGame 切到 1 页；匹配场只刷新玩法图标与底分（底分取 TableData.getBaseScore），不动封面页。锚点：layer/BoxHzmjBackView.ts → onIsGameStart
14. 自己头像位置切换只由包厢玩家层实现：true 移到 KW_POS_GAME、false 移到 KW_POS_FREE，同步头像坐标缓存并派发 onMeMoveHeadPos；匹配场玩家层没有该监听，匹配场头像不位移。锚点：layer/BoxHzmjPlayerView.ts → onIsGameStartPlayerPos
15. 界面重置事件 onResetUI 的触发点：准备回包成功、断线重连 gameSceneBack、复盘交换/批量复盘数据、再来一局、匹配重新加入、测试面板重置。前两处传 false（不隐藏其他玩家头像），其余不传参（默认清空他人头像）。锚点：controller/gameController.ts → playerReadyBack / gameSceneBack / exchangeFupanGame / dealBatchFupanData；layer/BoxHzmjMainView.ts → playAgain / onMatchJoinSuccess
16. 主界面重置会清空整套局内数据（GameData.clearData）、操作按钮状态回 0、隐藏全部放大出牌与台面标识、清空组合牌与杠选择、清听牌按钮、剩余张数置 0 并隐藏、取消所有定时回调并关掉小结算弹层。锚点：layer/BoxHzmjMainView.ts → resetUI
17. 提示动画层重置直接隐藏开局动画面板 KW_Start（不等动画结束）、庄提示、4 个结果分数、随机换座提示与换牌提示，停结果分数动画、清碰杠/胡牌动画、清文本提示、结束类型回 NONE 并清动作标识。锚点：layer/BoxHzmjTipAniView.ts → resetUI
18. 牌桌层重置清空四家手牌/河牌/胡牌/组合与整面牌墙，隐藏出牌箭头与方位盘亮光，清空并停止倒计时，隐藏两颗骰子，最后把自己手牌节点位置与缩放还原初始值。锚点：layer/BoxHzmjMah2DView.ts → resetUI
19. 玩家层重置隐藏全部庄标与权限光圈并取消定时回调；匹配场玩家层重置还会清全部座位动作标识与权限。锚点：layer/BoxHzmjPlayerView.ts → resetUI；layer/BoxHzmjPlayerMatchView.ts → resetUI

## 二、开局动画

20. 开局动画面板为提示动画层 KW_Main.KW_Start（含 spine 节点 KW_Ani 与 4 个玩家面板 KW_Player_0~3）；播放前先播开局音效 GameSoundConfig.start（Hzmj_sound/effect/sfx_start）、把面板置可见、隐藏「随机换座中」提示并隐藏全部 4 个面板节点；面板节点按 SC_PLAYER_LOCAL_SEAT_MAP[人数] 取 KW_Player_{uiIdx}。锚点：layer/BoxHzmjTipAniView.ts → _prepareStartAniPlayers / initWithPlayCnt
21. 开局面板逐座位初始化：先派发 onHidePlayer 隐藏局内头像，再把面板节点置可见、alpha=1、缩放 1、旋转 0。锚点：layer/BoxHzmjTipAniView.ts → _initStartPlayerNode
22. 开局面板玩家信息：分数按 10 万起点保留两位小数缩写、昵称截断 10 字、按 headId/headUrl 取头像；取不到玩家数据时直接跳过，面板留空（无兜底文案）。锚点：layer/BoxHzmjTipAniView.ts → _updateStartPlayerInfo
23. 头像挂 spine 骨骼按人数固定：2 人用 KW_Player_0→Player1Icon、KW_Player_2→Player3Icon；3 人用 KW_Player_0→Player1Icon、KW_Player_3→Player2Icon、KW_Player_1→Player4Icon；4 人用 KW_Player_0→Player1Icon、KW_Player_3→Player2Icon、KW_Player_2→Player3Icon、KW_Player_1→Player4Icon；其它人数返回空数组，不挂点。锚点：layer/BoxHzmjTipAniView.ts → _getStartAttachToBone
24. 开局 spine 播放 "animation"，资源地址赋值语句已被注释，动画资源由 FGUI 组件内置（不走代码设 url）。锚点：layer/BoxHzmjTipAniView.ts → _playStartSpineAni（注释行）
25. spine 事件 add_img1 触发全部开局头像 0.1 秒淡出；淡出完成计数达到人数时上行一次 end_wait，用于推动服务端继续。锚点：layer/BoxHzmjTipAniView.ts → _handleStartSpineEvent / _fadeStartPlayerNodes
26. add_img1 的淡出完成计数以人数为终点，若某个面板节点为空则计数永远到不了人数，该次不回 end_wait，且没有超时兜底。锚点：layer/BoxHzmjTipAniView.ts → _fadeStartPlayerNodes
27. spine 事件 add_img2 逐座位派发头像归位（onIsGameStartPlayerPos(true)）与局内头像淡入（alpha 0→1，0.0168 秒）；归位事件在循环里每个座位各派发一次，无去重。锚点：layer/BoxHzmjTipAniView.ts → _showStartPlayerAni；layer/BoxHzmjPlayerView.ts → onShowPlayerAni
28. 动画播完回调隐藏 KW_Start，并补一次头像归位与全体显示（兜底 spine 事件缺失）；该兜底不再补发 end_wait，spine 缺 add_img1 时流程不会自动推进。锚点：layer/BoxHzmjTipAniView.ts → _playStartSpineAni（完成回调）
29. onMsgStartAni 传入 false 时只把局内头像按座位全部显示（onShowPlayer），不播 spine、不播音效、不显示开局面板；当前唯一派发方不传参，该分支无调用方（恒走播放分支）。锚点：layer/BoxHzmjTipAniView.ts → onMsgStartAni / _showAllStartPlayers；controller/cmd/gameCmd/GameStartGameCmd.ts → execute
30. 换座提示与开局面板互斥：换座开始/换座通知把 KW_RandomSeatTip 置可见，开局动画准备阶段又强制置隐藏。锚点：layer/BoxHzmjTipAniView.ts → onPlayRandomSeatStart / onRandomSeat / _prepareStartAniPlayers

## 三、定庄与方位盘

31. 局数据 CMD_JU_DATA 把服务器庄位换算为本地座位写入，同时记录服务器庄位与连庄次数；门风取 men_feng 中「东」（牌值 65）所在座位，数组里找不到东时兜底用庄家服务器座位。锚点：controller/cmd/gameCmd/GameJuDataCmd.ts → execute
32. 定庄在客户端没有独立动画：只派发 onShowZhuang（庄家本地座位）与 onShowDeskCentBg（东风座位）两个表现事件；补数据模式只写数据、不派发。锚点：controller/cmd/gameCmd/GameJuDataCmd.ts → execute
33. 庄标显示前先隐藏本局全部座位的庄标，再把目标座位头像的 C_Bank 切到 "show" 页；包厢玩家层与匹配场玩家层实现同构。锚点：layer/BoxHzmjPlayerView.ts → onShowZhuang；layer/BoxHzmjPlayerMatchView.ts → onShowZhuang
34. onHideZhuang 传入座位号大于等于当前人数时按座位号遍历把全部庄标切回 "hide"，否则只隐藏指定座位。锚点：layer/BoxHzmjPlayerView.ts → onHideZhuang
35. 每局重置都会把全部庄标隐藏，重开一局不残留上一局庄标。锚点：layer/BoxHzmjPlayerView.ts → resetUI；layer/BoxHzmjPlayerMatchView.ts → resetUI
36. 方位盘底图按「人数 + 东风座位」取图（2 人 desk_base09/desk_base08，3 人 desk_base06/desk_base07/desk_base05，4 人 desk_base01/desk_base04/desk_base03/desk_base02），并按 SC_PLAYER_LOCAL_SEAT_MAP3 给每个座位下发东南西北风位光圈贴图；设置前先把方位盘背景置可见。锚点：layer/BoxHzmjMah2DView.ts → onMsgDeskCentBg / bg_url_map；config/GameDefine.ts → SC_PLAYER_LOCAL_SEAT_MAP3
37. 方位盘异常时不做兜底设置：人数小于等于 0、底图表为空、或光圈配置缺失时只打 warn 并返回，底图与光圈保持原状；东风座位在光圈表中不存在时回落到 0 号位取图，但仍需取到底图与光圈才继续。锚点：layer/BoxHzmjMah2DView.ts → onMsgDeskCentBg（两处 warn 分支 + eastSeat 回落）
38. 方位盘亮光有前置守卫：复盘模式或 time>999 时只停表并返回（不改可见性）；time>0 时仅目标座位亮并按秒奇偶交替闪烁；time=0 时停表并隐藏当前高亮。锚点：layer/BoxHzmjMah2DView.ts → setDeskCentLight
39. 方位盘朝向以「庄家为东风」为基准固定映射，不随出牌顺序变化。锚点：layer/BoxHzmjMah2DView.ts → onMsgDeskCentBg（注释「庄家为东风」+ lightCfg 按东风座位取表）
40. 连庄次数不参与开局界面展示，只出现在结算流水项文案里（连庄类型项后缀 (xN)）。锚点：controller/cmd/helperCmd/ResultCmd.ts → _createFlowItemNoFan

## 四、掷骰子

41. CMD_THROW_CHIP 先写入两颗点数，再派发 onShowDice(chips[0], chips[1], type==="skipAni")；补数据模式只存数据不播动画。锚点：controller/cmd/gameCmd/GameThrowChipCmd.ts → execute
42. 骰子节点为桌面中央 KW_DeskCent.KW_ANI_DICE_0 / KW_ANI_DICE_1：显示时两颗同时可见，skinName 直接取点数字符串；正常流程两颗都播 "animation"，第二颗播完后延迟 1 秒自动隐藏。锚点：layer/BoxHzmjMah2DView.ts → showDice
43. skipAni 分支两颗都播 "animation1" 静态帧且不注册自动隐藏，骰子停留到首出提示出现时由 onHideDice 收起。锚点：layer/BoxHzmjMah2DView.ts → showDice；controller/cmd/gameCmd/GamePowerCmd.ts → _updateFirstPlayTips
44. 掷骰命令不校验 chips 长度，只取 chips[0]/chips[1]；下发不足两颗时第二颗骰子的 skinName 会变成字符串 "undefined"（无守卫边界）。锚点：controller/cmd/gameCmd/GameThrowChipCmd.ts → execute；layer/BoxHzmjMah2DView.ts → showDice
45. 复盘恢复时骰子以 skipAni=true 直出点数、不播滚动，且恢复前先判点数长度等于 2 才派发。锚点：controller/cmd/RecoverGameSceneCmd.ts → _recoverThrowChip
46. 开局没有骰子滚动音效：音效配置 points（骰子滚动）在 42319 内无任何调用方（死配置）。锚点：config/GameSoundConfig.ts → GameSoundConfig.points
47. 重开一局 resetUI 强制隐藏两颗骰子。锚点：layer/BoxHzmjMah2DView.ts → resetUI

## 五、牌墙

48. CMD_WALL_MAH 先把 first_asc 为奇数的情况自减 1 对齐偶数索引，再以 wall_left 覆盖牌墙总数并 resetWall(first_asc, first_desc)，最后派发 onShowWall 与 onMsgWallAppear；补数据模式到写数据为止。锚点：controller/cmd/gameCmd/GameWallMahCmd.ts → execute；data/GameData.ts → setTotalCard / resetWall
49. 牌墙可见性由包厢设置 getBoxCardwallOpen 决定（缺省 false，即默认不显示牌墙），一次控制 wall0~wall3 四个方向；牌墙可见时出牌区缩放到 0.9，不可见恢复 1.0。锚点：layer/BoxHzmjMah2DView.ts → onShowWall；controller/cmd/gameCmd/GameWallMahCmd.ts → execute
50. 牌墙底图 wallbg0~3 由牌桌道具单独开关（SC_MAH_WALL 映射，复盘强制取 0），与牌墙牌块显隐互不联动。锚点：layer/BoxHzmjMah2DView.ts → initDress / onChangeMahWall
51. 设置面板改牌墙开关实时生效，直接复用牌墙显示逻辑。锚点：layer/BoxHzmjMah2DView.ts → onCardwallChange
52. 多一墩方向判定：骰子为两颗时按点数和奇偶、人数与庄位修正墙位与 isSelfLong——2 人时庄家不是自己则墙位换到 3/2，点数和为奇固定自己方向、为偶反之；3 人时按庄家服务器座位 2/0 把墙位重定向到 3，奇偶再结合自己是否庄家；4 人时按庄家座位奇偶决定；骰子不足两颗时保持默认「自己方向、多一墩」，不做修正。锚点：layer/BoxHzmjMah2DView.ts → onMsgWallAppear
53. 牌墙落桌使用 GameData.maxWallNum 作为格数、GameData.walls 作为占位数据，墙位由 TableData 的服务器座位写入。锚点：layer/BoxHzmjMah2DView.ts → onMsgWallAppear
54. 剩余张数通过 onUpdateMahCnt(GameData.getLeftCard()) 推到牌墙旁计数组件的 title；带 hide=true 时只隐藏 title 节点、不清值。锚点：layer/comp/BoxHzmjMahLeftComp.ts → updateMahCnt；controller/cmd/gameCmd/GameTakeFirstCmd.ts → execute；controller/cmd/gameCmd/GameTakeCmd.ts → _updateTakeView
55. 剩余张数组件注入有两处：主界面 initUI 派发 onBindMahLeftCompToBackButtonsView 注入返回按钮栏左上角 KW_LEFT_MAHS，返回按钮栏初始化时再回推 onNotifyGameBindMahLeftCompToBackButtonsView 让主界面补发一次（抵消延迟加载的时序差）；主界面加载完成后仅在匹配场额外注入通用菜单栏 GameMenuView。锚点：layer/BoxHzmjMainView.ts → bindMahLeftCompToBackButtonsView / loadFinishAll；common_game/layer/GameBackButtonsView.ts → initUI / _bindMahLeftComp / onUpdateMahLeftComp；common_game/layer/GameMenuView.ts → onUpdateMahLeftComp
56. 重开一局时整面牌墙被清空，同时主界面把剩余张数置 0 并隐藏。锚点：layer/BoxHzmjMah2DView.ts → resetUI；layer/BoxHzmjMainView.ts → resetUI
57. 默认牌墙总数为 136（万条筒 108 + 风 16 + 箭 12）；字段初值 144 在 init → clearData 后即被覆盖为 136，实际生效值为 136。锚点：data/GameData.ts → clearData / maxWallNum

## 六、发牌

58. CMD_TAKE_FIRST 只写数据：按本地座位 setHandFirst（写入并排序手牌）、置桌态 TAKEFIRST、自己额外扣减记牌器；界面只刷新剩余张数，本身不播发牌动画。锚点：controller/cmd/gameCmd/GameTakeFirstCmd.ts → execute；data/PlayerCardsData.ts → setHandFirst
59. 发牌动画由首个抓牌协议 CMD_TAKE 且 flag===0 触发：先按「自己手牌数 × 人数 + 1」计算要消失的牌墙索引（4 人常规 13 张手牌时为 53 张），再对本局每个本地座位各派发一次 onTakeFirstAniAll。锚点：controller/cmd/gameCmd/GameTakeCmd.ts → _takeWalls / _playTakeFirstAni
60. 首抓没有「只播一次」守卫：任何 flag===0 的抓牌命令都会对全部座位重复派发同一套发牌动画。锚点：controller/cmd/gameCmd/GameTakeCmd.ts → _playTakeFirstAni（无重复标记校验）
61. 他人发牌直接按手牌数据铺牌（hands[seat].takeFirst(cards)），没有逐张翻开过程。锚点：layer/BoxHzmjMah2DView.ts → onTakeFirstAniAll（非自己分支）
62. 自己发牌动画：手牌随机乱序 → 逐张飞入 → 按牌值排序 → 桌态置 START → 清重连标记 → 上行 end_wait。锚点：layer/BoxHzmjMainView.ts → onTakeFirstAniSelf
63. 自己首抓同时驱动牌墙消牌：一批同时消失 4 × 人数 张、单张时长取 MahDefine.Time_TakeFirstOneMah，并派发公共发牌事件 onEventFaPai(0)（42319 内无监听，由公共层 GamePlayerMysticView 消费）。锚点：layer/BoxHzmjMah2DView.ts → onTakeFirstAniAll（自己分支）；common_game/layer/GamePlayerMysticView.ts → onEventFaPai
64. 发牌阶段的摸牌事件被跳过：setTakeMah 收到 isTakeFirst=true 时直接 return，牌墙消牌只在 onTakeFirstAniAll 里做一次（原按 1.2 秒延迟消牌的代码已注释）。锚点：layer/BoxHzmjMah2DView.ts → setTakeMah
