# 记忆翻牌 迷你游戏 PRD（样例）

> 用途：Interactive Game PRD 管线验证样例，非真实卡五星 PRD。

## 1. 游戏概述

棋盘 4 列 2 行共 8 张牌，含 4 对图案。玩家逐张翻开，全部配对成功即胜利。

## 2. 玩法规则

### 2.1 翻牌

点击背面朝上的牌将其翻开。

### 2.2 配对判定

两张翻开的牌图案相同即配对成功，保持正面不再参与。

### 2.3 配对失败

两张牌图案不同，短暂展示约 1 秒后自动盖回背面。

### 2.4 胜利判定

4 对全部配对成功即胜利，展示总步数。

### 2.5 步数统计

每翻开两张牌计 1 步。

## 3. 功能需求

### 3.1 开局

点击开始游戏按钮重置棋盘并随机发牌。

### 3.2 结果展示

胜利后显示总步数与再来一局按钮，点击可重新开局。

## 4. 交互说明

### 4.1 点击牌

已翻开或已配对的牌再次点击无效。
