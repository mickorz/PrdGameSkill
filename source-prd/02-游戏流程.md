> 一局从开始到结束按时间发生什么：开局准备 → 打漂 → 定庄 → 摇骰方位 → 发牌 → 行牌 → 结束 → 结算续局；操作的条件与后果见 [打牌操作](03-打牌操作.md)。

## 一、开局准备

| 项 | 内容 |
|---|---|
| **创房** | 房主创建好友房，选定**卡五星**玩法与创房参数，见 [创房配置](07-配置.md)。 |
| **入座** | 房主创建房间后，后续加入房间的玩家按**逆时针顺序入座**，开局后与房主的逆时针顺序关系保持相同；**座位固定**。 |
| **座位布局** | **2 人**：固定与房主为对家，**一上一下**（下方自己，上方对家）。<br>**3 人**：固定为房主**下家**与房主**上家**，**一左一右一下**（下方自己，左侧上家，右侧下家）。 |
| **开局动画** | 每次开房**首局**播放开局动画；之后开局直接进入摇骰发牌。 |
| **玩家信息** | 展示头像、昵称、积分（初始 0）。 |

## 三、打漂

| 模式 | 流程 |
|---|---|
| **不漂** | 无打漂环节、不计漂分 |
| **固定漂** | 开局的同时，玩家头像旁直接出现选漂结果，**无过程动画**，并同时开始打骰子 |
| **首局定漂** | 仅**每个大局的第一小局**执行选漂环节；后续每个小局开局时流程同固定漂 |
| **自由漂**（每局选漂）| **每个小局**执行选漂环节 |

**选漂流程**（固定漂以外的模式）：

1. 小局开局后，每个玩家屏幕出现各漂选项。
2. 主视角：其他玩家头像旁出现【选漂中...】文字。
3. 玩家点击选项完成选漂；选漂后在头像旁出现选漂结果，**其他玩家直接可见**。
4. 最后一个玩家选漂完成的同时：选漂结果出现 → 所有玩家的选漂文字缩小、移动到头像旁漂 UI 的位置 → **开始打骰子**。

**漂分规则与示例见** [基础规则 §6.1](01-基础规则.md)。

## 四、定庄

| 选项 | 规则 |
|---|---|
| **随机坐庄** | 开局后首局**随机坐庄** |
| **房主坐庄** | 开局后首局**房主坐庄** |

- 同桌玩家继续游戏时，根据轮庄规则决定下一个坐庄玩家（见 §十）。
- 定庄时机：**逻辑上先于发牌** —— **定庄 → 定方位 → 发牌**。
  - **依据**：§2.0 对局节奏表的阶段序为「打漂 → 定庄、定方位（骰子点数展示 1S）→ 发牌」；§2.0 发牌行「**根据定方位**从正确起始位置发牌至各人」——发牌依赖方位、方位依赖庄家，故庄家必先确定；§3.2.5「**确认庄家并开始摸牌时**，显示对应的方位：庄为东」。
  - **UI 呈现**：§3.2.4 定庄 的庄家标签行作「**发牌开始后当骰子滚动停下时**，庄家头像上直接出现【庄】标志，无过程动画」——该句是**标签出现时机**（属呈现层），**不改变逻辑顺序**。
- **默认值**：**房主庄**（创房面板实拍「房主庄」为选中态）。

## 五、摇骰与方位

| 内容 | 规则 |
|---|---|
| **骰子** | 发牌时显示骰子，两个骰子环绕转动；在用户拿到所有手牌后，骰子停止转动并展现数字，停留 1 秒后消失 |
| **方位 —— 无方位** | 未开局默认为无方位展示；重新开局后，未指定某个玩家操作时不显示方位 |
| **方位 —— 有方位** | 确认庄家并开始摸牌时显示对应方位：**庄为东**，其他玩家按人数**逆时针**依次显示南、西、北（3 人仅显示南、西；2 人仅显示南）。之后方位不再变化，直到重新匹配重置成无方位展示 |
| **方位高亮** | 某个玩家轮到出牌时，其对应方位闪烁高亮；期间即使其他玩家在该玩家出牌后可进行碰 / 杠 / 胡操作，**也不会改变高亮方位**。对局结束则无方位高亮 |
| **倒计时** | 显示玩家可操作的倒计时，最多两位数。<br>· 默认蓝色，倒计时为 03 / 02 / 01 / 00 时**为黄色**。<br>· 有碰 / 杠 / 胡等操作时，**自己视角的倒计时需重置**成可操作的倒计时（例：左边玩家打出三条后自己可执行碰操作，则倒计时重置成初始值）。<br>· 当别人有碰 / 杠 / 胡等操作时，**别人视角的倒计时无变化** |
| **上楼展示** | 如果开启上楼规则且该局符合上楼，则在**骰子停止的同时**在骰子上方展示「上楼X2 / 上楼X4」（2 还是 4 按具体倍数定）——**UI 表现详见 [UI交互 §3.3.4](09-UI交互.md)** |

**上楼触发条件的规则细节见** [基础规则 §3.4](01-基础规则.md)。

## 六、发牌与理牌

### 6.1 发牌逻辑

| 项 | 内容 |
|---|---|
| **方向** | 从**庄家位**开始，**逆时针**顺序 |
| **第 1~3 轮** | 每人发 **4 张 / 次**，共 3 轮 |
| **第 4 轮** | 再从庄家位开始逆时针，每人发 **1 张** |
| **第 5 步** | 最后给**庄家位**发 **1 张** |

### 6.2 起手序列与合计

| 角色 | 发牌序列 | 起手合计 |
|---|---|---|
| **庄家** | **4+4+4+1+1**（4 组）| **14 张** |
| **闲家** | **4+4+4+1**（4 组）| **13 张** |
| **全体起手合计（3 人）** | — | **40 张** 🔎（14 + 13 × 2）|
| **全体起手合计（2 人）** | — | **27 张** 🔎（14 + 13 × 1）|

### 6.3 发牌后余量（= 总张数 − 起手合计）

| 牌张构成 | 总张数 | 3 人余量 | 2 人余量 |
|---|---|---|---|
| **基准** | 84 张 | **44 张** | **57 张** |

> 余量即「牌堆剩余牌数」。本玩法**不展示牌墙**，仅展示剩余张数。杠后补牌时**牌堆额外减 1 张**。

### 6.4 发牌节奏与展示

- 所有玩家获取手牌的节奏**一致**。
- 己方手牌：按从左到右排列，出现时为**扣在桌面**上，随后**向上翻开**。
- 第一组开始向上翻开时，第二组朝下的牌出现，按同样节奏扣住后向上翻；后续按相同节奏进行直到 4 组牌全部翻开。
- **庄家**的最后两张，右侧的一张会与前 13 张**有距离**，放置在**摸牌位置**。
- 他人手牌：只有出现动画，出现后就**立起**，无翻开动画；庄家的最后一张同样放置在庄家的摸牌位置。
- 每组牌出现的时间，桌上**所有玩家同步**。

### 6.5 理牌

- 所有玩家发牌完毕后，**将手牌扣下整理好顺序后立起**（自动理牌）。
- 手牌排列顺序：从**左至右花色依次为 筒 → 条 → 中 → 发 → 白**；同花色内从左至右大小 1~9。
- 庄家摸进的最后一张牌受理牌影响，**固定置于最右侧且与一般手牌保持距离**。

### 6.6 手牌张数与方位对应

| 角色视角 | 手牌 |
|---|---|
| 庄家 | 14 张（最后一张置于最右侧且与手牌保持距离）|
| 闲家 | 13 张 |

## 七、行牌阶段

**行牌顺序**：**逆时针**。庄家先出牌，之后按逆时针轮转。

**一轮的循环**：

```
当前玩家出牌
    ↓
其余玩家可选操作（按优先级）：吃胡/自摸/抢杠胡 > 碰 / 杠
    ├─ 有人碰 / 杠 → 该玩家取得出牌权 → 继续循环
    └─ 无人操作 → 下家摸牌 → 出牌 → 继续循环
```

**摸牌与出牌的衔接**：**摸牌需在上一家打出牌的同时进行**——肉眼可见上家打出牌的瞬间下家摸牌。

**可执行的操作**：摸 · 打 · 碰 · 杠（直杠 / 明杠 / 暗杠）· 补 · 胡 · 过 · 亮倒 · 扣牌。

- **不能吃牌**。
- 每个操作的条件、后果与限制见 [打牌操作](03-打牌操作.md)。
- 亮倒 / 扣牌 / 危牌的机制见 [基础规则 §五](01-基础规则.md)。

## 八、结束判定

### 8.1 正常结束（有人胡牌）

**触发**：有玩家胡牌（自摸 / 点炮 / 抢杠胡 / 杠上花 / 杠上炮 / 海底捞 / 海底炮 / 一炮多响）。

**流程**：

1. 所有玩家**摊牌展示**（对家按真实视角倒着）；根据胡牌顺序在对应玩家面前展示胡牌。
2. 胡牌人以「胡 / 自摸」文字展示。
3. 桌面中间播放「对局结束」文字提示，约 1.3 秒，「对局结束」文字停留 0.5 秒。
4. 进入 §九 和牌后步骤。

### 8.2 荒庄（流局）

**触发**：**玩家可摸牌数 = 0**（牌堆摸完）仍无人胡牌。

**流程**：

1. 所有玩家**摊牌展示**。
2. 展示【荒庄】文字，持续 1.3 秒。
3. 随后判断有无未听牌玩家：

| 情况 | 后续 |
|---|---|
| **无未听牌玩家** | 直接出小结算 |
| **有未听牌玩家** | 所有未听牌玩家同时飘字【未听牌】；<br>· **查叫**（需勾选）：触发查叫时，未听牌文字出现的同时展示查叫的分数；<br>· **亮倒赔付**：如果触发亮倒赔付，则在查叫后，触发亮倒赔付的玩家展示【亮倒荒庄】文字并赔付，展示加分和扣分；<br>持续 1.3 秒后，出小结算界面 |

**荒庄结算口径**（查叫赔付公式、亮倒荒庄赔付、杠分不退还、不买马）见 [结算 §十二](06-结算.md)。

## 九、和牌后步骤（M6）

本玩法在和牌之后、结算之前有一个**附加计分步骤：买马**。

| 情况 | 流程 |
|---|---|
| **本局触发买马**（勾选「自摸买马」或「亮牌自摸买马」且满足触发条件）| 直接弹出买马界面，界面与牌同时出现，**中的马带金色边且亮起**，同时出现「中X马」的文字；持续 1.5 秒后界面关闭，直接打开小结算界面 |
| **本局未触发买马** | 胡牌动画结束后，直接弹出小结算 |

- 买马的触发条件、翻牌张数与计分规则见 [基础规则 §6.2](01-基础规则.md)。
- **荒庄不买马**。

## 十、结算与续局

### 10.1 小结算

对局结束后进入小结算界面。界面内容与文案规则见 [结算 §十五](06-结算.md) 与 [UI交互 §十四](09-UI交互.md)。

### 10.2 大结算

- **最后一小局**时，小结算底部按钮显示为【查看结算】，点击进入**大结算界面**（复用杭麻大结算）。
- 大结算的数据统计类型按卡五星类调整：

| 统计项 | 口径 |
|---|---|
| **自摸 X 次** | 记录玩家自摸次数 |
| **点炮 X 次** | 记录玩家点炮次数；**一炮多响只算一次**（一小局最多一次）|
| **亮倒** | 记录玩家亮倒次数 |
| **未听** | 记录玩家**荒庄流局时未听牌**的次数 |

- 战绩周报中，卡五星玩法统计的特殊游戏次数使用「**亮倒次数**」。

### 10.3 续局与轮庄

| 上一局结果 | 下一局庄家 |
|---|---|
| **单个玩家胡牌** | **胡牌玩家坐庄** |
| **一炮多响** | **点炮玩家坐庄** |
| **荒庄（流局）** | **上一局庄家继续坐庄**（连庄）|

- 轮庄规则**三变体一致**。
- **按逆时针轮庄**（庄家以外的方位依次递补）。
- 非最后一小局时，小结算底部按钮显示为【继续游戏】，点击后关闭小结算界面并准备下一局。

### 10.4 对局后桌面

复用杭麻：对局结束后桌面保持展示，玩家可查看牌桌信息。

### 10.5 退出

好友房退出、解散、特殊解散复用玄武 2.0 通用流程。
