## 一、三大类总览

### 1.1 结构分类

| 结构类 | 数学形式 | 牌型构成 | 包含番型 |
|---|---|---|---|
| **4 副面子 + 1 对将** | 4×3 + 1×2 = 14 | 4 副顺子 / 刻子 / 杠 + 1 对将牌 | F01 平胡、F02 碰碰胡、F07 小三元、F08 清一色、F09 手抓一、F10 大三元 |
| **七对（2N）** | 7×2 = 14 | 7 个对子（其中含四张相同者按「龙」计）| F06 七对、F11 龙七对、F12 三元七对、F13 双龙七对、F14 三龙七对 |
| **条件型**（附加在上述结构上）| — | 不独立构成结构，是在 4 副面子 / 七对结构上追加的听口或四归条件 | F03 卡五星、F04 明四归、F05 暗四归 |

> 📌 **本分类是编排手段，不是游戏规则**。需求 §2.3.3.1 的三分类（基础番型 / 加倍项 / 其他加分项）是**计分层级**分类；本表按**牌型结构**重分（4 副面子 / 七对 / 条件型）是为便于阅读与实现，**不改变任何判定与结算结果**，故**无需产品确认**。

### 1.2 判定流水线

```
【第 1 步】拆结构，取结构档位
   ① 能拆成 7 对（2N）？ 龙数 = 含四张相同的牌种数
        ├─ 3 种 → 七对维度：三龙七对（128 倍）
        ├─ 2 种 → 七对维度：双龙七对（32 倍） 
        ├─ 1 种 → 七对维度：龙七对（8 倍）
        └─ 0 种 → 七对维度：七对（4 倍） 七对结构内再判三元（见第 2 步）
 ② 能拆成 4 副面子 + 1 对将（3N+2）？
        ├─ 4 副全为刻子 / 杠（无顺子）→ 结构维度：碰碰胡（2 倍）
        └─ 含至少 1 副顺子           → 结构维度：平胡（1 倍）
   ③ ① 与 ② 同时成立时 → 两者【取分值较高者】（跨结构，见 §1.3） 都拆不出 → ❌ 不可胡

【第 2 步】叠加各维度（均按 §1.3，与第 1 步结果【相加】） 三元维度：中/发/白三刻（杠）各一 → 大三元（8 倍） 中/发/白两刻 + 一对 → 小三元（4 倍） 均不满足             → 不追加 注：七对结构侧另判「中/发/白对子各一 → 三元七对」 花色维度：全部牌同一门序数牌（全筒 或 全条）→ 清一色（4 倍） 注：清一色与三元维度【互斥】（三元必含字牌） 听口维度：胡的牌为 4-6 卡 5 形态 → 卡五星（2 倍） 手牌形态：其余牌全在碰杠区、手牌只剩一张单吊 → 手抓一（2 倍） 四归子维度：碰牌区 3 张 + 手牌 1 张（含胡的那张）→ 明四归（2 倍） 非碰杠牌区 4 张相同且可拆为「刻子 + 顺子」→ 暗四归（4 倍） 注：**清一色与明四归【互斥】**（需求明示，仅限明四归）；**七对类与明/暗四归【互斥】**；**清一色与暗四归可叠加**（🔎 需求只把互斥限定在「明四归」，未规定暗四归，故按「未规定即不互斥」推导）；四归各只计一次

【第 3 步】剔除互斥项（§1.3 表），其余求和 → 牌型分
【第 4 步】加倍项乘算（§五）→ 参与封顶截断；加分项加算（§六）→ 不受封顶 均见 [结算](06-结算.md)
```

> **「取高」与「相加」的分界**：第 1 步（结构 / 七对）是**取高**；第 2 步各维度与第 1 步结果是**相加**。例：
> - `碰[中中中]碰[发发发]碰[白白白] + 123筒 + 将 44筒` → 结构 = 平胡（有顺子）1 + 三元 = 大三元 8 = **9 倍**
> - `碰[中中中]碰[发发发]碰[白白白] + 111筒 + 将 99筒` → 结构 = 碰碰胡（全刻）2 + 大三元 8 = **10 倍**

### 1.3 全局叠加与互斥原则

**总口径：按「维度」分层——同一维度内取高，跨维度叠加。**

| 维度 | 内含番型（同维度**取高**）| 跨维度关系 |
|---|---|---|
| **结构维度** | 平胡（1）/ 碰碰胡（2）| 与以下各维度**叠加** |
| **花色维度** | 清一色（4）| 叠加（但与三元维度互斥，见下）|
| **三元维度** | 小三元（4）/ 大三元（8）| 叠加（但与清一色互斥）|
| **听口维度** | 卡五星（2）| 叠加 |
| **手牌形态维度** | 手抓一（2）| 叠加（需求明示「与碰碰胡叠加」）|
| **四归子维度** | 明四归（2）／暗四归（4）**各自独立** | 二者**可同时成立即叠加**（2+4=6）；同一子维度内无档位，故**不适用「取高」**；各自**只计一次** |
| **七对维度** | 七对（4）/ 龙七对（8）/ 双龙七对（32）/ 三龙七对（128）| **与结构维度取高**（见下）|
| **七对叠加项** | 三元七对（8）| 在**七对维度所取档位**上**叠加 ×2**，可与龙 / 双龙 / 三龙叠加（**不按取高处理**）。**需求明示** —— §2.3.3.1 番型表 #12 原注「**在七对的基础上\*2，可与龙、双龙、三龙叠加**」|

**为什么是「取高 + 叠加」而非全部相加**：需求表头写「基础番型可叠加」，但**碰碰胡明示为 2 倍**——若结构维度内也相加，则碰碰胡应为 平胡 1 + 碰碰胡 2 = 3 倍，与需求冲突。故「可叠加」指**跨维度叠加**，同维度内取高。

**跨结构（七对 vs 4 副面子）**：两者**可同时成立**——例如 `1111筒 2222筒 3333筒 44筒`（14 张）既可按 7 对拆（`11/11/22/22/33/33/44`），也可按 4 副面子拆（`111筒`+`222筒`+`333筒`+`123筒`，将 `44筒`）。此时**取分值较高者**（上例七对侧 = 三龙七对 128 + 清一色 4 = **132 倍**；面子侧 = 平胡 1 + 清一色 4 = **5 倍**——注意 `123筒` 是**顺子**，故结构档位为平胡而非碰碰胡；取七对侧）。

**需求明示的互斥**（写死的，不适用上述取高规则）：

| 互斥对 | 需求依据 |
|---|---|
| **清一色 × 明四归** | §2.2.2：「清一色与明四归互斥，同时触发时仅计算清一色」——**仅限明四归**；🔎 **清一色与暗四归不互斥，可叠加**（需求对该互斥**只限定了明四归**，未提暗四归；按「未规定即不互斥」推导）|
| **七对类 × 明四归 / 暗四归** | §2.2.2 / §2.3.3.1：七对类牌型不计四归 |
| **龙七对 / 三元七对 / 双龙七对 / 三龙七对 × 暗四归** | §2.3.3.1 逐条注明「与暗四归互斥」 |
| **三元七对 × 小三元 / 大三元** | §2.3.3.1 #12：「不会同时触发小三大三元」 |
| **清一色 × 三元类（小三元 / 大三元）** | 🔎 **推导**：三元必含中 / 发 / 白，清一色禁字牌，结构上不可能同时成立 |

**其他规则**：

| 原则 | 说明 |
|---|---|
| **四归各只计一次** | 明四归 / 暗四归 **各自**只计算一次（手中有多种符合条件的牌也不重复）；但**明、暗可同时成立并叠加**（注：**如 4 张同牌**拆出「碰区 3+手牌 1」与「非碰杠区刻+顺」两种形态时**不并存**，故实际极少同现）|
| **三元维度内取高** | 大三元覆盖小三元（不同时计）|
| **七对维度内取高** | 龙数递增取最高档（**三元七对不在其内**，它是七对维度之上的叠加项）|

> 🔎 **维度划分与「取高 + 叠加」口径为推导结论**：需求未明示完整的叠加 / 覆盖清单，仅给出表头「可叠加」与个别互斥注记。本口径是唯一能同时满足「碰碰胡 = 2 倍」「清一色 + 平胡可同计」两条需求事实的解释。

## 二、4 副面子 + 1 对将 类

> **结构公式**：`14 = 4 副 × 3 + 1 对 × 2`
> **1 副** = 顺子 或 刻子（杠）；**1 对** = 将牌。

### 2.1 平胡（F01 · 1 倍）

#### 2.1.1 判定条件

| 判定项 | ✅ 满足 → 继续 | ❌ 不满足 → 改判 |
|---|---|---|
| **4 副 + 1 对结构** | 14 张可拆为 4 副面子 + 1 对将 | 改看**七对维度**（按龙数取档：七对 4 / 龙七对 8 / 双龙七对 32 / 三龙七对 128 倍）|
| **含顺子** | 4 副面子中至少 1 副顺子 | 改判 **碰碰胡（2 倍）**——同属结构维度，**取高不叠加** |
| **非字牌全刻** | 不是中 / 发 / 白三刻或两刻 + 一对 | **追加** 大三元（8 倍）/ 小三元（4 倍）——三元维度，**与本番型叠加** |
| **非单一花色** | 不全是筒，也不全是条 | **追加** 清一色（4 倍）——花色维度，**与本番型叠加** |
| **非单吊手抓** | 手牌不止一张单吊 | **追加** 手抓一（2 倍）——手牌形态维度，**与结构档位叠加** |

#### 2.1.2 行牌依赖

| 行牌状态 | 影响 |
|---|---|
| 有吃 / 碰 / 杠 | 平胡**不要求门清**，可正常计 |
| 亮倒 | 亮倒为**加倍项**（J01 ×2），不影响平胡本身判定 |
| 手牌只剩单吊 | 改判 **手抓一** |

#### 2.1.3 互斥与升级

| 关系 | 对手番型 | 结果 |
|---|---|---|
| 平胡 → **取高** | **碰碰胡**（4 刻无顺）| 同属结构维度，取**碰碰胡（2 倍）**，**平胡不另计** |
| 平胡 ↔ **叠加** | **清一色**（全同花色）| 平胡 1 + 清一色 4 = **5 倍** |
| 平胡 ↔ **叠加** | **小三元 / 大三元** | 平胡 1 + 小三元 4 = 5 倍；平胡 1 + 大三元 8 = **9 倍** |
| 平胡 ↔ **叠加** | **手抓一**（2 倍）| 需求明示其与碰碰胡叠加；⚠ 但**平胡 + 手抓一 结构上不可达**——手抓一要求 4 副面子全在碰杠区，而本玩法**不能吃**，副露只能是碰/杠 → 不可能含顺子 → 平胡不成立 |
| 平胡 ↔ **叠加** | **卡五星**（听口维度）| **叠加**（见 §4.1）|
| 平胡 ↔ **叠加** | **明四归 / 暗四归**（四归子维度）| **叠加**（见 §4.2 / §4.3）；但清一色与明四归互斥 |
| 平胡 ↔ **取高** | **七对类** | 跨结构**取分值较高者**（见 §1.3）|

#### 2.1.4 判定流程

```
14 张能拆 4 副 + 1 对？
  ├─ 否 → 改看七对维度（按龙数取档）
  └─ 是 → 4 副全是刻子 / 杠（无顺子）？
        ├─ 是 → 结构档位 = 碰碰胡（2 倍）
        └─ 否 → 结构档位 = 平胡（1 倍） 再叠加（与结构档位【相加】）：
 · 中/发/白 三刻 → +大三元 8；两刻 + 一对 → +小三元 4
 · 全筒 或 全条 → +清一色 4（与三元维度互斥）
 · 其余牌全在碰杠区、手牌单吊 → +手抓一 2
 · 胡张为 4-6 卡 5 → +卡五星 2
 · 四归条件满足 → +明四归 2 / 暗四归 4
```

### 2.2 碰碰胡（F02 · 2 倍）

#### 2.2.2 行牌依赖

| 行牌状态 | 影响 |

### 2.3 小三元（F07 · 4 倍）

#### 2.3.1 判定条件

| 判定项 | ✅ 满足 → 继续 | ❌ 不满足 → 改判 |
|---|---|---|
| **中 / 发 / 白两刻** | 手牌 + 碰杠牌区有中 / 发 / 白**任意两种**的杠子或刻子 | 改判**平胡（1 倍）** / **碰碰胡（2 倍）** / **清一色（4 倍）** |
| **第三种为对子** | 剩余 1 种字牌为**对子**（作将）| 若为刻子 → 改判 **大三元（8 倍）**（同属三元维度，取高）；若无对子 → 无可将，不可胡 |
| **4 副 + 1 对结构** | 其余面子满足 4 副 + 1 对 | 改看**七对维度**取档（七对 4 / 龙七对 8 / 双龙七对 32 / 三龙七对 128 倍）|

#### 2.3.2 行牌依赖

| 行牌状态 | 影响 |
|---|---|
| 两刻来自碰 | 碰出的字牌刻子计入 |
| 两刻来自杠 | 杠子按刻子计三元 |
| 单吊第三种字牌 | 可与**手抓一**叠加 |

#### 2.3.3 互斥与升级

| 关系 | 对手番型 | 结果 |
|---|---|---|
| 小三元 ↔ **取高** | **大三元**（同属三元维度）| 取**大三元（8 倍）**，小三元不另计 |
| 小三元 ↔ **叠加** | **平胡 / 碰碰胡**（结构维度）| 小三元 4 + 平胡 1 = **5 倍**；小三元 4 + 碰碰胡 2 = **6 倍** |
| 小三元 ↔ **叠加** | **卡五星 / 手抓一 / 四归** | **叠加**（见 §4.1~§4.3、§2.6）|
| 小三元 ✕ **互斥** | **清一色**（花色维度）| **互斥**——三元必含中 / 发 / 白，清一色禁字牌 |
| 小三元 ↔ **取高** | **三元七对** | 两个**结构**取高（七对结构 vs 4 副面子结构）；故**不会同时触发小三元 / 大三元** |

#### 2.3.4 判定流程

```
有中/发/白两刻（杠）？
 ├─ 否 → 平胡 / 碰碰胡 / 清一色
  └─ 是 → 第三种字牌是对子？
        ├─ 否（为刻子）→ 大三元（8 倍）
        └─ 是 → ✅ 小三元（4 倍，与基础番型叠加）
```

#### 2.3.5 正反示例

|---|---|---|---|---|---|
| 1 | ✅ 正例 | 标准小三元 | 碰[`中中中`]碰[`发发发`]手牌 `123筒 456筒 白`｜和入 `白`| 中 / 发两刻 + 白作将 | **小三元 4 倍 + 平胡 1 倍** |
| 2 | ✅ 正例 | 边界：杠代刻 | 杠[`中中中中`]碰[`发发发`]手牌 `123筒 456筒 白`｜和入 `白`| 杠子按刻子计三元 | **小三元 4 倍 + 平胡 1 倍** |
| 3 | ❌ 反例 | 不足：第三种字牌非对子 | 碰[`中中中`]碰[`发发发`]手牌 `123筒 456筒 7筒`｜和入 `7筒`| 中 / 发两刻，但第三种字牌（白）未成对，将牌为序数牌 | **不计小三元**，改判 **平胡 1 倍** |
| 4 | ❌ 反例 | 取高：三刻为大三元 | 碰[`中中中`]碰[`发发发`]碰[`白白白`]｜手牌 `123筒 4筒`｜和入 `4筒` | 三种字牌均为刻子；含顺子（`123筒`）→ 结构档位为平胡 | **平胡 1 倍 + 大三元 8 倍 = 9 倍**（三元维度取高为 8，再与结构维度叠加）|
| 5 | ❌ 反例 | 不足：仅一刻 | 碰[`中中中`]｜手牌 `111条 333条 555条 9条`｜和入 `9条` | 只有中一种为刻子；4 副全刻 | **碰碰胡 2 倍**（不计小三元）|
| 6 | ❌ 反例 | 跨结构：三元七对 | `中中 发发 白白 11筒 33筒 55筒 7筒`｜自摸 `7筒` | 七对结构 + 三种字牌对子 | 改判 **三元七对 8 倍**（不是小三元）|

| 清一色 ↔ **叠加** | **卡五星 / 手抓一** | **叠加** |
| 清一色 ✕ **互斥** | **小三元 / 大三元**（三元维度）| **互斥**——三元必含字牌，清一色禁字牌 |
| 清一色 ↔ **叠加** | **暗四归**（四归子维度）| 🔎 **叠加**——需求 §2.2.2【暗四归】条**未规定与清一色互斥**（互斥只明示在明四归上）；全筒 + 暗四归 = 清一色 4 + 暗四归 4（另加结构档位）|
| 清一色 ✕ **互斥** | **明四归** | **同时触发时仅计算清一色**（需求明示，**仅限明四归**）；**明四归不计** ⇒ **平胡 1 倍 + 清一色 4 倍 = 5 倍**（见 §4.2.5 反例 4）|

```
 ├─ 否 → 平胡 / 碰碰胡 / 小三元 / 大三元
  └─ 是 → 4 副全刻？→ 清一色 + 碰碰胡 否则       → 清一色 + 平胡
          ✅ 清一色（4 倍）
```

## 三、七对类（2N）

> **结构公式**：`14 = 7 × 2`（含四张相同的牌时，该 4 张算作 2 对）
> **龙数** = 牌型中含**四张相同**的牌种数。

### 3.1 七对（F06 · 4 倍）

#### 3.1.1 判定条件

| 判定项 | ✅ 满足 → 继续 | ❌ 不满足 → 改判 |
|---|---|---|
| **7 对结构** | 14 张恰可拆为 7 组对子 | 改看**结构维度**（平胡 1 倍 / 碰碰胡 2 倍）|
| **无四张相同** | 龙数 = 0 | 改判 **龙七对（8 倍）** / **双龙七对（32 倍）** / **三龙七对（128 倍）** |
| **无三元对子** | 中 / 发 / 白对子未同时出现 | 改判 **三元七对（8 倍）** |
| **七对类不计四归** | 七对类**结构上无碰牌区**（明四归不可能成立）；暗四归虽同为 4 张同牌，但需求明示**与七对类互斥** | 四归不计，见 §1.3 |

#### 3.1.2 行牌依赖

| 行牌状态 | 影响 |
|---|---|
| **有碰 / 明杠** | ❌ 破坏七对（7 对要求 14 张全在手）|
| **有暗杠** | ❌ **同样破坏七对**——声明暗杠后，那 4 张即进入**杠牌区**，不再构成手牌中的两个对子（7 对要求 14 张**全在手牌**）。<br>注：**不声明暗杠**时，4 张同牌留在手牌中作两个对子 → 即**龙七对**（§3.2）。故「有暗杠」与「龙七对」互斥，前者一成立即非七对牌型 |
| **门清** | 需求未把门清列为七对的前置条件 |

#### 3.1.3 互斥与升级

| 关系 | 对手番型 | 结果 |
|---|---|---|
| 七对 ← 升级 | 龙七对 / 双龙七对 / 三龙七对 | 取龙数最高档 |
| 七对 ↔ **叠加** | **三元七对** | 七对 + 中发白对子各一 → **在七对档位上 ×2**（七对 4 × 2 = 8 倍），**非升级取代** |
| 七对 ↔ 叠加 | 三元七对 × 龙系列 | **三元七对可与龙 / 双龙 / 三龙叠加**（需求明示）。**叠加倍数 = 所取七对档位 × 2**（需求「在七对的基础上 ×2」直读，非推导）：<br>七对 4×2=**8** ／ 龙七对 8×2=**16** ／ 双龙七对 32×2=**64** ／ 三龙七对 128×2=**256** |
| 七对 ✕ 互斥 | **明四归 / 暗四归** | 七对类牌型**不计明四归、暗四归** |
| 七对 ↔ **取高** | **4 副面子类**（结构维度）| 两结构**可同时成立**，跨结构**取分值较高者**（见 §1.3）|
| 七对 ↔ **叠加** | **清一色**（花色维度）| 全筒 / 全条七对 = 七对 4 + 清一色 4 = **8 倍** |

#### 3.1.4 判定流程

```
14 张恰可拆 7 对？
  ├─ 否 → 4 副面子 + 1 对将结构
  └─ 是 → 统计龙数（四张相同的牌种数）
        ├─ 3 → 三龙七对（128 倍）
        ├─ 2 → 双龙七对（32 倍）
        ├─ 1 → 龙七对（8 倍）
        └─ 0 → ✅ 七对（4 倍） 叠加检查：中/发/白对子各一 → 追加三元七对（×2）
```

|---|---|---|---|---|---|
| 1 | ✅ 正例 | 标准七对 | `11筒 33筒 55筒 77筒 99筒 22条 4条`｜自摸 `4条` | 7 对；龙数 0；无三元对子 | **七对 4 倍** |

#### 3.5.6 配置状态说明

**三龙七对的倍数由「高分玩法」开关决定，两值不冲突**：

| 配置状态 | 倍数 | 取值来源 |
|---|---|---|
| **高分玩法 未勾选** | **128 倍** | 需求 §2.3.3.1「基础番型」表 |
| **高分玩法 已勾选** | **80 倍** | 需求 §3.1.1.1/2/3「高分玩法」条 |

**分析**：勾选「高分玩法」后七对系列变为 **8 / 20 / 40 / 80**，其中 **20 → 40 → 80 构成完整的 ×2 递进链**，80 是该链的必然取值；而基准表为 **4 / 8 / 32 / 128**（32 → 128 为 ×4 递进）。即「高分玩法」是**另一套档位表**，非基准表的等比放大，故不保证每档都 ≥ 基准值。

**需注意**：勾选「高分玩法」后七对系列其余三项均升档（4→8、8→20、32→40），唯**三龙七对为 80 倍、低于基础的 128 倍**。**非笔误** —— 高分档的七对系列为 **20→40→80** 的完整 ×2 链，80 是该链在三龙档的必然取值。文档按需求明示值 **80** 落地。

## 四、条件型

> 条件型番型**不独立构成牌型结构**，而是在 4 副面子 / 七对结构上追加的**听口条件**或**四归条件**。

### 4.1 卡五星（F03 · 2 倍）

#### 4.1.1 判定条件

| 判定项 | ✅ 满足 → 继续 | ❌ 不满足 → 改判 |
|---|---|---|
| **听口为 4-6 卡 5** | 胡牌时，和入的牌为**卡张形态**：手中有 4、6 且**二者为孤张**（即和入的 5 用于补成 `456` 顺子，**不是用作将牌**）| 不计卡五星 |
| **基础结构成立** | 同时满足平胡 / 碰碰胡 / 清一色等基础番型 | 无基础番型 → 不可胡 |

#### 4.1.2 行牌依赖

| 行牌状态 | 影响 |
|---|---|
| 和入张为 5 筒或 5 条，且手中有对应的 4、6 | ✅ 计卡五星 |
| 和入张为边张、两面、单钓形态 | ❌ 不计卡五星 |

#### 4.1.3 互斥与升级

| 关系 | 对手番型 | 结果 |
|---|---|---|
| 卡五星 ↔ 叠加 | 平胡 / 碰碰胡 / 清一色 / 手抓一 | 可叠加 |
| 卡五星 ↔ 叠加 | 加倍项 / 加分项 | 可叠加 |
| 卡五星 ← 创房 | 卡五星\*4 | 勾选后变 **4 倍** |

#### 4.1.4 判定流程

```
和入张为 5，且手中同花色有 4 和 6，且 4/6 为孤张（和入的 5 补成 456 顺子，非作将）？
  ├─ 否 → 不计卡五星
  └─ 是 → ✅ 卡五星（2 倍 / 勾选后 4 倍）
```

#### 4.1.5 正反示例

| # | 类型 | 场景 | 牌面 | 判定要点 | 结论 |
|---|---|---|---|---|---|
| 1 | ✅ 正例 | 标准 4-6 卡 5（筒）| 手牌 `123筒 456筒 789筒 22条 4筒 6筒`｜和入 `5筒` | 手中有 4筒、6筒，和入 5筒成 `456筒`；将 22条 | **平胡 1 倍 + 卡五星 2 倍 = 3 倍** |
| 2 | ✅ 正例 | 边界：条子 4-6 卡 5 | 手牌 `123条 456条 789条 22筒 4条 6条`｜和入 `5条` | 条、筒均可 | **平胡 1 倍 + 卡五星 2 倍 = 3 倍** |
| 3 | ❌ 反例 | 不足：两面听 | 手牌 `123筒 456筒 789筒 22条 3筒 4筒`｜和入 `2筒` | 和入张为 2筒，非卡 5 | **不计卡五星**，按平胡计 |
| 4 | ❌ 反例 | 不足：边张 | 手牌 `123筒 456筒 789筒 22条 8筒 9筒`｜和入 `7筒` | 和入张为 7筒，边张形态 | **平胡 1 倍**（不计卡五星）|
| 5 | ❌ 反例 | 不足：单钓 | 手牌 `123筒 456筒 789筒 456条 5条`｜和入 `5条` | 和入张构成**将牌**（`55条`），非卡张 | **平胡 1 倍**（不计卡五星）|
| 6 | ❌ 反例 | 不足：两面听 | 手牌 `123筒 456筒 789筒 34筒 55筒`｜和入 `2筒` | 和入 2筒 与 `34筒` 组成 `234筒` → **两面听**，非 4-6 卡 5；**全筒 → 清一色亦成立** | **平胡 1 倍 + 清一色 4 倍 = 5 倍**（不计卡五星）|

### 4.2 明四归（F04 · 2 倍）

#### 4.2.1 判定条件

| 判定项 | ✅ 满足 → 继续 | ❌ 不满足 → 改判 |
|---|---|---|
| **碰牌区 3 张** | 同一种牌在**碰牌区有 3 张** | 不计明四归 |
| **手牌 1 张（含胡的那张）** | 手牌中有同种牌 1 张，且**含胡的那张** | 不计明四归 |
| **频道 —— 全频道** | 手牌符合明四归结构即可计算 | — |
| **频道 —— 半频道** | **胡的那张牌必须是四归第四张**才计算 | 胡的牌不是第四张 → **不计明四归** |
| **仅计一次** | 哪怕手中有多种符合明四归的牌，**只计算一次** | — |
| **非清一色** | 未同时触发清一色 | **清一色与明四归互斥**：同时触发时**仅计清一色** |
| **非七对类** | 不是七对牌型 | **七对类与明四归互斥** |

#### 4.2.2 行牌依赖

| 行牌状态 | 影响 |
|---|---|
| 碰出 3 张后手牌持有第 4 张 | ✅ 是明四归的必要形态 |
| **杠**（明杠 / 直杠 / 暗杠）| 杠的 4 张在杠牌区，**不构成明四归**（明四归要求碰牌区 3 张 + 手牌 1 张）|

#### 4.2.3 互斥与升级

| 关系 | 对手番型 | 结果 |
|---|---|---|
| 明四归 ← 升级 | 暗四归 | 结构不同（碰区 vs 非碰杠区），不构成升级关系 |
| 明四归 ↔ 叠加 | 平胡 / 碰碰胡 / 卡五星 / 手抓一 | 可叠加 |
| 明四归 ✕ 互斥 | **清一色** | **同时触发仅计清一色** |
| 明四归 ✕ 互斥 | **七对类** | 七对类不计明四归 |

#### 4.2.4 判定流程

```
碰牌区有 3 张同种牌，且手牌有第 4 张（含胡的那张）？
  ├─ 否 → 不计明四归
                    ├─ 是 → ✅ 明四归
                    └─ 否 → ❌ 不计明四归 互斥检查：若同时满足清一色 → 仅计清一色 若同时为七对类 → 不计明四归
```

#### 4.2.5 正反示例

| # | 类型 | 场景 | 牌面 | 判定要点 | 结论 |
|---|---|---|---|---|---|
| 1 | ✅ 正例 | 全频道：胡的牌不是第四张也算 | 碰[`555筒`]手牌 `456筒 789筒 123条 9条`｜和入 `9条` | 碰区 3 张 5筒 + 手牌 1 张 5筒（在 `456筒` 中）；**全频道不要求胡的那张是第四张**；将 99条 | **平胡 1 倍 + 明四归 2 倍 = 3 倍** |

### 4.3 暗四归（F05 · 4 倍）

#### 4.3.1 判定条件

> **结构限制：采用 §2.2.2 的口径**——4 张相同牌必须能拆为「**刻子 + 顺子**」的组合；**双顺子 + 雀头不算**。
>
> **裁决依据**：需求 §2.2.2【暗四归】（名词解释）明确写出该限制，**并附具体反例**「手牌中有一对 7 条，以及两个包含 7 条的顺子，此时不算暗四归」——属细则条款；§2.3.3.1「基础番型」表 #5 仅写「非碰杠牌区有四张相同牌」，属摘要行文。**细则优于摘要**。且 §2.2.2 该条自带「（做成配置）」标注，说明此限制本身是可配置项。
> 📌 **标识名说明**：需求 §2.2.2 该条自带「（**做成配置**）」标注，说明「刻子 + 顺子」这一结构限制本身是可配置项；但三张创房表**均无**对应开关。本套文档以「**暗四归结构限制**」作为该项的**定位标识**，**系本套自拟、非需求原名**。**Step 5 已裁：按「可配置的规则层约束」登记，不自行虚构开关**。
>
> **关于括注「（刻子可以是碰的牌）」——本套文档不采该读法**。需求 §2.2.2 同条既写「**非碰杠牌区**有四张相同牌」（§2.3.3.1 表 #5 重复同一表述），又括注「刻子可以是碰的牌」，二者不相容：若刻子可取自碰杠区，则「碰牌区 3 张 + 手牌 1 张」既构成**明四归**又构成暗四归，两者无法区分。故按「**非碰杠牌区**」的 **2 处表述**（含番型表重复）为现行口径，该括注**不作现行规则**。✅ **Step 5 已裁**（见 [配置 §19.3.1](07-配置.md) R10）。

| 判定项 | ✅ 满足 → 继续 | ❌ 不满足 → 改判 |
|---|---|---|
| **非碰杠牌区 4 张相同** | 非碰杠牌区有 4 张相同牌（含胡的那张）| 不计暗四归 |
| **结构限制** | 4 张相同牌可拆为**刻子 + 顺子**的组合 ⚠️ 需求 §2.2.2 括注「（刻子可以是碰的牌）」与同条的「**非碰杠牌区**」存在表述张力；本套文档**采「4 张同牌全部不在碰杠区」**——否则将与明四归形态重合 | **双顺子 + 雀头不算** → 不计暗四归 |
| **频道 —— 全频道** | 胡牌牌型中存在符合四归结构即可计算 | — |
| **频道 —— 半频道** | **胡的那张牌必须是四归第四张**才计算 | 胡的牌不是第四张 → **不计暗四归** |
| **仅计一次** | 哪怕手中有多种符合暗四归的牌，**只计算一次** | — |
| **非七对类** | 不是七对牌型 | **七对类不计暗四归** |

#### 4.3.2 行牌依赖

| 行牌状态 | 影响 |
|---|---|
| 4 张全在手牌中（未碰未杠）| ✅ 构成暗四归的必要形态 |
| 有碰牌区 3 张 + 手牌 1 张 | ❌ 那是**明四归**，不是暗四归 |
| 有杠 | ❌ 杠的 4 张在杠牌区，不构成暗四归 |

#### 4.3.3 互斥与升级

| 关系 | 对手番型 | 结果 |
|---|---|---|
| 暗四归 ↔ 叠加 | 平胡 / 碰碰胡 / 卡五星 / 手抓一 | 可叠加 |
| 暗四归 ✕ 互斥 | **七对类**（含龙七对 / 三元七对 / 双龙七对 / 三龙七对）| 需求逐条明示「与暗四归互斥」 |

#### 4.3.4 判定流程

```
非碰杠牌区有 4 张相同牌（含胡的那张）？
  ├─ 否 → 不计暗四归
  └─ 是 → 结构限制：4 张能否拆为「刻子 + 顺子」？
        └─ 否（双顺子 + 雀头）→ ❌ 不计暗四归
                    ├─ 是 → ✅ 暗四归
                    └─ 否 → ❌ 不计暗四归 互斥检查：若为七对类 → 不计暗四归
```

#### 4.3.5 正反示例

| # | 类型 | 场景 | 牌面 | 判定要点 | 结论 |
|---|---|---|---|---|---|
| 1 | ✅ 正例 | 刻子 + 顺子 | 手牌 `777筒 567筒 888筒 123条 9条`｜和入 `9条` | 非碰杠区 7筒共 4 张（`777筒` 刻子 3 张 + `567筒` 顺子 1 张）；将 99条 | **平胡 1 倍 + 暗四归 4 倍 = 5 倍** |
| 2 | ✅ 正例 | 边界：4 张可拆为刻 + 顺（含清一色叠加）| 手牌 `777筒 123筒 456筒 789筒 9筒`｜和入 `9筒` | 非碰杠区 7筒 4 张（`777筒` 刻子 + `789筒` 顺子）；将 99筒；**全筒 → 清一色亦成立**（清一色**只与明四归互斥**，与暗四归可叠加）| **平胡 1 倍 + 清一色 4 倍 + 暗四归 4 倍 = 9 倍** |
| 3 | ❌ 反例 | 双顺子 + 雀头（结构限制不通过）| 手牌 `77筒 567筒 789筒 123条 23条`｜和入 `4条` | 7筒共 4 张，但只能拆为「`77筒` 雀头 + `567筒` + `789筒`」两个顺子，**不构成刻子 + 顺子** | **不计暗四归**（按 **平胡 1 倍** 计）|
| 4 | ❌ 反例 | 半频道：胡的不是第四张 | 手牌 `777筒 567筒 888筒 123条 9条`｜和入 `9条`（半频道）| 手牌确有 4 张 7筒，但胡的那张是 9条 | **平胡 1 倍**（不计暗四归）|
| 5 | ❌ 反例 | 互斥：七对类 | `1111筒 33筒 55筒 77筒 99筒 2条`｜自摸 `2条` | 七对类牌型 | **龙七对 8 倍**（不计暗四归）|
| 6 | ❌ 反例 | 不足：杠不构成暗四归 | 杠[`7777筒`]｜手牌 `123筒 456筒 234条 9条`｜和入 `9条` | 4 张 7筒**全在杠牌区**，非碰杠区无 4 张 | **平胡 1 倍**（不计暗四归）|

## 五、加倍项

> **加倍项在番型分上乘算，并参与封顶**。

### 5.1 亮倒（J01 · 2 倍）

| 项 | 规则 |
|---|---|
| **触发** | 玩家处于亮倒状态 |
| **计算** | **输 / 赢时均计算**，**番型分 ×2** |
| **不影响** | **不影响加分项**（漂 / 马 / 坎 / 杠分）|
| **对亮** | **输赢双方均亮倒（对亮），仅计算一次亮倒 ×2** |
| **互斥与升级** | 见 §5.2 对亮 |

### 5.2 对亮（J02 · 2 倍）

| 项 | 规则 |
|---|---|
| **勾选「对亮 \*2」** | 胡牌双方均亮倒 → 计算**两个**亮倒的倍数（**共 4 倍**）|
| **未勾选** | 双方均亮倒时**只计算一个**亮倒（**×2**）|
| **需求原文说明** | 「比未勾选时多一个」|

**倍率关系**：

```
未勾选对亮：亮倒 ×2（无论几方亮倒，只计一次）
勾选对亮： 亮倒 ×2 × 对亮 ×2 = ×4（胡牌双方均亮倒时）
```

### 5.3 杠上花 / 杠上炮（J03 / J04 · 各 2 倍）

| 项 | 杠上花 | 杠上炮 |
|---|---|---|
| **触发** | 杠牌后通过**补的牌**胡牌 | 杠牌后**打出的牌**让其他玩家胡牌 |
| **倍数** | **2 倍** | **2 倍** |
| **创房** | 勾选「杠上花/炮\*4」后变为 **4 倍** | 同左 |
| **生效条件** | **默认生效（2 倍）**；勾选「杠上花/炮\*4」后升为 **4 倍**。⚠ 需求并存矛盾：§2.3.1.2 明写「杠上开花倍数 \*2」（**无勾选前置**）与创房表「勾选后…**变为** 4 倍」（蕴含原值），但 §2.3.3.1「加倍项」表 #3/#4 另写「**勾选后生效**」——**采前者**（创房表用「变为」、§2.3.1.2 无前置）| 同左 |
| **与杠上杠的关系** | 触发时**倍数不跟随杠上杠翻倍，走初始值**（初始 2，可勾选为 4）| 同左 |

> 🔎 **「杠开是否与其他番型叠加」为本文档裁决**（需求该处仅留批注「杠开不与其他番型叠加？」未给答案）。**结论：叠加（乘算）**。依据：§2.3.3.1 把杠上花 / 杠上炮列在**「加倍项」表**（非「基础番型」表），加倍项的定义即「在牌型分上乘算」；§2.3.1.2 亦写「杠上开花倍数 \*2」。需求 §3.1.1.2「高分玩法」条上原挂的批注「杠开不与其他番型叠加？」针对的是**高分玩法**场景——该处把「**杠开卡五星 20 倍**」列为**独立合并档**（即高分玩法下「杠上开花 + 卡五星」按 20 倍合并计，而非 8 × 8 叠乘）；**基础玩法下仍按加倍项乘算**。详见 [结算 §4.2](06-结算.md)。

### 5.4 抢杠胡（J05 · 2 倍）

| 项 | 规则 |
|---|---|
| **触发** | 玩家**补杠**时，其他家胡这张补杠的牌 |
| **倍数** | **2 倍** |
| **多人** | **可多人抢杠胡一家** |
| **后果** | **抢杠胡后，明杠玩家视为未杠成功，不收取杠分，杠上杠也会中断** |
| **杠分冲销** | 因本玩法**杠分实时结算**（见 [基础规则 §4.1](01-基础规则.md)），「**视为未杠成功、不收取杠分**」在实现上即**已实时收取的该杠杠分需回退**（🔎 由「实时结算」+「视为未杠成功」两句合成推导）；杠上杠随之中断 |
| **坐庄归属** | 属**点炮类**（见上）→ 按 §2.3.5【轮庄】「**一炮多响时，点炮玩家坐庄**」，**多人抢杠胡时由补杠的那一家坐庄** |
| **与杠上杠** | 倍数**不跟随**杠上杠翻倍，**走初始值**（初始 **2**；勾选创房「杠上花/炮\*4」后为 **4** 🔎）|

### 5.5 海底捞 / 海底炮（J06 / J07 · 各 2 倍）

| 项 | 海底捞 | 海底炮 |
|---|---|---|
| **触发** | 玩家摸到**最后一张牌**后胡牌 | 玩家摸到最后一张牌后，**打出的牌**点炮胡 |
| **倍数** | **2 倍** | **2 倍** |
| **生效条件** | 勾选「海底捞/炮\*2」后**才会计算海底**，且为 2 倍 | 同左 |
| **本变体** | 勾选「海底捞/炮\*2」后生效 | 同左 |

### 5.6 上楼（J08 · 2 倍 / 4 倍）

| 触发条件 | 倍数 |
|---|---|
| ① 同一大局内，**上一小局荒庄或者一炮多响** | 本小局**倍数** **×2** |
| ② 本小局**开局打骰子时两个骰子点数一致** | 本小局**倍数** **×2** |
| ① 与 ② **同时触发** | **×4** |

- 1、2 的翻倍**可叠加，最高 4 倍**。
- **上楼为加倍项，不可突破封顶倍数**。
- 需创房勾选「上楼」才生效。
- 📌 **「倍数」的射程**：指**番型 × 加倍项**，**不含**马 / 漂 / 坎等**加分项**。**Step 5 裁决**：需求 §2.3.3.1「加倍项」表 #8 两处均写「本小局**倍数** X2」，而 §2.2.2【上楼】的「所有分数\*2」与同条「不可突破封顶倍数」不相容（若含加分项则与「加分项不参与封顶」冲突）→ **采加倍项表**。

## 六、其他加分项

> **加分项为额外加分，每一项单独计算，不与番型、加倍项进行乘算，且不受封顶影响（无上限）。**

### 6.1 漂分（A01）

```
胡牌玩家向某玩家收取的漂分 = （胡牌玩家漂数 + 该玩家漂数）× 底分
```

- **捉炮胡**：仅收取**点炮玩家**。
- **自摸胡**：收取**所有玩家**。
- **每个玩家单独计算**。
- **荒庄查叫时漂也赔**。

### 6.2 买马（A02）

按马数规则单独计算（买一 / 买一送一 / 买 5 马 / 买 6 马），**自摸收取所有玩家**。规则细节见 [基础规则 §6.2](01-基础规则.md)。

### 6.3 数坎（A03）

| 牌型 | 加分 |
|---|---|
| 每个**暗刻** | +1 倍底分 |
| 每个**明杠 / 直杠** | +1 倍底分 |
| 每个**暗杠** | +2 倍底分 |
| 手中**4 张一样**的牌 | +2 倍底分（必须是**顺 + 刻**，**不与暗刻重复计算**）|

**计算范围** = 自己的**手中** + **胡的那张** + **碰杠牌区**。

**收分对象** = 需付胡牌分的玩家：点炮胡收**放炮玩家**；自摸胡收**其他所有玩家**。

| 口径 | 说明 |
|---|---|
| **必须是刻子** | 仅是 3 张相同牌但不成刻的**不算** |
| **胡的那张牌** | **自摸才参与计算，捉炮不参与** |
| **查叫时** | **也计算坎分**；但因为没有胡，**不计算胡的那张牌**；**听双碰时会生效** |

> 详细规则见 [基础规则 §6.3](01-基础规则.md)。

### 6.4 杠分（A07）

杠分的计算与收分方向见 [打牌操作 §五](03-打牌操作.md)。**杠分实时结算**，小局结束时不额外再算。

## 八、番型 ID 与判胡顺序

### 8.1 判定层次

```
① 拆结构：七对 / 4 副面子 + 1 对将；两者可同时成立时**取分值较高者**（见 §1.3）
② 结构内取高：**七对维度按龙数取档**；**4 副面子结构下小三元→大三元取高**
③ 叠加各维度番型（均按 §1.3，与①②结果**相加**）：
 · 三元维度（小三元 / 大三元）
    · 花色维度（清一色）
    · 听口维度（卡五星）
    · 手牌形态维度（手抓一）
 · 四归子维度（明四归 / 暗四归，各自独立可叠加）
 · **七对结构下另叠加三元七对 ×2**（可与龙 / 双龙 / 三龙叠加，**不按取高处理**）
④ 处理互斥（清一色 × 明四归 / 三元类；七对类 × 四归；三元七对 × 小三元 / 大三元）
⑤ 各维度求和 → 牌型分
⑥ 加倍项乘算 → 参与封顶截断（**例外**：高分玩法下「杠开卡五星」按 20 倍合并档，不叠乘）
⑦ 加分项加算 → 不受封顶
```
