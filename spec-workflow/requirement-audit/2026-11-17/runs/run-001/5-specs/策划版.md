# 杭州麻将好友房 — 规则说明（策划版）

本文把需求文档里的每条规则，翻译成玩家能看懂的说法，并逐条对照「需求要求什么 / 实际是什么」，供策划与运营阅读和验收使用。

本次共覆盖 416 条规则，分布在 23 个玩法阶段。绝大多数规则目前还没有在真实对局里核对过，因此本文更直接的用途，是一份可以拿去开局验收的清单。

结论标签的含义：

- 已验证：规则与游戏表现一致。
- 规则待验证：还缺证据确认，需要在实际对局或创房界面里看一眼。
- 待策划裁决：规则与游戏表现不一致，需要决定改规则还是改实现。
- 不适用：该规则在本玩法中不生效。
- 查证未完成：还没查完，暂时无法判断。
